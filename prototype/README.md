# 나작지 프로토타입 (브라우저)

`index.html`을 브라우저로 열면 바로 돌아갑니다 (설치 필요 없음).

- 무엇을 확인하나: **"5분 동안 아무것도 안 해도 보는 게 재밌는가"** + 주민 행동 명세(`docs/RESIDENT_AI.md`)의 규칙이 실제로 굴러가는가
- 들어 있는 것: 평평한 둥근 대지, 첫 정착민 10명, 하늘 낟알(첫 수확 전까지), 오두막·농장·나무꾼·산림관·채석장·제재소·우물(개척기) + 방앗간·빵집·목조주택(마을), 짐 나르기·건설·혼인·출산·노화·사망, 촌장의 자율 건설, 거인의 톡·물 뿌리기(기적)·계시, 주민마다 다른 믿음(부재 시 아이부터 의심 → 귀환 축제), 지형의 높낮이와 살아 있는 물길(64×64 높이 지도 · 물은 낮은 곳으로 흘러 고이면 호수 · 물방울 돌기 2곳과 유리벽의 골 5곳에서만 물이 들어옴 · 증발·스며듦 · 물이 안 들어오는 서쪽 큰 호수는 약 9일에 걸쳐 말라 소금 들판이 됨 · 병 돌리기(빛은 그대로, 그늘이 바뀌어 강 물줄기 변화) · 소금(마른 호수 바닥에 남고 물과 함께 흐름, 소금밭·절임·염해) · 창가 쪽 늘 따뜻함 · 자리별 농사 배율), 창가 쪽 늘 따뜻함, 자리별 농사 배율), 자리 비우기(오프라인 몰아서 계산), 연대기, 오솔길
- 조작: 드래그 = 둘러보기 · 두 손가락/휠 = 확대 · 사람 누르기 = 정보 · [건설] → 고르고 땅 누르기 · [×60] 누르면 속도 바뀜 (×1 / ×10 / ×60 / ×600)
- 수정: `app.html`을 고친 뒤 `python3 tools/build_prototype.py` 로 `index.html`을 다시 만듭니다.
- 빠진 것: 도로망·짐꾼 릴레이, 도구 제작, 광업, 기후대, 종이배·상점·선반, 사운드
