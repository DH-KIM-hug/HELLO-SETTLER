# 촌장의 결정 (Mayor's Decisions)

> **Status**: Designed (사용자 결정 반영, 2026-11-07 — `/design-review`는 새 세션에서)
> **Author**: 사용자 + 메인 세션 + systems-designer
> **Last Updated**: 2026-11-07

> **Implements Pillar**: 1 스스로 살고 나를 알아보는 사람들 · 2 보는 것이 곧 재미 · 3 작은 세상의 실감

## Summary

촌장의 결정은 마을에서 가장 나이 많은 어른이 **다음에 무엇을, 어디에 지을지, 누가 어디서 일할지**를 15분마다 고르는 계통이다. 거인은 터를 정하지 않는다. 주민은 이 결정을 숫자가 아닌 **터에 박히는 말뚝, 돌을 나르는 줄, 촌장의 한마디**로 보여 준다.

> **Quick reference** — Layer: `Gameplay` · Priority: `MVP` (최소판) · Key deps: `건물(13), 경제(16), 필요와 기분(10)` · 담당 파일: `sim/mayor.gd` (`Village.chief_build`와 일자리 배정을 옮겨 옴)

**최소판의 범위**: 누가 촌장인가 · 무엇을 먼저 지을까(우선순위 표) · 어디에 지을까 · 누가 어디서 일할까 · 자재가 막히면. 막힌 곳을 보고 고르는 영리한 판단은 MVP 밖(VS).

**사용자 결정 (2026-11-07)**:
1. **촌장 = 가장 나이 많은 어른**, 나이가 같으면 id가 작은 쪽 (R1).
2. **거인은 결과만 본다**: 말뚝·나르는 줄·연대기 한 줄·"자재가 모자라 고민해요" 쪽지(#26). 촌장 수첩·계획 미리보기·거인의 지시(밀어 넣기)는 없다.
3. **굶주림이 먼저**: 굶주리는 마을에서는 먹을 것 사슬이 집보다 앞선다 (F2의 5가 6보다 위).
4. **꽃 그늘 자리 고르기는 MVP에서 끔**: `SHADE_W = 0` 손잡이만 둔다 (시뮬에 그늘 자료가 아직 없음 — 꽃숲·렌더링 일과 함께 켬).
5. **나무 없는 세상**: 건물·자원 이름과 숫자(나무꾼·제재소·판자)는 그대로, 모양과 말맛만 바꾼다. 판자는 쪼갠 갈대 줄기로 보이고, 나무꾼은 나무 대신 **갈대·꽃대 무리**에서 일한다. 나무꾼 자리 찾기도 그 무리를 향한다 (모양·말맛은 건물 #13·그림 몫).

## Overview

- **촌장 = 가장 나이 많은 어른** (사용자 확정). 죽거나 없으면 다음 어른이 이어받는다.
- 15분(병 시간)마다 **한 번 살피고, 지을 것 하나를 고른다.** 짓는 중인 터가 2곳이면 쉰다 (들어준 소원은 3곳).
- **고르는 순서는 한 줄 표**다 (F2). 위에서부터 처음 맞는 것이 이긴다. 굶주림과 집 없음이 겹치면 **먹을 것이 먼저**다 (사용자 확정).
- **터는 주민이 고른다.** 거인은 맨 처음 스타터킷만 놓는다. 상점에서 내려 준 설계도도 터는 촌장이 정한다.
- **누가 일하는지**는 일터마다 `숙련 × 2 − 집에서 거리 × 0.25` 점수로 고른다. 먹을 것 일터부터 채운다.
- **아기 부모는 쉰다.** 이 규칙은 생산 계통(`caring_for`)이 정하고, 촌장은 비는 자리를 채우기만 한다.
- **거인이 보는지는 이 계통의 규칙에 들어가지 않는다** (ADR-0001 3절). 같은 씨앗이면 연출을 켜든 끄든 같은 결정이다.
- 결정은 `events.emit`으로만 밖에 알린다. 난수는 마을의 `rng`만 쓰고 순서를 고정한다.

## Player Fantasy

**"촌장이 저기에 말뚝을 박네. 다들 돌을 지고 모이는구나."** 거인은 계획서를 읽지 않는다. 촌장이 모닥불 곁에서 팔을 휘두르며 한마디 하면 어른들이 일어나 터로 간다. 굶는 마을에서는 촌장이 집 대신 밭부터 가리킨다. 자재가 막히면 촌장이 머리를 긁적이다 채석장 쪽으로 걸어간다. 거인은 **"저 사람들이 알아서 하는구나. 내가 낟알 한 줌만 주면 되겠네"** 하고 안심한다 (기둥 1·2).

- **"내 마을"이 아니라 "저 사람들의 마을"**: 터는 늘 주민 취향(모닥불 둘레, 볕 좋은 곳)에 앉는다.
- **내 손길이 이어진다**: 들어준 소원, ~~거인님이~~ 마을이 '{w:이/가} 좋아하신다'고 믿는 물건 (2026-11-12 STORY 4 규칙에 맞춤 — Q24 2차), 설계도가 우선순위를 밀어 올린다 — "내가 한 일이 마을에 남았다".

## Detailed Design

### Core Rules

**R1. 촌장 정하기** (사용자 확정)
1. 촌장 = 나이가 가장 많은 어른 (`age >= AGE_ADULT`). **나이가 같으면 id가 작은 쪽** (지금은 목록 순서 — 변경, 결정성).
2. 촌장이 바뀌면 `mayor_changed`를 내고 연대기에 "촌장 ○○이(가) 마을을 이끌게 되었다" 한 줄. 어른이 없으면 촌장 없음 → 이 계통은 쉰다.
3. 촌장은 분가·탐험에서 '남는 사람' 규칙을 따른다 (#37). 이 계통은 촌장을 마을 밖으로 보내지 않는다.

**R2. 살피기 시간**
1. `CHIEF_EVERY`(900초)마다 한 번 `Mayor.round(v)`. 첫 한 시간은 `OPENING_CHIEF_AT`(3분·4분30초)에 먼저 두 번.
2. 깨닫는 순간, 설계도가 떨어진 순간, 들어준 소원이 생긴 순간에는 **기다리지 않고 바로 한 번** 살핀다 (설계도는 지금도 그렇다).

**R3. 한 번의 살핌**
1. 사람이 0명이거나 어른이 0명이면 쉰다.
2. 짓는 중인 터가 `PENDING_MAX`(2) 이상이면 쉰다. 들어준 소원이 있으면 3. **굶주리는 마을(`starving_village()`)에서는 먹을 것 터가 아닌 새 터는 열지 않는다** (변경).
3. F2 순서에서 처음 맞는 `want`를 정한다.
4. `want`가 집이면 시대 집으로 바꾼다. 땅이 한계면 작은 옛 집을 넓혀 짓는다. 자재가 모자라면 오두막.
5. 자재가 모자라면 **자재 일터부터** 짓는다 (R6).
6. 일터 건물은 **직장 없는 어른이 2명 이상**일 때만 새로 짓는다. 예외: 먹을 것 일터(밭·맷돌·화덕), 들어준 소원.
7. 터(F4)를 못 찾으면 쉰다. 이 라운드는 '막힘'으로 센다 (R6).

**R4. 깨달음 뒤 제단 (변경)**
1. 깨달은 직후 촌장이 **~~"하늘의 분께 드릴 자리를 만들자"~~ → "{w}께 드릴 자리를 만들자"** (`awakening.gd` LINE_CHIEF, 2026-11-12 STORY 4 규칙에 맞춤 — Q24 2차)라고 말하고 제단 터를 모닥불 곁에 정한다. 지금은 `awakening.gd`가 건물을 직접 넣는다. 최소판은 이것을 `Mayor.place_altar(v)` 한 곳으로 옮긴다 (결과는 같다).
2. 제단은 `wished = true`, **우선순위 맨 위**, 소원 칸을 쓰지 않는다. 짓는 중인 터 상한에는 센다.
3. 깨닫기 전에는 제단·하늘의 분 이야기가 없다 (F2의 0번 칸은 깨닫기 전에는 건너뜀).

**R5. 일자리 배정 (20초마다)**
1. 일터를 `JOB_FIRST` 순으로 훑는다 (밭 0 → 화덕·빵집 1 → 맷돌간·방앗간 2 → … → 50).
2. 빈 일터마다 후보 중 F5 점수가 가장 높은 어른을 넣는다. 도구가 없으면 넣지 않는다.
3. **후보에서 빠지는 사람**: 아이, 일이 있는 사람, **아기를 돌보는 부모** (`Production.caring_for`가 null이 아님).
4. 아기를 돌보게 된 부모는 일터를 내놓고 도구는 창고로 돌아간다. 비는 일터는 다음 20초에 다른 사람이 채운다.
5. **먹을 것 일터(`JOB_FIRST < 10`)가 비었는데 놀고 있는 어른이 없으면** 가장 덜 급한 일터의 사람을 옮겨 온다 (`_job_swap`). 굶주리는 마을에서는 **방금 옮긴 일터에서 한 번 더 빼지 않는다** (연쇄 이동 막기, 변경).
6. 일을 시작하면 말풍선 "오늘부터 ○○에서 일해요" (5초).

**R6. 막혔을 때 (비상)**
1. 판자·돌이 모자라 `want`를 못 지으면 자재 일터를 짓는다: 판자 쪽이 모자라면 제재소, 아니면 채석장.
2. 그것도 못 지으면(자재가 둘 다 바닥) **막힘 라운드**를 센다. 연속 `STUCK_ROUNDS`(2)번이면 `build_stuck`을 내고, 다음 라운드부터 **비상 예비 판자 `PLANK_RESERVE`(4)를 풀어 나무꾼·제재소·채석장 중 가장 싼 것 하나**를 짓는다 (변경: 지금은 조용히 멈춘다).
3. 막힘이 풀리면(`want`를 지음) 센 값을 0으로 되돌린다.
4. 거인에게는 안내(#26)가 `build_stuck`을 받아 "촌장이 자재가 모자라 고민해요" 쪽지를 쓴다. 숫자는 없다.

**R7. 나무 없는 세상의 자재 일터** (사용자 확정)
1. 이름과 숫자는 그대로: 나무꾼 → 통나무, 제재소 → 판자, 산림관. 판자는 **쪼갠 갈대 줄기·납작 껍질**로 보인다 (GD 3.0).
2. 나무꾼·산림관은 나무 대신 **갈대·꽃대 무리**에서 일한다. 자리 찾기(F4)도 가장 가까운 갈대·꽃대 무리를 향한다. 큰 나무 다섯은 베지 않는다 (`GreatTrees.blocks`).
3. 모양·말맛(연대기 문장, 모델)은 건물 #13과 그림 몫. 이 계통은 '어디를 향하는가'만 바꾼다.

### States and Transitions

| 상태 | 들어올 때 | 하는 일 | 나갈 때 |
|---|---|---|---|
| 쉼 | 라운드 끝, 터 상한, 어른 없음 | 아무것도 안 함 | 다음 라운드, 또는 R2.2의 즉시 살핌 |
| 살핌 | 라운드 시작 | F2 위에서 아래로 훑음 | `want` 정함 / 없음 |
| 터 잡음 | `want`·터·자재가 다 맞음 | 건물 터 추가, `site_chosen` | 쉼 |
| 넓힘 | `upgrade` 대상이 있음 | 옛 건물을 개축 터로 | 쉼 |
| 막힘 | 자재 부족 + 자재 일터도 불가 | `stuck` +1 | 풀림 또는 비상 (R6.2) |

촌장이 죽거나 사라지면 **쉼**에서 다음 어른으로 이어진다 (R1).

## Formulas

**F1. 촌장** `mayor = argmax_{p: age ≥ AGE_ADULT} (age_p, −id_p)`

| Symbol | Type | Range | Description |
|---|---|---|---|
| age_p | float | 0~수명 | 주민 나이 (날) |
| id_p | int | ≥0 | 주민 번호 (같은 나이일 때 작은 쪽 우선) |
| mayor | Resident 또는 없음 | — | 어른이 없으면 없음 |

출력: 언제나 0명 또는 1명. 예: 어른 나이 {5.1, 7.9, 7.9}, id {3, 5, 2} → 7.9 둘 중 id 2.

**F3. 먹을 것 모자람** (지금 코드 그대로)
```
need_h     = pop × (3600 / FOOD_IV) × FARM_SAFETY
food_low   = food_total < BIRTH_FOOD_DAYS × day_need
food_short = (fr < need_h) OR (food_low AND fr < need_h × 1.5)
```

| Symbol | Type | Range | Description |
|---|---|---|---|
| pop | int | ≥0 | 인구 |
| fr | float | ≥0 | 시간당 먹을 것 어림 (`food_rate()`) |
| FOOD_IV | float | 900 | 한 사람이 식량 1을 먹는 간격 (초) |
| FARM_SAFETY | float | 1.3 | 안전 여유 |
| BIRTH_FOOD_DAYS | float | 1.25 | 창고가 이 날수 아래면 모자란 편 |
| food_short | bool | — | 참이면 밭을 먼저 |

출력: 참/거짓. 예 (임시 값): pop 10 → need_h = 10 × 4 × 1.3 = 52. fr = 60, food_low 참 → 60 < 52 거짓, 60 < 78 참 → 모자람.

**F4. 터 고르기** (지금 코드 + 변경 ※)
```
점수(p) = base(p) + SHADE_W × shade(p)                 ※ SHADE_W = 0 (MVP, 사용자 확정)
후보 = 계획(VillagePlan) 자리 → 없으면 나선: 반지름 2.0, 2.8, … < territory_r, 24방향
나선 중심 c = 마을 중심, 또는 자원 쪽 (채석장 = 바위, 버섯꾼 = 큰 버섯,
             나무꾼·산림관 = 가장 가까운 갈대·꽃대 무리 ※ — 지금은 나무)
일터의 중심 c' = c + HOME_PULL × (집 중심 − c)          ※ HOME_PULL = 0
```

| Symbol | Type | Range | Description |
|---|---|---|---|
| base(p) | float | 밭: `farm_mult(p) − 0.02·d`, 나머지: 먼저 찾은 빈 자리 | 지금 코드의 자리 점수 |
| shade(p) | float | 0~1 | 꽃 그늘 정도 (시뮬에 자료가 아직 없음) |
| SHADE_W | float | 0~0.5 | 그늘 가중. 0이면 지금과 같음 |
| HOME_PULL | float | 0~0.5 | 일터를 집 쪽으로 당김. 0이면 지금과 같음 |
| c, c' | Vector2 | 영역 안 | 나선 탐색의 중심 |
| p | Vector2 | 영역 안 | 고른 자리 |

출력: 자리 하나 또는 없음 (영역이 가득 차면 없음 → 막힘). `is_free`(영역·물·건물 간격·모닥불·제단·바위·큰 버섯·큰길·큰 나무)를 모두 통과해야 한다. 가장 나쁠 때 `(territory_r − 2) / 0.8 × 24`번 `is_free`를 묻는다. 예: 밭 후보 A `farm_mult 1.1, d 6` → 1.1 − 0.12 = 0.98, 후보 B `farm_mult 1.3, d 14` → 1.3 − 0.28 = 1.02 → B.

**F5. 일꾼 점수**
```
score(p, b) = skill_p(b.type) × 2 − dist(home_p, b) × 0.25 × k_p
k_p = 1.5 (p가 굶주림) ※, 아니면 1
```

| Symbol | Type | Range | Description |
|---|---|---|---|
| skill_p | float | 0~1 (코드에서 확인) | 그 일터 종류의 숙련 |
| dist | float | 0~영역 지름 | 집(없으면 지금 자리)에서 일터까지 |
| k_p | float | 1 또는 1.5 | 굶주린 사람의 먼 길 벌점 (새 규칙 — 걸음 ×0.9 고리를 키우지 않게) |
| score | float | 약 −(영역 지름 × 0.375) ~ 2 | 높을수록 먼저 |

출력: 후보 중 가장 높은 사람. 후보가 없으면 `_job_swap`. 예: 숙련 0.6·거리 8 → 1.2 − 2.0 = −0.8, 숙련 0.2·거리 1 → 0.4 − 0.25 = 0.15 → 뒤쪽이 이김 (걸음이 느려 가까운 일터가 이득).

**F6. 자재 여유**
```
affordable(t) = (판자 − owed판자 − cost_t판자 ≥ reserve_t) ∧ (돌 − owed돌 − cost_t돌 ≥ 0)
reserve_t = 0 (나무꾼·제재소), 아니면 PLANK_RESERVE (4)
```

| Symbol | Type | Range | Description |
|---|---|---|---|
| 판자·돌 | float | ≥0 | 창고에 있는 양 |
| owed | int | ≥0 | 짓는 중인 터에 아직 줄 몫 |
| cost_t | int | ≥0 | 건물 t의 자재 |
| reserve_t | int | 0 또는 4 | 비상 예비 |

출력: 참/거짓. 예: 판자 9, owed 3, 집 비용 3 → 9 − 3 − 3 = 3 < 4 → 못 지음 → 제재소부터. 비상(R6.2)에서는 reserve를 0으로 풀되 가장 싼 자재 일터 하나만.

**F7. 밭이 먹이는 수 (밭을 더 지을지)**
```
feeds = farms × FARM_FEEDS × yld / PORRIDGE_YIELD
밭 하나 더 = feeds < pop + 6
```

| Symbol | Type | Range | Description |
|---|---|---|---|
| farms | int | ≥0 | 밭 수 |
| FARM_FEEDS | float | 6 | 밭 하나가 죽으로 먹이는 사람 |
| yld | float | 0.75 (죽) 또는 1.5 (빵) | 빵을 굽고 있으면 빵 값 |
| PORRIDGE_YIELD | float | 0.75 | 죽 값 |
| feeds | float | ≥0 | 밭들이 먹이는 사람 수 |

출력: 참/거짓. 예: 밭 2, pop 14 → 기준 14 + 6 = 20. 빵을 구우면 feeds = 2 × 6 × 1.5 / 0.75 = 24 → 24 < 20 거짓 → 더 안 지음. 죽뿐이면 feeds = 2 × 6 × 0.75 / 0.75 = 12 → 12 < 20 참 → 밭 하나 더.

## Edge Cases

1. **촌장이 자고 있음**: 터는 정한다. 말풍선·말은 깨어 있을 때만.
2. **터 상한과 제단**: 제단이 있으면 일반 터는 1곳뿐. 굶주림이면 밭이 그 칸을 먼저 쓴다. 제단이 먼저인 것은 의도.
3. **어른이 모두 아기 돌봄**: 직장 없는 어른이 0이라 일터는 새로 안 짓는다. 먹을 것 일터는 지을 수 있지만 일꾼이 없다. 부모는 먹을 것이 하루치 아래면 먼저 일터로 (생산 계통).
4. **집 없는 어른이 많은데 굶주림**: 먹을 것이 먼저 (F2의 5). 집은 굶주림이 끝난 뒤.
5. **터가 없음(영역 가득)**: 집은 옛 집 넓힘, 그 밖에는 쉼 + 막힘을 센다.
6. **첫 한 시간**: `in_opening`에서는 부모도 일터에 있다 (`caring_for`가 null).
7. **개축 중인 건물**: 다 지은 건물이 아니라 R5가 일꾼을 넣지 않는다.
8. **따라잡기**: 라운드 타이머는 병 시간으로 그대로 돌고, 빠른 길은 20초 배정을 180초로 늘린다. 연대기의 건물 순서가 같아야 한다 (AC13).
9. **저장·불러오기**: 새 값 `stuck`(정수), `last_mayor_id`. 옛 저장에 없으면 0과 −1.
10. **같은 라운드에 촌장이 바뀜**: `mayor_changed`를 낸 뒤 새 촌장이 바로 `site_chosen`을 낼 수 있다.
11. **들어준 소원이 시대 때문에 못 지음**: `_wish_now`가 비어 다음 칸으로.
12. **설계도로 받은 건물**: 설계도는 '지을 줄 앎'일 뿐 자재를 면제하지 않는다.
13. **갈대·꽃대 무리가 없음**: 나무꾼 자리 중심은 마을 중심으로 돌아간다 (지금 나무가 없을 때와 같음).

## Visual/Audio Requirements

기둥 2: 촌장의 결정은 **행동**으로 보인다. 주민 쪽 화면에 숫자 없음.
- **터 잡음**: 촌장이 모닥불 곁에서 터를 가리키고, 터에 풀대 말뚝 넷이 박힌다. 어른들이 돌·갈대를 지고 모인다.
- **제단 터**: 촌장이 모닥불 곁에서 하늘을 올려다보며 말한다 (깨달은 뒤에만).
- **굶주림 모드**: 촌장이 집 터 대신 밭 쪽을 가리킨다.
- **막힘**: 촌장이 채석장·자재 쪽을 한참 바라본다. 말풍선은 그림 하나 (돌).
- **일 시작**: 말풍선 "오늘부터 ○○에서 일해요" (5초).
- **나무꾼**: 갈대·꽃대 무리에서 줄기를 베어 묶는다 (모델·동작은 #13·그림 몫).
- 소리: 말뚝 박는 소리 하나. 새 촌장은 연대기만. 새 소리는 만들지 않고 기존 건설 소리를 쓴다.

## Game Feel

- **알아챔**: 터가 정해지면 현실 몇 초 안에 말뚝이 보이고 어른이 움직인다.
- **자율**: 거인이 아무것도 안 해도 마을은 집·밭·우물을 스스로 늘린다. 터를 잡는 사이는 현실 몇 초~1분이 알맞다 (CHIEF_EVERY 재측정, Open Questions 1).
- **무게**: 한 번에 터 두 곳을 넘지 않아 "바쁘지만 무너지지 않는다".
- **굶주림 때 촌장이 밭부터**: 거인이 "알아서 먹을 것부터 챙기네"를 느낀다.

## UI Requirements

**거인은 결과만 본다** (사용자 확정). 촌장 수첩·계획 미리보기·다음에 지을 것 목록·거인이 지시하는 단추는 **없다**.
- 사람 목록: 촌장에게 **"촌장 ○○"** 표시, '지금 하는 일' 줄에 **"터 잡는 중 (집)"** 같은 한 줄 (숫자 없음).
- 화면: 터의 말뚝, 자재를 나르는 줄 (Visual 참고).
- 연대기: "촌장 ○○이 (건물) 자리를 정했다" (지금 `log_line`과 같은 문장).
- 안내(#26): `build_stuck`을 받으면 수첩 쪽지 **"촌장이 자재가 모자라 고민해요"** (반나절에 한 번까지).
- 주민의 말과 연대기에는 쓰지 않는 말(게임·앱·플레이어·키트·구매)을 지킨다.

## Acceptance Criteria

모두 헤드리스 (묶음 `mayor`, AC16은 느린 묶음).
1. **촌장 고르기**: Given 어른 나이 {5.1, 7.9, 7.9}, id {3, 5, 2} · Then 촌장 id 2. 촌장이 죽으면 다음 어른, `mayor_changed` 1번.
2. **터 상한**: Given 짓는 중 2곳 · When 라운드 · Then 새 터 0. 들어준 소원이 있으면 셋째 터 1.
3. **순서**: Given 첫 집 있음, 밭 0 · Then `site_chosen` why `first_farm`. 밭 있고 나무꾼 0 · Then `first_woodcutter`.
4. **제단**: Given 깨닫기 전 · Then 제단 터 0. 깨달은 직후 라운드 · Then 모닥불 둘레에 제단 터 1, `wished`, 터 상한을 먼저 채움.
5. **굶주림이 먼저**: Given 집 없는 어른 2 ∧ `starving_village()` · When 라운드 · Then 집이 아니라 농장·화덕·맷돌간 중 하나 (why `starving`). 집 없음만 있으면 집.
6. **굶주림 모드**: Given 굶주림 · Then 우물·채석장 같은 새 터는 열리지 않고 `build_paused`.
7. **일터 문턱**: Given 직장 없는 어른 1 · When want가 우물 · Then 못 지음. 먹을 것 일터는 지음.
8. **자재 부족**: Given 판자가 예비 아래 · Then 제재소가 먼저. 둘 다 불가로 2라운드 · Then `build_stuck`, 다음 라운드에 비상 자재 일터 1.
