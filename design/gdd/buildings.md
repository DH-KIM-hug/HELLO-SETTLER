# 건물·짓기 (Buildings & Construction)

> **Status**: Designed (메인 판단 반영, 2026-11-08 — `/design-review`는 새 세션에서)
> **Author**: game-designer + 메인 세션
> **Last Updated**: 2026-11-08
> **Implements Pillar**: 2 보는 것이 곧 재미 · 3 작은 세상의 실감 · 1 스스로 사는 사람들

## Summary

건물·짓기는 **건물 종류·크기·비용(판자·돌)·짓는 일·넓혀 짓기(개축)·시대 잠금·소인의 겉모습**을 맡는 계통이다. 터는 촌장(#18)이 고르고 자재는 짐꾼(#12·#16)이 나르며, 이 계통은 "무엇을 지을 수 있고, 터가 어떤 단계에 있고, 다 지으면 무엇이 되는가"를 정한다. 주민은 숫자를 보여 주지 않는다. 대신 **말뚝 박힌 터 → 쌓이는 갈대 다발과 조약돌 → 묶이는 가지 뼈대 → 꽃잎 지붕이 덮이는 순간**이 보인다.

> **Quick reference** — Layer: `Economy` · Priority: `MVP` · Key deps: `2 물·땅(터), 8 유전(능력 몫만), 18 촌장의 결정` · 담당 파일: 새 `sim/buildings.gd` (`Village.add_building`·`on_built`·`is_free`·`_owed`·짓기 op를 옮겨 옴), 데이터 `data/balance.gd` `B`

**지켜야 할 결정 (이미 확정)**: 나무 없는 세상 — 판자·통나무 모양 금지, 가지·풀대·갈대·꽃잎·씨앗 껍데기·조약돌·흙 (GD 3.0) · **이름·숫자 유지** (나무꾼·제재소·판자, 보이는 모양은 쪼갠 갈대 — 촌장 GDD R7) · 터는 촌장이 고름, 거인은 스타터킷만 놓음 · 이사 없음 (v3.8) · 밀밭 = 밀 숲 (줄기 3~5, 2026-11-08) · 초거대 해바라기 쓰러뜨리기 → 줄기 재료 (2026-11-08) · 목화솜 이불, 진딧물 목장, 하늘의 큰 알 껍데기 재사용, 집 강아지 (2026-11-08).

**메인 판단 (사용자 위임, 2026-11-08)**:
1. **성능**: 건물마다 `__far` 모델(≤ 600) + ppu < 24에서 선·껍데기 끔 + 마당 소품은 MultiMesh. 마을 통째 합치기·그림 카드는 쓰지 않음 (짓기·개축·지붕 색이 건물마다 바뀌므로).
2. **자재는 판자·돌 둘 그대로**: 해바라기 줄기는 창고 판자 몫으로 들어오고, 새 재료는 겉모습(`look`)과 작은 효과로만.
3. **알 껍데기 = 겉모습만**: 집 하나의 지붕(엎은 반쪽) 또는 공용 화덕 곁 그릇·아이 욕조. 새 집 종류 없음.
4. **밀 숲 그늘은 MVP에서 표시만**: 꽃 그늘 지도에 그리되 집 자리·추위 규칙은 읽지 않음 (VS에서 다시).
5. **강아지 잠자리 = 집 마당 소품** (마을 강아지는 모닥불 곁 공용 잠자리), 따로 건물 없음.
6. **영지 시대 건물은 MVP에서 뺌** (전쟁 내용 보류와 같이).
7. **보이는 이름**: 나무꾼 = '갈대밭 터', 농장 = '밀 숲 터', 사냥꾼 = '애벌레 사냥터' (`B_LABEL`만, 저장 키 그대로).

## Overview

- **건물 = 데이터 한 줄** (`Balance.B[type]`): 판자·돌 비용, 짓는 일(사람·초), 시대, 크기, 정원(집), 일터 여부, 레시피(#15), `replaces`(넓혀 짓는 옛 종류).
- **짓기 흐름 5단계**: 터 잡음 → 자재 모음 → 짓는 중 → 다 지음 → (넓혀 짓는 중). 같은 흐름을 새 건물과 개축이 함께 쓴다.
- **자재는 두 가지뿐**: 판자(보이는 모양: 쪼갠 갈대·납작 껍질)·돌(조약돌). 새 소인 재료(해바라기 줄기·알 껍데기·목화솜)는 **비용이 아니라 겉모습과 작은 효과**로 들어온다 (메인 판단 2).
- **시대가 건물을 연다**: 개척기 → 마을 → 읍내 (→ 영지는 보류). 시대 집이 바뀌면 옛 집을 넓혀 짓는다.
- **결정성**: 거인이 보는지(presence)는 이 계통의 규칙에 들어가지 않는다 (ADR-0001). 일은 `events.emit`으로만 밖에 알린다.

## Player Fantasy

**"말뚝 하나가 박혔을 뿐인데, 저녁엔 꽃잎 지붕이 올라갔네."** 거인은 진행 막대를 보지 않는다. 조약돌을 안고 줄지어 오는 사람들, 갈대 다발을 둘이 메고 오는 모습, 가지 뼈대에 풀 밧줄을 감는 손, 마지막에 **그 철에 핀 꽃 색 꽃잎**이 비늘처럼 덮이는 순간을 본다. 다 지으면 굴뚝에 연기 한 줄 — "이제 한 가족이 이 지붕 아래 잔다" (기둥 2·3).
- **기다림 → 완성**: 집 하나는 현실 1~2분 남짓의 작은 이야기 (짓는 일 2,400 사람·초, 둘이면 병 20분 = 현실 약 4초 × 여러 번 + 나르기).
- **세대의 흔적**: 개척기 벌집 돔이 마을 시대 원통 흙벽 + 2단 꽃잎 지붕으로 넓어진다. 같은 자리의 집이 자라는 것을 본다.
- **세상과 이어진 재료**: 해바라기를 쓰러뜨린 해 가을, 마을에 큰 줄기 들보가 보이기 시작한다. 하늘의 큰 알을 먹은 다음 날, 누군가 그 껍데기를 엎어 지붕으로 쓴다 — "내가 준 것이 마을의 일부가 됐다" (기둥 4).

## Detailed Design

### Core Rules

**R1. 건물 정의** — 모든 건물은 `Balance.B`의 한 줄. 필수 키 `plank, stone, time, era, size`, 선택 `cap`(집), `job`, `gather`, `in/out/cycle`(#15), `replaces`. 저장 키(한국어 종류 이름)는 바꾸지 않고, 보이는 이름은 `Balance.label()` 한 곳에서만 바꾼다 (`B_LABEL`).

**R2. 지을 수 있음 `can_build(v, type)`** = 잠김(`B_LOCKED`) 아님 ∧ 알고 있음(처음부터·계시·설계도·스스로 깨침) ∧ `era ≤ v.era`. 예외: 약초를 알면 약초원은 개척기에도. 발견 건물(소금밭·버섯 말림터)·제단은 시대와 무관.

**R3. 터 잡음** — 촌장(#18)이 `add_site(type, x, y)`를 부른다. `is_free`(영역 안, 물·물가 6방향, 제단 거리, 건물 간격, 모닥불, 바위·큰 버섯·큰길·큰 나무)를 통과해야 한다. 터는 땅에 **말뚝 넷 + 풀 밧줄 고리**로 보인다.

**R4. 자재 모음** — 터마다 `need(k) − delivered(k) − incoming(k)`를 짐꾼 일감으로 낸다. 들어준 소원·제단이 먼저. 창고 셈은 `_owed`로 아직 줄 몫을 뺀다 (F3).

**R5. 짓는 일** — `materials_ready()`이면 일감 `build`. 한 번에 `BUILD_CHUNK`(병 1,800초) — 첫 한 시간·대본 중엔 30초. `prog += chunk × build_mult × opening_build`. `prog ≥ time`이면 다 지음. 여럿이 함께 지을 수 있다 (사람·초가 더해짐).

**R6. 다 지음** — `on_built`: 시대 점수용 건물 수 +1, 집이면 R5(인구) 배정, 농장이면 첫 수확 시각, 제단이면 첫 기도(#20), 마을 시대 건물이면 효과(망루 안개 등). 연대기 한 줄. 사건 `building_completed`.

**R7. 넓혀 짓기(개축)** — 옛 건물에 `upgrade_to`를 붙여 같은 자리에서 새 비용·새 짓는 일. **그동안 사람은 그대로 살고(집) 일꾼은 쉰다(일터, #15 Edge 7)**. 다 지으면 종류가 바뀌고 timer 0. 쓰는 곳: 오두막 → 목조 주택 → 석조 주택(땅 한계일 때), 맷돌간 → 방앗간, 화덕 → 빵집 (`replaces`).

**R8. 시대 집** — 시대마다 기본 집 `ERA_HOUSE`: 개척기 오두막(4) · 마을 목조 주택(6) · 읍내 석조 주택(8). 시대 집 자재가 모자라면 오두막이라도 짓는다. 집 정원 합 ≤ 품는 인구 × `HOUSE_SLACK`(#17 F6) — 넘으면 새로 짓지 않고 작은 옛 집을 넓힌다.

**R9. 소인의 재료와 겉모습 (이름·숫자 유지)** — 시뮬 키·비용은 그대로, 모델·말맛만:
| 시뮬 이름 (그대로) | 보이는 이름 (`label`) | 겉모습 |
|---|---|---|
| 나무꾼 / 통나무 | 벌목장 → **갈대밭 터** / 가지 다발 | 갈대·꽃대 무리 곁, 가지 다발 더미 |
| 제재소 / 판자 | 제재소 (유지) / 판자 | 쐐기돌로 갈대 줄기를 쪼갬, 쪼갠 갈대 띠 더미 |
| 산림관 | 묘목원 | 갈대 싹 줄 |
| 농장 | 밀밭 → **밀 숲 터** | 밀 줄기 3~5개(소인 키 ×20), 풀실 사다리, 큰 그늘 |
| 사냥꾼 | 사냥막 → **애벌레 사냥터** | 낮은 돔 + 풀대 창 걸이 + 고치 |
| 오두막 / 목조 / 석조 주택 | 그대로 | 6.1 시대 표 (벌집 돔 → 원통 흙벽 2단 꽃잎 지붕 → 조약돌 흙벽 + 큰 가지 들보 + 씨앗 껍데기 돔) |

**R10. 2026-11-08 결정의 건물 몫**
1. **밀 숲 터**: 모델 = 줄기 3~5(줄기마다 이삭), 바닥은 흙 고리. 크기(`size` 1.8)·레시피 그대로. 그늘이 큰 것은 꽃 그늘 지도(#5)에 반경을 넘긴다 (집 자리·추위 영향은 안).
2. **해바라기 줄기 재료**: 쓰러뜨리기 사건(#6·#18)이 창고에 판자 몫을 크게 넣는다 (숫자는 #16). 이 계통은 **그 뒤 지은 건물의 `look_tag = sunflower_beam`**을 붙여, 읍내 들보·큰 다리 겉모습에 줄기 들보를 쓴다 (규칙 효과 없음).
3. **목화솜**: 건물 아님 — 집의 상태 `quilt`(이불 있음, #9 추위·#10 겨울밤 행복). 집 모델은 창가에 하얀 솜 이불 한 장(가까이만).
4. **진딧물 목장**: 새 일터 `진딧물목장` (마을 시대, 판자 2·돌 0, 짓는 일 60×K, 풀줄기 울타리 + 이슬 받는 도토리 깍정이). 레시피·위기 연결은 #15·#32 몫.
5. **하늘의 큰 알 껍데기**: 알을 다 먹으면 껍데기 반쪽이 남는다. 다음 새벽 가장 가까운 **개축 대상 아닌 집 하나**의 지붕이 `look = egg_roof`로 바뀌거나(엎은 반쪽), 공용 화덕 곁 그릇·아이 욕조가 된다. 규칙 효과 없음, 연대기 한 줄.
6. **강아지 집**: 별도 건물 아님. 집 강아지가 있는 집은 문 옆에 **엮은 풀 강아지 잠자리**(소품), 마을 강아지는 모닥불 곁 공용 잠자리. 모델 소품 몫.

**R11. 거인이 산 건물** — `bought = true`, 하늘에서 완성된 채 내려옴 (`built=true`, 짓기 흐름 생략). 터는 여전히 촌장이 고른다 (설계도).

**R12. 거인 무관** — 이 계통은 `is_watching()`·카메라·연출 켬을 읽지 않는다. (시대 점수의 지켜봄 배율은 #22 몫.)

## Formulas

**F1. 짓는 시간**: `time = base × BUILD_K` (BUILD_K 40). 사람 n이 함께면 현실 걸리는 시간 ≈ `time / (n × build_mult)` + 나르기.
| 기호 | 값 | 출처 |
|---|---|---|
| base | 30~300 | `B[type]` (오두막 60, 교회 300) |
| build_mult | 1 / 1.5(소원) × 하늘 통나무 덤 × 수첩 첫날 | `Village.build_mult` |
| BUILD_CHUNK | 1,800 병 초 | Balance |
- 해 본 예: 오두막 60×40 = 2,400 사람·초. 둘이면 1,200 병 초 = 병 20분 = 보통 속도 현실 약 4.2초. 교회 12,000 → 셋이면 병 67분 ≈ 현실 14초 (+ 자재 10개 나르기).

**F2. 집 상한** (#17 F6): `Σcap + cap(새) ≤ land_capacity × 1.1`. 넘으면 `cap(새) − cap(옛)`만큼 늘어나는 개축으로. 예: 품는 인구 40, 정원 42 → 목조(6) 새로 = 48 > 44 → 오두막(4) → 목조(6) 개축 = 44 ≤ 44 ✔.

**F3. 지을 수 있는 자재**: `affordable(t) = (판자 − owed판자 − cost판자 ≥ reserve) ∧ (돌 − owed돌 − cost돌 ≥ 0)`, reserve = 4 (나무꾼·제재소 0). 예: 판자 9, owed 3, 오두막 2 → 4 ≥ 4 ✔.

**F4. 시대 집 비용표** (지금 값)
| 집 | 시대 | 판자/돌 | 짓는 일 | 정원 | 정원당 판자+돌 |
|---|---|---|---|---|---|
| 오두막 | 0 | 2/0 | 2,400 | 4 | 0.5 |
| 목조 주택 | 1 | 4/1 | 4,800 | 6 | 0.83 |
| 석조 주택 | 2 | 2/4 | 7,200 | 8 | 0.75 |
- 개축 비용은 새 건물 전액 (옛 자재 돌려받지 않음) — 의도: 땅이 한계일 때만 쓰는 비싼 길.

**F5. 성능 몫 (아트 바이블 8장 기준)**: 실효 삼각형 = 몸 × (1 + 껍데기 + 그림자) + 선. 집·일터 가까이 몸 ≤ 2,000·선 ≤ 800 → 한 채 약 6.8k, 15채 102k (예산). **멀리 LOD ≤ 600, 선·껍데기 없음** → 한 채 ≤ 1.2k. 예: 건물 34채를 모두 가까이로 그리면 ≈ 231k + 소품 ≈ **280k (메인 세션이 전한 실측, PERF 문서엔 건물 분해값이 없음 — 다시 잴 것)**; ppu 16에서 멀리 LOD면 34 × 1.2k ≈ 41k.

## Edge Cases

1. **자재 교착**: 판자·돌 모두 바닥 → 촌장 R6 비상 예비(#18). 이 계통은 `affordable`만 답함.
2. **개축 중 집이 꽉 참**: 사람은 그대로, 다 지으면 정원만 늘어남 → 같은 걸음에 #17 출산 문이 열릴 수 있음 (의도).
3. **개축 중 일터**: 일꾼 쉼·입구 닫힘, 건물 앞 더미는 그대로 (#15).
4. **땅 가득 + 옛 작은 집 없음**: 집을 짓지 않음, 막힘 라운드 (#18).
5. **터 자리에 물이 차오름(홍수)**: 짓는 중 터는 prog 그대로 멈춤, 물이 빠지면 이어 짓기. 다 지은 건물은 물에 잠겨도 그대로(피해는 #24).
6. **짓던 사람이 죽음·앓음**: prog는 남는다, 다른 사람이 이어 짓는다.
7. **알 껍데기 지붕을 받을 집이 개축 중**: 다음 집으로. 집이 없으면 그릇이 됨.
8. **불러오기**: `delivered/incoming/prog/upgrade_to/look` 저장. 표시 3단계는 다시 셈, 사건 없음. 옛 저장의 `look` 없음 = 기본.
9. **따라잡기(큰 dt)**: 짓는 일은 op 단위라 dt와 무관. ×1과 ×8 결과 같음.
10. **잠긴 건물의 설계도**: 상점 '곧' 표시, 촌장은 짓지 않음.

## Visual/Audio Requirements

- **실루엣 = 지붕 윤곽 + 밖으로 나온 것 하나** (아트 바이블 6.1, 40px 시험). 모서리 날카로운 직육면체·반목조 박공 상자 금지 → 둥근 지붕·원뿔 + 묶음 띠.
- **꽃잎 지붕 색**은 그 집을 다 지은 철의 꽃 색 공식(채도 ×0.6·명도 ×0.85, 밝은 꽃 바램 보정). `built_t`의 철을 읽음.
- **예산**: 집·일터 평균 몸 ≤ 2,000(선 ≤ 800), 최대 2,500 · 멀리 ≤ 600 (`<부품>__far` 노드) · 랜드마크(예배당·제단·방앗간·광장·망루) ≤ 4,000 / 멀리 ≤ 800 · 밀 숲 터 ≤ 1,500 (줄기 5개, 이삭은 낮은 폴리곤).
- **가림 4겹**: 겹 1 마을 반경 안엔 큰 꽃 머리 없음 — 밀 숲 터는 예외로 마을 안에 있으니 **줄기는 가늘게, 이삭은 위로 벗어나 그늘만**; 겹 3 건물 뒤 주민은 청록 실루엣.
- **짓는 중**: 뼈대·벽·지붕 3단계 + 자재 더미(갈대 다발·조약돌)는 실물 개수로 (최대 6개 소품).
- **소리** (#38): 말뚝 박는 톡톡, 풀 밧줄 감는 사각, 다 지으면 따뜻한 짧은 화음 + 첫 연기. 막힘엔 소리 없음.
- **성능 작업 (A15 후속)**: (1) 모든 건물 모델에 `__far`, (2) ppu < 24에서 선·껍데기 끔, (3) 마당 소품(꽃·덤불·가지 더미)은 MultiMesh로, (4) 같은 모델 집은 인스턴스 공유.

## Game Feel

- 터가 박히고 **현실 5초 안**에 첫 자재를 든 사람이 보인다 — "무슨 일이 시작됐다".
- 지붕이 덮이는 마지막 20%는 꽃잎이 한 줄씩 올라가 — 완성의 한 박자. 연기는 그 집에 첫 가족이 들어올 때.
- 개축은 "옛 집이 자란다" — 비계가 둘러지고 사람은 계속 드나든다 (이사 없음과 맞음).

## UI Requirements

- **거인 UI** (숫자 허용): 건물 상세 = 이름(label)·지은 날·사는 사람/일꾼·짓는 중이면 자재 그림 칸(갈대 다발 ○○○●, 조약돌 ○●) — 막대 아닌 실물 칸. 이유 줄: "갈대가 오길 기다려요", "짓는 사람이 없어요".
- 상점 카드: 잠김 = '곧' + 까닭 한 줄(`B_LOCKED`). 시대 미달 = "새 시대에 열려요".
- **주민 쪽**: 말풍선 "○○ 완성!" 5초 (`label`), 숫자 없음. 금지어(상자·구매 등) 쓰지 않음.

## Acceptance Criteria

모두 헤드리스 (묶음 `buildings`).
1. **짓는 일**: Given 오두막 터, 자재 다 옴, 일꾼 2 · When 짓기 · Then prog가 2,400에 닿는 순간 `building_completed` 1번, 병 1,200 ± 30초.
2. **자재 셈**: Given 판자 9·짓는 중 터가 판자 3 남음 · Then `owed(판자)` = 3, `affordable(오두막)` 참, `affordable(목조)` 거짓.
3. **시대 잠금**: Given era 0 · Then `can_build(목조주택)` 거짓, era 1 · 참. 잠김(`B_LOCKED`)은 시대와 무관하게 거짓.
4. **개축**: Given 오두막(4명 삶) · When 목조로 개축 · Then 짓는 동안 4명 그대로 집, 다 지으면 cap 6, `upgrade_completed {from 오두막, to 목조주택}`.
5. **땅 한계 개축 고르기**: Given 작은 옛 집 둘, 첫째는 바꾸면 상한을 넘고 둘째는 맞음 · Then 둘째를 고름 (지금 코드 버그 회귀 시험).
6. **개축 중 일터**: 맷돌간 → 방앗간 중 입구 채움 0, 바로 보냄 0.
7. **산 건물**: `bought` 건물은 `built` = 참, 자재 일감 0.
8. **결정성·연출 무관**: 같은 씨앗, 연출 켬/끔 병 3일 → 건물 목록·prog·사건 줄 같음. ×1과 ×8 같음.
9. **겉모습 무관**: 겉모습 유전자만 다른 두 마을 → 짓기 결과 같음.
10. **알 껍데기**: Given 큰 알을 다 먹음 · When 다음 새벽 · Then 집 하나 `look_changed {egg_roof}` (개축 중 집 아님), 규칙 값 변화 0.
11. **저장·불러오기**: 짓는 중(prog 1,000·delivered 판자 1)·개축 중 저장 → 같음, 첫 걸음 사건 없음.
12. **사건 모양**: v에 Object 없음, kind가 event-kinds.md에 있음, emit 앞뒤 RNG 같음.
13. **모델 예산 (도구 시험)**: `models/buildings/*.glb` 몸 평균 ≤ 2,000, 모두 `__far` ≤ 600 노드 있음.
