## Summary

HUD는 **별지기의 책상** — 위 띠(읽기만), 위 모서리 칩, 아래 알림 자리, 아래 도구 띠 5칸(제단·상점·**손**·연대기·선반), 그리고 아래에서 올라오는 시트들(주민 상세·제단·상점·창고·사람들·설정)로 이루어진다. 원칙은 하나: **주민 위에 앉지 않는다.** 화면 가운데 25~70%는 비워 두고, 새 소식은 세상 안(편지를 든 주민·말풍선)이 먼저 알린다. 숫자는 별지기 UI에만.

> **Quick reference** — Layer: `Presentation/UI` · Priority: `MVP` · Key deps: `전 계통 (읽기만)` · 담당 파일: `view/test_village.gd`(띠 배치 — 떼어 낼 것) · `view/ui/*` (시트·칩·카드) · `view/ui/ui_theme.gd` · `view/ui/game_settings.gd` · `view/ui/safe_area.gd`

**메인 판단 (사용자 위임, 2026-11-08)**: H1 **위 띠 = "지구 이름 · 시대 · 인구 / 지폐 / 톱니"** + 시간 칩에 **"별생활 N일째"** (아트 바이블 7.12-10) · H2 **화면 말의 '거인'을 모두 '별지기'로** ("거인의 방으로 돌아갈까요?" → "별지기의 방으로 돌아갈까요?", "[거인의 수첩]" → "별지기의 수첩") · H3 **띠 배치를 `test_village.gd`에서 `view/hud/hud.gd`로 떼어 냄** (장면 파일 1,900줄+) · H4 **주요 버튼 짙은 밤색** (지금 이끼 초록 — 설정 [메일 쓰기] 등) · H5 **접근성 설정 7종을 MVP에** (글자 크기·또렷한 글씨·움직임 줄이기·화면 흔들림·색 보조·읽을 시간 늘리기·왼손 모드; 자막은 늘 켬) · H6 **디버그 글자는 출시·캡처에서 끔**.

## Player Fantasy

**"화면엔 사람들만 보여. 필요할 때만 책상 서랍을 연다."** 별지기는 UI를 보지 않고 마을을 본다. 손을 쓰려 할 때만 엄지 아래에서 도구가 퍼지고, 시트가 열리면 카메라가 비켜 보던 사람을 위쪽 가운데로 올린다 (기둥 2). 버튼 하나도 은청·밤색·크림의 '임자'가 있어 "이건 내 것, 저건 그들의 것"이 저절로 읽힌다.

## Detailed Design

### Core Rules

**R1. 층과 임자 (아트 바이블 7.1)**: 세상 안(주민: 말풍선·편지 든 주민 / 별지기: 손 그림자·도구 끝 동심원) · 반쯤 세상(주민 종이: 자막·펼친 편지·연대기 카드) · 화면 띠(별지기 크림 판). 세상 위 종이는 한 단계 어둡게 + 잉크 외곽선 1.5dp + 짧은 그림자.
**R2. 빨간 점·배지 금지**: 새 소식 = 세상 안 신호 먼저(편지를 든 주민, 제단 위 실제 공물). 도구 띠 칸은 **숨 쉬는 빛**으로만 (수첩이 가리킬 때·`glow` 박자).
**R3. 차례 (7.7)**: 0 연출(띠 400ms 물러남) > 1 안내 창 > 2 수첩 쪽지 > 3 주민이 든 편지 > 4 말풍선(기본 확대 3개). 연출·따라가기 중엔 1·2를 띄우지 않음. 안내 창이 열린 동안 시간은 보통 이하.
**R4. 시트**: 아래에서 220ms 미끄러짐(닫기 160ms), 뒤 어둠 0→30%, 버튼은 시트 맨 아래. 주민 상세는 35% → 85% 두 단계. 시트가 열리면 카메라가 대상을 남은 윗부분 가운데로 (HUD를 흐리게 하지 않음). 뒤로 가기 = 열린 시트 닫기, 없으면 "별지기의 방으로 돌아갈까요?".
**R5. 손 메뉴**: [손]에서 위로 부채꼴(반지름 90~120dp, 최대 5), **열린 도구만** (#26). 쓰는 중 = 은청 + 짙은 선 1.5dp + 도구 버튼이 떠오름 + '든 것' 칩 + [그만].
**R6. 누르기**: 최소 48dp, 간격 8dp. 주민은 반지름 24dp 안 가장 가까운 사람 + 선택 고리 + [◀ 곁의 사람 ▶]. 병 안 빈 땅 톡 = 유리 톡 (#19).
**R7. 숫자 (7.9)**: 위 띠·상점·제단·주민 상세·안내 창 머리·시간 칩만. 고정폭, `2,400`, `1.2만`. 확률은 상점 '확률 보기'에만. 주민 상태는 막대 5개(한 색 + 아이콘 + 길이 + 위험 빗금).
**R8. 색 + 모양 (7.10)**: 모든 상태는 색 + 모양 하나(✓ ! = ▲▼ 빗금). 주요 버튼 `#3A2A22` + 크림 글자. 빨강·초록 짝 금지.
**R9. 화면 말 (H2)**: 별지기 UI 글은 '별지기'·'별생활'. 주민 쪽 글(말풍선·편지·연대기)은 CLAUDE.md 1장. 별지기 UI는 '지폐·사다·팔다' 허용.

### States and Transitions

| 상태 | 띠 | 입력 |
|---|---|---|
| 지켜봄 | 보임 | 모두 |
| 손 쓰는 중 | 도구 띠 은청, 든 것 칩 | 겨누기·[그만] |
| 시트 열림 | 띠 보임, 카메라 비킴 | 시트 안 + 뒤로 |
| 따라가기 | 띠 보임, 1·2 차례 멈춤 | 주민 상세·[그만 따라가기] |
| 연출 | 띠 물러남 | 건너뛰기만 (#25) |
| 따라잡기 | 띠 숨김, 편지 화면 | 편지 버튼 (#27) |

### Interactions with Other Systems

읽기만: #1(시계·배속·별생활 날), #14(시대), #17(인구), #22(지폐), #10(막대), #21(제단 상태), #23(계시 빛), #26(빛낼 단추). 쓰는 것은 **별지기 입력**뿐(배속·손짓·받기·사기) — 각 계통의 입력 함수를 부름.
**구독 kind**: `notes_earned`(지폐 오름 효과) · `immigrants_arrived`·`born`·`died`(인구 숫자 톡) · `revelation`(시대 배지 바뀜) · `tool_unlocked`(손 메뉴 칸 생김) · `clock_slowed`(느려짐 카드 — #1) · `revelation_due`(제단 칸 빛).

## Formulas

**F1. 별생활 N일째**: `N = floor((jar_t − owned_from_t) / DAY) + 1` (그 병을 가진 병 날짜 — 비운 동안 흐른 날 포함).
**F2. 글자 크기 배율**: `size = base × {1.0, 1.15, 1.3}`, 줄바꿈은 Theme 하나로 (130%에서 깨지지 않게).

## Edge Cases

1. **노치·제스처 바**: `SafeArea` 값, 좌우 16dp. 가로 창은 시트를 오른쪽 패널로.
2. **지폐 1만 넘음**: `1.2만`, 상점 값은 그대로 쉼표.
3. **도구 0개 열림**: [손]은 '든 것 내려놓기'만, 부채꼴 대신 바로 든 것.
4. **밤**: 세상 위 UI 개수를 줄임(색은 그대로).
5. **시트 위 시트**: 하나만 — 새 시트가 열리면 앞 시트 닫힘(주민 상세 → 가계도는 시트 안 쪽 넘김).
6. **130% + 긴 이름**: 위 띠 지구 이름 말줄임, 누르면 전체.

## Visual/Audio Requirements

- 크림 판 `#F4EAD3` + 테두리 `#6B5442`, 글자 `#3A2A22` (11.4:1). 아이콘 셀 2톤 + 외곽선 1.5~2dp, 도트 아이콘 모두 바꿈.
- 글꼴: 나눔스퀘어라운드(본문 14~16) · 주아(제목) · 나눔손글씨 펜(주민 종이만).
- 소리: 시트 종이 미끄러짐, 버튼 작은 나무 톡, 지폐 오름 동전 아닌 '종이 넘김'.

## Game Feel

- 버튼 누름 80ms 안에 0.96배 + 내려앉음. 어떤 움직임도 250ms 넘게 입력을 막지 않음.
- 손 쓰는 중은 300ms 은청 쓸림 한 번 → "지금 내 손이 병 안에 있다".

## UI Requirements

**설정 (H5, UI.md 10 + 아트 바이블 7.11)**: 소리(음악·효과음·목소리) · 진동 · 알림(#30) · 글자 크기 100/115/130 · 또렷한 글씨 · 움직임 줄이기 · 화면 흔들림 · 색 보조 · 자막(늘 켬 / 말하는 사람 이름) · 읽을 시간 늘리기 · 왼손 모드 · 안내 다시 보기 · 수첩 다시 켜기 · 비운 시간 빠르기(1.5/3/6일) · 문의하기 · 처음부터(두 번 묻기).
**접근성 점검표**: 한 손 엄지(도구 띠·시트 버튼 아래) ✓ · 색만으로 뜻 없음 ✓ · 번쩍임 1초 3번 이하 ✓ · 자막 늘 ✓ · 글자 130% ✓ · 키보드/게임패드: 모바일 전용이라 MVP 밖 (열린 질문).

## Acceptance Criteria

1. **가운데 비움**: 기본 확대·지켜봄에서 화면 25~70% 띠 안에 HUD 노드 0 (말풍선 제외) — 캡처 시험.
2. **말**: 모든 별지기 UI 글에 '거인' 0; 시간 칩에 "별생활 N일째".
3. **누르는 곳**: 모든 버튼 ≥ 48dp.
4. **글자 130%**: 모든 시트에서 잘림·겹침 0 (캡처 시험 3장).
5. **배지 없음**: 빨간 점·숫자 배지 노드 0.
6. **차례**: 연출 중 안내 창·쪽지 0; 따라가기 중 0.
7. **주요 버튼 색**: 이끼 초록 버튼 0.
8. **결정성**: HUD를 켜고/끄고 병 3일 → 시뮬 같음.
9. **디버그 끔**: 출시 빌드·캡처에서 디버그 글자 0.
