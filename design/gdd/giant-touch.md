# 거인의 손길 (Giant's Touch)

> **Status**: Designed (사용자 결정 반영, 2026-11-08 — `/design-review`는 새 세션에서)
> **Author**: 사용자 + 메인 세션 + game-designer
> **Last Updated**: 2026-11-08
> **Implements Pillar**: 4 의미 있는 손길 (주) · 1 스스로 살고 나를 알아보는 사람들 · 2 보는 것이 곧 재미

## Summary

거인의 손길은 거인(화면 이름 **별지기**)이 병 안에 직접 하는 **몇 안 되는 손짓**의 규칙이다. 손짓은 여섯 가지 — **내려 주기·유리 톡·물 뿌리기·유리 닦기·핀셋·등불 옮기기** — 이고, 하나하나 분명한 까닭·결과·대가를 가진다. 유리 톡과 내려 주기를 빼면 모두 **그 손짓이 필요한 사건이 처음 생길 때** 열린다. 손은 화면에 그리지 않는다 (그림자와 도구 끝만).

> **Quick reference** — Layer: `Gameplay` · Priority: `MVP` (VS 손짓 일부) · Key deps: `병 시간(1), 물·빛(3·4), 사건 흐름(7), 필요와 기분(10)` · 담당 파일: `sim/giant_hand.gd` (+ `Village`의 손짓 입구, `Firsts` 도구 열림)

**정해진 것 (사용자 2026-11-07~08)**: 감싸기·커튼·불기·[뚜껑] 단추 없앰 · 유리 톡은 단추가 아닌 손짓 · 도구는 사건과 함께 하나씩, **별지기 전체에서 한 번** (병마다 아님) · 잠긴 도구는 자리도 없음 · 손은 보이지 않음 · 톡·등불 옮기기는 그날 3번까지 두렵지 않음 · 깨닫기 전 주민은 '거인'을 모르고 그저 경이를 본다 · 화면 호칭 '별지기'.

**사용자 결정 (2026-11-08)**: ① 유리 톡은 그날 **3번**까지 무료, **등불 옮기기는 1번**만 무료 — 2번째부터 두려움 ("등불 3번이나 할 필요가 있나?"), 횟수는 따로 셈 · ② 병 안 유리 톡 = **주민·제단이 아닌 빈 땅 아무 곳** (지금대로), 단 **두 번 눌러 들어가기의 첫 누름은 톡으로 세지 않음** · ③ **세게 친 톡(지진)은 손짓에서 뺌** — 개발 키 전용 · ④ **물 뿌리기·핀셋은 내려 주기와 같은 끌어 겨누기** (땅 그림자, 손은 안 보임) · ⑤ 깨닫기 전 손짓은 **경이만** (믿음 없음 — 등불의 믿음 문 고침), 없앤 뚜껑·불기·감싸기·커튼의 남은 값·코드 길은 지움 (아래 '정리할 것').

**주민·강아지를 누르면 (2026-11-10 귀여움 묶음 ① — 메인 판단, 사용자 위임)**: 주민을 누르면 정보 카드가 열리면서 **그 주민이 화면에서만 반응한다** — 깨닫기 전에는 움찔·두리번·갸웃·재채기 (올려다보거나 손을 흔들지 않는다), 깨달은 뒤에는 폴짝 손 인사·꾸벅·수줍음. 아이는 두 번 폴짝, 노인은 느린 끄덕임, 아기는 까르르, 자는 사람은 돌아눕고, 짐 든 사람은 짐을 든 채 폴짝, 앓는 사람은 한숨. 세 번 넘게 연달아 누르면 어지러워하거나 털썩 앉거나 볼을 부풀린다. **강아지를 누르면 유리 톡으로 세지 않고** 강아지가 폴짝·꼬리 흔들기·빙글 (전에는 빈 땅 누름으로 넘어가 톡이 됐다). 이 반응은 시뮬 결과를 바꾸지 않는다 (경이·두려움·그날 횟수 없음, `view/tap_react.gd`, 시험 `tap_react`).

## Overview

- **MVP에서 열림**: 내려 주기(손에 든 것·낟알·가지), 유리 톡, 물 뿌리기.
- **VS(위기와 함께) 열림**: 유리 닦기, 핀셋, 떠돌이 물방울 톡(유리 톡의 새 효과), 등불 옮기기.
- **손짓 종류는 늘리지 않는다** (기둥 4 기준: 추가보다 깊게). 늘어나는 것은 내려 줄 **물건**(상점 #22).
- 이 계통은 손짓을 받아 **결과(물·두려움·경이·믿음)를 다른 계통에 요청**하고, 일어난 일을 `events.emit`으로 알린다. 믿음·깨달음(#20)은 그 사건을 구독한다 (systems-index 계약).
- 손짓은 **시각이 찍힌 입력**이다 (ADR-0001 3절). 같은 씨앗 + 같은 입력 기록이면 결과가 같다. 지켜봄(presence)·연출 여부는 손짓 결과에 들어가지 않는다.

## Player Fantasy

**"내 손이 닿으면 저 작은 세상이 달라진다 — 그러니 아껴 써야 한다."** 마른 밭 위로 은빛 물방울이 쏟아지고 아이들이 젖은 얼굴로 하늘을 올려다본다. 길을 막은 날벌레를 핀셋 끝이 집어 올리면 사람들이 손뼉을 친다. 그러나 유리를 장난처럼 자꾸 두드리면 어깨를 움츠리고 집으로 숨는다.
- **경이 (깨닫기 전)**: 주민은 누가 했는지 모른다. "하늘이 울렸어!" 아이가 가리키고, 어른은 "그냥 바람이야". 이 엇갈림이 깨달음까지의 설렘이다 (기둥 1).
- **무게**: 손짓마다 1~2초, 위에서 내려오는 그림자가 마을을 덮는다. 드물어서 무겁다 (아트 바이블 5.1).
- **배움, 벌이 아님**: 대가(두려움·넘침·짓눌림)는 화면으로 먼저 보이고 하룻밤이면 반쯤 잊힌다.
- MDA: 주 미학 **Submission(돌봄)·Discovery(새 도구가 열림)**, 곁들임 Challenge(위기를 손길로 넘김). SDT: 자율(돕지 않아도 마을은 산다 → 도움은 선택), 유능감(1초 안에 결과가 보임).

## Detailed Design

### Core Rules

**R1. 손짓 여섯 가지**
| 손짓 | 어디서 | 하는 일 | 대가 | 쿨타임 |
|---|---|---|---|---|
| 내려 주기 | 손에 든 것(최대 5칸) → 땅을 골라 놓음 | 물건·낟알·가지·건물이 하늘에서 내려옴 (뚜껑 저절로 열림) | 집·사람 위면 부서짐 (경고 후 허용) | 없음 |
| 유리 톡 | 병 밖: 유리 직접 · 병 안: 주민·제단이 아닌 빈 땅 아무 곳 (사용자 결정 ②) | 주민이 올려다봄, 떠돌이 물방울을 누른 쪽 빈 땅에 미리 떨어뜨림 (VS) | 그날 4번째부터 두려움 (F1) | 없음 |
| 물 뿌리기 | 끌어 겨눈 자리(땅 그림자) 반경 3칸 | 땅 적심, 마른 밭 하루 ×1.3, 불·연기 끔 | 1시간 안 같은 자리 3번째 → 넘침 (집 잠김·두려움, 죽음 없음) | 30 병 초 |
| 유리 닦기 | 화면 어디서 문질러도 유리 전체 | 김·먼지막 걷음, 반나절 볕 ×1.08 | 없음 (김은 다시 서림) | 10 병 분 |
| 핀셋 | 끌어 겨눈 자리(땅 그림자, 대상 반경 32dp) | 날벌레·먼지 뭉치·떨어진 것·바위를 집음, 6칸 안 옮겨 놓기 | 멀리서 집으면 서툴러 곁의 집 짓눌림 | 없음 |
| 등불 옮기기 | 나침반 + 미리보기 → 확정 | 볕 드는 쪽·물길·추위가 바뀜 | 그날 **2번째**부터 두려움 (F2, 사용자 결정 ①) | 없음 |
- **세게 친 톡(지진)은 손짓이 아니다** (사용자 결정 ③): 화면 손짓으로 닿지 않고 개발 키(`KEY_T`)·시험에서만. `tap_glass(hard)` 길은 개발 전용으로 남김.
- **겨누기 문법 하나** (사용자 결정 ④): 내려 주기·물 뿌리기·핀셋 모두 [손]에서 고름 → 땅 위 그림자(손가락 40dp 위)를 끌어 옮김 → [놓기] / 손을 뗌. 화면 가운데 겨누기는 없앰.

**R2. 열림 (별지기 전체, 한 번)**
| 손짓 | 열리는 일 (처음, 어느 병에서든) | 판정 (지금 코드 `Firsts.check`) |
|---|---|---|
| 내려 주기·유리 톡 | 처음부터 | — |
| 물 뿌리기 | 지은 밭이 6시간 넘게 마름 / 첫 더위 노출 | `DRY_HOURS` · `heat ≥ DISEASE_EXPOSED` |
| 유리 닦기 | 김 ≥ 0.4 또는 먼지막 ≥ 0.3 | `FOG_AT` · `DUST_AT` |
| 핀셋 | 날벌레·먼지 뭉치·떨어진 것이 처음 생김 | `smalls.things` |
| 등불 옮기기 | 첫 추위 노출 / 마을 시대 | `cold ≥ DISEASE_EXPOSED` · `era ≥ 1` |
- 열리면 안내 창(EVENTS_STAGING 6b 모양) + 수첩 쪽지로 그 자리에서 한 번 써 보게 함. 소원(#23)이 아직 잠긴 도구를 부르면 소원이 연다 (`WISH_TOOLS`).
- 잠긴 도구는 손 메뉴에 자리도 없다. 첫 10분 수첩(#26)엔 유리 톡·내려 주기만.

**R3. 손짓은 입력**: 화면이 `Village`의 입구 함수(`tap_glass`·`spray_water`·`wipe_glass`·`tweeze`·`move_lamp`·내려 주기)를 부르면 그 시각·자리·물건을 입력 기록에 남기고 다음 고정 걸음 경계에서 적용한다. 시뮬 안에서 `is_watching()`·`stage_on`·카메라를 읽지 않는다. 손짓 결과에 난수가 필요하면 손길 전용 흐름을 쓴다 (다른 흐름을 흔들지 않게).

**R4. 그날 횟수 (사용자 결정 ①)**: 병마다 달력 날(`cal_day`)로, 톡과 등불을 **따로** 센다. 톡은 3번(`FEAR_FREE_PER_DAY`), 등불 옮기기는 1번(`LAMP_FREE_PER_DAY`, 새)까지 무료. 등불은 몇 칸을 건너든 한 번. **두 번 눌러 병에 들어가기의 첫 누름은 톡이 아니다** — 병 밖 누름은 두 번 누르기 간격(`DOUBLE_TAP`)이 지난 뒤에야 톡으로 확정 (사용자 결정 ②). 물 뿌리기 감동은 그날 거듭될수록 ×0.6.

**R5. 깨닫기 전 / 뒤**
- **깨닫기 전**: 결과(물·볕·집음)는 그대로 일어나고, 주민은 **목격**만 한다 — `Awakening.witness`로 경이를 쌓고, 아이·노인이 먼저 하늘을 가리킨다. **믿음은 오르지 않는다** (사용자 결정 ⑤ — 모든 `bless_all`·믿음 더하기는 `aware`일 때만; 지금 등불 `_after_lamp`가 문 없이 0.06을 더함 → 고침). 주민 말·연대기에 '거인'·'거인님'·'하늘의 분' 없음 (STORY 4 — 마을이 고른 부르는 말은 깨달은 뒤에만).
- **깨달은 뒤**: 같은 손짓이 '기적'이 되어 믿음 조금↑ (이미 있는 SPRAY_BELIEF·PICK_BELIEF·등불 0.06). 처음 쓴 날 연대기 한 줄.

**R6. 손은 보이지 않는다**: 손짓마다 화면 위에서 큰 손 그림자가 내려오며 짙어지고, 도구 끝(물방울·낟알·핀셋 끝·동심원)만 순백·은청(P6). 끝나면 은빛 먼지를 남기고 위로. 3D 손 모델 없음.

**R7. 뚜껑은 손짓이 연다**: 물 뿌리기·핀셋·내려 주기는 뚜껑을 저절로 열고 곧 닫는다. 유리 톡·닦기·등불은 병 밖 손짓이라 열지 않는다.

### States and Transitions

**도구 상태 (별지기 전체, 저장 — 거인 묶음 `firsts`)**: 잠김 → (열리는 일) → 열림·첫 쪽지 대기 → (한 번 씀) → 열림. 되돌아가지 않는다. 옛 저장(값 없음)은 모두 열림.

**손짓 하나의 흐름 (화면)**
| 상태 | 들어올 때 | 나갈 때 |
|---|---|---|
| 쉼 | — | [손] 열기 / 유리 톡 |
| 겨눔 | 내려 주기·물·핀셋·등불 고름 → 땅 위 그림자(손가락 40dp 위), 위험하면 붉은 테 | [놓기] / [그만] / 다른 시트 열림 |
| 하는 중 (1~2초) | 입력 기록, 그림자 내려옴 | 결과 연출 끝 |
| 거절 | 쿨타임·대상 없음 → 한 줄 말 ("집을 것이 없어요") | 1.5초 |

**마을의 대가 단계 (그날)**: 무료(톡 1~3번 · 등불 1번) → 대가(톡 4번째 · 등불 2번째부터) — 주민 반응이 '올려다봄' → '움찔' → '웅크림'으로 단계만 보임 (숫자 없음, 두려움 단계는 #10).

## Formulas

**F1. 톡의 두려움**: `n > FREE → fear_r += FEAR_TAP × r.f("fear_rise")` (모든 주민)
| 기호 | 값 | 뜻 |
|---|---|---|
| n | 1~ | 그날 이 병의 톡 횟수 |
| FREE | 3 (`FEAR_FREE_PER_DAY`) | 무료 횟수 |
| FEAR_TAP | 0.05 | 한 번 |
| fear_rise | 0.5 / 1 / 1.5 | 혈통 담대 / 보통 / 겁 많음 |
- 예: 보통 사람이 무서움(0.6)까지 → 무료 3 + 12번 = **15번** (needs-and-mood F6과 같음).

**F2. 등불의 두려움**: `n_lamp > LAMP_FREE → fear_r += FEAR_ROTATE × lamp_mult × fear_rise` — LAMP_FREE 1 (사용자 결정 ①), FEAR_ROTATE 0.1, lamp_mult 0.5(발견 '해의 길') / 1. 예: 하루 3번 옮김, 해의 길 없음, 보통 사람 → 2·3번째에 +0.1씩 = **+0.2** (불안 단계 문턱 0.3 아래). 해의 길이 있으면 +0.1.

**F3. 경이 (깨닫기 전)**: `wonder += base_k × TAP_FADE^(m) × share`, `share = clamp(Σw / N, 0, 1.5)` (깨어 본 사람 w = 1, 아이·노인 1.5)
| kind | base | | kind | base |
|---|---|---|---|---|
| tap | 15 (그날 m번째 ×0.6^m) | | spray(water) | 35 |
| drop | 40 | | tweeze | 35 |
| lamp | 25 | | wipe | 10 |
- WONDER_NEED 60. 예: 10명 중 어른 6명만 깨어 봄(share 0.6), 그날 톡 4번 → 15 × (1+0.6+0.36+0.216) × 0.6 = **19.6** — 톡만으로는 하루에 깨닫지 못함. 같은 마을에 낟알 내려 주기 한 번(40 × 0.6 = 24) 더해 43.6.

**F4. 물 뿌리기 넘침**: 지난 `SPRAY_SOAK`(1시간) 안 반경 3칸 안에 적신 기록이 `SPRAY_FLOOD_AT − 1`(2)개 이상이면 넘침 → 깊이 0.05, 반경 +1. 보통 속도(병 하루 = 현실 5분)에서 쿨타임 30 병 초 ≈ 현실 0.1초라 쿨타임은 사실상 없고, **넘침 규칙이 실제 대가**다. 같은 까닭으로 SPRAY_SOAK 1시간 ≈ 현실 12.5초 — 연타하면 넘치지만 자리를 옮기면 대가가 없다 (OQ5).

**F5. 깨달은 뒤 물 뿌리기 믿음**: `belief += SPRAY_BELIEF × SPRAY_FADE^(k−1)` (k = 그날 k번째). 예: 하루 3번 → 0.03 + 0.018 + 0.0108 = 0.059.

## Edge Cases

1. **비운 동안·따라잡기**: 손짓 입력 없음 → 횟수·쿨타임만 시간으로 흐름. 날이 바뀌면 횟수 0.
2. **여러 병**: 도구 열림은 별지기 전체(한 병에서 열리면 모두). 그날 횟수·쿨타임·적신 자리는 병(무리)마다. 넓은 세상에서 등불은 같은 물을 쓰는 모든 무리가 함께 겪고 각자 두려움 셈.
3. **모두 잠든 밤의 톡**: 목격자 0 → 경이 0. 두려움은 지금 코드에서 잠든 사람에게도 오름 → OQ1.
4. **잘못 누름**: 주민·제단을 못 맞힌 빈 땅 누름도 톡이다 (사용자 결정 ② — 의도). 주민 누름 반경 24dp가 빗나감을 줄이고, 무료 3번이 첫 실수를 받아 준다. 겨누는 중(내려 주기·물·핀셋)의 누름은 톡이 아니다.
5. **병 밖 두 번 눌러 들어가기** (사용자 결정 ②): 첫 누름을 `DOUBLE_TAP` 동안 미뤄 두고, 두 번째가 오면 들어가기만 (톡 0번), 안 오면 그때 톡 1번으로 확정. 소리는 바로 내도 됨 (시뮬 입력만 미룸).
6. **겨누는 중 위기가 끝남 / 대상이 사라짐**: 핀셋은 놓는 순간 다시 찾음, 없으면 거절 (쿨타임 없음).
7. **내려 주기로 집·사람 위**: 경고 후 허용 — 부서짐·다침은 #9·#13 규칙, 깨달은 마을은 두려움 (OPENING 규칙 따름).
8. **사람 0명**: 손짓 결과(물·볕)는 일어나고 두려움·경이·믿음은 없음.
9. **옛 저장**: 도구 모두 열림, 없앤 손짓 값(cups·curtain)은 읽고 버림.
10. **떠돌이 물방울이 없을 때의 톡**: 올려다봄·경이·두려움만 (MVP의 톡 전부).

## Game Feel

- 누르고 **0.5초 안에** 그림자, **1초 안에** 결과(물·집음·올려다봄).
- 톡 1~3번: 올려다봄·아이 손짓 → 즐거움. 4번째부터 움찔 → "손이 무겁다"를 화면으로 배움.
- 새 도구는 그 도구가 필요한 화면 앞에서 열려 "아, 이걸로 하는구나" (발견).

## Acceptance Criteria

모두 헤드리스 (묶음 `giant_touch`).
1. **톡 무료 3번**: Given 보통 주민 10명, 두려움 0 · When 그날 톡 4번 · Then 1~3번째 두려움 변화 0, 4번째 뒤 모두 0.05 (±1e-6), `giant_acted` 4번 (free 셋 true).
2. **날 바뀜**: Given 그날 톡 5번 · When 다음 날 톡 1번 · Then 두려움 변화 0.
3. **등불 대가 (1번 무료)**: Given 두려움 0, 해의 길 없음 · When 그날 1번째 옮기기 · Then 변화 0; 2번째 → +0.1 × fear_rise. 해의 길이 있으면 2번째 +0.05 × fear_rise. 톡 횟수는 등불에 섞이지 않음 (톡 3번 뒤 등불 1번 → 변화 0).
4. **깨닫기 전 믿음 없음**: Given aware = false · When 물 뿌리기·등불·핀셋·내려 주기 각 1번 · Then 모든 belief = 0, wonder > 0, 연대기·말에 '거인' 문자열 없음.
5. **깨달은 뒤 믿음**: Given aware · When 그날 물 뿌리기 3번 · Then 평균 belief 증가 0.059 ± 1e-4.
6. **경이 감쇠 (F3)**: Given 10명 중 어른 6 깨어 있음 · When 톡 4번 · Then wonder 19.6 ± 0.01.
7. **넘침**: Given 같은 자리 1시간 안 물 뿌리기 3번(쿨타임 지남) · Then 3번째만 `spray_flooded`, 죽음 0.
8. **도구 열림 전체 공유**: Given 병 A에서 `tool_unlocked{spray}` · Then 병 B 손 메뉴에도 물 뿌리기 있음, 다시 사건 안 냄.
9. **잠긴 도구 없음**: Given 새 별지기 · Then 손 메뉴 = 내려 주기만 (자리 0개).
10. **소원이 엶**: Given 핀셋 잠김 · When 'pest' 소원을 들어줌 · Then `tool_unlocked{tweeze, cause: wish}`.
11. **입력 결정성 (ADR)**: 같은 씨앗·같은 손짓 입력 기록으로 연출 켬/끔, ×1/×8 → 병 2일 뒤 물·두려움·경이·사건 줄 같음.
12. **지켜봄 무관**: 같은 입력, `set_watching` 기록만 다름 → 손짓 결과 같음 (지켜봄이 바꾸는 다른 계통 값 제외).
13. **사건 모양**: 손길 사건의 v에 Object 없음, kind가 event-kinds.md에 있음, emit 앞뒤 RNG 상태 같음.
14. **없앤 손짓**: `Village`·`GiantHand`·손 메뉴·수첩·`WONDER`에 cup·curtain·blow·lid 입구가 없음 (옛 저장 값은 읽고 버림, 불러오기 오류 없음).
15. **손 모델 없음**: 내려 주기·물·핀셋 겨눔 장면 트리에 손 메쉬 없음 (그림자·도구 끝·물건만).
16. **두 번 눌러 들어가기**: Given 병 밖 · When `DOUBLE_TAP` 안에 두 번 누름 · Then 그날 톡 0, `giant_acted` 0. 한 번만 누름 → 간격 뒤 톡 1.
17. **세게 친 톡 없음**: 화면 손짓 처리(`_on_tap`·드래그·길게 누름)로 `tap_glass(hard=true)`에 닿는 길이 없음 (개발 키만).
18. **끌어 겨누기**: 물 뿌리기·핀셋을 고른 뒤 그림자를 화면 가운데가 아닌 자리로 끌어 놓음 → 결과가 그 땅 자리에서 일어남 (±0.5칸).
