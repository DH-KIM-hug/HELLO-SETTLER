## Summary

지갑·상점은 **별지기(플레이어)의 돈 = 지폐**를 다룬다. 지폐는 제단 공물을 **받아** 별지기의 장터에 팔 때만 생기고(#21이 양을, 이 계통이 값을), 상점의 물건·설계도·이주민·등불·제단 넓히기·새 병에 쓰인다. 산 것은 **별지기의 손**(5칸)에 들리고, 뚜껑을 열어 **바깥 크기**로 떨어뜨린다. 마을은 그것을 '하늘에서 내려온 것'으로만 안다.

> **Quick reference** — Layer: `Economy` · Priority: `MVP` · Key deps: `제단·공물(21), 마을 경제(16), 깨달음(20), 손길(19)` · 담당 파일: 새 `sim/giant.gd`의 `Wallet` 부분 (`Market` static → 거인 인스턴스, ADR-0001 5절), `sim/shop.gd`, `sim/sky_drops.gd`

**메인 판단 (사용자 위임, 2026-11-08)**: D1 **값의 기준은 코드(v5)** — SHOP.md·GD 12.1을 맞춤 · D2 **생물 탭 정리**: 작은 강아지 한 쌍·진딧물 한 무리·송사리 한 줌만 (돼지·양·소·닭·당나귀·사슴·토끼 내림) · D3 **하루 장터 완만 상한**(빨리감기 수입 고삐, F4) · D4 **메추리알** 800지폐, 병마다 3일에 하나, 2일차부터 · D5 `Market` static을 이 GDD 구현 때 **거인 인스턴스로** 옮김 · (덧) 먹을 것 카드 값은 마을 크기 비례 (F3 — #16 F5 되팔기 막기).

## Overview

- **지폐는 거인 단위**: 모든 병이 한 지갑을 쓴다. 손 5칸·등불·이주민 하루 횟수·첫 제물 웃돈도 거인 단위.
- **수입원(수도꼭지)은 셋**: 공물 받기 · 강제로 거두기 · 첫 제물 웃돈 600 (한 번). 그 밖에 지폐가 생기는 길은 없다. **유료 재화 없음** (BM 보류).
- **장터**: 같은 물건을 현실 하루에 많이 팔수록 단가가 내려가고(F1), 그날 받은 지폐 총액이 크면 전체가 완만히 줄어든다(F4).
- **상점**: 탭이 마을의 일에 맞춰 하나씩 열리고, 카드마다 '별지기에게는 / 병 안에서는' 두 줄.
- **떨어뜨릴 수 있는 것**(R5): 별지기의 방의 작은 물건 = 병 안의 산더미. 진짜 크기 짐승·사람의 물건·발견은 내려 줄 수 없다.
- 화면 호칭은 **별지기** (STORY 4). 문서 안 작업 용어 '거인'은 그대로.

## Player Fantasy

**"각설탕 한 조각이 저 사람들에겐 하얀 돌집이구나."** 별지기는 손톱만 한 것을 손가락으로 집어 뚜껑 틈으로 떨어뜨리고, 소인들이 몰려와 산을 깎아 나르는 것을 본다. 지폐는 마을이 바친 것에서 오므로 **마을을 잘 돌보면 손이 넉넉해진다**. 무엇을 살지 고민한다 — 지금 마을을 키울 이주민인가, 오래 비워도 되는 등불인가, 두 번째 세상인가 (기둥 4).
- 메추리알 하나에 온 마을이 사흘 잔치 — "내 손이 큰 기쁨을 만들었다".
- 집 위에 떨어뜨리면 집이 부서진다 — 손이 무겁다는 것을 미리보기가 먼저 알려 준다.

## Detailed Design

### Core Rules

**R1. 지갑**
1. `notes`(실수), 0 아래로 내려가지 않음. `pay(cost)`는 모자라면 거절, 빚 없음.
2. 쓰기 경로: 장터 판매(`sell`) · 첫 제물 웃돈 · 상점·등불·제단·병·키트 값 치르기. 그 밖은 금지 (시험).
3. 환불 없음. 손에 든 것은 저장된다.

**R2. 별지기의 장터**
1. `take_offering`(#21)과 `force_take`가 `sell(item, n)`을 부른다. 값 = F1 × F4.
2. '그날' = 기기 현실 날짜, **모든 병 합산** (`sold`·`day_total`).
3. 장터는 #16의 기본가만 읽는다. 거인 몫(gift)·주화·알은 팔 수 없다.

**R3. 상점 진열** (지금 코드 `Shop.update_unlocks` 그대로 + 바뀐 것)
| 탭 | 열리는 때 | 물건 |
|---|---|---|
| 건물 (설계도) | 1일차 | 그 시대(또는 이전) 건물의 설계도, 병마다 종류마다 한 번 |
| 먹을 것·재료 | 1일차 빵 부스러기·하늘 낟알 한 줌(무료, 첫 빵 전) → 2일차 전부 | 빵 부스러기·쌀 한 톨·밀 이삭·각설탕·**메추리알**·나무젓가락·자갈·녹슨 못(철기) |
| 이주민 | 2일차 | 뽑기 (확률 공개) |
| 돌봄 | 첫 병자·첫 위기 조짐 | 알약·반창고·마른 약초·소금 (나머지 '곧') |
| 땅 | 첫 수확 다음 날 | 영양제 앰플, 광맥 돌 4종 (돌마다 시대) |
| 생물 (D2) | 마을 시대 | 작은 강아지 한 쌍 · 진딧물 한 무리 · 송사리 한 줌 (송사리가 줄었을 때만) |
| 꾸미기 | 3일차 ('곧') | 조약돌·병 받침·유리 빛깔·코르크 무늬 |
- 탭이 열리는 순간 상점 단추 옆 작은 반짝임 (빨간 점 금지). 선반 화면: 등불·키트·새 병.

**R4. 손의 흐름** (SHOP 3 그대로): 사면 손에 (최대 5, 거인 단위) → 병에서 뚜껑 열기 → 끌어 놓기 → 그림자 미리보기(집·사람 위면 붉게, 창고·제단·모닥불·물 위·유리벽 곁은 불가) → 떨어짐. 설계도는 어디 놓든 촌장 곁에 내려앉고 터는 촌장이 고른다.

**R5. 떨어뜨릴 수 있는 것 (원칙)**
1. **별지기의 방의 작은 물건만**, 병 안에서는 '바깥 크기' (빵 부스러기 = 갈색 바위, 메추리알 = 허리 높이 알).
2. **진짜 크기 짐승은 없다** — 병에 새·큰 짐승이 없다 (GD 3.0). 예외는 이름 붙은 하나, **주민 크기의 작은 강아지**. 진딧물·송사리는 원래 병 안에 사는 소인 크기 생물을 다시 넣는 것.
3. **완성된 건물은 내려오지 않는다** — 설계도만. 다 지은 건물이 통째로 내려오는 것은 소원 들어주기의 기적(#23, 설계도 값 × 2.5)뿐.
4. **발견·지식은 줄 수 없다** (GD 8.5) — 조건만 앞당긴다 (광맥 돌의 암염은 소금을 알아야 캠).
5. 사람의 물건(단추·실패)은 별지기가 내려 준 것만 병 안에 있다.
6. **내려 준 것은 거인 몫** (#16 R3) — 제단으로 되돌아오지 않는다.
7. 한도: 앰플 동시 2, 광맥 돌 종류마다 2, 설계도 종류마다 1, 메추리알 3일에 1, 이주민 현실 하루 5번.

**R6. 메추리알** (D4, 기획서 3.0 '우유·계란 없는 부엌')
1. 카드: 별지기에게는 "메추리알 하나" / 병 안에서는 "허리 높이의 큰 알 — 온 마을이 사흘 잔치를 해요". 800지폐, 2일차부터, 병마다 마지막 알을 떨어뜨린 뒤 병 3일이 지나야 다시 (`EGG_COOLDOWN`).
2. 떨어지면 여럿이 굴려 와 깸 → 창고에 `알` = 식량 3일치(떨어진 때 인구 비례, 전부 거인 몫) + 그날 저녁 **잔치** (#35 축제 행복과 같은 몫 `HAPPY_FESTIVAL`, 혼례·추수 축제와 같은 '최근 3일 축제' 칸).
3. 껍데기는 그릇·욕조·작은 지붕 **모양**으로 남음 (MVP 자원 아님).
4. 깨닫기 전: "하늘에서 큰 알이 떨어졌어!" (경이). 깨달은 뒤: "{w}의 큰 알이다!" — 주민 말에 '계란 사 왔다' 같은 말 없음.
5. 열병 묻어 옴 2% (`FOOD_FEVER_ITEMS`에 추가 — 바깥의 먹는 물건).

**R7. 이주민 뽑기** (BALANCE v3-4 그대로): 그날 300 × 1.5^(n−1), 현실 하루 5번, 확률은 카드의 [확률 보기]에만, 마을 영역 안에만 내려놓음.

**R8. 금지어** (CLAUDE.md 1장): 주민 말·연대기 — 게임·앱·플레이어·휴대폰·키트·상자·구매·상점·거인 없음, '하늘에서 내려온 것'. 별지기 UI는 '지폐·사다·상점' 허용.

## Formulas

**F1. 물건별 포화** (지금 코드): `unit(n) = price × 0.5^((n−1)/MARKET_HALF)`, n개 한꺼번에 = 등비 합 `price × q^n0 × (1 − q^n)/(1 − q)`, `q = 0.5^(1/600)`. 물건 하나 하루 최대 ≈ price × 866.

**F2. 하루 수입 (보통 놀이)** — 기도 한 번 값 `P = N × 8 × 0.5 × (0.3 + 0.7f) × om` (#21 F5b), 병 하루 기도 2번, 보통 = 병 하루 현실 5분.
```
수입_하루 ≈ P × 2 × (놀이 분 / 5) + P × min(slots, 비운 동안 기도 수)
```
| 변수 | 뜻 | 예 |
|---|---|---|
| N / f | 사람 수 / 믿음 0~1 | 15 / 0.7 |
| om | 교회 ×1.3 | 1 |
| slots | 제단 단계 1/2/4/6 | 1 |
- 해 본 예: 15명·f 0.7 → P = 47.4. 30분 놀이 = 기도 12번 = 569 + 비운 12시간(제단 돌무더기 1번치) 47 = **약 616/일**. 20명·f 0.8 → P 68.8 → 약 900/일. BALANCE v5 측정(현실 1~6일 600~1,300)과 맞음.

**F3. 먹을 것 카드 값 (마을 크기 비례, 덧 판단)**: `price_food = base × max(1, N / 15)` — 양이 인구 비례이므로 값도. 예: 쌀 한 톨 15명 180 · 40명 480. #16 F5 되팔기 검사가 큰 마을에서도 지켜짐 (40명·f 1 → budget_day 320 < 480).

**F4. 하루 장터 완만 상한 (D3)**: 그날(현실·모든 병) 판 총액 `T`에 대해 이번 판매에 곱함
```
m(T) = 1                               (T ≤ FREE_V)
m(T) = 0.5 ^ ((T − FREE_V) / HALF_V)   (T > FREE_V)
받는 값 = Σ unit × m(T 그때까지)
```
| 변수 | 값 | 근거 |
|---|---|---|
| FREE_V | 2,000 | 보통 놀이 하루(600~1,300)와 2주 차 둘째 병(2,000) 위 |
| HALF_V | 2,000 | |
- 해 본 예: 보통 30분 616 → m = 1, 영향 0. 빨리감기(병 하루 24초)로 30분 = 기도 150번 ≈ 7,100 → 2,000 + 2,000/ln2 × (1 − 0.5^2.55) = 2,000 + 2,885 × 0.83 = **약 4,400** (영향 없을 때의 62%). 큰 마을 둘(하루 4,000) → 2,000 + 2,885 × 0.5 = 3,440.
- 넘는 순간 장터 시트에 "오늘 장터가 붐벼요 — 내일 값이 돌아와요" (숫자 없이, `market_busy`).

**F5. 사는 데 걸리는 날** (F2의 616/일 기준 — 보통 마을 1~6일차)
| 무엇 | 값 | 날 (현실) |
|---|---|---|
| 빵 부스러기 | 100 | 0.16 (약 5분 놀이) |
| 쌀 한 톨 | 180 | 0.3 |
| 이주민 첫 번 | 300 | 0.5 |
| 제재소 설계도 | 500 | 0.8 |
| 제단 2단 | 600 | 1.0 |
| 메추리알 | 800 | 1.3 |
| 각설탕 | 950 | 1.5 |
| 영양제 앰플 | 1,200 | 1.9 |
| 등불 1단 | 1,500 | 2.4 |
| 둘째 병 | 5,000 | 8.1 |
| 등불 3단 | 12,000 | 약 10 (그때 수입 ~1,200) |

**F6. 수도꼭지·하수구** (병 하나, 다 쓰는 것과 늘 쓰는 것)
| 하수구 | 다 씀 (한 번) | 늘 씀 |
|---|---|---|
| 설계도 11종 | 5,600 (병마다) | — |
| 제단 넓히기 | 7,600 (병마다) | — |
| 광맥 돌 (종류마다 2) | 19,400 (병마다) | — |
| 등불 | 18,500 (거인 한 번) | — |
| 키트 | 45,000 (거인 한 번) | — |
| 새 병 | 5,000 / 25,000 / 60,000… | 넷째부터 60,000씩 |
| 이주민 | — | 하루 최대 3,957 |
| 먹을 것·돌봄·앰플·알 | — | 위기·빠듯함마다 |
- 첫 병의 다 쓰는 하수구 합 ≈ 37,000 + 둘째 병 → 하루 600~1,300이면 30~40일. 그 뒤로는 이주민(하루 3,957까지)·새 병이 남은 지폐를 받음 → **끝없이 쌓이지 않음**. 이주민도 영역 인구 상한에 막히면 남는 하수구는 먹을 것·돌봄과 새 병 — 측정 항목(AC12).

## Edge Cases

1. **첫 제물 웃돈**: 거인에게 한 번 600 — 설계도가 200이 된 뒤에도 유지 (첫날 우물 + 첫 이주민 1~2번).
2. **자정 넘김**: `sold`·`T`를 함께 0으로 (기기 날짜). 시계를 되돌려도 하루에 한 번만 (마지막 날짜보다 이전이면 그대로).
3. **손이 가득**: 사기 거절. 병을 바꿔도 손은 같음.
4. **뚜껑 닫힘**: 떨어뜨리기 거절 "뚜껑을 먼저 열어 주세요".
5. **비운 동안**: 이주민은 오지 않고 손에 그대로. 장터는 돌아와 받을 때 그날 값.
6. **알을 집 위에**: 다른 물건처럼 부서짐 + 두려움 +0.05. 알은 **사람을 다치게 하지 않음** (화들짝 피함).
7. **잔치 + 굶주림**: 알이 식량 3일치라 굶주림을 끝냄 — 구출 물건으로도 쓰임 (의도).
8. **옛 저장**: 손의 `작은 사슴 한 쌍` 등 내린 물건 → 불러올 때 값만큼 지폐로 돌려줌 (환불 없음 원칙의 유일한 예외, 이음 판 옮김).
9. **빨리감기**: F4가 받는 값을 줄일 뿐 공물·기도 규칙은 그대로 (결과는 병 시간 기준).

## Visual/Audio Requirements

- 카드 그림: 별지기 크기 사진풍 아이콘 (메추리알 = 얼룩 알 하나). 병 안: 허리 높이 얼룩 알, 깨면 노른자 웅덩이에 주민이 그릇을 들고 모임.
- 떨어지는 그림자가 먼저 커짐 (씨앗비·알 같음). 받기: 손가락 → 0.3초 빛 → 지폐 숫자 올라감 + 짤랑.
- `market_busy`: 소리 없음, 장터 줄의 작은 등 하나가 흐려짐 (색 + 모양).

## Game Feel

- 사고 1초 안에 손 칸에 물건이 앉음, 떨어뜨리고 1초 안에 주민이 올려다봄.
- 첫 주는 하루 수입으로 '돌봄 하나 또는 이주민 1~2명 또는 재료 몇 개' — 고민하는 눈높이.
- 빨리감기로 벌어도 손해는 아니지만 "오늘은 붐빈다"로 천천히 멈춤 — 벌이 아니라 하루의 결.

## Acceptance Criteria

모두 헤드리스 (묶음 `wallet`).
1. **포화**: 빵 600개를 한 번에 → 3.2 × (1 − 0.5)/(1 − q) ≈ 1,385 (±1), 하나씩 600번과 같음 (±1e-6).
2. **하루 상한 F4**: T = 1,999 → m 1; T = 4,000 → 0.5. 보통 30분(15명·f 0.7) 수입 616 ± 10%에서 영향 0.
3. **자정**: 오늘 날짜를 바꾸면 sold·T 0.
4. **지폐는 세 길로만**: 시험 병 10일 동안 notes 변화 = 판매 + 웃돈 − 지출 (차이 < 1e-6).
5. **웃돈 한 번**: 병 둘에서 첫 받기 → +600은 한 번.
6. **설계도 한 번**: 같은 병 둘째 설계도 '이미 받았어요', 다른 병은 살 수 있음.
7. **한도**: 앰플 3번째·광맥 돌 3번째·손 6번째·이주민 6번째·알 3일 안 둘째 → 거절, 까닭 한 줄.
8. **먹을 것 값 F3**: 15명 쌀 180, 30명 360.
9. **메추리알**: 떨어뜨림 → 알 = 3일치 식량, 모두 gift, `egg_feast` 1번, 사흘 '축제' 행복 칸, 제단에 알 0.
10. **생물 탭 D2**: 진열에 돼지·양·소·닭·당나귀·사슴·토끼 없음. 옛 저장의 손에 든 것은 지폐로 돌려받음.
11. **금지어**: sky_drops SAY·BOOK·알 대사 전부에 금지어(게임·앱·플레이어·휴대폰·키트·상자·구매·상점·거인) 0, 깨닫기 전 대사에 `{w}` 0.
