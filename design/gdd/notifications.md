## Summary

별지기가 병을 내려놓을 때 **기기 안 로컬 알림**을 예약하고(서버 없음), 세션을 부드럽게 닫는 계통이다. 알림은 **설정에서 켠 경우만, 하루 최대 2번, 밤 10시~아침 8시 금지**, 출석 압박·보상 미끼 없이 "그 병에서 일어날 일" 하나를 다정하게 알린다. 세션 끝 훅은 나갈 때 "이따 와서 봐 주세요" 한 줄과 등불 상태를 보여 주는 것까지다.

> **Quick reference** — Layer: `Polish/Meta` · Priority: `MVP` · Key deps: `사건 흐름(7), 병 시간(1), 제단(21)` · 담당 파일: `save/save_manager.gd` `schedule_local_notifications`(지금은 계산·출력만) → 새 `meta/notifier.gd` · 안드로이드 플러그인(로컬 알림)

**메인 판단 (사용자 위임, 2026-11-08)**: A1 **MVP 알림 종류는 둘** — ① 제단이 가득 참 ② 등불이 꺼짐 (SAVE 5의 '첫 출생·첫 사망'은 미리 알 수 없어 뺌, 위기 조짐 알림은 위기(VS)와 함께) · A2 **기본값 꺼짐**, 첫 제단 안내 창(2c) 뒤 한 번 "제단이 가득 차면 알려 드릴까요?" [알려 줘요]/[괜찮아요] (안드로이드 13 권한 요청도 이때) · A3 **문장은 별지기에게 하는 말**, '별지기님' 호칭, 숫자 없음 · A4 **예약은 앱이 뒤로 갈 때 다시 계산, 앱이 앞으로 오면 모두 취소** · A5 **알림을 누르면 거인의 방 → 돌아온 편지** (#27, 바로 병 안 아님).

## Overview

- 병은 비운 동안 **등불이 타는 시간만** 흐른다 (SAVE 3). 그래서 미래 사건은 계산할 수 있다: 제단이 차는 시각(`altar_full_in`)과 등불이 꺼지는 시각.
- 알림은 **그 병의 시간 계산**을 읽기만 한다 — 시뮬을 미리 돌리지 않는다 (따라잡기는 돌아왔을 때).
- 세션 끝: 뒤로 가기 → "별지기의 방으로 돌아갈까요?" → 저장 → 방에서 병을 선반에 내려놓는 짧은 장면 + 등불 한 줄 "등불은 12시간 탈 거예요" → 앱 밖.

## Player Fantasy

**"제단에 제물이 가득 쌓였어요."** — 휴대폰이 잠깐 떨리고, 나는 '그들이 오늘도 기도했구나'를 안다. 혼내거나 조르지 않는 알림, 받아도 기분 좋은 알림 (SDT: Relatedness, 반대로 손실 회피 미끼는 쓰지 않음). 나가는 순간에도 "이따 와서 무슨 일이 있었는지 봐 주세요"로 다음 만남을 약속한다.

## Detailed Design

### Core Rules

**R1. 켜짐 조건**: 설정 '알림' 켬 ∧ 기기 권한 있음. 꺼져 있으면 예약 0.
**R2. 종류 (A1)**
| id | 언제 (현실 시각) | 문장 |
|---|---|---|
| `altar_full` | 지금 + `altar_full_in(v)` (가장 이른 병) | "별지기님, 제단에 제물이 가득 쌓였어요." |
| `lamp_out` | 지금 + 등불 남은 시간 | "등불이 꺼졌어요. 병 속 마을이 조용히 잠들었어요." |
| (VS) `crisis_sign` | 위기 조짐 예측 | "유리에 김이 서리기 시작했어요." |
**R3. 하루 2번**: 같은 현실 날 예약 ≤ 2. 넘치면 무게(altar_full > lamp_out) 순.
**R4. 조용한 시간**: 22:00~08:00에 걸리면 08:00으로 민다(지금 코드 그대로). 08:00에 둘이 겹치면 하나로 합침("제단이 가득 차고, 등불도 꺼졌어요.").
**R5. 가까운 알림 버림**: 예약 시각이 지금부터 `MIN_LEAD`(30분) 안이면 보내지 않음 — 방금 나간 사람을 부르지 않게.
**R6. 앞으로 오면 취소 (A4)**: 앱이 앞으로 오면 예약 모두 취소, 뒤로 갈 때(`NOTIFICATION_APPLICATION_PAUSED`·`WM_CLOSE`) 다시 계산.
**R7. 누름 (A5)**: 알림을 누르면 거인의 방(타이틀) → 따라잡기 → 돌아온 편지. 알림 id는 편지 '기다리는 것' 맨 위 줄을 고른다.
**R8. 금지 문장**: "지금 안 오면…", "놓치면", 보상·한정·카운트다운, 숫자·확률, 주민의 목소리 흉내(알림은 별지기 UI).
**R9. 시뮬 무관**: 알림은 시뮬 값을 바꾸지 않고, 사건 흐름에 쓰지 않는다. 읽기: `Altar.slots/used`, `OFFER_HOURS`, 등불 남은 시간.

### States and Transitions

`꺼짐` → (설정 켬 + 권한) `켜짐·대기` → (앱 뒤로) `예약됨` → (앱 앞으로) 취소 → `켜짐·대기`. 권한 거절 → `꺼짐`, 설정에 "기기 설정에서 알림을 허락해 주세요" 한 줄.

## Formulas

**F1. 제단이 차는 시각** (지금 `altar_full_in`): `need = slots − used`; `need = 0 → 0`; 아니면 `next_prayer + (need − 1) × DAY/2` (병 초 = 비운 현실 초 × 비운 빠르기 몫). 예: 첫 제단(반나절치 = 1칸), 비어 있음, 다음 기도까지 병 3시간 → 현실 = 3시간 ÷ (병 3일/12시간 = ×6) = 30분 → R5로 버림.
- 고칠 점: 지금 코드는 병 초를 그대로 현실 초에 더한다 (`Time.get_unix_time_from_system() + best`) — **비운 빠르기 몫(12시간 = 병 3일, ×6)으로 나눠야** 한다.
**F2. 등불 꺼짐**: `lamp_left_real` (등불 상한 − 이미 탄 시간). 예: 12시간 등불 → 12시간 뒤.
**F3. 조용한 시간 밀기**: `h ∈ [22, 24) ∪ [0, 8) → 다음 08:00`.

## Edge Cases

1. **병 여럿**: 가장 이른 `altar_full` 하나만 (병 이름 붙임: "초록방울의 제단에…").
2. **제단 없음 (깨닫기 전)**: `altar_full` 없음, `lamp_out`만.
3. **사람 0명**: 둘 다 없음.
4. **기기 시각을 바꿈**: 앞으로 오면 다시 계산하므로 무해.
5. **오래 안 옴 (7일↑)**: 알림을 더 보내지 않는다 (재촉 금지) — 등불이 꺼진 뒤엔 0.
6. **권한 영구 거절**: 질문 다시 안 함, 설정에서만.
7. **세션 끝 장면 도중 앱이 죽음**: 저장은 앞에서 끝났다 (#5).

## Visual/Audio Requirements

- 알림 아이콘: 앱 아이콘 + 작은 제단/등불 실루엣 (셀 2톤, 상태바용 흰 실루엣 따로).
- 소리: 기기 기본 (따로 만들지 않음 — 밤에 놀라지 않게).
- 세션 끝 장면: 병이 선반에 놓이고 등불이 작게 흔들림 1.5초, 건너뛸 수 있음.

## Game Feel

- 알림 문장은 한 줄, 15~25자. 읽고 웃을 수 있게.
- 나갈 때 "이따 와서 무슨 일이 있었는지 봐 주세요" — 약속, 협박 아님.

## UI Requirements

- 설정 '알림' 줄: [켜짐]/[꺼짐] + 아래 작은 글 "제단이 가득 찰 때, 등불이 꺼질 때 (하루 두 번까지)".
- A2 질문 창: 안내 창 모양(#26), 그림 = 제단, [알려 줘요]/[괜찮아요].
- 화면 말 '별지기', 금지어는 주민 쪽 규칙과 별개지만 '거인' 없음.

## Acceptance Criteria

1. **꺼짐**: 설정 끔 · When 앱 뒤로 · Then 예약 0.
2. **조용한 시간**: 계산 시각 23:10 → 08:00.
3. **하루 2번**: 같은 날 세 후보 → 2개, 무게 순.
4. **빠르기 몫 (F1 고침)**: Given 비운 빠르기 ×6, 제단까지 병 6시간 · Then 현실 1시간 뒤.
5. **MIN_LEAD**: 25분 뒤 후보 → 보내지 않음.
6. **앞으로 오면 취소**: 예약 2 → 앱 앞으로 → 0.
7. **문장**: 모든 문장에 숫자 0, '거인' 0, 압박 낱말 목록 0.
8. **시뮬 무관**: 알림 켬/끔으로 같은 비운 시간 따라잡기 → 결과 같음.
9. **누름**: 알림으로 열면 편지가 먼저, 병 안 아님.
