# 빛·등불·계절·날씨 (Light, Lamp, Seasons & Weather)

> **Status**: Designed (메인 판단 반영, 2026-11-08 — `/design-review`는 새 세션에서)
> **Author**: 메인 세션 + systems-designer (초안)
> **Last Updated**: 2026-11-08
> **Implements Pillar**: 3 작은 세상의 실감 · 4 의미 있는 손길

## Summary

빛 계통은 병 안의 해 — **거인의 등불** — 이 어느 쪽(네 자리)에서 비추는지, 그에 따라 칸마다 **볕(−1~1)·따뜻함(0~1)**이 얼마인지, 그리고 **병 날짜 → 계절 → 온도(기후대 + 계절 + 낮밤 + 자리)**를 정한다. 넓게 내리는 비는 없으므로 '날씨'는 **기온·김(습도)·새벽 안개·서리**뿐이다. 물(#3)·꽃숲(#6)·건강(#9)·생산(#15)이 이 값을 읽는다.

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `병 시간(1)` · 담당 파일: `sim/lamp.gd`(등불 자리·미리보기), `sim/health.gd` 1~130줄(병 날짜·온도 — 이 GDD로 옮겨 `sim/climate.gd` 새로), `JarWater.warm/sun`·`WorldWater.light`

**메인 판단 (사용자 위임, 2026-11-08)**: ① **계절 = 병 날짜** (창조한 현실 날 + 병에서 흐른 날, 북반구 달력) — GD 4.1의 "현실 달력 그대로"는 21장·HEALTH 1.1·코드와 어긋나 **21장 쪽으로 맞춤**(메인이 4.1 문구 고침) · ② 날짜·온도 함수는 `Health`에서 떼어 새 `Climate`(RefCounted, static 상태 없음)로 · ③ 등불 무료 1번/일·두려움은 #19 소유, 이 계통은 빛을 돌리는 규칙과 미리보기만 · ④ 오프라인 상한 '등불 시간'(`Market.lamp_seconds`)은 같은 이름이지만 #1·#5 소유 — 이 GDD는 **빛으로서의 등불**만.

## Overview

- 빛은 한쪽(창가·등불)에서만 (GD 4.1). 자리 4개: 0 뒤 · 1 왼쪽 · 2 앞 · 3 오른쪽 (lamp.gd:12).
- **볕** `sun = (p · light) / R` (−1 그늘 끝 ~ 1 창가), **따뜻함** `warm = clamp(0.5 + 0.55·sun, 0, 1)`.
- 하루는 병 시계 24시간 (보통 = 현실 5분, #1). 낮밤 기온은 4시 가장 춥고 14시 가장 따뜻.
- **병 날짜**가 계절을 정한다: 3~5 봄, 6~8 여름, 9~11 가을, 12~2 겨울. 보통 속도로 한 철 ≈ 병 91일 ≈ 현실 7.6시간 플레이 (비운 동안 12시간 = 병 3일).
- 온도는 숫자로 주민 쪽에 보이지 않는다 — 입김·땀·서리로.
- 이 계통의 함수는 `is_watching()`을 읽지 않는다.

## Player Fantasy

**"해를 옮기자 해바라기들이 고개를 돌리고, 그늘진 벽에서 폭포가 굵어졌다."** 등불은 거인이 가진 가장 큰 손이다. 한 번 옮기면 그림자가 3초에 걸쳐 돌고, 커다란 해바라기 꽃판 그림자가 마을 위를 쓸고, 며칠 뒤엔 강의 길이 바뀐다. 계절은 꽃의 색으로 온다 — 봄 민들레, 여름 장미·해바라기, 가을 코스모스, 겨울 마른 억새와 서리 (기둥 3·4).

## Detailed Design

### Core Rules

**R1. 등불 자리**: 자리 = 물의 `rot`(0~3). 옮길 때마다 빛 `(x, y) → (y, −x)`. 소형 병은 **데이터가 돌고 빛 고정**(`JarWater.rotate_jar`), 넓은 세상은 **빛이 돎**(`WorldWater.rotate_jar` → `light`) — 같은 뜻 (lamp.gd:2-4, 23-32). 물방울 돌기·호수 자리는 그대로.

**R2. 옮기기 = 미리보기 → 확정**: `Lamp.preview(villages, w, dir)`가 옮긴 뒤의 빛으로 같은 식을 미리 셈 — 골마다 물(up/down/new/gone, `LAMP_UP` 1.25 · `LAMP_DOWN` 0.8 · `MIN_FLUX` 0.03), 호수 자리 따뜻함(±0.12 넘으면 ▲▼), 밭 농사 배율(±6%), 집·마을 곁 강 → 1~3문장 (숫자 없음, lamp.gd:82-). 확정은 #19 `move_lamp` (입력 기록 → 다음 고정 걸음).

**R3. 온도** (F2): `T = 바탕 + 계절 + 낮밤 + SPOT_WARM × warm(자리) + 뚜껑 섞임`.

**R4. 철 자람**: 첫 빵 뒤부터 밭 자람 = `clamp(1 + (T_season − 12) × 0.04, 0.55, 1.1)`, 병 하루에 한 번 셈 (첫 빵 전엔 1.0 — 튜토리얼 숫자 고정, health.gd:35-47).

**R5. 날씨 = 기온·김·안개·서리**:
- 추위/더위 정도(#9 F1)는 이 계통의 T에서.
- 김(`JarAir.humid`)은 땅 젖음·기후·하루 물 순환으로 6시간 시간상수로 다가감 (jar_air.gd:157-161) — 곰팡이·버섯·떠돌이 물방울이 읽음.
- 새벽 안개: humid 높은 날 4~8시 화면 연출 (시뮬 효과 없음).
- 서리·눈: 냉대·툰드라 겨울, T < 0이면 겉흙 '눈' (화면, GD 4.4b). 녹으면 진흙.
- **비·폭풍·가뭄 재해는 없다** (GD 10 — 위기는 작은 세계의 것).

**R6. 계절이 바꾸는 것** (이 계통은 `season`만 주고 각자 셈): 꽃 종류·피는 정도(#6 `DAND_BLOOM`, FloraLook), 과일나무 열매 6~10월(#6), 날벌레 확률(뚜껑), 고뿔 겨울 ×2(#9), 땔감 '추운 철'(#9), 겉흙 색.

## Formulas

**F1. 볕·따뜻함**
```
sun(p) = (p.x·l.x + p.y·l.y) / R          warm(p) = clamp(0.5 + 0.55 × sun, 0, 1)
```
| 기호 | 범위 | 뜻 |
|---|---|---|
| p | 원 안 | 칸 자리 (병 좌표) |
| l | 단위벡터 4방향 | 빛 방향 |
| R | 32 / 512 | 반지름 |
| warm | 0~1 | 따뜻함 (sun ≥ 0.91이면 1, ≤ −0.91이면 0) |
- 예: 창가 쪽 반지름 절반 자리 sun 0.5 → warm 0.775.

**F2. 온도**
```
T = base + (−amp_s × cos(2π (doy − 14)/365)) + amp_d × day_curve(h) + 3 × warm
day_curve: 4→14시 −cos(π(h−4)/10), 14→4시 cos(π·s), s = ((h−14) mod 24)/14
```
| 기호 | 값 | 출처 |
|---|---|---|
| base / amp_s / amp_d | 온대 12/11/4 · 냉대 3/15/4 · 아열대 18/8/5 · 열대 26/2/3 · 툰드라 −6/14/3 · 사막 24/10/9 | `Balance.CLIMATES` |
| doy | 0~364 | 창조 날 doy + 흐른 병 날 (소수) |
| SPOT_WARM | 3 | 자리 몫 |
- 범위: 툰드라 1월 새벽 그늘 ≈ −23 ~ 사막 7월 한낮 창가 ≈ 46. 예: 온대 1월 15일 4시 warm 0.5 → 12 − 11 − 4 + 1.5 = **−1.5**; 7월 15일 14시 → 12 + 11 + 4 + 1.5 = **28.5**.

**F3. 철 자람** `g = clamp(1 + (T_s − 12) × 0.04, 0.55, 1.1)`, T_s = 낮밤·자리 뺀 그날 기온. 예: 온대 1월 T_s 1 → 0.56, 7월 23 → 1.1(상한).

**F4. 미리보기 골 변화** `r = g_new / g_now` → up(r ≥ 1.25) · down(r ≤ 0.8) · new(now < 0.03 ≤ new) · gone. 0 나눔: now < MIN_FLUX면 비율을 셈하지 않음.

## Edge Cases

1. **빨리 돌리기**: 철도 빨라짐 (병 날짜가 기준). ×8 한 시간 = 병 4일.
2. **비운 동안**: 같은 함수 — 철이 바뀌면 `season_changed` 쌓임, 알림은 요약.
3. **같은 자리로 옮기기**: 미리보기 빈 결과, 횟수 안 셈 (#19).
4. **창조 날이 2월 29일**: doy 계산이 윤년 무시 — 3월 1일로 취급.
5. **기기 날짜 바뀜**: 병 날짜는 창조 날 고정 + 병 시간이라 영향 없음.
6. **넓은 세상 여러 무리**: 빛은 병 하나에 하나, 모든 무리가 함께 겪음.
7. **첫 빵 전 계절**: 밭 자람 1.0 고정, 하지만 추위 노출은 있음 → 겨울 창조는 첫날 춥다 (OPENING 확인 — OQ1).
8. **뚜껑 열림 겨울**: 방 기온 −2가 섞임 → 잠깐 추위.

## Visual/Audio Requirements

- 등불 옮김: 그림자 3초 회전, 하늘 가장자리 밝은 쪽 이동, 볕 쪽 유리벽 반짝, 화면 구석 **작은 해 표시** (GD 4.6). 해바라기 꽃판이 등불 쪽으로 천천히 고개, 마을에선 **꽃판 그림자**가 쓸고 지나감 (#6).
- 미리보기: 볕 노랑 / 그늘 파랑 칠, 골 화살표 파랑 ↑ · 빨강 ↓ · 점선 새로 — **색 + 모양** 함께 (아트 바이블 7.10).
- 계절: 겉흙 색·꽃 종류·큰 나무(벚꽃·은행 노랑·단풍) (RENDERING, art-bible).
- 날씨: 입김(추위 0.3↑), 땀방울, 새벽 안개, 서리 반짝. 소리: 등불 옮김 낮은 울림, 겨울 바람 소리 은은하게, 여름 벌레 소리.

## Game Feel

- 등불은 **결과가 크고 느리다** — 그림자는 3초, 물길은 며칠. 하루 1번 무료라 "신중한 한 수".
- 처음 옮기려 하면 노인이 귀띔 (깨달은 뒤 — 깨닫기 전엔 노인이 해의 길 이야기를 '거인' 없이).
- 계절은 플레이 몇 시간마다 바뀌어 "돌아오면 꽃이 바뀌어 있다".

## Acceptance Criteria

모두 헤드리스 (묶음 `climate`).
1. **온도**: 온대, 창조 1월 15일, 4시, warm 0.5 → T = −1.5 ± 0.05; 7월 15일 14시 → 28.5 ± 0.05.
2. **낮밤 연속**: day_curve(4) = −1, (14) = 1, 0~24시 이어짐 (이웃 1분 차 < 0.01).
3. **병 날짜**: 창조 3월 30일 7시 + 병 2일 → 4월 1일 '봄'; 11월 30일 + 1일 → '겨울', `season_changed` 1번.
4. **등불 돌림 같음**: 소형 병 데이터 돌림과 넓은 세상 빛 돌림 → 같은 자리의 warm 같음 (±1e-6).
5. **미리보기 = 실제**: 미리보기 'up'인 골이 옮긴 뒤 2일 안에 실제 flux ≥ 1.25배 (넓은 세상 3씨앗, 90% 이상).
6. **철 자람**: 첫 빵 전 1.0, 뒤 온대 1월 0.55~0.6, 7월 1.1.
7. **결정성·연출 무관**: 같은 씨앗·입력 → T·season 배열 같음.
8. **static 없음**: `sim/climate.gd`에 static var 없음 (지금 `Health._wmax` 캐시 같은 것은 인스턴스로).
