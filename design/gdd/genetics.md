> **Status**: Designed (메인 판단 반영, 2026-11-08 — `/design-review`는 새 세션에서)
> **Author**: 메인 세션 + systems-designer (초안)
> **Last Updated**: 2026-11-08

## Summary

유전 계통은 아이가 태어날 때 **두 갈래**를 부모에게서 물려받게 한다: **겉모습 유전자**(피부 톤·키·체격·얼굴은 부모 사이 스펙트럼, 눈·머리색·붉은 머리·머리결·주근깨·대머리는 우성·열성, 드문 변이·점박이)와 **혈통**(능력 값 — 담대·겁 많음·추위 견딤 같은 몇 안 되는 효과). 두 갈래는 **서로 읽지 않는다**: 겉모습은 능력에 아무 영향이 없고, 시뮬은 겉모습 유전자를 읽지 않는다. 인종 이름은 어디에도 없다.

> **Quick reference** — Layer: `Gameplay` · Priority: `MVP` · Key deps: `병 시간(1)` · 담당 파일: `data/genetics.gd`(겉모습, 22바이트), `data/bloodlines.gd`(혈통·능력 `r.f()`), `Resident.genes/blood/fx/stunted`

**메인 판단 (사용자 위임, 2026-11-08)**: ① 방향은 한쪽뿐 — **필요 → 겉모습**(어릴 때 굶주림 키 −0.05)과 **나이 → 겉모습**(흰머리·대머리)만 허용, **능력(혈통) → 겉모습은 이름 붙은 장식 하나만**(‘장수’ 혈통의 이른 은빛 머리 — 겉모습이 능력을 알려 주는 단서, 반대 방향 아님) · ② 겉모습 난수는 `gene_rng` 하나(다른 흐름과 분리, 지금대로) · ③ 고유 특징·등급 뽑기는 #17 인구(출생)가 소유, 이 계통은 혈통 유전만 · ④ 강아지 털 유전은 같은 원리의 별도 표(#33/강아지), 이 계통 규칙을 재사용.

## Overview

- **겉모습**(`Genetics`, BLOODLINES 7장): 사람마다 `PackedByteArray` 22바이트. 연속값(피부·키·체격·얼굴형·코·눈썹) · 대립유전자 6쌍(눈 갈 > 초 > 파 · 짙기 검 > 갈 > 금 · 붉음 열성 · 곱슬 반우성 · 주근깨 우성 · 대머리 성 영향) · 드문 변이(0.5%, 유전 안 됨) · 점박이(1벌, 50% 전달) · 차림 취향 씨앗(유전 안 됨).
- **혈통**(`Bloodlines`): 사람마다 최대 2개, 부모 것에서 물려받고 가끔 조부모 것이 다시 나옴(격세유전 — `parent_blood`), 드물게 새로. 효과는 `r.f("fear_rise")` 같은 배율로만 다른 계통에 들어감.
- **스타터 가족**: 겉모습은 거인이 꾸밈(OPENING), 혈통은 키트 표.
- **멀리서 구분**: 실루엣·머리색·모자·옷 색 / 가까이: 얼굴·수염·주근깨 (GD 7.1).

## Player Fantasy

**"엄마를 닮은 붉은 머리, 그런데 눈은 할아버지의 파란 눈."** 거인은 세대를 지나며 가문의 얼굴을 알아본다. 갈색 눈 부부에게서 파란 눈 아이가 나오면 *"할아버지를 닮았구나"* — 숨은 유전자가 이야기가 된다. 겉모습은 그저 그 사람일 뿐, 누가 더 잘나지도 못나지도 않다 (기둥 1·2).

## Detailed Design

### Core Rules

**R1. 태어남** (`Genetics.child(mom, dad, gene_rng)`):
1. 연속값: `부모 평균 + 흔들림` (F1), 0~255로 자름.
2. 대립유전자: 쌍마다 부모가 각자 두 벌 중 하나를 무작위로 줌 (F2). 겉모습 = 우성 규칙 (F3).
3. 드문 변이: `RARE_P` 0.5%로 새로 (짝짝이 눈 · 흰 앞머리 한 줌), 유전 안 됨.
4. 점박이: 가진 부모 한쪽마다 50%, 둘 다 없으면 0.03%로 새로. 무늬 시드는 새로 굴림.
5. 차림 취향 씨앗(`STYLE`)은 늘 새로 — 형제도 머리 모양·꾸밈이 다름.

**R2. 처음 사람** (키트·이주민): 집단 빈도 `P_EYE [0.4, 0.2, 0.4]` · `P_DARK [0.3, 0.4, 0.3]` · 붉음 0.18 · 곱슬 0.45 · 주근깨 0.15 · 대머리 0.3로 각 벌을 굴림. 이주민은 다른 병 사람이라 같은 빈도 (병마다 다른 빈도는 OQ2).

**R3. 나이에 따른 겉모습**: 흰머리는 노년(20 일생 날)부터 8일에 걸쳐(‘장수’ 혈통은 12일부터), 대머리는 남자 한 벌이면 12일부터 정수리 → 20일 대머리(두 벌이면 17일), 여자는 두 벌일 때만.

**R4. 굶주림 → 키**: 아이(4 일생 날 미만)가 처음 굶주리면 키 −0.05 (`stunted`, 한 번). 필요와 기분(#10)이 부름.

**R5. 혈통 유전** (`Bloodlines`): 아이는 부모가 가진 혈통 중에서(+ 조부모 것 격세유전 작은 확률, + 드문 새 혈통) 최대 2개. `blood_src`에 출처(father/mother/grandfather/grandmother/new/kit/migrant) — 화면의 "엄마에게서 물려받은 담대함". 짝 혈통(추위 견딤 + 추위 탐)은 상쇄 (BLOODLINES 1장).

**R6. 읽기 경계** (가장 중요한 규칙):
- 시뮬 파일(`sim/*`)은 `genes`를 읽지 않는다 — 예외 `Genetics.stunt` 쓰기 하나.
- 능력은 `r.f(key)`만: `fear_rise · happiness · house_happy · festival · food · cold · heat · illness · heal`.
- 화면(`view/resident_model.gd`)은 `genes`와 나이·`stunted`를 읽어 그림 — 혈통은 R3 은빛 머리 하나만.
- 문서·화면·코드 주석에 인종 이름 없음 — "피부 톤", "머리색"만.

### States and Transitions

겉모습 유전자는 태어날 때 정해져 바뀌지 않는다. 바뀌는 것은 표시뿐: 아기(둥근 몸) → 아이 → 어른 → (흰머리 시작) → (대머리) → 노년. `stunted`는 거짓 → 참 한 번.

### Interactions with Other Systems

**입력**: #17 출생 (엄마·아빠·`gene_rng`) · #22 이주민·#2 키트 (처음 사람) · #10 굶주린 아이 (`stunt`).
**출력**: `r.f()` 능력 배율 (#9·#10·#11·#15·#17) · 겉모습 읽기 (#28 모델·초상화, #29 사람 목록·가계도) · 닮음 판정 `resembles(child, who)` (#27 연대기 *"할머니를 닮은 주근깨"*).

**사건**
| kind | 언제 | who | v |
|---|---|---|---|
| `&"hidden_trait_shown"` | 부모 둘 다 겉으로 없는 열성 형질(파란 눈·금발·붉은 머리)이 아이에게 보임 | 아이 id | `{"trait": StringName, "from": id}` (가장 가까운 조상 중 그 형질을 보인 사람) |
| `&"rare_mark_born"` | 드문 변이·새 점박이 | 아이 id | `{"mark"}` |
| `&"bloodline_returned"` | 격세유전 | 아이 id | `{"blood", "from"}` |
| `&"child_stunted"` | 키 줄어듦 | 아이 id | `{}` |

## Formulas

**F1. 연속값**
```
g_child = clamp(round((g_mom + g_dad)/2 + 255 × N), 0, 255),  N ~ U(−noise, +noise)
```
| 기호 | 범위 | 뜻 |
|---|---|---|
| g_mom, g_dad | 0~255 | 부모 값 |
| noise | 피부 0.08 · 키·체격 0.1 · 얼굴형·코·눈썹 0.18 | `*_NOISE` |
| g_child | 0~255 | 자름 |
- 예: 피부 60 × 140 → 평균 100, ±20 → 80~120. 키는 굶주림 뒤 −0.05 × 255 ≈ −13.

**F2. 대립유전자 전달** `child = (mom[randi()%2], dad[randi()%2])` — 각 벌 50%.

**F3. 겉모습 규칙**
| 형질 | 규칙 |
|---|---|
| 눈 | min(두 벌) (0 갈 > 1 초 > 2 파) |
| 머리 짙기 | min(두 벌) (0 검 > 1 갈 > 2 금) |
| 붉은 머리 | 두 벌 모두 1일 때만 |
| 머리결 | 1의 개수: 2 곱슬 · 1 웨이브 · 0 직모 |
| 주근깨 | 하나라도 1 |
| 대머리 | 남자 하나라도 · 여자 둘 다 |
- 예: 갈/파 × 갈/파 부부(둘 다 갈색 눈) → 파/파 아이 = 1/2 × 1/2 = **25%** → `hidden_trait_shown{eye_blue}`.

**F4. 처음 사람의 겉 빈도** (R2 빈도에서): 파란 눈 = 0.4² = 16% · 붉은 머리 = 0.18² ≈ 3.2% · 주근깨 = 1 − 0.85² ≈ 28% · 남자 대머리 기질 = 1 − 0.7² = 51% (노년에 보임).

## Edge Cases

1. **옛 저장 (유전자 18바이트)**: 얼굴·코·눈썹·취향은 앞 18바이트에서 정해진 값으로 채움 (`MIN_BYTES`) — 다시 불러도 같은 얼굴.
2. **유전자 없는 아주 옛 저장**: 처음 사람처럼 만들되 사람 id로 씨앗 → 결정적.
3. **한 부모만 알 때** (이주민 아이 등): 없는 쪽은 R2 빈도로 한 번 만든 가상 부모.
4. **남매 혼인 없음** (#17) — 근친 효과는 다루지 않음.
5. **아기 키 줄어듦 두 번**: `stunted`로 한 번만.
6. **겉모습이 결과를 바꾸지 않음 검사**: 겉모습 유전자만 다른 두 마을 → 모든 시뮬 결과 같음 (AC3).
7. **스타터 가족 꾸미기**: 거인이 고른 겉모습은 유전자에 그대로 써 넣음 (그 아이들도 이어받음).

## Acceptance Criteria

모두 헤드리스 (묶음 `genetics`).
1. **멘델 비율**: 갈/파 × 갈/파 부부 아이 10,000명(`gene_rng` 고정) → 파란 눈 25% ± 1.5%.
2. **연속값**: 피부 60 × 140 → 모든 아이 80~120, 평균 100 ± 2.
3. **겉모습 무관**: 겉모습 유전자만 다른 두 마을, 병 10일 → 인구·사망·창고·사건 줄 같음 (키 줄어듦 사건 제외).
4. **시뮬이 genes를 읽지 않음**: `godot/sim/` 안 `genes` 읽기는 `Genetics.stunt` 부르는 한 곳뿐 (정적 검사).
5. **흐름 분리**: 출생 전후 `v.rng`·`health_rng` 상태가 겉모습 계산과 무관 (겉모습 굴림 수를 바꿔도 같음).
6. **옛 저장**: 18바이트 유전자 → 불러오기 두 번 같은 얼굴값.
7. **혈통 출처**: 엄마만 '담대'를 가짐 → 물려받은 아이의 `blood_src` = "mother".
8. **인종 이름 없음**: `data/`·`view/`·`docs/` 문자열 검사에 금지 단어 목록 0개.
9. **stunt 한 번**: 아이 두 번 굶주림 → 키 −0.05 한 번.

## Open Questions

1. **‘장수’ 혈통의 은빛 머리**: 능력이 겉모습에 드러나는 유일한 예외 — 유지할지(단서로 좋음), 없앨지 사용자 확인 (메인 판단 ①은 유지).
2. **병마다 다른 집단 빈도** (기후대마다 피부 톤 바탕을 다르게) — 인종 연상 위험이 있어 MVP는 같은 빈도, 사용자 결정 필요.
3. **고유 특징 유전**(GD 7.2 "부모 특징이 유전되어 가문마다 색") — #17과 함께 정함.

**Ownership**: `godot/data/genetics.gd` (`class_name Genetics`, static 함수만 — 상태 없음, 색표 상수) · `godot/data/bloodlines.gd` (`class_name Bloodlines`, 표 + 유전 함수). 상태는 `Resident.genes/blood/parent_blood/blood_src/fx/stunted`. 난수는 `Village.gene_rng`. 출생 시점·특징·등급은 #17.
