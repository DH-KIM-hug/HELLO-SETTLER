> **Status**: Designed (사용자 결정 반영, 2026-11-07 — `/design-review`는 새 세션에서)

> **Last Updated**: 2026-11-07

## Summary

필요와 기분은 주민 한 사람마다 **배고픔(0~4)·행복(0~1)·두려움(0~1)** 세 값을 갖고, 먹은 것·집·축제·슬픔·거인의 손길에 따라 바꾸는 계통이다. 주민은 이 값을 숫자가 아닌 **행동**(창고 앞 서성임, 자기 몫을 아이에게 양보, 축 처진 어깨, 숨기)으로 보여 주고, 건강·일정·인구·제단은 이 값을 읽어 결과를 낸다.

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `병 시간(1), 유전·겉모습(8, 능력 쪽 혈통만), 생산 사슬(15)` · 담당 파일: `sim/needs.gd` (ADR-0001 이행 5단계의 첫 계통)

**사용자 결정 (2026-11-07)**: 필요는 세 가지뿐 · 배고픔 벌점은 "지난 하루 배고팠던 적" · **먹을 것이 모자라면 아이 먼저 먹임** · **굶주리면 실제로 걸음 ×0.9** (BALANCE 다시 잼) · 주민이 바친 식량 공물을 거인이 받는 것은 '식량 거둠'이 아님 (두려움 없음).

## Overview

- **필요는 세 가지뿐** (사용자 확정): 배고픔·행복·두려움. 잠·놀이·위생 같은 새 필요는 만들지 않는다. 추위·더위·병은 건강(#9) 몫이고 이 계통에는 결과(슬픔·두려움)로만 들어온다.
- **배고픔**은 못 먹은 식량을 쌓은 값. 3 이상이면 굶주림 → #9가 건강을 깎는다.
- **먹을 것이 모자라면 아이 먼저** (사용자 확정): 창고에서 꺼낸 몫은 아기·아이에게 먼저 돌아가고, 남은 몫을 어른이 나눈다. 그래서 빠듯할 때 **어른이 먼저 배고프다** — 거인은 "자기 몫을 아이에게 양보하는 부모"를 본다.
- **행복**은 매일 새벽 여러 요소를 더해 0~1로 자른다. 마을 평균이 출산 환경 배율(#17)이 된다.
- **두려움**은 거인의 지나친 손길·죽음·홍수·병에 오르고 반감기 12시간으로 내려간다. 마을 두려움(평균 × 100)은 신앙 상태(#20)와 공물(#21)이 읽는다.
- **겉모습 유전자는 절대 읽지 않는다.** 사람마다의 차이는 고유 특징·혈통(능력)·나이에서만. 인종 이름 없음.
- **거인이 보는지(presence)는 이 계통의 규칙에 들어가지 않는다** (ADR-0001 3절). 같은 씨앗·같은 입력이면 연출을 켜든 끄든 세 값이 같다.
- 일어난 일은 `events.emit`으로만 밖에 알린다 (ADR-0001).

## Player Fantasy

**"저 아이는 먹었구나… 엄마가 굶고 있네."** 거인은 숫자로 알지 않는다. 빈 창고 앞에서 어른이 빵 한 조각을 아이 손에 쥐여 주고 돌아서는 모습, 어른 머리 위에 뜬 마른 잎 말풍선의 빵 그림, 저녁 모닥불가가 평소보다 조용한 것을 **보고** 안다. 손을 뻗어 낟알 한 줌을 내려 주면 사람들이 달려와 줍고 "맛있다!"며 펄쩍 뛴다. 이 **안도의 한 박자**가 이 계통이 만드는 핵심 감정이다 (기둥 1·2·4).
- **알아챔 → 도움 → 안도**: 배고픔은 금세 보이고(현실 수십 초), 위험해지기까지는 넉넉한 틈(건강 1 → 0이 현실 5분)이 있다 — "늦지 않았다".
- **기쁨의 날**: 첫 수확 축제 다음 날 아침, 콧노래와 펄쩍 뛰기 — "내가 도운 마을이 잘 산다".
- **양날의 손길** (기둥 4): 유리를 너무 자주 치면 어깨를 움츠리고 숨는다. 손이 무겁다는 것을 화면으로 배운다.
- **그냥 둬도 무너지지 않는다**: 거인이 아무것도 안 해도 60일에 굶어 죽는 사람 0~2명 (BALANCE v5-0) — 불안이 아니라 "도우면 더 좋아진다".

## Detailed Design

### Core Rules

**R1. 배고픔 (사람마다, 걸음마다)**
1. 마을이 이번 걸음에 필요한 식량 `need = Σ 사람별 식량 배율 × dt / FOOD_IV`를 창고에서 꺼낸다 (#15·#16 `consume`). 꺼낸 몫 `got`.
2. **아이 먼저 나누기 (사용자 확정, F1a)**: `got`을 아기·아이(4일 미만)의 필요부터 채우고, 남은 몫을 어른·노인에게 고르게 나눈다. 사람마다 자기 `deficit_r`(0~1)이 생긴다. 아이 몫이 다 채워지지 않을 때만 아이도 모자란다.
3. `deficit_r > 0`이면 F1로 배고픔을 바꾼다 — `HUNGER_EASE = 1`이면 절반 넘게 모자랄 때만 쌓인다 (v5-0). `deficit_r = 0`이면 `dt / FOOD_IV`만큼 풀린다. 0~`HUNGER_MAX`(4)로 자른다 (상수로 뺌, 값 그대로).
4. 배고픔이 `STARVING_AT`(3) 이상이면 **굶주림**. 이 계통은 상태와 까닭만 정하고, 건강 깎기(F2)는 #9가 한다 (계약: 굶주림이면 하루에 건강 1).
5. **굶주리면 걸음 ×0.9** (사용자 확정 — 시뮬 걸음 자체가 느려짐, `STARVE_WALK` 0.9). BALANCE v5-0 측정을 다시 한다.
6. 아이가 굶주리면 키가 한 번 줄어든다 (`Genetics.stunt` — 방향은 필요 → 겉모습 한쪽뿐).
7. 하늘 낟알을 주워 먹으면 그 사람의 배고픔 0, 행복 +`HAPPY_SNACK`(0.08, 상수로 뺌).
8. **마을이 굶주리는 중** `starving_village()` = 이번 걸음 모자람이 있었거나 마지막 모자람부터 `STARVED_RECENT`(1일)가 안 지남. #17·#18·#21이 함께 읽는다.

**R2. 행복 (사람마다, 매일 새벽)**
1. 새벽 6시 F4로 다시 센다: 바탕 + 집 + 음식 가짓수 + 배고픔 + 축제 + 슬픔 + 광장·묘지 + 혈통 + 빵·죽 + 꽃차·낚시·이주민 + 두려움 + 같은 집 '명랑' 식구, 0~1로 자름.
2. 하루 중 작은 기쁨(유모차 아기 +0.03, 하늘 낟알 +0.08)은 지금 값에 바로 더하고 다음 새벽에 새로 센다 ("그날의 기쁨").
3. **배고픔 벌점 = 지난 하루 안에 이 사람의 배고픔이 `HUNGRY_AT`에 닿았던 적이 있음** (사용자 확정 — 예전 '새벽 순간 h > 0.5'는 낮에 굶어도 거의 걸리지 않았음). `Resident.last_hungry_t` 추가, 저장 판 올림.

**R3. 두려움 (사람마다)**
1. 오름 F6: `fear += 양 × fear_rise`(혈통 담대 0.5 · 겁 많음 1.5), 0~1로 자름. 까닭과 양은 HEALTH.md 4장 표.
2. 내려감 F7: 반감기 12시간, 기도 중·축제 뒤 1일 안이면 두 배 빠르게. 1e-4 아래는 0.
3. 마을 두려움 F8 = 평균 × 100.
4. 효과 F9: 두려움 ≥ 0.6이면 일 ×0.7, 낮 결정마다 15% 숨기 (2.5세 이상) · 새벽 행복 −0.1 × 두려움 · 마을 두려움 ≥ 50 → 신앙 경외·공포 (#20) · 굶주리며 바침 (#21, R4).
5. 그날 톡 3번·등불 옮기기 1번까지는 두렵지 않다 (사용자 2026-11-08, 횟수는 #19가 셈).
6. **주민이 스스로 바친 식량 공물을 거인이 받는 것은 '식량 거둠'이 아니다** (사용자 확정) — 두려움 없음. `FEAR_TAKE_FOOD`(+0.1)는 거인이 **창고에서 직접** 집어 갈 때만. 굶으며 바치는 고리가 닫히지 않게.

**R4. 굶주릴 때의 공물 (읽기 규칙 — 실행은 #21)**: 마을이 굶주리는 중이고 마을 두려움 < 50이면 식량을 바치지 않는다. ≥ 50이면 빵·밀·건량을 각각 창고의 10%씩 바친다 (연대기의 어두운 이야기). 이 계통은 `starving_village()`와 `village_fear`만 준다.

**R5. 나이**: 아이 먼저 먹임(R1-2)이 나이 차이의 전부다 (사용자 확정 — 노인 슬픔 배율·아이 문턱 보정은 쓰지 않음). 노인의 추위 예민함은 이미 #9 `FRAIL_AGE_MULT`가 맡으므로 이 계통에서 더하지 않는다.

**R6. 거인이 보는지와 무관**: 이 계통의 함수는 `is_watching()`·`stage_on`·`pace_walk`·카메라를 읽지 않는다 (AC12).

### States and Transitions

**배고픔 단계** (문턱은 지금 값)
| 단계 | 범위 | 들어올 때 행동 | 다른 계통이 읽는 것 |
|---|---|---|---|
| 배부름 | h < 0.5 | 평소 | — |
| 출출함 | 0.5 ≤ h < 0.8 | 식사 시간에 먼저 모닥불로 | — |
| 배고픔 | 0.8 ≤ h < 3 | 창고 앞 서성임(120초), 빵 말풍선, 어른은 아이에게 몫을 양보하는 모습 | 다툼 확률 +0.05 (#35) |

## Formulas

**F1. 배고픔 갱신** (걸음마다, 사람마다)
```
deficit_r > 0:  h' = clamp(h + (deficit_r − (1 − deficit_r) × HUNGER_EASE) × dt / FOOD_IV, 0, HUNGER_MAX)
deficit_r = 0:  h' = max(0, h − dt / FOOD_IV)
```
| 기호 | 범위 | 뜻 | 출처 |
|---|---|---|---|
| h | 0~4 | 배고픔 | `Resident.hunger` |
| deficit_r | 0~1 | 이 사람이 못 먹은 비율 (F1a) | 새 |
| HUNGER_EASE | 0.5~1.5 (1.0) | 먹은 몫이 푸는 세기 | `Balance` |
| dt | 병 초 | 걸음 | 병 시계 |
| FOOD_IV | 900 | 1명이 식량 1개 먹는 간격 | `Balance` |
| HUNGER_MAX | 4.0 | 상한 (상수로 뺌) | 새 이름 |
- 해 본 예: 창고가 비어 deficit_r = 1이면 0 → 3까지 2,700 병 초 (보통 속도 현실 약 9.4초). need = 0이면 deficit 0 (0 나눔 방지 유지).

**F1a. 아이 먼저 나누기** (사용자 확정)
```
need_c = Σ_{아이·아기} food_r × dt / FOOD_IV ;  need_a = Σ_{어른·노인} food_r × dt / FOOD_IV
got_c = min(got, need_c) ;  got_a = got − got_c
deficit_r = 1 − got_c / need_c   (r이 아이, need_c > 0)
deficit_r = 1 − got_a / need_a   (r이 어른, need_a > 0)
```
| 기호 | 범위 | 뜻 |
|---|---|---|
| got | 0~need | 이번 걸음 창고에서 꺼낸 몫 |
| need_c / need_a | ≥ 0 | 아이 쪽 / 어른 쪽 필요 |
| food_r | 0.5~1.2 | 사람별 식량 배율 (혈통 `food`, 아이 몫 포함) |
- 해 본 예: 어른 6·아이 4, 아이 식량 배율 0.6 → need 비율 6 : 2.4. 창고가 절반만 채우면(got = 0.5 × 8.4 = 4.2) 아이는 2.4 다 채움(deficit 0), 어른은 1.8/6 = 0.3 → deficit_r 0.7 → 배고픔이 오름 (0.4/900 per 초). 아이는 배부름 유지.
- 결과: 아이가 굶는 것은 창고가 아이 몫조차 못 채울 때뿐.

**F2. 굶주림 → 건강** (계약, 셈은 #9): `h ≥ STARVING_AT → health −= dt / STARVE_HEALTH_TIME` (1일에 1). 큰 dt(따라잡기 빠른 길)는 문턱을 넘은 뒤 시간만 깎음: `dt_above = max(0, dt − (3 − h0)/기울기)` (AC14).

**F3. 굶주림 걸음** (사용자 확정): `walk_mult(r) = STARVE_WALK (0.9) if is_starving(r) else 1.0` — #12 걸음 속도에 곱함.

**F4. 행복 합** (새벽)
```
H = HAPPY_BASE + (HAPPY_HOME | HAPPY_NO_HOME) + HAPPY_VARIETY×[음식 3종↑]
  + HAPPY_HUNGRY × [t − last_hungry_t < 1일]
  + HAPPY_FESTIVAL × fest_mult × r.f("festival") × [최근 3일 축제·혼례]
  + HAPPY_GRIEF × grave_mult × [t < grief_until] + place_happy + r.f("happiness")
  + food_happy + TEA_HAPPY×[꽃차] + Wildlife.happy + Immigrants.mood + FEAR_HAPPY × fear + 명랑 식구 몫
happiness = clamp(H, 0, 1)
```
| 기호 | 값 | 출처 |
|---|---|---|
| HAPPY_BASE | 0.5 | Balance |
| HAPPY_HOME / NO_HOME | +0.1 / −0.15 | Balance |
| HAPPY_VARIETY | +0.1 | Balance |
| HAPPY_HUNGRY | −0.3 | Balance |
| HAPPY_FESTIVAL · fest_mult · festival | +0.1 · 1~1.2 · 0.5~1.2 | Balance·혈통 |
| HAPPY_GRIEF · grave_mult | −0.2 · 0.5(묘지)/1 | Balance |
| food_happy | +0.06 빵 / −0.04 죽만 | HAPPY_BREAD·PORRIDGE_ONLY |
| TEA_HAPPY · FEAR_HAPPY | +0.05 · −0.1/두려움 1 | Balance |
| last_hungry_t | 병 초 | 새 (h ≥ HUNGRY_AT일 때 갱신) |
- 해 본 예: 집·3종·빵·두려움 0.3·배고픈 적 없음 → 0.5+0.1+0.1+0.06−0.03 = **0.73** (보통).

**F5. 출산 환경 (행복 몫)**: `avg = Σhappiness/N` (N=0 → 0), `env_happy = 0.9 (avg<0.4) / 1.0 / 1.1 (avg>0.75)`.

**F6. 두려움 오름**: `fear' = clamp(fear + amt × r.f("fear_rise"), 0, 1)` — amt: 톡 0.05 · (세게 친 톡 0.2 — 개발용만) · 등불 0.1(×0.5/1) · 창고에서 식량 거둠 0.1 · 가족 죽음 0.2 · 죽음 목격 0.05(반경 6) · 홍수 0.15 · 앓는 비율 0.05/일. 예: 보통 사람이 0 → 0.6이 되려면 그날 무료 3번 + 12번 = 15번 톡.

**F7. 두려움 내려감**: `s = 2 (기도 중·축제 뒤 1일) / 1`, `fear' = fear × 0.5^(dt·s/FEAR_HALF)`, < 1e-4 → 0. 걸음 크기에 무관. 예: 0.6 → 12시간 뒤 0.3.

**F8. 마을 두려움**: `village_fear = (Σfear/N) × 100` (N=0 → 0), 문턱 50.

**F9. 두려움 효과**: `afraid = fear ≥ 0.6` → 일 ×0.7, 숨기 = afraid ∧ 낮 ∧ 2.5세↑ ∧ `ai_rng < 0.15` (숨기 굴림은 `health_rng`에서 `ai_rng`로 옮김 — 두려움 조정이 병 발생 흐름을 흔들지 않게).

**F10. 단계 판정**: 오를 때 h ≥ 문턱인 가장 높은 단계, 내릴 때 h < 문턱 − `BAND_HYSTERESIS`(배고픔 0.05 · 행복·두려움 0.02).

## Edge Cases

1. **따라잡기**: `Village.step`을 그대로 돌림 — F1 선형, F7 걸음 무관, 새벽마다 `on_dawn`. 큰 dt는 F2 경계 보정 (AC14). 사건은 그대로 쌓고 연출 구독자가 거름, 알림(#30)은 `starving_started`·`food_short_started`만 요약.
2. **아기**: 아이 먼저 나누기에 포함. 2.5세 아래는 숨기·말풍선 없음 — 돌보는 부모 머리 위에 빵 말풍선. 두려움은 오르고 평균에 들어감.
3. **죽은 사람**: 셈에서 빠짐, 사건 없음. 죽음은 가족에게 `grief_until` +3일·두려움 +0.2, 반경 6 깨어 본 사람 +0.05.
4. **축제 + 슬픔 같은 날**: 둘 다 더함. 두려움은 축제 덕에 두 배 빨리. 유족은 춤 고리 밖 모닥불가 (#35 연출, 결과 무관).
5. **두려워서 굶으며 바침**: 마을 두려움 ≥ 50 + 굶주림 → 10% 바침 → 모자람↑ 고리. 막는 것: 하루 2번 기도, 제단 상한, 반감기, 그리고 **주민이 바친 공물을 받는 것은 두려움을 올리지 않음** (사용자 확정).
6. **아이만 남은 마을 / 어른만 남은 마을**: need_c 또는 need_a가 0이면 그쪽 deficit 0 (0 나눔 방지).
7. **거인이 있는지에 따른 규칙**: 이 계통 안에 없음. 보지 않을 때 위기 죽음 아끼기(`OFFLINE_MIN_COUPLES`)는 #9 몫.
8. **저장·불러오기**: 사람 값(hunger·happiness·fear·grief_until·last_hungry_t) `Resident.to_dict`, 마을 값(last_short_t 등) `Needs.to_dict`(판 1). 옛 저장은 last_hungry_t = −1e9. 단계 캐시는 불러온 뒤 다시 셈하고 **그때 사건을 내지 않음** (AC16).
9. **사람 0명**: 모든 값 0, 사건 없음.
10. **새 이주민·새 아기**: 배고픔 0, 행복 0.6, 두려움 0.
11. **하늘 낟알을 먹은 사람만 배고픔 0**: 의도 — 거인의 손이 닿은 사람.
12. **문턱 깜빡임**: F10 히스테리시스.
13. **두려움 1.0에 붙음**: 자름, 1 → 0.6 아래까지 8.8시간.
14. **굶주림 걸음 ×0.9가 나르기를 늦춰 모자람을 키움**: 강화 고리 — BALANCE v5-0 다시 측정으로 확인 (AC15).

## Game Feel

- **알아챔**: 창고가 비면 현실 몇 초 안에 어른이 아이에게 몫을 양보하는 장면, 약 10초 안에 어른들이 배고픔 단계 — "지금 무슨 일이 생겼다".
- **틈**: 굶주림 → 건강 0까지 현실 5분, 보지 않을 때는 #9가 죽음을 아낌 — "늦지 않았다".
- **안도**: 낟알을 내려 주면 주운 사람은 그 자리에서 배고픔 0 + "맛있다!" + 펄쩍. 마을이 다시 먹으면 약 12초 안에 굶주림에서 벗어나 자세가 펴짐. 손을 쓴 뒤 1초 안에 무언가 보임.
- **기분**: 행복은 하루 한 번 바뀌어 묵직하고, 작은 기쁨은 그날만 — 축제 다음 날 아침이 "좋은 날".
- **대가**: 톡 3번까지 자유, 그 뒤 쌓이다가 0.6에서 갑자기 움츠림, 하룻밤이면 반쯤 잊힘 — 벌이 아니라 배움.
- **주의**: 빠듯한 때가 60일에 2~4번보다 잦으면 경보 피로 → v5-0 측정.

## UI Requirements

**거인 UI (숫자 허용 — 아트 바이블 7.9)**
- 주민 상세 막대 5개 (건강·행복·믿음·두려움·배고픔): **한 색(밤색) + 앞 아이콘 + 길이**, 위험 구간 빗금, 빨강·초록 짝 금지. 배고픔 막대 = h / STARVING_AT (0~1로 자름), 배고픔 기준(0.8/3)부터 빗금, 굶주림이면 아이콘을 '!' 모양으로 (색 + 모양 하나). 행복 < 0.4 빗금, 두려움 ≥ 0.6 빗금.
- 상태 줄(말, 숫자 없이): '배고파함' · '아이에게 몫을 양보함' · '굶주리고 있음' · '슬퍼함 (가족을 잃음)' · '무서워함' · '기분이 좋음'.
- 사람 목록: 기분 얼굴 3단계(통일된 기준), "배고픈 사람 먼저" 정렬 칩(선택).
- 첫 빵 전 배고픔 안내 (#26): `food_short_started`를 받으면 반나절마다 수첩 쪽지 "배고파 보여요. 낟알을 곁에 내려 줘요" → [상점 → 하늘 낟알 한 줌]. 차례 7.7의 2단계, 연출 중엔 미룸.
- 돌아온 편지 (#27): 비운 사이 굶주림이 있었으면 숫자 없는 한 줄 ("창고가 빈 날이 있었습니다. 어른들이 아이들 먼저 먹였지요."). 금지어 규칙 그대로.

**주민 쪽**: 말풍선 그림만 (빵·하트), 확률·수치 없음.

## Acceptance Criteria

모두 헤드리스 (묶음 `needs`, AC15는 느린 묶음).
1. **배고픔 문턱**: Given h = 1, EASE = 1 · When deficit_r = 0.5로 900초 · Then h = 1.0 (±1e-6); deficit_r = 0.6이면 1.2.
2. **굶주림 진입**: Given h = 0, 창고 0 · When 10초 걸음 2,700초 · Then h ≥ 3이 처음 2,700 ± 10초, `starving_started` 1번.
3. **회복**: Given h = 4, 모자람 없음 · When 3,600초 · Then h = 0, `starving_ended`·`hunger_band_changed`(to 배부름).
4. **아이 먼저 (F1a)**: Given 어른 6·아이 4, 창고가 필요의 절반 · When 1시간 · Then 아이 모두 h = 0, 어른은 h > 0, `fed_child_first`가 어른마다 1번. Given 창고 0 · Then 아이·어른 모두 오름.
5. **건강 계약**: Given h = 3.5, 건강 1 · When 43,200초 · Then 건강 0.5 (±1e-3).
6. **굶주림 걸음**: Given 굶주린 사람 · Then `walk_mult` = 0.9이고 같은 거리 걷는 시간이 1/0.9배.
7. **행복 합**: Given 집·3종·빵·두려움 0.3·배고픈 적 없음 · When 새벽 · Then 0.73. 모든 벌점이면 [0,1] 안 0.
8. **배고픔 벌점 (지난 하루)**: Given 낮 12시 1시간 h ≥ 0.8, 새벽엔 0 · When 새벽 · Then −0.3 들어감.
9. **환경 배율**: 평균 0.39 / 0.5 / 0.76 → 0.9 / 1.0 / 1.1.
10. **두려움 오름·자르기**: 겁 많음 0.9 + 세게 친 톡 → 1.0, `fear_spike` {cause &"tap_hard"}. 그날 4번째 톡 → 보통 +0.05.
11. **반감기**: 0.8 → 43,200초 뒤 0.4, 기도 중이면 21,600초. 10초·80초 걸음 차이 < 1e-9.
12. **결정성 + 연출 무관 (ADR a)**: 같은 씨앗·같은 지켜봄 입력, 연출 켬/끔으로 병 3일 → 세 값 배열과 필요 사건 줄 같음.
13. **겉모습 무관**: 겉모습 유전자만 다른 두 마을, 병 5일 → 세 값·사건 줄 같음 (키 줄어듦 제외).
14. **걸음 크기 무관**: ×1과 ×8 (고정 걸음) 2일 → 차이 < 1e-6, 굶주림 시작 시각 같음. 따라잡기 빠른 길과 정밀 따라잡기 연대기 같음.
15. **빠듯함 곡선 (BALANCE v5-0, 느린 묶음)**: 3씨앗 × 60일 손 없음 → 빠듯한 때 2~4번, 굶어 죽음 0~2, 비축 10일치↑ 날 < 15%, 인구 14~23. 도우면 0명. **아이 먼저·굶주림 걸음 ×0.9를 넣은 뒤에도 지킴.**
16. **저장·불러오기**: 배고픔 3.2·두려움 0.7 저장 후 불러옴 → 값 같음, 첫 걸음에 단계 사건 없음. 옛 저장(키 없음) 오류 없음.
17. **사건 모양**: 필요 사건의 v에 Object 없음, kind가 모두 event-kinds.md에 있음, emit 앞뒤 RNG 상태 같음.
18. **공물 받기**: 주민이 바친 식량 공물을 거인이 받음 → 두려움 변화 0. 창고에서 직접 식량을 거둠 → +0.1.
19. **첫 빵 전 안내**: 첫 빵 전, 먹을 것 < 반나절치, 병 하루 → 안내 2번. 첫 빵 뒤 0번.
20. **static 금지**: `sim/needs.gd`에 static var 없음 (ADR d).

## Open Questions

1. **아기의 두려움**: 아기도 톡에 두려움이 오르고 평균에 들어감 — 아기는 오름 ×0.5로 할지 그대로 둘지.
2. **관계 → 기분**: 다툰 날 −0.05·화해 +0.05 같은 입력 — MVP에선 하지 않고 #35 VS에서 다시.
3. **행복이 낮을 때의 결과**: 기획서 7.4의 노동 거부·분파 독립은 코드에 없음 — MVP 효과는 얼굴·자세·출산 배율뿐, 분파 독립은 분가(#37)와 함께.
4. **깨닫기 전 배고픔 안내**: 지금은 깨달음 뒤에만 안내 — OPENING 첫날(깨닫기 전)에도 수첩 쪽지가 필요한지 #26과 정함.
5. **축제 기간이 다름**: 행복 3일, 두려움 빨리 내려감 1일 — 의도로 보고 유지.
6. **배고픔 속도를 먹는 간격에서 떼어 낼지** (`HUNGER_IV`): 지금은 현실 10초 단위 — MVP 유지, 히스테리시스로 버팀.
7. **엔티티 기록부**: `design/registry/entities.yaml`이 아직 없음 — 문턱·사건 kind·새 상수(STARVE_WALK·HAPPY_SNACK·BAND_HYSTERESIS)를 기록부를 만들 때 넣을지.
