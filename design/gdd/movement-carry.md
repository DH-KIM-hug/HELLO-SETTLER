# 움직임·나르기 (Movement & Carrying)

> **Status**: Designed (사용자 결정 반영, 2026-11-08 — `/design-review`는 새 세션에서)
> **Author**: 사용자 + 메인 세션 + game-designer
> **Last Updated**: 2026-11-08
> **Implements Pillar**: 2 보는 것이 곧 재미 · 3 작은 세상의 실감 · 1 스스로 살고 나를 알아보는 사람들

## Summary

움직임·나르기는 주민이 **어디로 어떻게 걷고, 무엇을 들고 가는지**를 정하는 계통이다. 걸음 빠르기, 길 찾기(큰길·오솔길·나루터), 발길이 만드는 흙길, 한 번에 드는 짐의 양, 그리고 **손에 든 물건·문 앞 더미·멈춤 표시**를 맡는다. 거인은 숫자로 물류를 보지 않는다. **밀단을 멘 사람이 방앗간으로, 밀가루 자루를 진 사람이 화덕으로 가는 줄**을 보고 마을이 돈다는 것을 안다.

> **Quick reference** — Layer: `Gameplay` · Priority: `MVP` · Key deps: `물·땅(2), 하루 일정(11), 필요와 기분(10), 생산(15)` · 담당 파일: `sim/movement.gd` (`ResidentAI.update`의 걷기·`haul_*`·`_carry_steps`·`Resident.walk_speed`·`Village.mark_path_seg`·`path_mult`를 옮겨 옴)

**사용자 결정 (2026-11-08)**:
1. **흙길 ×1.15는 남긴다** (첫날 덤만 없앰 — 흙길 위 어른 0.81칸/초).
2. **짐을 늘린다**: `CARRY` 3 → **4**, `CARRY_BIG` → **5** (걸음 일에서 이미 바꿈). 수레 물건(밀·가루·빵·물) `BULK`는 **약 200~215** — 마지막 값은 BALANCE v5-0 다시 재기로 정한다.
3. **수레 물건도 MVP에선 한 사람이 밀단·자루로** 멘다 (수레 소품은 VS).
4. **화면에서 현실 1초에 4칸을 넘으면** 화면이 주민을 그 자리로 옮긴다 — 다리가 허둥대는 동작 없음 (결과 무관).

**지켜야 할 계약**: 보통 걸음 **0.7칸/현실초** (GD 6.6) · **첫날 걸음 덤 없음** · 느리게·조금 느리게에서는 사람도 느려짐 · 굶주리면 걸음 ×0.9 (#10 `walk_mult`) · 거인이 보는지는 결과에 없음 · 나르는 물건이 손에 보임 (A22, 아트 바이블 6.8).

## Overview

- **걸음은 병 시간으로 센다.** 보통 속도(병 하루 = 현실 5분)에서 현실 1초 = 병 288초, 그래서 `WALK = 0.7 / 288` 칸/병초. 느리게 돌리면 사람도 느리게, 빠르게 돌리면 빠르게 보인다 — 규칙은 하나.
- **덤은 곱셈 하나의 줄에만**: 나이·혈통·다침·짐·굶주림·흙길·물 건너기 (F1). **첫날 덤과 대본 걸음 배율은 시뮬에서 뺀다** (ADR-0001 3절 — 연출이 느린 걸음을 원하면 JarClock).
- **길 찾기는 단순하다**: 곧장 걷되, 4칸 넘으면 큰길 그래프(나무 모양)로 돌아가는 게 1.3배 안이면 길로, 강 건너면 나루터. 걷는 칸마다 발길이 쌓여 흙길이 된다.
- **나르기 요청 네 가지**: ① 건물 앞 산출물 → 창고 ② 창고 → 짓는 터 ③ 창고 → 가공 건물 ④ 창고 → 집 땔감(추운 철). 하늘 낟알 줍기는 따로.
- **짐의 양** (사용자 확정): 사람 짐 `CARRY` 4 (특징 '짐을 많이 듦' 5), 수레·자루 물건(밀·가루·빵·물) `BULK` 약 200~215 (BALANCE로 확정), 생선·고기·버섯 16.
- **보이는 것**: 든 짐 소품(밀단·자루·반죽 그릇·빵 바구니·가지 다발·돌덩이·송사리), 문 앞 더미(산출물 `out`), 멈춤 표시(#11 `stall_reason`).
- 사건은 **막힘·흙길·첫 나르기**처럼 드문 것만. 걸음·짐 하나하나는 사건이 아니다.

## Player Fantasy

**"저 자루가 화덕까지 가는구나."** 거인은 한 사람을 손가락으로 따라가 본다. 밭에서 밀단을 어깨에 메고, 방앗간 앞에 내려놓고, 다른 사람이 밀가루 자루를 등에 지고 화덕으로 간다. 짐을 지면 몸이 5° 숙고 걸음이 짧아진다 (기둥 2·3).
- **"길이 생겼다"**: 며칠 지나면 풀 위에 닳은 자국 → 흙길. 마을의 모양이 사람들의 발로 그려진다 (기둥 1).
- **"저기가 막혔네"**: 방앗간 앞에 밀 자루가 기울게 쌓이고 화덕 앞은 비었다 — 나를 사람이 모자란 곳이 **보인다** (기둥 2). 거인은 낟알 대신 다른 손길을 고민한다.
- **"작고 느리다"**: 소인이 큰 꽃숲 사이를 천천히 걷는다 — 산책 걸음 (기둥 3).

## Detailed Design

### Core Rules

**R1. 걷기 (걸음마다)**
1. 걸음 목록 첫 칸이 `walk`이면 목표까지 F1 빠르기로 간다. 남은 시간 안에 닿으면 다음 칸, 아니면 그만큼만.
2. 처음 걷기 시작할 때 한 번: 나루터 길(`VillageEra.route`) → 큰길 길(`VillagePlan.route`). 사이 걸음이 끼면 첫 칸부터 다시.
3. 걸은 선분마다 발길 지도에 길이를 더한다 (`mark_path_seg`, 칸마다 상한 60). 안개 마을이면 걸은 곳이 걷힌다 (#36).
4. 걷는 방향 `facing`, 화면 동작 `walk`/`carry`(짐이 있으면).

**R2. 걸음 빠르기 (F1)**: 아래 곱만. **`pace_walk()`는 시뮬에서 뺀다** (변경 — 지금 `WALK_OPENING`·`PACE_FIRST_DAY` ×12×1.25가 들어감). 굶주림 ×0.9 추가 (변경).

**R3. 길과 흙길**
1. 큰길 그래프: 광장(모닥불)이 뿌리, 큰길 4개, 문 → 길 골목. 고리 없음 → 길 찾기가 거의 공짜. 그래프는 건물 목록의 순수 함수 (결정성).
2. 4칸(`ROUTE_MIN`) 넘는 걸음은 길 값이 곧장의 1.3배(`ROUTE_SLACK`) 안이면 길로.
3. 숲·바위 같은 먼 곳은 `TRAIL_CELL` 격자 가운데로 모이는 오솔길을 거친다 → 같은 오솔길.
4. 발길 ≥ `PATH_AT`(8)인 칸 = 흙길, 걸음 ×`PATH_SPEED`(1.15, 사용자 확정 — 남김). 마을 시대부터 돌길 (그림만, 덤은 같음).

**R4. 나르기 요청 고르기**
1. 짐꾼(일 없는 어른 또는 쉬는 일꾼)이 `haul`을 고르면 아래 차례로 처음 맞는 하나.
2. **id 짝수 = 짓는 터 먼저 (② → ③ → ①), 홀수 = 산출물 먼저 (① → ③ → ②)**, 그다음 ④ 땔감. 터가 자재를 영영 못 받는 일을 막는다 (지금 코드).
3. 터는 들어준 소원 먼저, 그다음 id 순.
4. 산출물은 `haul_min` 넘게 쌓여야 (수레 물건은 4분의 1 수레). 가공 재료는 한 자루 아래로 떨어지면 채움.
5. 일꾼은 자기 건물 앞에 4개 넘게 쌓이면 직접 창고로 (RESIDENT_AI 9장).

**R5. 한 번의 나르기 (F2)**
1. 집는 곳으로 걸음 → `pick`(3초, 손에 짐) → 내려놓는 곳으로 걸음 → `put`(3초, 빈손).
2. 창고에서 꺼내는 짐은 **떠날 때 창고에서 빠지고** 터·건물의 `incoming`에 예약된다. 도중에 그만두면(죽음·숨기·배정 바뀜) `undo`로 되돌린다 — 물건이 사라지거나 두 번 생기지 않는다.
3. 짐의 양: `load = BULK[k]` (수레 물건) 또는 `carry_cap(r)`.

**R6. 손에 든 물건 (보이는 것 — 그림은 #28)**
1. `r.carry`(이름)·`r.carry_amt`가 시뮬 값. 화면은 `ResidentModel.CARRY` 표로 소품·드는 자리(어깨·등·앞·머리·손·밀기·장대)를 고른다.
2. 아이는 작은 것 (빵 바구니 → 빵 한 덩이). 같은 길을 가는 둘이 송사리를 들면 장대에 함께 멤 (화면 짝짓기).
3. **수레 물건(BULK 약 200~215)도 한 사람이 든 모습** (사용자 확정): 밀단은 어깨, 밀가루·낟알 자루는 등에. 양이 많아도 소품 크기는 같다 (보이는 크기 예외 — 기둥 3). 수레 소품은 VS.
4. 화면이 짐을 지어내지 않는다 — 소품은 늘 `r.carry`에서만.

**R7. 더미와 멈춤 표시 (기둥 2)**
1. **더미**: 건물 앞 `out`(산출물)이 실물 더미로 보인다. `out ≥ 2 × load`면 기운 더미 (넘침).
2. **멈춤 표시**: `Schedule.stall_reason(b)`가 있으면 일터 위에 그림 하나 — 재료 없음(빈 바구니) · 앞이 가득(기운 더미) · 벨 것 없음(그루터기) · 일꾼 없음(빈 의자). 숫자 없음.
3. 이 계통은 `pile_level(b)`(0 없음 · 1 있음 · 2 넘침)만 준다. 그리기는 #28.

**R8. 아주 빠른 속도 (화면 규칙 — 결과 무관, 사용자 확정)**: 화면 빠르기(F1 × 현실 1초당 병 초)가 `TELEPORT_AT`(4칸/현실초)을 넘으면 화면은 다리 동작을 빨리 돌리지 않고 **주민을 그 자리로 옮긴다** (서 있는 자세 또는 짐 든 자세, 옮길 때 짧게 흐려짐). 4칸 아래에서는 다리 박자를 빠르기에 맞춘다. 시뮬 셈은 같다. 보통 속도 기준 빠르게(1.75칸/초)는 걷고, 아주 빠르게(3.5)는 걷고, 1초=1시간(8.75)부터 옮김.

**R9. 거인이 보는지와 무관**: `is_watching()`·`stage_on`·카메라·`pace_walk`를 읽지 않는다. 보는 병만 매 프레임, 안 보는 병은 큰 걸음 — 같은 선형 셈이라 위치가 같다 (AC10).

## Formulas

**F1. 걸음 빠르기** (칸/병초)
```
v = WALK × age_m × r.f("walk") × inj_m × carry_m × walk_mult(r) × path_m × wade_m
```
| 기호 | 값 | 뜻 | 출처 |
|---|---|---|---|
| WALK | **0.7/288** (지금 1/288) | 보통 어른 | `Balance.WALK` |
| age_m | 노인 0.75 · 아이 0.9 · 어른 1 | 나이 | `WALK_ELDER/CHILD` |
| r.f("walk") | 0.8~1.2 | 혈통 | Bloodlines |
| inj_m | 0.5 / 1 | 다침 | `INJURY_SLOW` |
| carry_m | `r.f("carry_work")` (허약 0.8) / 1 | 짐 들었을 때 | 혈통 |
| walk_mult | 0.9 / 1 | 굶주림 (#10) | `STARVE_WALK` |
| path_m | 1.15 / 1 | 흙길 | `PATH_SPEED` |
| wade_m | < 1 | 물 건너기 | VillageEra |
- 화면 빠르기 = v × (현실 1초당 병 초). 보통 288 → 어른 **0.7칸/초**, 흙길 0.81, 굶주린 노인 0.47.
- 느리게(병 하루 = 20분, 72) → 0.175칸/초. 빠르게(2분, 720) → 1.75칸/초.

**F2. 짐꾼 한 사람의 나르는 양** (병 시간당)
```
trip = 2 × d / v + T_PICK + T_PUT          (병 초)
rate = load / trip × 3600
```
| 기호 | 값 | 뜻 |
|---|---|---|
| d | 2~20칸 | 집는 곳 ↔ 내려놓는 곳 |
| load | 4 (사람 짐, 큰 짐꾼 5) · 16 · 200~215 (수레 물건, BALANCE로 확정) | 한 번에 (사용자 확정) |
| T_PICK / T_PUT | 3 / 3 (창고 4) | 집기·놓기 |
- 해 본 예 1 (밀): d = 10, v = 0.7/288 → trip = 20 × 411.4 + 6 = 8,235초 → BULK 200이면 200 / 8,235 × 3,600 = **87.4 /시간** (215면 94.0). 예전(1칸/초, 150)은 150 / 5,766 × 3,600 = 93.7 → 200~215가 예전 나르기와 거의 같음. 14명 마을은 시간당 식량 56.
- 해 본 예 2 (통나무): load 4 → 4 / 8,235 × 3,600 = **1.75 /시간**. 예전(1칸/초, 3)은 1.87 → 약 6% 느림 (3 그대로였으면 30% 느림). 큰 짐꾼(5)은 2.19.
- 걸음 1/288 → 0.7/288이면 오가는 시간 ×1.43, 짐 ×4/3·×1.33~1.43이 거의 메움. 마지막 값은 BALANCE v5-0.

**F3. 흙길**: `paths[c] = min(60, paths[c] + 걸은 길이)`, `흙길(c) = paths[c] ≥ PATH_AT`. 예: 한 칸(0.5칸 크기)을 하루 16번 지나면 8 → 흙길.

**F4. 더미 단계**: `pile(b) = 0 if out < haul_min, 2 if out ≥ 2 × load, else 1`.

## Edge Cases

1. **따라잡기**: 걷기는 선형이라 큰 걸음(30·60초)도 같은 자리. 길 찾기는 걸음 처음 한 번 → 걸음 크기 무관. 발길 지도도 길이 합이라 같음.
2. **창고가 없음**: 첫 집 전. 나르기 요청 0, 낟알은 모닥불 곁 (지금 `v.store()` 대체 규칙 확인 필요).
3. **짐 든 채 죽음·병**: `cancel`이 `undo`를 모두 돌린 뒤 빈손. 물건 보존 (AC6).
4. **목표 건물이 사라짐** (홍수·개축): `put`의 op가 건물을 붙잡음 → 사라졌으면 창고로 되돌림 (`carry_back`).
5. **물 위 목표**: 나루터 길이 없으면 건너기 ×`wade_m`. 깊은 물은 목표에서 빼야 함 (#2).
6. **굶주림 고리**: 굶주리면 ×0.9 → 밀 나르기 10% 느림 → 모자람↑. 막는 것: #18 F5 굶주린 사람 먼 일터 벌점 1.5, 아이 먼저. BALANCE v5-0으로 확인.
7. **짐꾼 0명**: 일꾼 모두 일터 → 일꾼이 자기 앞 4개 넘으면 직접 나름 (R4.5). 더미가 넘치면 `pile_overflow` → 안내(#26).
8. **같은 짐을 둘이 집음**: 꺼낼 때 바로 `out`에서 빼므로 없음.
9. **저장·불러오기**: 걸음 목록·`carry`는 지금처럼 SaveCodec. 새 값: 더미 단계 캐시(저장 안 함, 불러온 뒤 다시 셈, 사건 없음).
10. **아주 빠른 속도**: 화면 자리 옮김만 (R8).

## Visual/Audio Requirements

- 짐을 지면 앞으로 5° 숙이고 걸음이 짧아짐, 짐이 걸음에 맞춰 통통 (`CARRY_BOB`) (아트 바이블 5.x).
- 다리 박자는 실제 빠르기에 맞춤 (`STRIDE` 표를 0.7칸/초로 다시 — A29).
- 사슬이 보이게: 밀단(어깨) → 밀가루 자루(등) → 반죽 그릇(앞) → 빵 바구니(앞·머리) (A22).
- 흙길: 닳은 풀 → 흙 → 조약돌, 폭 = 다닌 횟수 (아트 바이블 6.8).
- 더미는 문 앞 실물, 넘치면 기움. 멈춤 표시는 그림 하나 (빈 바구니·그루터기·빈 의자).
- 소리: 짐 내려놓는 작은 톡, 흙길 발소리는 따라가기 시점에서만.

## Game Feel

- 병을 열면 5초 안에 짐을 든 사람이 적어도 하나 보인다 (낮).

## Acceptance Criteria

모두 헤드리스 (묶음 `movement`, AC11은 느린 묶음).
1. **보통 걸음**: Given 어른, 풀밭, 보통 · When 7칸 · Then 병 2,880초 (±1) = 현실 10초.
2. **덤 없음**: Given 첫날 수첩·대본 중 · Then 같은 걸음 (`pace_walk` 곱 없음).
3. **곱셈 줄**: 노인 × 다침 × 굶주림 → 0.75 × 0.5 × 0.9 = 0.3375배.
4. **흙길**: Given 칸 발길 8 · Then 걸음 ×1.15, `path_formed` 하루 한 번.
5. **길 따라**: Given 4칸 넘는 걸음, 길 값 ≤ 1.3배 · Then 사이 걸음이 길 위. 4칸 아래면 곧장.
6. **물건 보존**: Given 판자 3을 터로 나르는 중 · When 죽음 · Then 창고 +3, 터 `incoming` −3, 합 같음.
7. **번갈이**: Given 짝수·홀수 짐꾼, 터·산출물 요청 둘 다 · Then 짝수는 터, 홀수는 산출물.
8. **짐 보임**: Given `pick` 뒤 · Then `r.carry` = 물건 이름, 화면 동작 `carry`. `put` 뒤 빈손.
9. **더미**: Given 밀 `out` = 2 × BULK · Then `pile_overflow` 1번, 비우면 `pile_cleared`.
9a. **짐 양**: Given 보통 어른 · Then `carry_cap` = 4, 특징 '짐을 많이 듦' = 5.
9b. **화면 옮김 (화면 시험, 결과 무관)**: Given 화면 빠르기 > 4칸/현실초 · Then 걷기 클립 없이 자리 옮김, 시뮬 위치는 옮김을 켜든 끄든 같음.
10. **결정성 + 연출 무관 + 걸음 크기 무관**: 같은 씨앗·지켜봄 입력, 연출 켬/끔, ×1과 ×8 · Then 위치 차이 < 1e-6, 발길 지도 같음.
11. **경제 (느린 묶음)**: 0.7/288 + 굶주림 ×0.9 넣고 3씨앗 × 60일 → BALANCE v5-0 곡선 지킴.
12. **static 금지**: `sim/movement.gd`에 static var 없음, 사건 v에 Object 없음.
