## Summary

사건 연출은 시뮬레이션이 낸 큰 사건(깨달음·제단·첫 기도·계시·첫 아기·첫 죽음·첫 기적·첫 빵)을 **별지기가 보고 있을 때** 카메라·테두리 어둠·몸짓·손글씨 자막 카드로 몇 초 동안 보여 주고, 연대기에 그림 카드 한 장을 남기는 화면 계통이다. **연출은 시뮬 결과를 바꾸지 않는다** — 바꾸는 것은 병 시간의 빠르기(지켜봄·배속은 기록된 입력)와 화면뿐이다.

> **Quick reference** — Layer: `Presentation` · Priority: `MVP` · Key deps: `사건 기록 흐름(7), 카메라(24), 병 시간(1)` · 담당 파일: `view/stage_director.gd`(재생기) · `view/stagings.gd`(콘티 표) · `view/ui/revelation_show.gd`(계시 — 재생기로 합침)

**메인 판단 (사용자 위임, 2026-11-08)**: S1 **연출은 사건 구독으로 시작** (지금의 상태 폴링 `_due()`를 `awakened`·`altar_built`·`born{first}`·`died`·`wish_granted{drop}`·`revelation`·`first_bread` 구독으로 바꿈) · S2 **건너뛰기는 두 번 누름** (아트 바이블 7.6 — 첫 톡은 [건너뛰기]를 3초 띄우기만) · S3 **MVP 콘티 8개** (1·2·2b·3·4·5·6 + 첫 빵), 나머지(혼례·이주민·발견…)는 VS · S4 **계시 연출을 StageDirector 콘티로 합침** (`revelation_show.gd`의 별도 층 은퇴) · S5 **보지 않던 일은 연출 없이 안내 창 + 그림 없는 카드**.

## Overview

- 연출 하나 = 콘티 표 한 칸(`Stagings.SCENES`): 길이·짧은 판 배율·연출 중 병 빠르기·카메라 자리·박자(beats)·끝난 뒤 안내 창·그림 카드 시각.
- 큰 사건이 오면 빠르게 흐르던 병은 **보통 이하**로 내려가고, 위 띠에 "천천히 — 무슨 일" 칩. 끝나면 원래 빠르기로.
- 레터박스 없이 **테두리 어둠** (하늘의 일 남청 / 사람의 일 밤색), 위·아래 띠는 400ms 물러남.
- 손글씨 자막 카드 한 줄이 그대로 연대기의 그림 카드 줄이 된다 (#27).
- **별지기의 손은 보이지 않는다.** 기적에서도 손 그림자·코르크 소리·내려오는 물건만.

## Player Fantasy

**"아이가 먼저 하늘을 가리켰어. 그다음 노인이 무릎을 꿇었지."** 별지기는 사건을 *읽지* 않고 *본다* — 한 사람씩 조금씩 늦게 고개를 드는 몸짓, 고요, 빛 한 줄기. 연출은 "내가 한 손짓이 이 사람들의 역사가 됐다"를 몇 초 안에 몸으로 느끼게 하는 계통이다 (MDA: Narrative·Sensation). 두 번째 병에서는 짧은 판으로 지나가 같은 감동을 억지로 반복하지 않는다.

## Detailed Design

### Core Rules

**R1. 시작 = 사건 구독 (S1)**: 재생기는 `events`에서 아래 kind를 받아 **지금 보고 있는 무리**이고 사건 시각이 `STALE`(병 20분) 안이면 콘티를 튼다. 아니면 R7.
| kind (ADR-0001) | 콘티 | 끝난 뒤 안내 (#26) |
|---|---|---|
| `&"awakened"` | `awakening` (11초) | awakening |
| `&"altar_site_placed"` | `altar_build` (짓는 동안, `until altar_built`) — 첫 병 첫날은 수첩 빠르기가 대신 | — |
| `&"altar_built"{first}` | `first_prayer` (10초) | altar |
| `&"revelation"` | `revelation` (12초, 3장·3b) | revelation |
| `&"born"{first}` | `first_baby` (8초) + 이름 창 | baby |
| `&"died"` (그 병 첫 죽음) | `first_death` (12초, 조용히) | death |
| `&"wish_granted"{how: drop}` (첫 번) | `miracle` (8초) | miracle |
| `&"first_bread"` | `first_bread` (8초, OPENING 3.1c-5) | bread |

**R2. 한 번에 하나**: 연출 중 들어온 연출은 줄을 서고(최대 3), 계시가 늘 맨 앞. 줄이 차면 가장 오래된 것을 R7로.

**R3. 병 빠르기**: 빠르게 흐르던 중이면 `JarClock.set_speed(보통)` + `stage_rate`(콘티의 `rate`)로 더 느리게. 끝나면 `resume_fast`. 이것은 **별지기의 배속 입력**과 같은 길로 기록된다 — 고정 걸음이므로 같은 씨앗·같은 입력이면 결과가 같다 (ADR-0001 (a)).

**R4. 몸짓은 덧씌우기만**: `pose_over`(화면)로 얼굴·자세·팔을 덮어쓴다. 주민의 자리·행동·일감·RNG는 건드리지 않는다. 연출 중 `say`는 **화면 말풍선 줄**에만 넣는다 — 지금의 `v.speak`(시뮬 쪽 말 기록)는 쓰지 않게 바꾼다 (코드 점검 1).

**R5. 건너뛰기 (S2)**: 연출 중 화면 첫 톡 → 오른쪽 아래(왼손 모드면 왼쪽) [건너뛰기] 3초. 그것을 누르면 끝 상태로: 카메라·몸짓 제자리, 자막 카드 1초, 그림 카드는 지금 화면, 안내 창은 그대로. 두 번째부터 같은 연출은 `short` 배율.

**R6. 그림 카드**: 콘티의 `card.at`초에 띠·자막을 빼고 화면을 찍어 360px로 줄여 `user://chron_pics/`에 두고, 연대기 줄(`card.find`)에 붙인다. 찍기 전 자막이 없어야 한다.

**R7. 보지 않던 일 (S5)**: 비운 동안·다른 무리·`STALE` 지남 → 연출 없이 안내 창만 줄 세움(#26), 연대기 줄은 그림 없이 장식 카드. 돌아온 편지(#27)가 이야기한다.

**R8. 말 규칙**: 자막·대사에 CLAUDE.md 1장 금지어 없음, 깨닫기 전 연출(첫 아기 등)에는 지켜보는 존재 이야기 없음, 깨달은 뒤에는 `{w}`(마을이 부르는 말) — '거인'은 절대 없음. 숫자 없음.

## Formulas

**F1. 연출 길이**: `L = dur × k`, `k = 1` (처음) / `short` (0.5~0.6, 두 번째부터). 박자 시각도 `× k`.
**F2. 연출 중 병 시간**: `jar_dt = real_dt × min(현재 배속, rate)`. 예: 깨달음 `rate` 5 → 11초 연출에 병 55초 (보통 288이면 53분이 흐를 것을 1분으로).
**F3. 자막 머묾**: `max(2.5초, 글자 수 ÷ 6 + 1초)` (아트 바이블 7.6). 예: 26자 → 5.3초.

## Edge Cases

1. **연출 중 앱이 뒤로 감**: 연출은 끝 상태로 정리, 그림 카드는 찍지 않음(장식 카드). 시뮬은 이미 그 사건을 확정했다.
2. **역할 주민이 없음** (아이 없음·노인 없음): `child` → 가장 어린 사람, `elder` → 가장 나이 많은 어른.
3. **사건 자리가 화면 밖 무리**: 카메라가 날아감. 넓은 세상에서 다른 무리면 R7.
4. **연출 중 별지기가 시트를 엶**: 연출 중엔 띠가 물러나 있어 열 수 없음. 시트가 열린 채 시작하면 닫음.
5. **첫 죽음 + 첫 아기 같은 날**: 줄 차례 (R2), 죽음 뒤 아기 사이 2초 숨.
6. **계시 중 닫힘**: 시대는 [계시] 확정 순간 이미 오름 (#23 엣지 6) — 다시 열면 카드만.
7. **창세의 날**: 제단 짓기 연출은 수첩이 대신 (카메라를 붙잡지 않음 — 지금 코드 그대로).
8. **움직임 줄이기 설정**: 카메라 기울기 없음, 겹쳐 바꿈, 빛줄기는 0.5초 넘게 서서히.

## Visual/Audio Requirements

- 콘티는 EVENTS_STAGING 1~6, 3b, 첫 빵은 OPENING 3.1c-5. 깨달음만 카메라 기울기(아트 바이블 7.6).
- 번쩍임 1초 3번 이하, 빛줄기·기적은 0.5초 넘게 밝아짐.
- 소리: 사건마다 짧은 음악 한 마디 + 박자 `fx` (AUDIO.md). 첫 죽음은 낮은 음 하나, 배경 소리 줄임.
- 계시: 병 안이 밤처럼 → 빛 두루마리(고른 가르침 그림 + **귀퉁이의 이해 못 할 조각** — #23 R7-5) → 빛 그림자 → 시대 이름 카드.

## Game Feel

- 시작 0.6초 안에 테두리 어둠과 카메라가 움직이기 시작 — "무슨 일이 생겼다".
- 사람마다 0.12~0.22초씩 늦는 몸짓(stagger)이 '군중'이 아닌 '사람들'로 보이게 하는 핵심.
- 끝나고 2초 숨 고른 뒤 안내 창 — 감동과 설명이 겹치지 않게.

## UI Requirements

- 자막 카드: 마른 잎 띠, 손글씨 **24dp**(최소 22), 화면 위쪽 15~25% 높이 (지금은 아래 띠 위 — 고침), '또렷한 글씨' 설정 따름.
- 위 칩 "천천히 — 사람들이 하늘을 올려다봐요" (거인 UI, 본문 글꼴 12).
- [건너뛰기] 48dp 이상, 엄지 자리, 왼손 모드 뒤집기.
- 대사가 있는 연출은 자막 필수 (말하는 사람 이름 함께 — 설정).

## Acceptance Criteria

1. **결정성**: Given 같은 씨앗·같은 입력 기록 · When 연출 켬/끔으로 병 3일 · Then 주민 값·사건 줄·연대기 같음 (연출이 넣은 배속 입력은 기록에 포함).
2. **구독 시작**: Given 보고 있는 무리에서 `awakened` · When 다음 화면 · Then `awakening` 시작 1번, 같은 사건으로 다시 안 시작.
3. **오래된 일**: Given `altar_built` 뒤 병 30분 지나 처음 봄 · Then 연출 0, 안내 창 `altar` 줄 1.
4. **건너뛰기 두 번**: Given 재생 중 · When 화면 톡 1번 · Then 계속 재생 + [건너뛰기] 보임; 그것을 누르면 끝, 그림 카드 1장.
5. **짧은 판**: 두 번째 `awakening`(다른 병) 길이 = 11.2 × 0.5 ± 0.1초.
6. **빠르기 되돌림**: Given ×8 배속 · When 연출 끝 · Then 다시 ×8.
7. **말 규칙**: 모든 콘티 자막·대사에 금지어 0, '거인' 0, 숫자 0; `{w}`가 채워짐.
8. **줄**: 연출 중 `born{first}` + `died` · Then 차례대로, 계시가 오면 맨 앞.
9. **R4**: 연출 동안 `v.speak`·주민 행동 쓰기 0 (시험이 감시).
