## 화면 목록

| # | 화면 | 핵심 |
|---|---|---|
| 01 | 메인 — 병 화면 | 병 하나가 화면 중앙. 위: 지구 이름·시대·인구·지폐·행복 / 아래: 도구 5개 (건설·거인의 손·상점·연대기·선반). 거인의 손 = 물·빛·톡. 새 소식은 빨간 점 대신 **주민이 든 편지**. 위기는 예고 카드로 |
| 02 | 건설 | 아래에서 올라오는 시트. 분류 탭 → 건물 카드 (레시피·자재·시간·효과). 잠긴 건물은 열리는 시대 표시. 위쪽엔 터와 효과 반경 미리보기 |
| 03 | 주민 정보 | 초상·등급·가족 / **고유 특징** / 건강·행복·남은 생애 / 손글씨 개인 기록 / [따라가 보기] [종이배에 태우기] |
| 04 | 종이배 (주민 판매) | 혼자 / 가족 모두 선택 → 지폐 계산 (등급·숙련, 미성년은 대금 없이 동행) → **마을에 생기는 일** 경고 → [종이배 띄우기]. 오늘 판매 수 / 상한 표시 |
| 05 | 선반 | 다음 병까지 지폐 진행도 → [새 병 사서 지구 만들기]. 병들 사이 **거인의 다리**. 병 목록 (상태 배지), 유적 탐방 입구 |
| 06 | 거인의 상점 | 분류 탭 (자원·생물·건축물·유물·기적). 카드마다 "병 안에서: 무엇이 되는지" (각설탕 = 식량 1주일치). 산 물건은 손가락으로 떨어뜨림 |
| 07 | 연대기 | 양피지 + 손글씨. 탭: 최근 / 창세 신화 / 사람들 (살아 있음·잠듦·종이배로 떠남) |
| 08 | 창조 — 핵 넣기 | 어두운 배경, 9단계 진행 점. 핵 크기 작게·보통·크게 → 빛·크기·자막이 바뀜 (숫자 없음) |

## UI 원칙
- **병이 주인공**: 메인 화면 UI는 위아래 가장자리에만. 가운데는 병.
- **빨간 점·알림 배지 금지**: 새 소식은 병 안의 편지·주민 말풍선으로.
- **숫자는 필요한 곳에만**: 경제(지폐·자재·판매가)는 숫자, 창조·감정(핵·행복)은 빛·막대·말.
- **한 손 조작**: 주요 버튼은 화면 아래쪽, 누르는 영역 44px 이상.
- **글꼴**: 제목 고운바탕(세리프) / 본문 Noto Sans KR / 기록·자막 나눔펜(손글씨).
- **색**: 크림 바탕 #F4EDE0, 잉크 #2A2620, 이끼 초록 #3E5C3A(주요 동작), 호박 #9A5B12(편지·경고), 밤 #1E1F2A(창조).
