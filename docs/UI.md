## UI 원칙
- **병이 주인공**: 메인 화면 UI는 위아래 가장자리에만. 가운데는 병.
- **두 시점**: 병 시점(밖, 세로 병) = 구경·거인의 손 / 지구 시점(안, 넓은 대지) = 구경·사 준 건물 놓기. 두 손가락으로 벌리고 오므려 오간다.
- **빨간 점·알림 배지 금지**: 새 소식은 병 안의 편지·주민 말풍선으로.
- **숫자는 필요한 곳에만**: 경제(지폐·자재·판매가)는 숫자, 창조·감정(핵·행복)은 빛·막대·말.
- **한 손 조작**: 주요 버튼은 화면 아래쪽, 누르는 영역 44px 이상.
- **글꼴 (v3, 2026-11-06 — 한국 먼저 출시)**: 그림체가 셀 채색으로 바뀌어 도트 글꼴(갈무리)은 시안 v1·v2에만 남긴다. 모두 상업 이용·앱 내장 가능한 **OFL** 글꼴 (안):
  | 쓰임 | 글꼴 (안) | 이유 |
  |---|---|---|
  | 본문·버튼·숫자 | **나눔스퀘어라운드** (Regular·Bold) | 둥근 획이 셀 채색과 맞고 작은 글자도 또렷 (휴대폰 12~14pt) |
  | 제목·시트 이름·시대 배지 | **주아 (Jua)** | 통통하고 따뜻한 제목체, 아이콘 L_2의 분위기 |
  | 편지·연대기·창조 자막·말풍선 | **나눔손글씨 펜** (또는 개구 Gaegu) | 주민이 쓴 글 = 손글씨. 연대기 양피지와 맞음 |
  - 크기: 본문 14 / 작은 글 12 / 제목 22 / 큰 제목 28 (390 폭 기준). 줄 간격 1.4.
  - 숫자는 본문 글꼴의 고정폭 숫자.
  - 영어 목소리와 별개로 화면 글자는 한국어만 (출시 언어 = 한국 먼저, 22장).
- **색·모양 (v2 — 도트 시안 기준, 셀 채색 UI가 정해지면 바뀜)**: 64색 팔레트 — 바탕 #dbd8d6, 잉크 #242121, 이끼 초록 #44622d(주요 동작), 갈색 #8b5733(편지·경고), 밤 #1e1f2a(창조). (시안 그림은 48색 1차안 값 #e2ded8·#252122·#3e5c2c — 가장 가까운 64색으로 바꿈)
- **모양 (v2)**: 둥근 모서리 없음, 버튼은 밝은 위·왼쪽 / 어두운 아래·오른쪽 3픽셀 입체 테두리, 그림 선은 계단처럼 각지게.

## 03 주민 상세 (v2, 2026-11-06)

> 화면 그림체(UI 스타일)는 아직 열린 질문이다. 지금은 **임시 테마 하나**(Theme 리소스 한 곳에 색·글꼴·여백)로 만들어 나중에 통째로 바꿀 수 있게 한다.

**여는 법**: 지구 시점에서 주민을 누름 (손가락 둘레 넉넉히 — 가장 가까운 주민). 시간은 멈추지 않는다. 세로 화면은 아래에서 올라오는 시트(화면 높이 약 60%), 가로 창(개발용)은 오른쪽 패널.

| 칸 | 내용 |
|---|---|
| 머리 | 초상(주민 모델 정면 가까이, 천천히 숨 쉼) · 이름 · 나이(표시 나이 = 일 × 2.4세) · 성별 · 직업 · 등급(일반이면 안 보임) |
| 상태 | 막대 5개: 건강 · 행복 · 믿음 · 두려움 · 배고픔. 막대 아래 지금 상태 한 줄: '열병을 앓고 있음 (2일째)' · '몹시 아픔' (중증) · 그 아래 작게 '이겨 낸 병: 열병 · 고뿔' · '다리를 다침' · '추위에 떨고 있음' · '무서워함' · '배고픔' ([HEALTH.md](HEALTH.md) 6장) |
| 고유 특징 | 1~2개, 이름 + 효과 한 줄 |
| 혈통 | 칩. 좋은 혈통 = 초록, 나쁜 혈통 = 갈색, 짝이 함께 있어 상쇄되면 둘 다 회색 + '서로 상쇄'. 누르면 효과·겉모습 표시 한 줄 ([BLOODLINES.md](BLOODLINES.md)). 어디서 왔는지 작게 ('아버지에게서', '할머니에게서', '새로 생김', '키트 가족') |
| 겉모습 | 보이는 것만 말로: 피부 톤 · 눈 색 · 머리색·머리결 · 주근깨 · 키·체격. **숨은(열성) 유전자는 보여 주지 않는다** — 거인도 겉모습만 본다. 눈송이(점박이)는 '하늘의 눈송이가 내려앉은 아이' 한 줄. 인종 이름 금지 |
| 가계도 | 3대: 조부모 4 · 부모 2 · 본인과 배우자 · 자녀. 사람마다 작은 얼굴 + 이름 + 혈통 점. 누르면 그 사람 상세로 넘어감. 죽은 사람은 회색 + '잠듦' (원인 한 단어: 노환·병 이름(고뿔·배앓이·열병·기침병·곪은 상처·역병)·굶주림·추위·더위·사고) |
| 버튼 | [따라가 보기] (카메라가 그 주민을 따라감, 아무 곳이나 끌면 풀림) · [닫기] |

- 연대기의 개인 기록(손글씨 몇 줄)은 연대기가 생기면 이 화면에 붙인다.
- 글자는 거인에게 하는 말이라 '혈통'·'유전' 같은 말을 써도 된다. 주민 말풍선에는 금지어 규칙(RESIDENT_AI 2.4) 그대로.

## 10 문의하기 (v1)
- **입구**: 설정(⚙) → [문의하기]. 설정은 메인 위 띠의 오른쪽 끝 작은 톱니 (빨간 점 없음). 결제가 생기면 상점(06) 맨 아래에도 [결제 문의] 한 줄.
- **화면**: 한 장짜리 시트.
  - 종류 고르기 (하나): **버그·멈춤 / 결제 / 제안 / 그 밖**
  - 안내 한 줄: *"메일 앱이 열립니다. 화면 사진을 붙여 주시면 빨리 살펴볼 수 있어요."*
  - [메일 쓰기] (아래쪽, 이끼 초록)
  - 받는 주소를 글로 보여 주고 옆에 [복사] — 메일 앱이 없는 기기용.
- **동작**: `mailto:` 로 기기 메일 앱을 연다 (Godot `OS.shell_open`). 제목·본문은 URL 인코딩.
  - 받는 사람: `hello@ddoystory.com`
  - 제목: `[나의 작은 지구] {종류} 문의`
  - 본문: 빈 줄 3개(사용자가 쓸 곳) 다음 구분선 아래에 자동 정보 —
    ```
    ---- 아래는 지우지 말아 주세요 ----
    버전: {앱 버전} ({빌드 번호})
    기기: {기기 모델} · {OS 이름 버전}
    언어: {언어}
    문의 번호: {설치 ID 앞 8자리}
    병: {병 수}개 · 지금 병 {N}일째
    ```
  - 결제 문의일 때만 마지막 결제의 **주문 번호**를 한 줄 더 (결제 도입 후).
- **넣지 않는 것**: 이메일·이름·위치 등 개인 정보, 세이브 파일 전체. 설치 ID는 기기에서 만든 임의 값 (광고 ID 아님). 본문은 사용자가 보내기 전에 보고 지울 수 있다.
- 메일 앱이 열리지 않으면(`shell_open` 실패) 토스트: *"메일 앱을 열 수 없어요. 주소를 복사했어요."* + 주소 복사.
- 스토어 등록·개인정보처리방침의 연락처도 같은 주소.

## 건물 정보 카드 (사용자 2026-11-08: "건물 누르면 정보가 나오면 좋겠어")
- **열기**: 지구 시점에서 건물을 한 번 누르면 (주민을 누를 때와 같은 방식, 주민이 앞에 있으면 주민 우선) 아래에서 작은 카드가 올라옴. 빈 땅을 누르거나 아래로 밀면 닫힘. 카메라는 건물이 카드에 가리지 않게 살짝 비켜 줌 (A26 시트 규칙).
- **카드 내용** (거인 쪽 UI — 숫자·'지폐' 써도 됨):
  1. 이름 + 작은 그림(건물 썸네일) + 한 줄 설명 (무엇을 하는 곳인지).
  2. **사는 사람 / 일하는 사람**: 얼굴 동그라미 줄 — 누르면 그 주민 상세(resident_detail)로.
  3. **지금 하는 일**: 만드는 것·오늘 만든 양·쌓인 것 (예: 빵집 — 오늘 빵 6, 창고에 밀가루 12), 집은 땔감·온기, 창고는 칸별 양.
