# 나의 작은 지구 — 소리와 음악 (v1)

> 음원: 처음엔 **픽사베이 로열티 프리**로 정했으나, 픽사베이는 자동 내려받기를 막고(403) 후보 곡 다수가 유튜브 Content ID 등록곡이라 **시험판 음악 6곡은 ElevenLabs Music으로 생성** (2026-11-06, Creator 요금제 — 상업 이용, Content ID 걱정 없음, `tools/gen_music.py`에 프롬프트). 효과음은 픽사베이·ElevenLabs Sound Effects를 섞어 쓴다. 반응이 좋으면 나중에 메인 테마만 작곡 의뢰를 검토한다.

## 1. 방향
- **병 안 = 중세 시골 민요** (류트·리코더·하프·작은 북·허디거디), **거인의 방 = 오르골·유리 하모니카·피아노**.
- **듣는 자리가 소리를 바꾼다** (이 게임만의 장치):
  - 병 시점(밖): 마을 소리에 **로우패스 필터**(유리 너머 먹먹하게, 약 800Hz) + 음량 −8dB, 거인의 방 음악이 앞.
  - 지구 시점(안): 마을 음악 또렷, 새·물·사람 소리 가까이. 거인의 방 음악은 먹먹하게 뒤로.
  - **뚜껑을 열면**: 필터가 0.5초 동안 열림 → 마을 소리가 확 선명해짐.
- 힐링이 기본 — 큰 북·전투 음악 없음. 위기도 '긴장'이지 '공포'가 아니다.

## 2. 곡 목록 (시험판 6곡)

| id | 쓰임 | 느낌 | 픽사베이 검색어 (예) | 길이·반복 |
|---|---|---|---|---|
| `theme` | 메인 화면·선반·창조 | 오르골, 따뜻하고 조금 아련함 | `music box lullaby`, `music box gentle` | 1~2분, 반복 |
| `day` | 병 안 낮 | 류트·리코더 시골 민요, 밝고 느긋 | `medieval folk lute`, `medieval village peaceful` | 2~3분, 반복 |
| `night` | 밤 | 하프·플루트, 고요 | `medieval night harp`, `calm harp ambient` | 2~3분, 반복 |
| `evening` | 저녁 기도 (19시) | 허밍·잔잔한 성가풍 | `medieval chant soft`, `humming choir calm` | 1분 |
| `crisis` | 위기 (곰팡이·날벌레 등) | 낮고 느린 긴장, 조금 장난스러움 (바순·피치카토) | `pizzicato mischievous`, `curious tension light` | 1~2분, 반복 |
| `festival` | 축제·귀환 축제·혼례 | 탬버린·피리 춤곡 | `medieval dance festive`, `celtic jig happy` | 1~2분 |

- 고를 때 기준: 같은 악기 톤(류트·리코더 계열)끼리 맞춤 / 가사 없음 / 앞뒤 끊김 없이 반복되는지 / 너무 유명한 곡 피하기.
- 나중에 추가: 계절별 낮 곡, 시대별 편성(개척기 독주 → 마을 합주), 기후별(사막·툰드라) 곡.

## 3. 효과음 (시험판 약 30개)

| 분류 | 소리 | 픽사베이 검색어 (예) |
|---|---|---|
| 병 | 유리 톡(약·강), 코르크 뽁(열기·닫기), 등불 옮기기(등잔 끌림·불꽃 일렁임), 물방울 똑, 물 뿌리기 | `glass tap`, `cork pop`, `water drop`, `spray bottle` |

| 마을 | 망치질, 톱질, 도끼, 우물 두레박, 닭·양, 아이 웃음, 종(혼례), 모닥불 | `hammer wood`, `saw wood`, `axe chop`, `church bell small`, `campfire crackle` |
| 자연 | 새소리(아침), 귀뚜라미(밤), 물가 찰랑, 바람 없는 고요(병 안 앰비언트) | `birds morning`, `crickets night`, `lake water lapping` |

## 4. 전환 규칙
- 곡 바꿈은 **2초 크로스페이드**. 위기·축제는 4초.
- 낮 ↔ 밤: 병 시계 6시·20시. 저녁 기도 곡은 19시에 한 번 (끝나면 밤 곡으로).
- 위기 곡은 조짐 단계에선 낮 곡 위에 낮은 음만 살짝 → 한창일 때 위기 곡.
- 병 시간을 빨리 돌릴 때(×8 이상): 음악은 그대로 1배속, 효과음은 줄임 (같은 소리가 1초에 3번 넘게 나지 않게).
- 설정(UI 10)의 소리 끄기 = 음악·효과음 따로. 진동은 유리 톡·물건 떨어뜨림에만.

## 5. 라이선스 기록 (꼭)
- 픽사베이 콘텐츠 라이선스: 상업적 이용 가능·출처 표기 의무 없음. 단 **음원만 따로 재배포·판매는 금지**, 게임에 넣는 건 가능.
- **유튜브 콘텐츠 ID에 등록된 곡은 피한다** — 플레이어가 게임 영상을 올릴 때 저작권 신고가 걸릴 수 있다 (곡 페이지·작가 설명에 'Content ID' 언급이 있으면 제외).
- 받은 파일마다 `godot/audio/LICENSES.csv`에 한 줄: `file,title,author,pixabay_url,download_date,content_id(none/yes)`. 출처 표기 의무는 없지만 크레딧 화면에 작가 이름을 넣는다 (예의 + 분쟁 대비).
- 형식: 모두 `.mp3` (이 Mac의 ffmpeg에 vorbis 인코더가 없음; Godot 4 mp3 반복 재생 가능). 음량을 −14~−16 LUFS 근처로 맞춘다.

## 6. 작업 순서
1. 사용자가 픽사베이에서 2·3장 목록대로 골라 받는다 (계정 로그인 필요 — 사람이 직접). 받은 파일은 `godot/audio/music/`, `godot/audio/sfx/`에 두고 LICENSES.csv를 채운다.
2. 개발: `AudioManager` (자동 로드) — 버스: Music / SFX / Village(로우패스) / Room. 시점·뚜껑·시간·위기 상태를 보고 위 4장 규칙대로 전환.
3. 휴대폰에서 듣고 음량·필터 값 조정.

## 7. 주민 목소리 — 영어 짧은 말 (ElevenLabs, v1.1)
- 주민은 상황마다 **영어 한두 마디**를 짧게 외친다 (*"The sky is open!"*, *"Fuzzies!"*, *"Wheee!"*). 말풍선 글은 한국어 그대로 — 목소리는 번역이 아니라 **분위기**다.
- **목소리 6종**: 여자아이 · 남자아이 · 젊은 여자 · 젊은 남자 · 할머니 · 할아버지. 주민마다 성별·나이로 고르고, 주민마다 음높이를 ±1반음 흔들어 같은 목소리도 조금씩 다르게.
- **작은 사람 소리**: 생성한 음성을 **+4반음, 1.08배 빠르게** 처리 (`tools/gen_voice.py`가 ffmpeg로). 병 밖 시점에선 다른 마을 소리처럼 유리 너머로 먹먹하게.
- **목록**: [`design/voice/lines.json`](../design/voice/lines.json) — 18가지 상황 (뚜껑 열림·톡·제물 받음·소원·기적·강제로 거둠·곰팡이·버섯·꽃씨·주민 누름·앓음·굶주림·일·혼례·출생·저녁 기도 허밍 …), 약 120개 파일.
- **얼마나 자주**: 같은 상황에서 화면 안의 주민 한두 명만, 같은 줄은 30초에 한 번까지. 빨리 돌리기(×8 이상)에선 끔. 설정의 효과음 음량을 따름 (따로 '목소리' 끄기 추가).
- 금지: 게임·앱·플레이어·휴대폰 같은 말, 실존 인물 목소리 흉내.
- **ElevenLabs 이용 조건**: 상업 이용은 **유료 요금제**(Starter 이상)에서 만든 음성만. 보이스 라이브러리의 목소리를 쓰면 그 목소리의 이용 조건도 확인. 만든 목소리 id·요금제·날짜를 `godot/audio/LICENSES.csv`에 기록.
- 생성: 키는 `~/.config/elevenlabs/key` (저장소 밖, 팥죽 게임과 공용). `python3 tools/gen_voice.py` (목소리 id는 스크립트에 기본값) → `godot/audio/voice/*.mp3` (118개, 받아쓰기로 검사). 효과음 `godot/tools/gen_sfx.py` (35개), 음악 `tools/gen_music.py` (6곡).
- 참고: ElevenLabs는 **효과음 생성**(Sound Effects)도 된다 — 픽사베이에서 못 찾은 작은 세계 소리(곰팡이 퐁, 꽃씨 바람, 코르크 뽁)는 거기서 만들어도 된다.
