# 나의 작은 지구 — 성장·허들·동기 (v1)

> 이 게임에는 플레이어 레벨이 없다. **자라는 것은 세상이다** — 병 안의 문명, 병의 수, 내가 아는 세상의 넓이, 주민과의 관계. 모든 허들은 '벽'이 아니라 **"조금 더 지켜보면 넘는 것"**이어야 한다 (힐링 게임).

## 1. 무엇이 자라나 — 네 개의 축

| 축 | 보이는 것 | 단계 | 근거 |
|---|---|---|---|
| **① 문명** (병 하나) | 시대 · 인구 · 건물 · 발견 | 개척기 → 마을 (~2일) → 읍내 (~17일) → 영지 (~40일) | 기획서 8.3, 발견 25종 |
| **② 세상** (병 하나의 넓이) | 안개가 걷힌 땅 · 분가한 마을 수 | 첫 빈터 → 영역 확장 → 분가 1·2·3 → 넓은 세상 | 3.1 영역·분가 |
| **③ 선반** (병의 수) | 병 · 기후 | 온대 1개 → 2개 (~13일) → 3개 (~30일) → 4개+ · 기후 6종 해금 | 12.1, 5.3 |
| **④ 관계** (거인과 주민) | 믿음 · 혈통 · 연대기의 두께 · 아는 얼굴들 | 이름 아는 주민, 3대 가계, 전설이 된 사람 | 7장, 연대기 |

- 레벨 숫자 대신 **'지구 카드'**(병마다)에 지금 모습이 쌓인다: 시대 배지, 인구, 발견 수, 가장 오래된 가문, 연대기 쪽수.
- 플레이어 칭호는 '거인의 이름' 하나 — 주민이 부르는 이름이 믿음에 따라 바뀐다 (*"하늘의 손님"* → *"거인님"* → *"우리의 거인"*). 숫자 레벨은 없다.

## 2. 허들 — 어디서 막히고 어떻게 넘나

> **v2 (2026-11-07): 새 시간 기준(하루=5분)의 허들 표는 [PLAYER_JOURNEY.md](PLAYER_JOURNEY.md) 4b가 기준.** 아래 표는 옛 병-날짜 기준 (참고).

원칙: **막힘은 세상 안의 이유로** (돈 벽·타이머 벽 아님). 넘는 방법이 늘 두 가지 이상 (기다리기 / 거인의 손).

| 시점 | 허들 (주민이 겪는 것) | 넘는 법 | 배우는 것 |
|---|---|---|---|
| 0~1일 | 하늘 낟알이 그침 → 첫 수확을 해야 함 | 밭 소원 들어주기, 물 주기 | 소원·거인의 손 |
| 1~2일 | 집이 모자라 아이를 못 낳음 (집 정원) | 주민이 지음 / 판자·건물 사 주기 | 마을은 주민이 짓는다 |
| 2~3일 | **첫 병** (고뿔·배앓이), 첫 노인의 죽음 | 우물·약초, 기다리기 | 생로병사, 돌봄 물건 |
| 3~5일 | **첫 위기 조짐** (김 서림 → 곰팡이 무리, 또는 날벌레) | 뚜껑 열기·횃불·소금 | 병의 법칙, 위기는 예고된다 |
| 5~10일 | 땅이 모자람 (영역 90%) → 출생 멈춤 | 국경 건물 / **분가** (새 마을) | 세상을 넓히기 |
| ~13일 | 두 번째 병 6,000 — 사고 싶은 것과 경쟁 | 제물 모으기 (믿음↑ = 수입↑) | 저축과 선택 |
| 13~20일 | 새 기후의 낯선 위기 (냉대 혹한, 아열대 열병) | 그 기후의 대응 발견 | 병마다 다른 세상 |
| 17일~ | 읍내 시대 — 시대 배율이 낮아 느려짐 | 발견으로 점수 채우기 (거인이 조건을 앞당김) | 발견 |
| 30일~ | 큰 마을의 탁한 공기·연기·녹 | 숲지기, 뚜껑, 영양제 | 균형 |
| 40일~ | 영지 · 분파 · 병 사이 교역 | 다리·외교 (업데이트 1) | |

- **실패는 이야기다**: 마을이 크게 상해도 멸망 직전에 경고가 오고, 오프라인 보호(하루 1명·2쌍)가 있다. 잃은 것은 연대기에 남는다.
- **기다리기만 해도 넘는다** (느리게) — 거인의 손은 앞당길 뿐. 결제로 허들을 지우지 않는다 (발견·기후 해금은 결제 불가, 기획서 원칙).

## 2.5 게임오버 — 없다. 병의 끝만 있다 (v1)

> **플레이어에게 게임오버는 없다.** 지폐·키트 업그레이드·해금한 기후·발견 도감·혈통 도감·연대기는 무슨 일이 있어도 남는다 (거인의 것). 끝날 수 있는 것은 **병 하나의 문명**뿐이고, 그 끝도 이야기로 남는다.

### 병이 끝나는 조건
| 끝 | 조건 | 결과 |
|---|---|---|
| **멸망** | 병의 주민이 모두 죽음 | 병은 **폐허**가 된다 (12.3) — 집·묘지·연대기가 그대로 남은 조용한 세상 |
| (끝 아님) 믿음이 바닥 | 믿음 0 근처가 오래 감 | 제물이 끊기고 분파가 생길 뿐 — 거인이 다시 믿음을 쌓을 수 있다 |
| (끝 아님) 아이를 낳을 수 없음 | 가임 부부 0 | '마지막 불씨' 경고 (아래) — 이주민이 오면 다시 이어진다 |

### 멸망까지 가는 길과 막는 장치
- 길: 굶주림, 역병·열병 유행, 위기(곰팡이·화재·떠돌이 물방울), 거인의 손(강제로 거두기·물건으로 집 부수기·물난리), 늙음(아이가 없을 때).
- **보호**:
  - 첫 병의 **첫 3일은 멸망하지 않는다** (튜토리얼 보호 — 위기 없음, 굶어 죽지 않음).
  - **거인이 없을 때**: 위기 사망 하루 1명, 부부 2쌍 아래로 줄지 않음 (14장) — 돌아왔더니 끝나 있는 일은 없다.
  - **거인이 볼 때만** 멸망할 수 있다 — 즉, 멸망은 늘 거인이 지켜보는 앞에서, 도울 기회가 있는 채로 온다.
- **'마지막 불씨' 경고** — 인구 6명 이하 또는 가임 부부 0:
  - 병 밖: 유리가 잿빛으로 흐려지고 오르골 음악이 느려짐. 촌장(또는 가장 나이 많은 사람)의 편지: *"거인님, 우리가 얼마 남지 않았어요."*
  - **구원의 가족**: 그 병에 **한 번 무료**로 이주민 가족(부부 + 아이)을 내려 줄 수 있다 (병마다 현실 7일에 한 번). 돌봄 물건·먹을 것은 평소 값.
- 멸망하면: 마지막 사람의 마지막 말이 연대기 끝에 남고 (*"…그리고 병은 고요해졌다."*), 병 밖에서 등불이 꺼진다. 슬프지만 짧게 — 바로 아래 선택지.

### 폐허에서 다시 시작
| 방법 | 내용 | 값 |
|---|---|---|
| **폐허 위의 새 마을** | 같은 병에 새 정착민 가족 (스타터 키트 + 산 업그레이드). 옛 집터·묘지·유물이 남아 있고, 새 주민이 **옛 문명을 발견**한다 (발견 점수, 유물 → 박물관·전설). 연대기는 '2장'으로 이어짐 | 무료 |
| **다른 병에서 분가** | 거인의 다리로 내 다른 병의 가족을 보냄 — 혈통·기술이 이어짐 | 다리 규칙대로 |
| **병 비우고 새로 창조** | 지형부터 다시 (빠른 창조). 옛 연대기는 선반의 '지난 세상' 책으로 보관 | 무료 |
| **폐허로 두기** | 유적으로 남겨 구경·발굴 (12.3) | — |

### 다시 시작해도 남는 것 (거인의 것)
- **지폐 전부**, 손에 든 물건, 키트 업그레이드, 해금한 기후, 선반의 다른 병들, 발견 도감·혈통 도감, 모든 연대기, 설정.
- 병 안의 것(주민·건물·창고·그 병의 발견)만 폐허와 함께 남거나 사라진다.
- 결제로 산 것은 절대 사라지지 않는다 (BM 원칙, 17장).

## 3. 동기 — 사람들이 왜 다시 오나

| 동기 | 이 게임에서 | 짧은 세션 (3~5분) | 긴 세션 (20분+) |
|---|---|---|---|
| **궁금함** (무슨 일이 있었지?) | 비운 동안 태어나고 죽고 지어진 것, 촌장의 편지 (SAVE.md 4장) | ✔ 핵심 | |
| **애착** (내 사람들) | 이름·얼굴·혈통·3대 가계, 아기 이름 짓기, 따라가 보기 | ✔ | ✔ |
| **돌봄** (도와줘야 해) | 소원 편지, 중증 환자 편지, 위기 조짐, 제단에 쌓인 제물 | ✔ 핵심 | |
| **발견** (처음 보는 것) | 발견 25종, 누룩·푸른곰팡이, 버섯·민들레, 소금, 세상의 끝 | | ✔ 핵심 |
| **수집** | 혈통 33종 (좋은 18 · 나쁜 15), 희귀 출생 (눈송이 아이), 기후 6종, 발견 도감, 연대기 | | ✔ |
| **창조·꾸미기** | 새 병 창조, 물길 바꾸기, 앰플 탑 자리, 병 꾸미기 | | ✔ |
| **성장** | 시대 배지, 선반의 병, 분가한 마을들 | ✔ (조금씩) | ✔ |
| **힐링** | 소리·빛·느린 시간, 꽃씨 날리기, 축제 | ✔ | ✔ |

### 3.1 하루의 리듬 (목표)
- **아침 (1~3분)**: 촌장의 편지 → 제단의 제물 받기 → 소원 하나 들어주기.
- **틈틈이 (1분)**: 알림 *"유리에 김이 서리기 시작했어요"* → 뚜껑 열기.
- **저녁 (10~20분)**: 저녁 기도 구경, 이주민 뽑기·상점, 연대기 읽기, 새 병 준비, 꽃씨 불기.
- 출석 보상·연속 접속 보너스는 **없다** (압박 없는 초대 — OPENING 원칙). 대신 '돌아오면 늘 무언가 일어나 있다'가 보상.

### 3.2 길게 보는 목표 (주·달)
- 1주: 마을 시대, 첫 분가, 첫 위기 극복, 두 번째 병 준비.
- 2주: 두 번째 병 (새 기후), 3대 가계, 발견 8~10종.
- 1달: 병 3개, 읍내, 발견 15종, 기후 4종, '전설이 된 사람' (연대기에 이름이 반복되는 주민).
- 그 뒤: 영지·교역·분파 (업데이트), 폐허 탐방·발굴 (12.3).

## 4. 화면에서 성장이 보이는 곳
- **지구 카드** (선반에서 병을 누르면): 시대 배지 · 인구 그래프 · 발견 n/25 · 가장 오래된 가문 · 연대기 쪽수 · 만든 날.
- **발견 도감** (연대기 안 탭): 발견한 것은 그림·처음 발견한 주민 이름·날짜, 못 한 것은 실루엣 + 한 줄 힌트 (*"물이 마르면…"*).
- **혈통 도감**: 만난 혈통만 채워짐.
- **시대가 바뀔 때**: 계시 연출 + 마을 모습이 바뀜 (집 양식·옷) — 가장 큰 보상 순간.
- 숫자는 최소 (UI 원칙): 인구·지폐·발견 수만 숫자, 나머지는 그림·말.

## 5. 확인할 지표 (시험판·소프트런칭)
- 첫 세션 길이 · 창조 완료율 · 첫 제물 받기까지 걸린 시간 · 1일/3일/7일 재방문 · 하루 세션 수 · 두 번째 병 산 날 · 첫 위기에서 뚜껑을 연 비율.
- 시험판(지인)에서는 설문 3개: 처음 5분이 지루했나 / 누구 이름을 기억하나 / 왜 다시 열었나.
