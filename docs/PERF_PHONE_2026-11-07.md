## 읽기
1. **이 폰(최상급)에선 대부분 60fps 근처**지만 120Hz 화면의 여유는 없다. 세상 전체 보기는 59fps.
2. **예산을 크게 넘음**: 아트 바이블 예산은 삼각형 300k / 그리기 호출 300 (ppu 16). 실측 **삼각형 약 2M (6~7배), 그리기 호출 480~980 (2~3배)**.
3. **배율 0.75가 거의 효과 없음** (GPU ms 거의 같음) → 화면 칠하기가 아니라 **꼭짓점·그리기 호출이 병목**. 해상도 낮추기로 풀리지 않는다.
4. **꽃숲·풀이 삼각형의 2/3 (1.35M)** — 소인 세계에서 꽃숲은 더 늘어날 것이라 가장 먼저 손볼 곳: 멀티메시 묶음, 거리별 단계(LOD)·멀리선 카드, 화면 밖 자르기.
5. 외곽선·그림자는 비용이 작다 (≤1ms).
6. 시뮬·장면 4~5ms는 괜찮다. 따라잡기 덩어리 100ms는 쪼개야 한다 (≤33ms 목표).
7. 중급 폰(예산 기준 기기)은 이 폰의 1/3~1/4 GPU — 지금 그대로면 20~30fps 예상. **ADR-0003 성능 예산**과 꽃숲 묶음 작업이 필요.
