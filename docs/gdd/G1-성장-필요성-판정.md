# G1 성장 필요성 판정

> 2026-11-16 · 초안. 성장을 넣을지는 Sonnet max 검토로 위임 결정한다 (사용자 위임 2026-11-16).

## 판정
**성장은 필요하다. 다만 캐릭터의 수직 성장(레벨, 능력치)은 넣지 않는다. '가진 것이 늘어나는' 수평 성장으로 한다.**

| 구분 | 이 게임 |
|---|---|
| 캐릭터 성장 | 없음. 플레이어 캐릭터가 없고, 정령에게도 능력치가 없다 |
| 플레이어 성장 | 수집과 배치 지식이 늘어난다. 누가 무엇을 좋아하는지 알게 된다 |
| 수직 / 수평 | **수평**: 놀잇감, 간식, 방이 늘어나 만날 수 있는 정령과 장면이 넓어진다. 숫자가 커지지 않는다 |
| 영구 / 런 내 | 전부 영구. 리셋이 없다 (X10 해당 없음) |
| 관계 성장 (0.3판) | **친밀도**: 정령별 방문 횟수가 기준을 넘으면 단골 일러와 특별 선물이 열린다 (G2) |

**왜 필요한가:**
- 놀잇감과 방이 늘지 않으면 같은 질문("누가 올까")의 답이 금방 고정되어 설렘이 줄어든다 (필러 1).
- 늘어나는 것이 그림(새 정령, 새 일러)이어야 필러 3을 지킨다.

## 체감 가능한 변화 목록
1. 새 놀잇감을 놓으면 처음 보는 정령이 온다 → 도감과 일러 카드가 늘어난다.
2. 좋은 간식을 쓰면 희귀 정령이 올 수 있다.
3. 둘째 방이 열리면 놓을 칸이 5→9칸(놀잇감 칸 4→7, 방마다 그릇 칸 1)으로 늘고, 방의 그림과 창밖 풍경이 달라진다.
4. 장면 일러가 해금된다.
5. (0.3) 단골 일러: 같은 정령의 두 번째, 세 번째 일러가 열린다.

## 속도 목표 (플레이 시간 환산 — 값은 X9·T7에서 검증)

| 목표 | 시점 (하루 3~6회 접속, 1회 1~3분) |
|---|---|
| 첫 정령 만남 | 첫 접속 30초 안 (튜토리얼 보장) |
| 흔한 정령 6명 중 4명 | 첫날 |
| 놀잇감 6종 다 갖기 | 3~4일째 |
| 둘째 방 열기 | 4~5일째 |
| 흔한 6명 전부 | 3일째 |
| 희귀 2명 | 5~7일째 (조건을 노리면) |
| 장면 일러 3장 | 6~7일째 |
| **MVP 7일 시험이 끝날 때** | 도감 8/8, 정령 일러 8/8, 장면 2~3/3. 다 모으기 직전의 갈증이 남게 한다 |

**성장 곡선 vs 난이도 곡선:** 난이도가 없다. 대신 **'다음 것이 얼마나 멀리 있나'**가 곡선이다. 처음에는 빨리 열리고, 희귀와 장면으로 갈수록 조건이 까다로워진다.

## 연결 시스템
- S9 상점과 소지품: 놀잇감, 간식, 방
- S7 수집: 도감, 일러 해금
- S4 방문: 새 후보 정령
- S8 재화: 성장의 연료
- (0.3) 친밀도: S7에 추가
