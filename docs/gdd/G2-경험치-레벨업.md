# G2 친밀도 단계 (경험치·레벨업 재해석)

> 2026-11-16 · 초안. **0.3판 기능**이다. MVP에서는 visit_count만 기록하고 단계는 쓰지 않는다. 기준값은 Sonnet max 검토로 위임 결정한다.
> 책의 '경험치 → 레벨'은 이 게임에서 **'정령별 방문 횟수 → 친밀도 단계'**다. 플레이어 레벨은 없다.

## 획득 출처

| 출처 | 양 | 지급 시점 | 중복 방지 |
|---|---|---|---|
| 정령이 떠남 (Leaving 진입) | visit_count +1 | Leaving 진입 1회 (K4) | 방문 1건당 1회. 방문 ID(`visit_seq`)로 확인 |
| ~~탭, 사진~~ | 없음 | - | 친밀도를 탭 연타로 올리지 못하게 한다 (악용 방지, F7) |

## 데이터
- **저장:** `collection[spirit].visit_count` (정수 ≥ 0)
- **파생 (저장 안 함):** `bond_level` = 기준표에서 visit_count 이하인 가장 높은 단계
- **정적:** `BondTable` (단계별 필요 방문 수와 해금 내용)

## 단계 기준표 (TEMP — X9에서 하루 방문 수와 맞춰 확정)

| 단계 | 이름 (정령 쪽 표현, 숫자 없음) | 필요 visit_count (누적) | 열리는 것 |
|---|---|---|---|
| 0 | 처음 만남 | 1 | 정령 일러 카드 (MVP부터) |
| 1 | 얼굴을 기억함 | 15 | 단골 일러 1 · 정령의 한마디 2개 |
| 2 | 단골 | 45 | 단골 일러 2 · 특별 선물 확률 소폭 상승 |
| 3 | 오랜 친구 | 120 | 단골 일러 3 (그 정령의 '집' 장면) |
| (최대) | - | 120 이후 | 더 열리는 것 없음. 방문 수는 계속 센다 |

- **공식이 아닌 표를 쓴다.** 정령마다 기준을 다르게 둘 수 있다. 희귀 정령은 기준을 1/3로 둔다 (`BondTable.rare_scale` TEMP 0.33).
- **숫자 예제:** 흔한 정령이 하루 평균 8번 방문한다면 → 2일째 단계 1, 6일째 단계 2, 15일째 단계 3. (하루 방문 수는 X9에서 정함)

## 처리 규칙
- **다중 단계:** 방치 계산으로 한 번에 기준을 여러 개 넘으면 모든 단계를 순서대로 해금한다. 연출은 한 번에 하나씩 보여 준다 (U8).
- **이월:** 누적 방식이라 이월 개념이 없다.
- **최대 이후:** 계속 센다. 도감 기록용이다.
- **단계 내림 금지:** visit_count는 줄지 않는다 (필러 2).
- **처리 순서:** visit_count +1 → bond_level 다시 계산 → 새 단계면 S7 해금 → 저장 표시.

## 경계 테스트
1. **Given** visit_count = 14. **When** 정령이 떠난다. **Then** 15가 되고 단계 1이 해금되며, 해금은 1회만 일어난다.
2. **Given** visit_count = 14. **When** 방치 계산 중 32번 방문한다. **Then** 46이 되고 단계 1과 2가 순서대로 해금된다.
3. **Given** visit_count = 120 (최대). **When** 다시 방문한다. **Then** 121이 되고 새로 해금되는 것은 없다.
4. **Given** 같은 방문 기록으로 방치 계산을 두 번 돌린다 (버그 상황). **Then** visit_seq 검사로 +1만 된다.
5. **Given** 저장한 뒤 다시 불러온다. **Then** bond_level은 저장 없이 같은 값으로 다시 계산된다.
