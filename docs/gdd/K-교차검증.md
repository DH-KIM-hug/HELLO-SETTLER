# K 단계 교차 검증 (2026-11-16)

| 검사 | 결과 |
|---|---|
| 입력 상태 조건 = 상태 머신 상태 | K3의 입력 가능표는 화면 컨텍스트(K1) 기준이고, 정령 탭은 '노는 중'(K4)일 때만 된다. 서로 맞는다 |
| 애니메이션 전환 = 상태 전환 | K6 전환표의 진입과 종료가 K4 T1~T8과 1:1로 맞는다. 우선순위도 같다 |
| 능력치 표 단일화 | K7이 유일한 수치 표다. B4·G3은 해당 없음이다. 값은 T7 한 곳에서 관리한다 |
| 책임표(K8)에 모든 규칙의 담당이 있음 | S1~S14, 입력, 데이터, 묶기를 모두 다룬다 |
