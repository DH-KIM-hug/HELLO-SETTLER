# C5 데이터 목록 (초안)

> 2026-11-16 사용자 확정 (초안 단계 확정, 필드 세부는 T단계에서).
> **4분류**
> - **설정(정적):** 기획 데이터 파일. 실행 중에 바뀌지 않는다.
> - **런타임:** 실행 중에만 있다. 저장하지 않는다.
> - **저장:** 저장 파일에 들어간다.
> - **계산(파생):** 다른 값에서 매번 계산한다. 저장하지 않는다.

## 1. 설정(정적) 데이터 — 기획 데이터 파일 (`data/*.json` 또는 Godot Resource, T8에서 결정)

| 데이터 | ID 형식 | 필드 (타입 · 설명 · 기본값/범위) | 쓰는 시스템 |
|---|---|---|---|
| **SpiritDef** 정령 | `spirit_xxx` | name: 문자열 · element: 속성(꽃, 물, 별 등) · rarity: common/rare · likes_toys: ToyId 목록 · likes_food: FoodId 목록 · weather: 맑음/흐림/비 중 0개 이상(없으면 상관없음) · time: 낮/밤/둘 다 · weight: 실수 > 0 · stay_min / stay_max: 초 · gift_table: GiftTableId · card_art: 그림 경로 | S4, S6, S7, S8 |
| **ToyDef** 놀잇감 | `toy_xxx` | name · size: 칸 크기(작음/큼) · art · pose_slots: 정령이 앉는 자리 수(1~2) · price: 정수 ≥ 0 · unlock: 처음부터/상점 | S2, S4, S6, S9 |
| **FoodDef** 간식 | `food_xxx` | name · duration: 가득에서 빔까지 초 · attract: 방문 가중치 배율 ≥ 1 · price · art | S3, S4, S9 |
| **RoomDef** 방 | `room_xxx` | name · art(낮/밤) · window: 창 위치 · slots: SlotDef 목록 · price: 0이면 처음부터 | S2, S9 |
| **SlotDef** 칸 | `room_xxx/slot_n` | position: 화면 좌표 · accepts: 놀잇감/간식 그릇 · size | S2 |
| **PoseDef** 정령 모습 | `spirit_xxx@toy_xxx` | art(프레임들) · anim: 숨쉬기/깜빡임 설정 · is_special: 사진첩 '처음 본 모습' 대상 여부 | S6, S7 |
| **SceneArtDef** 장면 일러 | `scene_xxx` | name · art · condition: {정령 목록, 날씨, 시간대, 방} · hint: 문자열 | S7 |
| **GiftTableDef** 선물 표 | `gift_xxx` | coin_min / coin_max: 정수 · special: 특별 선물 목록과 확률 0~1 | S8 |
| **ShopItemDef** 상품 | `shop_xxx` | target: ToyId/FoodId/RoomId · price · requires: 해금 조건(없음 또는 ID) | S9 |
| **WeatherMapDef** 날씨 묶기 | 고정 1개 | 실제 날씨 코드 → 맑음/흐림/비 표 | S1 |
| **SoundDef** 소리 | `sfx_xxx` | 파일 · 크기 | S13 |
| **TutorialDef** 안내 단계 | `tut_n` | 말풍선 글 · 가리킬 대상 · 끝 조건 | S12 |
| **Tuning** 조정값 | 고정 1개 | visit_interval_s · offline_cap_s · first_visit_tutorial_s · weather_refresh_s 등 (값은 X9·T7) | S1, S3, S4, S5 |

**하드코딩 금지 기준:** 정령, 놀잇감, 간식, 방, 장면, 가격, 확률, 시간 값은 모두 데이터 파일에 둔다. 셋 중 하나에 해당하면 코드에 쓰지 않는다.
- 자주 바뀐다.
- 종류가 늘어난다.
- 기획자가 조정한다.

## 3. 런타임 데이터 (저장 안 함)
- 지금 보는 방

## 4. 계산(파생) 데이터 — 저장하지 않는다

| 값 | 계산 | 계산하는 시스템 |
|---|---|---|
| 지금 낮/밤 | 지금 시각 + 위치의 해 뜨고 지는 시각 (위치가 없으면 고정 시각) | S1 |
| 지금 날씨 | weather_cache(유효 기간 안) 또는 날짜 시드 | S1 |
| 수집률 | collection 크기 ÷ SpiritDef 수 (도감에는 그림으로만 표시, 숫자 표시 안 함) | S7 |
| 그릇 남은 양 | amount − 경과 시간 ÷ duration | S3 |
| 살 수 있는지 | wallet ≥ price 이고 조건 충족 | S9 |
| 잠긴 일러 힌트 | SceneArtDef.hint + 이미 만난 정령 | S7 |

## 5. 관계 (ID 참조)

```
RoomDef ─1:N─ SlotDef ── placement ── ToyDef ─N:M─ SpiritDef ── PoseDef(spirit@toy)
                        food_bowls ── FoodDef ─N:M─┘      │
SpiritDef ── GiftTableDef            SceneArtDef.condition ─▶ SpiritDef, 날씨, 시간대, RoomDef
ShopItemDef.target ─▶ ToyDef | FoodDef | RoomDef
```

모든 참조 ID는 존재해야 하고 중복이 없어야 한다. 데이터 파일을 읽을 때 검사하는 시험을 둔다 (T단계).

## MVP 최소 필드
SpiritDef 8개 · ToyDef 6개 · FoodDef 2개 · RoomDef 2개(칸 5+4) · PoseDef 최대 8×6(정령이 좋아하는 놀잇감만 그린다, 실제로는 더 적음) · SceneArtDef 3개 · GiftTableDef 2개(흔한/희귀) · ShopItemDef 약 8개.
