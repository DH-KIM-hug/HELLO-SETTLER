## 일정이 부족할 때 (순서)
1. **선택 기능부터 뺀다.** 사진 내보내기, 탭 반응 다양화, 설정 세부를 뺀다.
2. **중요 기능을 단순화한다.**
   - 장면 일러를 3장에서 1장으로 줄인다.
   - 사진은 앨범 저장만 한다.
   - 첫 안내는 말풍선 3개로 줄인다.
   - 둘째 방은 첫 방 그림의 색만 바꾼다. 다만 필러 3과 충돌하므로 사용자 확인이 필요하다.
3. **필수 기능은 유지한다.** 특히 정령 일러 8장과 그림체 품질은 줄이지 않는다 (사용자 기준 "일러가 이뻐야 돼").

## 우선순위 ≠ 개발 순서

우선순위는 무엇이 중요한지를 정하고, 개발 순서는 위험과 의존관계로 정한다.

| 순서 | 판 | 무엇 | 이유 |
|---|---|---|---|
| 1 | 0.0 프로토 | S11 저장 → S1(대체 날씨만) → S2 → S3 → S4 → S5 (네모 그림) | 고위험인 확률 감과 방치 계산을 먼저 본다 |
| 2 | 0.1 수직 조각 | 정령 1명 + 놀잇감 2 + 일러 카드 1장을 최종 그림체로. S6, S7 최소 | 고위험인 그림체를 사용자가 승인한다 |
| 3 | 0.2 MVP 앞부분 | S8 → S9 → S7 전체 → 정령 8명 그림 | |
| 4 | 0.2 MVP 뒷부분 | S1 위치 연동 → S10 → P6 → S13 → S12 → 둘째 방 → S14 | |
