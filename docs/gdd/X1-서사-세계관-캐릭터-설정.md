# X1 서사 · 세계관 · 캐릭터 설정 (작은 세계관과 프로필만)

> 2026-11-16 · 확정 (위임 결정 1·2 반영). 사용자 결정: "캐릭터 프로필·작은 세계관만", 큰 이야기는 없다. 톤과 호칭은 위임 결정 2 (Sonnet max, 2026-11-16 — 위임결정-2.md) X-1·X-2. 결말은 없다 (끝없는 수집).

## 세계관 (한 문단)
사람들이 사는 집에는 아무도 모르는 손님들이 드나든다. 꽃잎, 물방울, 별빛, 이끼 같은 작은 것들에서 태어난 **손가락만 한 정령들**이다. 정령들은 사람 눈에 잘 띄지 않는다. 하지만 누군가 작은 간식과 놀잇감을 놓아 두면 슬그머니 놀러 와서 놀다 가고, 고맙다는 뜻으로 반짝이는 것을 두고 간다. 창밖 날씨가 바뀌면 찾아오는 정령도 바뀐다. 플레이어는 자기 집에 정령들이 다녀간다는 것을 아는 **단 한 사람**이다. 그 사실은 플레이어만의 비밀이다 (D8 판타지).

## 톤 (X-1)
- **포근하고, 조금 신비롭고, 혼자 웃게 되는 작은 귀여움.**
- **피할 것:** 슬픔, 위기, 이별 서사. 정령이 사라지거나 아프거나 화나는 일은 없다 (필러 2).
- 정령의 말은 짧고 의성어가 많다. 숫자를 쓰지 않는다.
- 게임, 앱, 플레이어, 휴대폰, 상점, 구매 같은 메타 단어는 정령의 말에 쓰지 않는다 (옛 규칙을 이어감).
- **정령은 플레이어를 정령어로 '사람'을 뜻하는 말로 부른다** (사용자 결정 2026-11-16: "정령의 말 - 사람을 뜻하는 정령어로 말하기"). 위임 결정 X-2 '큰 사람'을 대체한다. 단어는 정해지는 대로 여기에 적는다. 다만 한마디 대부분은 호칭 없이 쓴다.
- 신비는 '비밀을 나만 안다'까지다. 수줍은 정령은 '부끄러워 숨는' 쪽이다. 슬픔, 이별, 위협, 비꼼은 없다.

## 주요 인물

| 인물 | 역할 | 동기 | 플레이 영향 |
|---|---|---|---|
| 플레이어 (큰 사람) | 집주인. 놓고 기다리고 기록한다 | 정령을 만나고 싶다 | 모든 행동의 주체 |
| 정령 8명 (MVP) | 손님 | 좋아하는 놀잇감, 간식, 날씨를 찾아 논다 | 방문 조건 = 성격 (G7 표) |
| 수줍은 정령 | 보이지 않는 손님 (간식을 몰래 먹음) | 부끄러워서 볼 때는 안 나온다 | 그릇 소모의 이유. 0.3판 이후 숨은 정령 후보 |

## 정령 프로필 형식 (SpiritDef.profile, 0.3에서 한마디 목록으로 확장)

| 항목 | 예: spirit_petal (꽃잎 머리) |
|---|---|
| 이름 | (아트와 함께 정함) 예: 꽃잎이 |
| 태어난 곳 | 봄 창가 화분의 첫 꽃잎 |
| 좋아하는 것 | 흔들리는 것 (그네, 해먹), 햇볕 |
| 성격 한 줄 | 잘 웃고 금방 잠든다 |
| 한마디 (0.3) | "흔들흔들… 졸려…" / "오늘 햇볕 따뜻해!" |

- 8명 모두 이 형식으로 쓴다. 이름은 2~4자 순우리말 느낌으로 한다.
- 겉모습은 능력과 상관없다. 속성 표식은 '좋아하는 것'의 힌트일 뿐이고 수치를 읽지 않는다 (옛 규칙을 이어감).

## 서사 ↔ 게임플레이 연결

| 서사 요소 | 게임플레이 |
|---|---|
| 정령은 좋아하는 것을 찾아온다 | 방문 조건 (G7) → 배치를 바꿀 동기 |
| 날씨마다 다른 정령 | 위치 연동 날씨 (S1) → 다시 열 이유 |
| 반짝이는 것을 두고 간다 | 선물 재화 (G6) |
| 수줍은 정령 | 그릇 소모와 다시 채우기 |
| 정령의 비밀을 아는 사람 | 도감과 일러 수집 = '나만의 기록' |
| 친해지면 더 보여 준다 (0.3) | 친밀도 → 단골 일러 |

## 전달 방식
- **대사:** 탭 반응의 말풍선 한 줄. 한마디는 0.3판부터이고, MVP는 의성어 그림만 쓴다.
- **텍스트:** 도감 프로필, 힌트.
- **연출:** 등장과 퇴장, 반응.
- **환경:** 부스러기, 발자국, 창밖 날씨.
- **긴 컷신이나 대화창은 없다** (반필러).
