## 현지화

| 규칙 | 내용 |
|---|---|
| 문자열 키 | 화면에 보이는 모든 글은 키로 쓴다. 형식: `<영역>.<항목>[.<변형>]` (예: `msg.buy_ok`, `spirit.petal.name`, `toy.thimble.desc`). 문자열 표는 `data/text/ko.csv` 한 곳 (Godot Translation) |
| 하드코딩 금지 | 코드와 씬에 한국어 문자열을 직접 쓰지 않는다. 검사 시험으로 `.gd`와 `.tscn`의 한글 리터럴을 찾아낸다 (개발용 로그 제외) |
| 숫자·날짜 | 재화는 천 단위 쉼표로 표시한다. 날짜는 지역 형식을 따르고, 도감 '처음 만난 날'은 '11월 16일'처럼 쓴다 |
| 길이 여유 | 버튼과 카드 글은 한국어 기준 +40%를 견디도록 자동 줄바꿈하거나 줄인다 (영어 대비) |
| 글꼴 | 한글 전체와 기본 라틴 문자를 지원하고, 상업 사용 가능한 글꼴을 쓴다 (선택은 아트 바이블) |
| 방향 | 왼쪽에서 오른쪽만 (오른쪽에서 왼쪽 쓰기는 지원하지 않음) |
| 이름 | 정령 이름도 키로 관리한다 (언어별 이름 변경 가능) |
| 이후 언어 | **영어 (1.0 출시)** → 일본어 (1.0 뒤 첫 콘텐츠 판, 원어민 검수 필수) (X-4) |

## 법·등급
- **연령 등급:** 폭력, 공포, 성적 내용이 없다 → 전체 이용가 목표.
- **광고(0.9):** 아동 대상으로 분류되지 않도록 대상 연령을 정한다 `[X6]`.
- **위치 정보:** 대략 위치만 쓴다. 개인정보 처리방침과 스토어 표시에 적는다 (X6·X8).

## 테스트 항목
1. 모든 화면을 글씨 '크게'로 열었을 때 넘치거나 잘리는 곳이 없다.
2. 반짝임 줄이기를 켜면 번쩍임과 깜빡임이 없다.
3. 소리를 끈 상태에서도 새 손님과 해금을 알 수 있다.
4. 한글 리터럴 검사가 0건이다.
5. 색맹 시뮬레이션(3종)에서 날씨, 잠김, 빈 그릇을 구분할 수 있다.
