# K5 상태 상세 — 정령 4상태

> 2026-11-16 · 초안. 이 게임은 Idle/Move/Attack/Hit/Dead 대신 K4의 4상태를 쓴다. 책의 항목은 이렇게 바꿔 읽는다.
> - **Attack의 3구간**(선딜, 판정, 후딜) → Arriving과 Leaving의 연출 구간
> - **Hit 경직** → 탭 반응 시간
> - **Dead 후속 흐름** → Leaving 뒤의 재방문 규칙
>
> 2026-11-16 사용자 확정. 시간 값은 TEMP이며 폰에서 조정한다. 쿨다운 길이는 X9에서 정한다.

## Away (없음)

| 항목 | 내용 |
|---|---|
| 의미 | 칸에 정령이 없다 |
| 진입 조건 | 게임 시작 · Leaving 끝 |
| 진입 시 | visits_now에서 그 칸을 지운다 |
| 유지 중 | 방문 판정 간격마다 S4가 이 칸을 판정한다 (칸에 놀잇감이 있고 간식 그릇이 비어 있지 않을 때만) |
| 허용 입력 | 칸 탭 · 끌어 놓기 (빈 칸 또는 놓인 놀잇감) |
| 제한 입력 | 정령 탭 (정령 없음) |
| 종료 조건 | 방문 판정 성공 |
| 다음 상태 | Arriving (보이는 방, 앱 켜짐) / Playing (Restore: 보이지 않는 방이거나 방치 계산 중) |

## Arriving (오는 중)

| 항목 | 내용 |
|---|---|
| 의미 | 창틀이나 문틈에서 나타나 놀잇감까지 오는 연출 |
| 진입 조건 | Away에서 방문 성공, 그 방이 화면에 보임 |
| 진입 시 | 등장 위치 고르기(방의 '입구' 점 중 하나), 등장 소리(희귀하면 다른 소리) |
| 유지 중 | 구간 ① 나타남 `appear_s` → ② 이동 `walk_s` → ③ 놀잇감에 자리 잡기 `settle_s` |
| 허용 입력 | 놀잇감 바꾸기/빼기 (→ ForceLeave) |
| 제한 입력 | 정령 탭 (무시) |
| 종료 조건 | 세 구간 끝 |
| 다음 상태 | Playing · ForceLeave면 Leaving |

## Playing (노는 중)

| 항목 | 내용 |
|---|---|
| 의미 | 놀잇감 위에서 그 놀잇감 자세로 논다 |
| 진입 조건 | Arriving 끝 · Restore |
| 진입 시 | 자세 애니 시작. 처음 온 정령이면 S7에 '처음 방문'을 알림 (일러 카드 해금, 새 손님 띠). 그 자세가 처음이면 '본 모습' 기록 |
| 유지 중 | 머무는 시간 흐름 (`leave_at`) · 숨쉬기·깜빡임 · 탭 반응 (`reacting` 플래그, `react_s` 동안) |
| 허용 입력 | 정령 탭 · 사진 찍기 · 칸 탭(바꾸기) |
| 제한 입력 | 반응 중 같은 정령 재탭 |
| 종료 조건 | `leave_at` 도달 · 놀잇감 바뀜/빠짐 |
| 다음 상태 | Leaving |

## Leaving (떠나는 중)

| 항목 | 내용 |
|---|---|
| 의미 | 손을 흔들고 나가며 선물을 남긴다 |
| 진입 조건 | Playing·Arriving 종료 |
| 진입 시 | **S8에 선물 생성 요청 1회** (선물 표시가 칸 옆에 생김) · S7에 방문 횟수 +1 · 손 흔들기 시작 |
| 유지 중 | 구간 ① 손 흔들기 `wave_s` → ② 나감 `exit_s` |
| 허용 입력 | 선물 탭 (선물은 이미 생겨 있음) |
| 제한 입력 | 정령 탭 |
| 종료 조건 | 두 구간 끝 (보이지 않는 방이거나 방치 계산 중이면 즉시) |
| 다음 상태 | Away |

## 시간 값 (데이터 `Tuning.spirit`, TEMP: 폰에서 조정)

| 값 | 초안 | 뜻 |
|---|---|---|
| appear_s · walk_s · settle_s | 0.4 · 0.8 · 0.3 | 오는 연출 합 1.5초 |
| react_s | 1.2 | 탭 반응 1회 |
| wave_s · exit_s | 0.6 · 0.4 | 떠나는 연출 합 1.0초 |
| stay_min / stay_max | 흔한 1,800~5,400 · 희귀 1,200~3,600 (T7) | 머무는 시간 |
| revisit_cooldown_s | 3,600 (T7) | **떠난 정령이 다시 올 수 있기까지의 시간** (Dead 후속 흐름 대신) |

## 후속 흐름 (Leaving 뒤)
- 떠난 정령은 `revisit_cooldown_s` 동안 어느 칸에도 오지 않는다. 같은 정령만 계속 오는 것을 막아 설렘을 지킨다 (필러 1).
- 쿨다운이 끝나면 다시 판정 후보가 된다. 영영 안 오는 일은 없다 (필러 2).

## 허용 · 금지 전환 테스트
1. **Given** Playing 중이다. **When** `leave_at`이 지난다. **Then** Leaving이 되고, 선물이 정확히 1개 생기고, 방문 횟수가 +1 된다.
2. **Given** Arriving 중이다. **When** 놀잇감을 뺀다. **Then** 바로 Leaving이 되고, 선물 1개가 생긴다 (C7 정책).
3. **Given** Leaving 중이다. **When** 그 칸에 놀잇감을 다시 놓는다. **Then** 이 정령은 돌아오지 않는다. 다음 판정에서 다른 정령이 오거나, 쿨다운이 끝난 뒤에만 같은 정령이 올 수 있다.
4. **Given** Away 상태다. **When** 어떤 입력이든 들어온다. **Then** 선물이 생기지 않는다 (Away → Leaving 금지).
5. **Given** 정령 A가 칸 1에서 Playing 중이다. **When** 칸 2의 방문 판정에서 A가 뽑힌다. **Then** A는 제외되고 다시 뽑는다.
6. **Given** 반응 중에 `leave_at`이 지난다. **Then** 반응을 끊고 Leaving으로 간다 (우선순위 2 > 4).
