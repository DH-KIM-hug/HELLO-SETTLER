# D6 범위 판정

> 2026-11-16 사용자 결정: 초안에서 **사진·사진첩과 날씨를 '필수'로 올렸다** ("둘 다 지금으로"). 계절은 다음 판에 남는다.

## 제약 조건

| 항목 | 내용 |
|---|---|
| 기간 | 1~2년 (정식 출시 목표) |
| 인원 | 사용자 1명(기획 결정, 검수) + Claude 메인 세션과 서브에이전트(개발, 그림, 문서) |
| 실력과 도구 | Godot 4.7.2 운영 경험 있음(시험 체계, 폰 빌드). 2D 경험은 새로 쌓아야 함. 그림은 AI 생성(codex)과 후처리, 소리는 ElevenLabs |
| 리소스 | **캐릭터 그림이 가장 큰 비용이다.** 손님 1명에 기본 그림, 놀잇감별 모습, 표정, 도감 그림이 필요하다. 그림체를 일정하게 지키는 것이 위험 요소다 |
| 예산 | 큰 외주는 없음. AI 생성 비용과 스토어 등록비 정도 |
| 플랫폼 | 휴대폰 세로. 안드로이드 먼저, iOS는 나중에. 오프라인 위주, 클라우드 저장만 온라인 |
| 규칙 | 외부 그림을 복사하지 않는다, 특정 게임을 재현하지 않는다, 정령(손님) 쪽에는 숫자를 보이지 않는다 (CLAUDE.md) |

## 3분류 (확정)

| 분류 | 기능 | 이유 |
|---|---|---|
| **필수 (지금)** | 집 화면(방 2개) · 놓기 · 방문 판정 · 방치 시간 처리 · 손님 캐릭터(8명) · 도감 · 선물·재화 · 작은 상점 · 시간대(낮/밤) · **날씨(맑음·비 등 소수)** · **사진·사진첩** · 기기 저장 · 첫 안내(최소) · 기본 소리 | 핵심 재미(열어 보는 설렘) 검증 최소 판(D5) + 사용자가 차별화(날씨)와 감상(사진)을 첫 판부터 검증하기로 함 |
| **있으면 좋음 (다음 판)** | 친밀도 · 계절 · 손님 한마디·프로필 · 손님 확장(20명 이상) · 방 3개 이상으로 넓히기 · 알림 | 설렘과 재방문을 키우고, 차별화 요소를 완성한다 |
| **나중에 (보류)** | 꾸미기 테마 · 클라우드 저장 · 광고 보상 · 유료 재화 · iOS · 현지화 | 출시 준비 단계. 코어가 재미있다고 검증된 뒤에 한다 |

**삭제한 기능은 없다.** '나중에' 칸은 보류다. 현재 판에서 빼 둔 것일 뿐, 출시 전 판에서 다시 판단한다.
