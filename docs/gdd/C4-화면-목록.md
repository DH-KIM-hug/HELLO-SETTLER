## 팝업 · 띠 · 연출

| ID | 이름 | 종류 | 언제 | 입력 | 막는 범위 |
|---|---|---|---|---|---|
| Q1 | '새 손님!' 띠 | 위쪽 띠 (2초) | 처음 온 정령이 방에 보일 때 | 탭 → P5 | 막지 않음 |
| Q2 | 일러 해금 연출 | 전체 덮개 | 정령 일러나 장면 일러가 해금됐을 때 (열기 직후, 한 번에 하나씩) | 탭 → 다음 / 닫기 | 전체 막음 (닫기 전까지) |
| Q3 | 선물 받기 알림 | 아래 짧은 띠 | 선물을 받았을 때 | 없음 | 막지 않음 |
| Q4 | 구매 확인 | 가운데 창 | 상점에서 상품 탭 | 사기 / 그만 | 뒤 화면 막음 |
| Q5 | 위치 사용 안내 | 가운데 창 | 첫 안내가 끝난 뒤 한 번 | 허락 → 시스템 권한 창 / 나중에 | 뒤 화면 막음 |
| Q6 | 첫 안내 말풍선 | 말풍선 + 손가락 | 첫 안내 중 | 안내된 곳만 누를 수 있음 | 안내 대상 외 막음 |
| Q7 | 알림 띠 | 아래 짧은 띠 | 재화 부족, 저장 실패 등 | 없음 | 막지 않음 |

**팝업 우선순위 (동시에 생기면):** Q6 첫 안내 > Q2 일러 해금 > Q4 구매 확인 > Q5 위치 안내 > Q1 새 손님 띠 > Q3·Q7 짧은 띠.
- **필러 1을 지킨다:** Q2는 방이 먼저 보인 뒤 0.5초 뒤에 띄운다. 그래야 "누가 와 있나"를 먼저 본다.

## 화면 전환 흐름

```
P0 시작 ─▶ P1 방 ◀─┬─▶ P2 놓기 고르기
                   ├─▶ P3 상점 ─▶ Q4 구매 확인
                   ├─▶ P4 도감 ─┬─▶ P5 정령 상세
                   │            └─▶ P6 일러 보기
                   ├─▶ P7 앨범
                   ├─▶ P8 사진 찍기
                   └─▶ P9 설정 ─▶ P10 (숨김)
(모든 화면의 '뒤로'는 한 단계 위로, 결국 P1)
```

## 게임 상태 ↔ UI

| 게임 상태 | 보이는 UI |
|---|---|
| 방치 계산 중 | P0 (2초 상한, 넘으면 계산을 계속하면서 P1을 먼저 보여 줌) |
| 첫 안내 중 | P1 + Q6. 아래 버튼은 안내 순서대로만 열림 |
| 보통 | P1과 모든 화면 |
| 위치 끔 / 인터넷 없음 | P1 그대로 (대체 날씨), P9에 '대체 날씨' 표시 |
