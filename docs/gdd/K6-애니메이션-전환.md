# K6 애니메이션 전환 — 정령

> 2026-11-16 사용자 확정
> **원칙 (사람이 정한 것):**
> - **애니메이션은 게임 규칙을 결정하지 않는다.** 언제 오고 언제 떠나는지, 선물과 해금은 S4·S7·S8이 시간과 데이터로 정한다. 애니메이션은 그 결과를 보여 줄 뿐이다.
> - 애니메이션이 늦거나 건너뛰어져도(보이지 않는 방, 방치 계산) 규칙 결과는 같다.

## 그림 방식 (2D)
- 정령은 **컷아웃 2D**로 그린다 (몸통, 머리, 팔, 속성 표식을 조각으로 나눠 움직임). 자세마다 그림 한 장 위에 작은 움직임을 더한다.
- 프레임을 한 장씩 그리는 방식은 자세 수가 많아 비용이 크므로, 기본으로 쓰지 않는다.
- 정확한 방식(Godot Skeleton2D, 조각 Tween, 스파인류 도구)은 아트 바이블과 X8에서 정한다 `[TBD]`.
- **수직 조각(0.1)에서 그림체 승인과 함께 시험한다.**

## 상태 → 애니메이션 매핑

| 상태 / 플래그 | 애니메이션 | 루프 | 길이 | 끝난 뒤 |
|---|---|---|---|---|
| Arriving ① 나타남 | `appear` — 창틀이나 문틈에서 빛 방울이 퍼지며 나타남 | 아니오 | appear_s 0.4 | ② |
| Arriving ② 이동 | `walk` 또는 `float` (속성별: 꽃·별 정령은 둥실, 물 정령은 통통) | 예 | walk_s 0.8 | ③ |
| Arriving ③ 자리 잡기 | `settle` — 놀잇감 위에 앉거나 매달림 | 아니오 | settle_s 0.3 | Playing |
| Playing | `pose@toy` — 놀잇감별 자세 + 숨쉬기 + 깜빡임(2~5초마다 무작위) + 속성 표식 흔들림 | 예 | - | - |
| Playing + reacting | `react` — 놀람, 손 흔들기, 꺄르르 웃기 중 하나 (MVP는 1종) | 아니오 | react_s 1.2 | `pose@toy`로 복귀 |
| Playing + is_new | `pose@toy` + 머리 위 반짝임 1회 | - | 1.0 | - |
| Leaving ① 손 흔들기 | `wave` | 아니오 | wave_s 0.6 | ② |
| Leaving ② 나감 | `exit` — 빛 방울로 흩어짐 | 아니오 | exit_s 0.4 | Away (그림 지움) |
| Away | 없음 (그릇 옆에 부스러기와 발자국이 남아 있을 수 있음) | - | - | - |

## 이벤트 시점 (애니메이션 안의 표시 타이밍 — 규칙 판정이 아님)

| 이벤트 | 시점 | 하는 일 |
|---|---|---|
| `spawn_sfx` | appear 0초 | 등장 소리 (희귀면 다른 소리) |
| `settled` | settle 끝 | 새 손님 띠 표시 허용 (Q1) |
| `gift_pop` | wave 0초 | 선물 표시 '퐁' 등장. 선물 데이터는 Leaving 진입 때 이미 생겼다 |
| `gone` | exit 끝 | 정령 그림 노드 지우기 |

## 우선순위 (K4와 같음)

**ForceLeave(wave) > 시간 끝(wave) > 진행(appear→walk→settle→pose) > react**

- **ForceLeave나 시간 끝이 오면:** react와 Arriving 중간 동작을 끊고 바로 `wave`로 간다.
- **반응을 끊는 방식:** react를 Playing 중간에 끊을 때는 0.1초 섞기로 자연스럽게 넘긴다.

## 전환표

| 지금 → 다음 | 조건 | 섞는 시간 | 끊기 가능 |
|---|---|---|---|
| appear → walk → settle | 각 구간 끝 | 0 | 예 (ForceLeave) |
| settle → pose@toy | 구간 끝 | 0.1 | 예 |
| pose@toy → react | `reacting` 켜짐 | 0.05 | 예 (Leave) |
| react → pose@toy | react 끝 | 0.1 | - |
| 무엇이든 → wave | Leaving 진입 | 0.1 | 아니오 |
| wave → exit → (지움) | 구간 끝 | 0 | 아니오 |
| (없음) → pose@toy | Restore (열 때 이미 와 있음) | 0 (바로) | - |

## 테스트
1. **Given** Arriving의 walk 중이다. **When** 놀잇감을 뺀다. **Then** walk를 끊고 wave가 나오며, 선물 데이터는 정확히 1개 생긴다.
2. **Given** react 재생 중이다. **When** `leave_at`이 지난다. **Then** react가 끊기고 wave가 나온다.
3. **Given** 앱을 연다. **When** 정령이 Playing으로 Restore된다. **Then** appear 없이 pose@toy가 바로 보인다.
4. **Given** 보이지 않는 방에서 방문이 성공한다. **When** 그 방으로 넘긴다. **Then** 이미 pose@toy 상태로 보인다.
5. **Given** 애니메이션 길이를 2배로 바꾼다. **Then** 방문, 선물, 해금 결과와 시각은 바뀌지 않는다 (애니메이션 ≠ 규칙).
