# K3 입력 조건 · 불가 조건

> 2026-11-16 사용자 확정. 간식은 채운 순간부터 줄어든다. 정령 없이 줄어든 몫은 **'수줍은 정령'**이 몰래 먹고 간 것으로 보여 준다 (사용자 선택).
> **흐름:** 입력 → 컨텍스트 확인(K1) → 조건 검사(가벼운 것부터) → 실행 또는 무시. 실행은 항상 담당 시스템이 다시 검증한다.

## 조건 5유형 (이 게임식)

| 유형 | 이 게임에서 |
|---|---|
| 상태 | 지금 컨텍스트(Busy, Room, Sheet…) · 정령 상태(오는 중, 노는 중, 떠나는 중) · 첫 안내 단계 |
| 위치 | 어느 방, 어느 칸, 칸 종류(놀잇감 칸, 그릇 칸) |

| 시간 | 같은 대상 재탭 간격, 셔터 간격, 애니메이션 중 여부 |
| 장비 | (해당 없음) → 대신 '가진 물건인지' |

## 행동별 조건표

| 행동 | 가능 조건 (검사 순서) | 불가 시 처리 |
|---|---|---|
| 정령 반응 | ① 컨텍스트 Room ② 정령 상태가 '노는 중' ③ 같은 정령의 반응이 끝났음 | 무시 (피드백 없음) |
| 선물 받기 | ① Room ② 방치 계산 끝남 ③ 그 선물이 pending에 있음 | 무시. 이미 받았으면 표시가 이미 사라져 있음 |
| 칸 열기 | ① Room ② 그 칸이 열린 방에 있음 | 무시 |
| 그릇 탭 | ① Room ② (비었음 → 기본 간식으로 채움) / (차 있음 → 간식 고르기 판) | 해당 없음 (항상 가능, C7 진행 막힘 방지) |
| 물건 놓기 (탭/끌기) | ① Sheet ② 가진 물건(수량 ≥ 1) ③ 칸 종류가 맞음 ④ 같은 칸에 같은 물건이 아님 | ② 부족: 판에 안 보임 · ③ 안 맞음: 끌기 중에 그 칸이 빛나지 않고, 떼면 원래 자리로 · ④ 무시 |
| 놓인 물건 빼기 · 바꾸기 | ① Sheet ② 칸에 물건 있음 | 정령이 놀고 있으면 떠나고 선물은 남김 (C7) |
| 방 넘기기 | ① Room ② 열린 방이 2개 이상 ③ 넘기는 중 아님 | 끝 방이면 살짝 튕김 |
| 사기 | ① 상점 ② 이미 가진 유일 물건(방 등) 아님 ③ requires 충족 ④ 재화 ≥ 가격 | ②③: 상품에 '가짐'·'잠김' 표시 · ④: '사기' 흐림 + "조금 더 모으면 살 수 있어요" |
| 사진 찍기 | ① 사진 덮개 ② 찍는 중 아님 ③ 저장 공간 있음 | ③: "사진을 저장할 공간이 없어요" |
| 둘째 방 열기 | = 사기 (상품 target이 RoomId) | 같음 |

**검사 순서 원칙:** 가벼운 것부터 검사한다 (컨텍스트 → 상태 → 위치 → 자원 → 파일). 하나라도 실패하면 그 뒤는 검사하지 않고, 아무것도 바꾸지 않는다.

## 자원 소모 시점 · 쿨타임 시작 시점 (사용자 확정)

| 자원·시간 | 언제 줄거나 시작되나 (초안) |
|---|---|
| **간식 그릇 양** | **채운 순간부터** 시간에 따라 줄어든다. 정령이 와 있든 없든 같다. 와 있는 정령 1명마다 시간당 0.01씩 더 준다 (K7 eat_rate). **연출:** 정령 없이 줄어든 만큼은 '수줍은 정령'이 몰래 먹은 것으로 보여 준다. 그릇 주변에 부스러기와 작은 발자국이 남는다. 수줍은 정령은 보이지 않는다. **수줍은 정령은 플레이어가 보고 있을 때는 먹지 않는다** (사용자 결정). 따라서 줄어드는 양은 두 몫으로 나뉜다. ① **수줍은 정령 몫:** 앱이 꺼져 있거나 백그라운드일 때만 시간에 비례해 준다. ② **와 있는 정령 몫:** 보든 안 보든 정령이 와 있는 동안 준다. 결과적으로 앱을 켜 두고 보는 동안에는 정령이 없으면 그릇이 줄지 않는다. 나중에 특별 조건(예: 그릇을 일정 횟수 채움)으로 만나는 숨은 정령 후보로 남긴다 (0.3판 이후, X1·S7) |
| 좋은 간식(산 것) 소지품 | 그릇에 **넣는 순간** 1개가 줄어든다 |
| 기본 간식 | 줄지 않는다 (무한, 무료) |
| 놀잇감 소지품 | 줄지 않는다. 놓으면 '놓임' 상태, 빼면 다시 소지품으로 |
| 재화 | 구매 확인 창에서 **'사기'를 누르고 검증이 끝난 순간** 줄고 물건이 들어온다 (한 번에) |
| 정령 반응 재사용 | 반응 애니메이션이 **끝난 순간**부터 다시 탭 가능 |
| 셔터 | 찍기가 **끝난 순간**부터 0.5초 |
| 같은 대상 재탭 0.3초 | 첫 탭을 **뗀 순간**부터 |

## 불가 입력 처리 방식
- **무시:** 컨텍스트 밖의 입력, 애니메이션 중 입력, 중복 탭. 소리도 표시도 없다.
- **피드백:** 재화 부족, 저장 공간 부족, 잠긴 상품. 짧은 띠나 흐린 버튼으로 알린다. 정령 쪽에는 숫자가 없다. 거인 쪽 UI(HUD 재화, 상점 가격)에는 숫자가 있다.
- **저장하지 않음:** 입력 버퍼를 쓰지 않는다 (K1).
- **전환:** 끌기를 칸 밖에서 떼면 '취소'로 바뀌고, 물건은 원래 자리로 돌아간다.

## 공통 제한 vs 개별 제한
- **공통:** Busy 동안에는 모든 게임 입력을 막는다. 같은 대상을 0.3초 안에 다시 탭하면 무시한다. 한 손가락만 쓴다(확대 제외).
- **개별:** 셔터 0.5초, 정령 반응 1회, 첫 안내 대상 한정.

## 테스트 케이스 (Given / When / Then)
1. **Given** 그릇이 비어 있다. **When** 그릇을 탭한다. **Then** 기본 간식으로 가득 차고, 재화와 소지품은 변하지 않는다.
2. **Given** 재화가 가격보다 1 적다. **When** 사기를 누른다. **Then** 재화와 소지품이 변하지 않고, '사기'가 흐리게 보인다.
3. **Given** 정령이 칸 A의 공에서 놀고 있다. **When** 칸 A의 공을 다른 놀잇감으로 바꾼다. **Then** 정령이 떠나고 선물 1개가 pending에 생기며, 새 놀잇감이 놓인다.
4. **Given** 놀잇감을 끄는 중이다. **When** 그릇 칸 위에서 뗀다. **Then** 놓이지 않고 원래 자리로 돌아가며, 아무것도 바뀌지 않는다.
5. **Given** 선물을 받았다. **When** 0.1초 안에 같은 자리를 다시 탭한다. **Then** 재화가 한 번만 늘어 있다.
6. **Given** 방치 계산 중(P0)이다. **When** 선물 자리를 탭한다. **Then** 무시된다.
