# F2 시작 · 종료 흐름

> 2026-11-16 · 초안. 스테이지가 없으므로 Retry, Respawn, 스테이지 포기 정책은 해당 없다.

## 시작
**Bootstrap → (타이틀 없음) → P0 → P1** (U2 흐름)
1. 엔진 시작 → 설정 읽기 → 소리 적용
2. 정적 데이터 읽기와 검증 (T8)
3. 저장 확인 → New Game 또는 Continue (U2 분기)
4. 방치 계산 (S5) → P1

## Reset 범위표

| 대상 | New Game | Continue | 처음부터 다시 (P9) | 백그라운드 복귀 30분 미만 | 백그라운드 복귀 30분 이상 |
|---|---|---|---|---|---|
| 정적 데이터 | Load | Load | Keep | Keep | Keep |
| 저장 데이터 | **Create** (초기값) | **Load** | **Reset** (초기값) | Keep (메모리) | Keep → 방치 계산 |
| 설정 | Load (없으면 Create) | Load | **Keep** | Keep | Keep |
| 런타임 (화면, 애니, 대기열) | Create | Create | Reset → P1 | Keep | Reset → P0 |
| 사진 파일 | 없음 | Keep | **Reset** (삭제, 확인 창에서 알림) | Keep | Keep |
| 시험 기록 | Create/Keep | Keep | Keep | Keep | Keep |

## Lifetime
- **Application:** Defs, Settings, World (하나)
- **Session (앱이 앞에 있는 동안):** 화면 스택, 팝업 대기열, 입력 컨텍스트
- **Stage:** 해당 없음

## 전환 총괄
**GameFlow(= `view/main.gd` + World)**가 P0, P1, Reset, 백그라운드 전환을 맡는다. UI는 요청만 한다.

## 종료 4종 구분

| 종료 | 이 게임 | 처리 |
|---|---|---|
| QuitStage | 해당 없음 | - |
| ReturnToLobby | 모든 Back → P1 | 화면 스택만 정리 |
| ReturnToTitle | 해당 없음 (타이틀 없음). '처음부터 다시' 뒤에는 P1로 간다 | - |
| QuitApplication | P1에서 Back 두 번 / 시스템이 앱 종료 | 저장 표시가 있으면 **즉시 저장** → last_seen 기록 → 종료 |
| (추가) 백그라운드로 감 | 홈 버튼, 전화 등 | **즉시 저장**, last_seen 기록, 끌기·확인 창 취소 (재화 변화 없음) |

**포기할 때의 보상과 소비템:** 해당 없음. 정령이 와 있는 상태로 나가도 그대로 저장되고, 방치 계산이 이어서 처리한다.

## 저장 시점 (자세한 것은 F4)
- **자동 저장만 있다.** 바뀌는 즉시 저장 표시 → 0.5초 안에 묶어서 저장, 백그라운드로 갈 때 즉시 저장.
- 손으로 하는 저장은 없다.

## 로딩 중 입력
- P0와 방치 계산 중에는 게임 입력을 무시한다 (K1 Busy).
- 데이터 초기화 중에는 모든 입력을 막는다.

## 실패 시 플래그 해제
- 모든 '진행 중' 플래그는 실패하거나 예외가 나도 `finally`처럼 반드시 해제한다.
  - 대상: Busy, 구매 처리 중, 셔터 잠김, 방치 계산 중
  - 이유: 하나라도 남으면 영원히 막힌다 (Soft Lock).
- **시험:** 각 단계에서 일부러 예외를 낸 뒤, 다음 입력이 받아지는지 확인한다 (F9).
