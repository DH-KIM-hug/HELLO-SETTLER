# D4 참고 게임 분석

> 2026-11-16 사용자 결정: 차용 범위는 초안대로 한다. 참고 게임은 네코아츠메(시스템), 동물의 숲 포켓 캠프(친밀도·초대), 블루 아카이브류 서브컬처(SD 그림체와 UI 분위기)다.
> **분석 목적으로만 쓴다.** 이름, 캐릭터, 그림, 화면 배치, 음악은 복사하지 않는다 (CLAUDE.md 1장).

## 1. 네코아츠메 — 시스템 7질문

| # | 질문 | 구현 항목 |
|---|---|---|
| 1 | 입력 | 마당의 정해진 칸에 굿즈를 놓는다. 밥그릇에 밥을 채운다. 탭으로 고양이를 보고 사진을 찍는다 |
| 2 | 실행 기능 | 시간이 지나는 동안(앱이 꺼져 있어도) 칸마다 고양이 방문을 판정하고, 일정 시간 뒤 떠나게 한다 |
| 3 | 조건 | 밥이 남아 있는지, 굿즈 종류(고양이별 선호), 밥 등급(희귀 고양이 조건), 같은 고양이가 이미 와 있는지 |
| 4 | 바뀌는 데이터 | 밥 잔량, 칸별 방문자, 방문 횟수, 남긴 재화(받기 전 보관), 수첩(처음 본 고양이·본 굿즈 조합), 사진 목록 |
| 5 | 상태 전환 | 칸: 빈 칸 → 굿즈 놓임 → 고양이 놂 → 떠남(재화 남김) → 다시 굿즈 놓임 · 밥: 가득 → 줄어듦 → 빔 |
| 6 | 피드백 | 앱을 열면 놀고 있는 고양이가 보인다. 새 고양이는 수첩 알림, 재화는 '받기' 버튼, 사진 찍는 소리가 난다 |
| 7 | 다음 행동 | 재화를 받는다 → 새 굿즈나 좋은 밥을 산다 → 배치를 바꾼다 → 다시 닫고 기다린다 |

**핵심 구조:** `배치(조건) × 시간 → 확률 방문 → 기록 + 재화 → 구매 → 배치 변경`. 희귀 손님은 특정 굿즈와 밥 조합에서만 와서 "다음에 무엇을 놓을까" 하는 동기를 만든다.

## 2. 동물의 숲 포켓 캠프 — 가져올 시스템만

| 질문 | 구현 항목 |
|---|---|
| 입력 | 캐릭터에게 말을 건다. 원하는 물건을 준다. 캠프장에 초대한다 |
| 실행·조건 | 캐릭터별 친밀도가 오른다. 단계를 넘으면 초대 가능, 대사와 선물이 열린다 |
| 바뀌는 데이터 | 캐릭터별 친밀도 값, 열린 대사, 받은 보상 |
| 피드백 | 친밀도가 오르는 연출, 캐릭터의 짧은 한마디 |
| 가져올 것 | **캐릭터별 짧은 한마디와 친밀도 단계 보상.** 대화를 길게 만들지 않는다 |

## 3. 블루 아카이브류 서브컬처 — 그림체와 UI 분위기만

| 항목 | 가져올 '느낌' (구체 형태는 우리 것으로) |
|---|---|
| 캐릭터 | 2~3등신 SD, 큰 눈, 단순한 몸, 표정이 풍부한 작은 모션 |
| UI | 밝은 단색 면, 둥근 카드, 큼직한 아이콘, 가벼운 반투명, 또렷한 글자 |
| 연출 | 짧은 통통 튀는 등장, 말풍선 한 줄 |
| **가져오지 않음** | 그 게임의 캐릭터, 학원과 총기 설정, 헤일로 같은 고유 상징, 로고와 글꼴, 화면 배치 |

## 4. 3분류 표

| 분류 | 요소 |
|---|---|
| **공통 (장르의 기본으로 가져옴)** | 놓기 → 기다리기 → 방문 → 선물로 이어지는 반복 · 처음 본 손님 도감 기록 · 사진첩 · 희귀 손님이 특정 놀잇감·간식에만 오는 구조 · 선물 재화로 상점 구매 · 방치 시간 계산 |
| **선택 (고른 것)** | 친밀도 단계별 특별 선물과 모습 (네코아츠메의 보은품과 포켓 캠프의 친밀도를 섞음) · 꾸미기 테마(방의 벽지, 바닥, 커튼 바꾸기) |
| **차별화 (우리 것)** | 날씨·계절·시간대가 방문 조건이 된다 · 손님은 **작은 사람처럼 생긴 정령**뿐이다. 손가락만 한 SD 모습에 속성 표식(꽃잎, 물방울, 별빛 등)을 지닌다 · 무대는 **사람 크기의 집 전체(방 여러 개)**다. 큰 가구 위의 작은 정령이라는 크기 대비를 쓰고, 방을 넘겨 보며 방이 늘어난다 · 창밖 날씨가 방 안에 비친다(빛, 빗소리) · 손님마다 짧은 프로필과 한마디가 있다 |

## 5. 따라 하지 않을 요소 (명시)

- 고양이를 주인공 손님으로 쓰지 않는다. 고양이 귀를 단 캐릭터 한둘은 가능하지만, 고양이 수집 게임으로 보이면 안 된다.
- 네코아츠메의 단순 선화 그림체, **툇마루에서 마당을 내려다보는 구도**, 멸치·금멸치 같은 재화 이름과 모양을 쓰지 않는다.
- 굿즈, 고양이, 캐릭터의 이름과 모양, 수첩·카탈로그 화면 배치를 그대로 옮기지 않는다.
- 포켓 캠프의 캠프장·트럭 구도, 캐릭터 디자인, 대사를 쓰지 않는다.
- 블루 아카이브의 캐릭터, 세계관 설정, 헤일로, 로고, 글꼴, UI 레이아웃을 쓰지 않는다.
- 유료 뽑기(가챠)는 쓰지 않는다. 수집은 놓기와 기다리기로만 한다 (D3 '아닌 것').
