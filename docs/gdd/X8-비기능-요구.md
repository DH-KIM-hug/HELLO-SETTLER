# X8 비기능 요구 · 마일스톤

> 2026-11-16 · 확정 (위임 결정 1·2 반영). 목표 사양과 출시 범위는 메타 결정(안드로이드 먼저, 세로, Godot 4.7.2 2D)을 따른다. 세부 수치는 Sonnet max 검토로 위임 결정한다.

## 플랫폼 · 사양

| 항목 | 값 |
|---|---|
| 대상 | 안드로이드 (먼저) → iOS (1.0 뒤) |
| 최소 사양 | 안드로이드 9 이상, RAM 3GB, 2019년급 중급 기기 (예: 갤럭시 A50급) |
| 개발 기준 기기 | SM-S931N (사용자 폰) |
| 방향 | 세로 고정 |
| 해상도 | 기준 1080×2340. 다른 비율은 방 그림 안전 영역 안에서 맞춘다 |
| 렌더러 | Godot Mobile (TEMP). 0.0에서 최소 사양 실기를 측정하고, 콜드 스타트 3초 초과나 크래시 1건이면 Compatibility로 바꾼다 |

## 성능 예산

| 항목 | 예산 |
|---|---|
| 프레임 | 60fps (16.6ms). 방 화면에서 정령 7명과 효과가 있어도 유지. 최소 사양에서 30fps 이상 |
| 시작 (콜드 스타트 → P1) | **≤ 2초** (필러 1). 최소 사양 ≤ 3초 |
| 방치 계산 | 12시간 분량 ≤ 200ms (판정 약 7칸 × 72회) |
| 메모리 | ≤ 400MB |
| 빌드 크기 | MVP ≤ 150MB. 그림은 webp나 압축 텍스처를 쓴다. 정령 하나당 그림 ≤ 2MB 목표 |
| 저장 파일 | ≤ 200KB (사진 파일 제외) |
| 사진 | 한 장 ≤ 1MB (jpg 90). 앨범 상한 200장 (TEMP). 가득 차면 새 사진을 막고 안내한다 (자동 삭제 없음). `photo_cap_hit`이 시험자의 10%를 넘으면 올린다 |
| 배터리 | 화면이 켜져 있는 동안 틱 1초, 판정 10분 간격. 백그라운드에서는 일하지 않음 (방치 계산으로 처리) |
| 네트워크 | 날씨 조회 한 번에 ≤ 5KB, 30분 간격 |

## 입력 장치
터치만 쓴다. 개발용으로 마우스를 탭으로 쓴다. 안드로이드 뒤로 버튼을 지원한다.

## 저장 · 클라우드
- MVP는 기기 저장만 한다 (F4).
- 0.5판: 클라우드 저장과 기기 옮기기. 자체 백엔드 + 연결 코드 쪽이다 (0.9 영수증 서버와 같이). 클라우드본에서 weather_cache와 settings는 뺀다. 0.4 끝에 확정한다.

## 빌드 · 배포 채널
- 0.0~0.2: 디버그 APK를 adb로 설치한다 (CLAUDE.md 5장 절차).
- 0.3~0.4: 구글 플레이 비공개 테스트 트랙.
- 1.0: 구글 플레이 출시.
- `build/`는 저장소에 넣지 않는다.

## 제한 (정책)
- **위치 권한:** '대략 위치'(ACCESS_COARSE_LOCATION)만 요청한다.
- **알림(0.4):** 안드로이드 13 이상은 알림 권한이 필요하다.
- **광고와 결제(0.9):** 스토어 정책, 아동 대상 설정, 개인정보 라벨.
- **날씨 서비스:** MVP는 Open-Meteo(키 없음)다. 무료는 비상업 한정으로 알려져 있으므로 **0.2 전에 약관 원문을 확인한다.** 0.9(광고·유료) 전에 상업 구독, 대체 서비스(MET Norway 등), 자체 캐시 프록시 중 하나로 옮긴다.

## 마일스톤

| 판 | 완료 기준 |
|---|---|
| 0.0 프로토 | 네모 그림으로 방문과 방치 계산이 동작한다. 시뮬레이션과 헤드리스 결과가 일치한다. 빈 방 비율과 하루 재화가 목표 범위 안이다 |
| 0.1 수직 조각 | 정령 1명, 놀잇감 2, 일러 카드 1장을 최종 그림체로 만든다. 열기 → 놓기 → 도착 → 선물 → 사진 한 바퀴. 폰 60fps. **사용자가 그림체를 승인한다** |
| **0.2 MVP** | D7 포함 목록 전부. 최소 완성도 기준(D7)을 통과한다. 전체 헤드리스 시험을 통과한다. 7일 외부 시험을 마친다 |
| 0.3 | 친밀도, 단골 일러, 한마디, 정령 16명 |
| 0.4 | 계절, 방 3~4개, 알림, 정령 24명 이상 |
| 0.5 (알파) | 꾸미기 테마, 클라우드 저장. 기능 고정 |
| 0.9 (베타) | 광고와 유료 재화, 분석, 개인정보 처리방침. 비공개 테스트 |
| 1.0 (출시) | 스토어 등록, 등급, 스크린샷. 크래시 없는 비율 99.5% 이상 |
