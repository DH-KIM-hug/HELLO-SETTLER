# U2 타이틀 (= P0 시작)

> 2026-11-16 · 초안. 덮어쓰기 정책은 Sonnet max 검토로 위임 결정한다 `[U-결정 2]`.
> **원칙:** 필러 1(2초 안에 방)을 지키려고 **버튼이 있는 타이틀 화면을 두지 않는다.** 로고가 짧게 나온 뒤 바로 방으로 간다.

## 흐름

```
앱 실행
 → 설정 먼저 읽기 (소리 크기 바로 적용)
 → 저장 파일 확인 (SaveStore, UI는 요청만)
    ├ 유효한 저장 있음 → Continue: 불러오기 → 방치 계산 → P1
    ├ 저장 없음        → New Game: 초기값(G10) → P1 + 첫 안내 시작
    └ 저장 손상        → 백업 읽기 시도
          ├ 백업 성공 → Continue (조용히, 시험 기록에 남김)
          └ 백업 실패 → 손상 파일을 broken_<시각>으로 보관 → New Game + 띠 "기록을 되살리지 못했어요"
```

| 항목 | 내용 |
|---|---|
| Start의 의미 | 버튼이 없다. 저장이 있으면 자동으로 이어 하고, 없으면 새로 시작한다 |
| 로고 시간 | 최소 0.6초 (TEMP). 방치 계산이 길어도 2초에서 끊고 P1을 먼저 보인다. 나머지 계산은 뒤에서 마저 한다. 그동안 칸·선물 입력을 막는다 (K1 Busy) |
| 첫 실행 | 로고 → P1(빈 창가 방) → 첫 안내(S12) |
| 설정 적용 시점 | 부팅하자마자 (U7) |
| Quit | 타이틀에서는 없다. P1에서 Back 두 번 (K1) |
| 로딩 중 입력 | 전부 무시 (중복 탭 영향 없음) |

## 덮어쓰기 / 새로 하기 `[U-결정 2]`
- **초안:** '새로 하기' 버튼은 타이틀에 두지 않는다. **P9 설정 → 데이터 → '처음부터 다시'**에 둔다. 확인은 두 번 받는다.
  - 1차: "모든 정령 기록과 일러가 사라져요"
  - 2차: '처음부터 다시'라는 글자를 직접 눌러 확인한다.
- **다시 시작해도 일러 해금은 남길지:** 초안은 남기지 않는다 (완전 초기화).

## 초기화 범위 (New Game)
- **초기화한다:** 저장 데이터 전부 (G10 초기값).
- **남긴다:** 설정(소리, 위치)과 시험 기록 파일.

## 책임 분리
- **SaveStore:** 파일 유효성, 백업, 손상 처리.
- **World:** 초기값 만들기, 방치 계산.
- **P0 화면:** 로고와 진행만 보여 준다. 무엇을 할지 판단하지 않는다.

## 테스트
1. **Given** 저장이 없다. **When** 실행한다. **Then** 2초 안에 빈 방이 보이고, 첫 안내가 시작된다.
2. **Given** 저장이 손상됐고 백업은 정상이다. **When** 실행한다. **Then** 백업 상태로 이어 하고, 띠는 뜨지 않는다.
3. **Given** 저장과 백업이 모두 손상됐다. **When** 실행한다. **Then** broken 파일이 남고, 새 게임과 띠가 나온다.
4. **Given** 방치 계산이 5초 걸린다 (3일 만에 열기). **Then** P1이 2초에 보이고, 계산이 끝날 때까지 선물 탭은 무시된다.
