# C7 예외 · 제한 (초안)

> 2026-11-16 사용자 확정 (기본 간식 무료·무한, 놀잇감을 빼면 정령은 떠나고 선물은 남김). 기능별 세부는 F1에서.
> **원칙:**
> - 실패하면 아무것도 바뀌지 않는다 (검증한 뒤에 반영).
> - 보상은 한 곳(S8, S7)에서 한 번만 확정한다.
> - 가진 것은 줄지 않는다 (필러 2).

## 우선 4종

| # | 종류 | 조건 | 처리 | 사용자 피드백 |
|---|---|---|---|---|
| 1 | **데이터 손실** | 저장 도중 앱 종료, 전원 꺼짐 | 임시 파일에 쓰고 다 쓴 뒤 바꿔 끼운다 (원자적 저장). 직전 저장본 1개를 백업으로 둔다. 읽기에 실패하면 백업을 읽는다 | 없음 (조용히 복구). 백업까지 실패하면 "기록을 되살리지 못했어요" 안내와 시험 기록용 로그 |
| 2 | **보상 중복** | 선물 탭을 여러 번 빠르게 누름 · 방치 계산이 두 번 돎 · 일러 해금이 두 번 뜸 | 선물은 받는 순간 pending에서 지우고 재화를 더하는 일을 한 번에 처리한다. 방치 계산은 last_seen을 먼저 갱신하고 한 번만 실행한다. 해금은 collection에 이미 있으면 무시한다 | 두 번째 탭은 반응 없음 |
| 3 | **진행 막힘** | 재화 0이고 간식 0, 놀잇감도 못 삼 | **기본 간식은 무한, 무료다** (그릇 채우기는 언제나 가능). 좋은 간식만 상점에서 산다 | 빈 그릇이 반짝이며 "채워 주세요" |
| 4 | **상태 충돌** | 정령이 놀고 있는 놀잇감을 빼거나 바꿈 | 그 정령은 즉시 떠나고, 선물은 정상대로 남긴다 (잃는 것 없음) | 정령이 손을 흔들며 떠나는 연출 |

| 유형 | 조건 | 처리 | 피드백 |
|---|---|---|---|
| 입력 | 화면 전환 중 연속 탭, 두 손가락 동시 탭 | 전환 중 입력 막기. 첫 탭만 받기 | 없음 |
| 입력 | 사진 셔터 연타 | 찍는 중에는 셔터를 막음 (0.5초) | 셔터 흐려짐 |

| 동시성 | 일러 해금과 '새 손님!' 띠가 동시에 | 우선순위 규칙(C4): 일러 해금이 먼저, 띠는 그 뒤 | |
| 외부 | 인터넷 없음, 날씨 조회 실패 | 마지막 조회 결과(유효 시간 안) 또는 날짜 시드 날씨 | 설정에 '대체 날씨' |
| 외부 | 위치 권한 거절, 나중에 해제 | 대체 날씨로 바꿈. 다시 묻지 않음 (설정에서 켤 수 있음) | 없음 |
| 외부 | 기기 시계를 뒤로 돌림 | 경과 시간이 음수면 0으로 처리하고 last_seen을 갱신하지 않음. 재화와 선물은 늘지 않음 | 없음 |
| 외부 | 기기 시계를 앞으로 크게 돌림 | 방치 계산 상한(`[TBD]`, X11) 넘는 시간은 버림 | 없음 |
| 외부 | 시간대 변경(여행) | 시각은 UTC로 저장하고 낮/밤만 현지로 계산 | 없음 |

## 경계값
- **닫아 둔 시간:** 0초, 1분, 판정 간격 직전과 직후, 상한 직전과 직후, 3일.
- **간식 양:** 0, 아주 조금(판정 1회분 미만), 가득.
- **재화:** 0, 가격과 정확히 같음, 가격보다 1 적음.
- **칸:** 모두 비어 있음, 모두 놀잇감이고 간식 없음.

## 복구 경로
- **저장 파일:** 깨지면 백업을 읽는다. 백업도 깨지면 새로 시작한다. 이때 저장 파일을 지우지 않고 `broken_<시각>`으로 보관한다.
- **방치 계산 오류:** 그 회차 계산을 건너뛰고 last_seen만 갱신한다. 가진 것은 그대로다.
- **날씨 조회 오류:** 대체 날씨로 계속하고 다음 간격에 다시 시도한다.
