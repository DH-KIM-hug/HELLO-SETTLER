# U8 팝업 · 띠(토스트) · 확인 창

> 2026-11-16 · 위임 결정 2 (Sonnet max, 2026-11-16 — 위임결정-2.md) U-4·U-5.
> **고르는 기준:** 플레이어가 반응해야 하는가?
> - 반응하지 않아도 되면 **띠**
> - 보고 넘겨야 하면 **팝업**
> - 되돌릴 수 없는 행동이면 **확인 창**

## 타입 비교

| | 띠 (Toast) | 팝업 (Popup) | 확인 창 (Confirm) |
|---|---|---|---|
| 예 | 새 손님(3초), 선물 받음, 재화 부족, 한 번 더 누르면 나가요 | 일러 해금(Q2), 위치 안내(Q5) | 구매(Q4), 사진 지우기, 처음부터 다시 (Q8) |
| 뒤 입력 | 막지 않음 | 막음 (Modal) | 막음 |
| 닫기 | 자동 2초 (새 손님 띠는 3초, 탭하면 P5) | 탭 / 닫기 / Back | 버튼 / Back = 취소 |
| 동시 | 최대 2개 겹침 (위·아래) | 한 번에 하나, 나머지는 대기열 | 한 번에 하나 |
| 게임 정지 | 아니오 | 아니오 (Modal이 게임을 멈추지 않음) | 아니오 |

## 띠 규칙
- **같은 메시지 ID가 2초 안에 다시 오면** 새로 띄우지 않고 표시 시간만 늘린다. 선물을 연속으로 받으면 "+12" 식으로 합친다.
- **우선순위:** 위쪽은 새 손님 띠가, 아래쪽은 그 밖의 띠가 쓴다. 쌓이면 최대 3개까지 대기하고 나머지는 버린다 (중요하지 않은 정보이기 때문).

## 팝업 대기열 (열기 직후 여러 해금이 몰릴 때)
1. 방이 먼저 보인다 → 0.5초 뒤 대기열을 시작한다.
2. **순서:** 해금된 시각 순서. 정령 일러 → 장면 일러가 섞여 있으면 시각 순서대로 한다.
3. **최대 연속 3개** (U-5). 4개 이상이면 3번째를 **요약 카드**로 바꾼다. 요약 카드는 남은 일러의 썸네일 격자와 '도감에서 보기' 버튼이다. 팝업이 뜬 뒤 0.4초는 탭을 무시한다 (직전 탭이 팝업을 닫는 사고 방지). 대기열의 원본은 저장된 `reveal_shown=false` 목록이다. Q2는 아무것도 덮이지 않은 P1에서만 띄운다 (U9 충돌 규칙).
4. 첫 안내 중에는 대기열을 미룬다. 단, 첫 정령의 일러 해금은 첫 안내의 한 단계로 보여 준다.
5. **보이지 않는 방에서 처음 온 정령:** 열기 직후의 대기열에 넣는다 (일러 해금 팝업). '새 손님' 띠는 그 방을 처음 볼 때 띄운다 (K8 빈칸 해소).

## 확인 창 규칙
- **메시지는 구체적으로 쓴다.** 숫자를 넣는다 (거인 쪽 UI라 허용). 예: "꽃꿀 방울 3개를 이슬구슬 30개에 들일까요?"
- **버튼 이름은 행동이다.** '사기' / '그만', '지우기' / '그만'. '예'와 '아니요'는 쓰지 않는다.
- **위험한 행동**(지우기, 처음부터 다시)은 '그만'을 기본 강조한다.
- **연타를 막는다.** 확인 버튼을 누르면 바로 비활성화한다.
- **확인한 뒤 로직이 재검증한다** (G9).
- **남발 금지.** 확인 창 대상은 아래 목록뿐이다 (U-4). 놓기, 바꾸기, 빼기, 첫 안내 건너뛰기, 위치 끄기, 앱 종료에는 확인 창이 없다.
  - 구매: 모든 상품
  - 사진 지우기
  - (좋은 간식이 남은 그릇 바꾸기는 확인 창이 아니라 **차단 + 띠** — 위임 결정 4)
  - 처음부터 다시 (두 번)
  - 노는 정령의 놀잇감 바꾸기: **확인 창 없음.** 정령이 떠나는 연출로 충분하고, 잃는 것도 없다.

## 입력 계층 (UI Layer)
아래에서 위로 쌓는다. 위 계층이 입력을 먼저 받는다.
1. 방
2. 덮개 (P2, P8)
3. 전체 화면
4. 팝업 · 확인 창
5. 첫 안내 말풍선
6. 띠 (입력은 띠 자기 영역만)

**포커스 복원:** 팝업을 닫으면 열기 전에 보던 화면과 스크롤 위치로 돌아간다.
