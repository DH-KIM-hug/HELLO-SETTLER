# U1 화면 목록 확정

> 2026-11-16 · C4(사용자 확정)를 바탕으로 확정한다. 화면 구성은 사용자가 확정했다. 팝업 정책은 C4 우선순위를 따르고, 남은 세부는 Sonnet max 검토로 위임 결정한다 (U-결정 목록 참고).
> **유형:**
> - 전체 화면
> - HUD
> - 팝업: 뒤를 막는다
> - 덮개(오버레이): 화면 위에 겹치고, 뒤는 보인다
>
> 띠(토스트)와 말풍선은 화면이 아니라 U8에서 다룬다.

**게임 정지:**
- 이 게임에는 '정지'가 없다. 어떤 화면을 열어도 방문, 간식, 시간은 계속 흐른다 (현실 시간 게임).
- 앱이 백그라운드로 가면 그때부터는 방치 처리(S5)로 넘어간다.

## 화면마다 명세 (C4 표를 확정. 바뀐 점만 적는다)
- **P1:** HUD는 U4. 놓기와 그릇은 P2를 연다. 아래 버튼은 '상점, 도감, 소지품, 사진, 앨범, 설정' 중 무엇을 둘지 `[U-결정 1]`.
- **P2:** 열린 칸이 정해진 경우(칸 탭)와 정해지지 않은 경우(소지품 버튼 → 끌어 놓기 전용)가 있다.
- **P4/P5/P6:** 도감과 일러는 같은 화면의 탭으로 묶는다 (C4: 도감 → 일러 보기).
- **P6z/P7z 추가:** 확대 보기를 별도 화면으로 둔다 (Back 규칙을 분명히 하려고).
- **Q8 추가:** 공용 확인 창이다. 대상은 U8에서 정한다.

데이터 출처, 입력, 진입·종료는 C4 표와 U3~U8 각 문서를 따른다.

## 팝업 중첩 정책
- **팝업은 한 번에 하나만 띄운다.** 대기열은 U8에서 다룬다.
- 덮개(P2, P8) 위에 팝업이 뜰 수 있다. 다만 일러 해금(Q2)은 덮개가 닫힌 뒤에 띄운다.

## Back 우선순위 (안드로이드 '뒤로')
첫 안내(무시) > 팝업 닫기 > 덮개 닫기 > 확대 보기 닫기 > 전체 화면에서 부모로 > P1에서 종료 확인 띠

## 입력 컨텍스트
K1 표를 따른다. P2는 Sheet, P3~P10은 Screen, Q는 Modal이다.

## 중복 열기 금지
같은 화면이 이미 열려 있거나 열리는 중이면 다시 열지 않는다. 예를 들어 H1 버튼을 연타해도 한 번만 열린다.

## 막다른 길 점검

| 화면 | 나가는 길 |
|---|---|
| P0 | 자동 → P1 |
| P1 | 모든 화면으로 · 종료 |
| P2, P8 | Back · 바깥 탭 · 닫기 → P1 |
| P3~P7, P9 | Back → 부모 |
| P10 | Back → P9 |
| P6z, P7z | Back → 온 곳 |
| Q2, Q4, Q5, Q8 | 버튼 · Back |

**모든 화면에서 P1로 돌아갈 수 있다.** 들어갈 수 없는 화면도 없다 (P10은 숨김 경로로 들어간다).

## MVP 화면
- P0~P9, Q2, Q4, Q5, Q8: 전부 MVP다.
- P10: MVP 시험 판에만 넣는다.
