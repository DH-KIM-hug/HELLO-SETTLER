# D7 MVP 정의

> 2026-11-16. 범위는 D6에서 사용자가 확정했다. **수정:** 손님은 정령만, 무대는 사람 크기 집(방 여러 개)이다 (사용자). MVP 방 수 2개는 사용자가 확정했다. 제목은 보류 중이다. 이 문서는 그 '필수' 칸을 MVP로 옮긴 것이다. 로드맵과 MVP 범위는 사용자가 확정했다 (2026-11-16).

## 검증할 핵심 가설 (1개)

**"닫기 전에 놀잇감과 간식을 놓아 두면, 타깃 유저(D2)는 '누가 와 있을까' 궁금해서 하루 3번 이상 스스로 앱을 다시 연다."**

- 측정: 시험 사용자 3~5명이 7일 동안 쓴 기록을 본다. 하루 평균 열기 횟수, 열었는데 빈 화면이던 비율, 배치를 바꾼 횟수, 사진 찍은 횟수.
- 통과 기준:
  - 하루 평균 열기 **3회 이상**
  - 빈 화면 비율 **10% 이하**
  - 7일 동안 희귀 손님을 노리고 배치를 바꾼 사람이 **절반 이상**

## '이게 없으면 가설을 시험할 수 없나?' 분류

| 기능 | 분류 | 이유 |
|---|---|---|
| 집의 방 2개 (첫 방 칸 5개, 상점으로 여는 두 번째 방 칸 4개), 옆으로 넘겨 보기 | 필수 | 질문을 걸 장소. 방이 늘어나는 맛을 한 번은 시험한다 |
| 놀잇감 6종 · 간식 2종 놓기 | 필수 | 질문을 거는 행동 |
| 방문 판정 + 방치 시간 처리 | 필수 | 닫혀 있는 동안 답이 만들어짐 |
| 열 때 결과 공개 | 필수 | 설렘의 순간 |
| 정령 손님 8명(흔한 6, 희귀 2) · 놀잇감별 모습 | 필수 | 답의 내용 |
| 처음 온 손님 표시 + 도감 | 필수 | "새로 왔다"는 확인 |
| 선물 재화 + 작은 상점 | 필수 | 질문을 넓히는 다음 행동 |
| 낮/밤 + 날씨(맑음·비·흐림 3종) | 필수 | 같은 배치에서 다른 답 → 다시 열 이유 (사용자 결정) |
| 사진 찍기 + 사진첩 | 중요 | 감상 재미 측정 (사용자 결정으로 MVP 포함) |
| 기기 저장 | 필수 | 7일 시험 |
| 최소 첫 안내 | 중요 | 시험 사용자가 설명 없이 시작 |
| 기본 소리 | 중요 | 처음·희귀 피드백 |
| 시험 기록(열기 횟수 등, 기기 안 로그) | 필수 | 가설 측정 (출시 판에서는 분석 지표로 대체, X6) |

## MVP 포함 / 제외

- **포함:** 위 표 전부
- **제외 (다음 판):** 친밀도 · 계절 · 손님 한마디와 프로필 · 손님 20명 이상 · 방 3개 이상 · 알림
- **제외 (나중):** 꾸미기 테마 · 클라우드 저장 · 광고 · 유료 재화 · iOS · 현지화

## 최소 완성도 기준

- **그림:**
  - 손님 8명 모두 아트 바이블 기준 그림과 같은 그림체여야 한다. 검수에서 '다른 사람이 그린 것 같다'가 0건이어야 한다.
  - 임시 네모나 대충 그린 그림(placeholder)은 금지한다.
- **반응:** 앱을 열고 2초 안에 방과 정령 손님이 보여야 한다. 누르는 영역은 44pt 이상으로 한다.
- **안정성:** 7일 시험 동안 저장이 날아가는 일이 0건이어야 하고, 게임이 꺼지는 일은 사용자당 1회 이하여야 한다.
- **방치 계산:** 닫아 둔 시간이 1분, 1시간, 12시간, 3일일 때 결과가 모두 상식적이어야 한다. 시계를 되돌려도 재화가 늘지 않아야 한다.
- **텍스트:** 한국어만. 손님 쪽에는 숫자를 표시하지 않는다.

## 프로토타입 ≠ MVP · 수직 조각

| 단계 | 무엇 | 확인할 것 |
|---|---|---|
| 프로토타입 (버림) | 네모 그림으로 방문 판정과 방치 계산만 | 확률과 간격이 "열면 누가 있다"를 만드는가 |
| **수직 조각** | 손님 1명, 놀잇감 2종을 최종 그림체로, 열기부터 선물과 사진까지 한 바퀴 | 그림체, UI 크기, 2D 파이프라인이 실제로 되는가 |
| MVP | 위 포함 목록 전부 | 핵심 가설 |
