# C2 핵심 플레이 루프

> 2026-11-16 사용자 확정. 추가로 **일러스트 해금**을 보상에 넣는다 ("일러가 이뻐야 돼").

## 한 문장 요약
놓아 두고 닫는다 → 닫힌 동안 정령이 오간다 → 열어서 누가 왔는지 보고 기록하고 선물을 받는다 → 선물로 새 물건을 사서 놓을 것을 바꾼다 → 다시 놓아 두고 닫는다.

## 전체 루프 (플레이어 관점, 5단계)

```
 ① 놓기 ──▶ ② 닫고 기다리기 ──▶ ③ 열어 보기 ──▶ ④ 기록·선물 ──▶ ⑤ 사기·바꾸기 ─┐
   ▲                                                                       │
   └───────────────────────────────────────────────────────────────────────┘
```

| 단계 | 플레이어 행동 | 시스템 반응 | 결과 | 필요한 시스템 |
|---|---|---|---|---|
| ① 놓기 | 방의 칸을 탭 → 가진 놀잇감이나 간식을 골라 놓는다. 빈 간식 그릇을 채운다 | 칸에 물건을 놓고, 간식 그릇 양을 가득으로 바꾸고, 저장한다 | 방문 조건이 걸린다 | 배치, 간식 소모, 인벤토리(가진 물건), 저장 |
| ② 닫고 기다리기 | 앱을 닫는다 (또는 켜 둔 채 본다) | 일정 간격마다 놀잇감 칸별로 방문을 판정한다(선호, 날씨, 시간대, 희귀도). 머무는 시간이 끝나면 정령이 떠나고 선물을 남긴다. 간식이 준다 | 방문 기록과 받지 않은 선물이 쌓인다 | 방문 판정, 방치 시간 처리, 환경(날씨·시간대), 간식 소모 |
| ③ 열어 보기 | 앱을 연다 | 닫혀 있던 시간만큼 한꺼번에 계산하고, 마지막으로 본 방을 2초 안에 보여 준다. 지금 와 있는 정령은 놀잇감 위에서 놀고, 다녀간 흔적은 선물 표시로 남는다 | **설렘의 답** — 누가 왔는지 보인다 | 방치 시간 처리, 방 화면, 정령 모습(애니메이션), 환경 표시 |
| ④ 기록·선물 | 정령을 탭해 반응을 본다. 사진을 찍는다. 선물 표시를 탭해 받는다 | 처음 온 정령이면 도감 칸을 열고 '새 손님!'을 띄운다. 그 정령의 **일러 카드**를 해금해 크게 보여 준다. 처음 본 모습이면 사진첩에 표시한다. 특별 장면 조건(정령 조합, 날씨, 시간대)이 맞았으면 **장면 일러**를 해금한다. 재화를 지갑에 더한다 | 도감·사진첩·일러가 늘고 재화가 생긴다 | 도감, 사진·사진첩, **일러스트 해금**, 선물·재화, 피드백(소리·효과) |
| ⑤ 사기·바꾸기 | 상점에서 새 놀잇감·간식·방을 산다. 도감 빈 칸 실루엣과 힌트를 보고 놓을 것을 바꾼다 | 재화를 확인한 뒤 차감하고 물건을 지급한다 (실패하면 아무것도 바뀌지 않는다) | 새로운 질문 "이번엔 누가 올까?" → ①로 | 상점, 인벤토리, 해금(둘째 방), 도감 힌트 |

**보상이 다음 행동에 미치는 영향:**
- **재화:** 새 놀잇감이나 간식을 사면 올 수 있는 정령이 늘어나 ①이 바뀐다.
- **도감 실루엣과 힌트:** "비 오는 날, 우산 놀잇감" 같은 조건을 알려 주어 ①의 배치를 바꾸게 한다.
- **둘째 방:** 놓을 칸이 늘어나 ①의 선택지가 넓어진다.
- **잠긴 일러:** 일러 보기의 잠긴 장면 일러는 흐린 그림과 조건 힌트("비 오는 밤, 두 정령이 함께")로 보인다. 그것을 노리고 ①의 배치를 바꾼다.
- **다음 판:** 단골 일러(같은 정령이 여러 번 오면 해금)와 도감 달성 일러(절반·전부)를 넣는다. 장기 목표가 된다.

## 시간 규모별 루프

| 규모 | 루프 | 내용 |
|---|---|---|
| 초 (열자마자) | ③ | 2초 안에 답이 보인다. 새 정령 띠, 선물 표시 |
| 분 (한 번 들어옴, 1~3분) | ③ → ④ → ⑤ → ① | 확인하고, 탭하고, 사진 찍고, 받고, 사고, 놓는다 |
| 시간 (닫혀 있는 1~3시간) | ② | 방문, 떠남, 선물이 쌓이고 간식이 준다 |
| 일 (하루 3~6번) | 낮/밤과 날씨가 바뀐다 | 같은 배치에 다른 정령이 온다. 다시 열 이유가 생긴다 |
| 주 (MVP 7일) | 도감 8칸과 정령 일러 8장 채우기, 장면 일러 3장, 둘째 방 열기, 희귀 2명 만나기 | 장기 목표 |

## 플레이어 상태 변화
- **가진 것 (늘기만 함):** 재화, 놀잇감·간식, 열린 방, 도감 칸, 사진, 해금 일러 (필러 2)
- **바뀌는 것:** 칸 배치, 간식 그릇 양, 지금 와 있는 정령, 받지 않은 선물

## 성공 흐름
열면 정령이 있고 → 처음 온 정령이 기록되고 → 선물로 산 새 놀잇감에 다음에 새 정령이 온다.

## 실패 → 재도전 흐름
이 게임의 '실패'는 아무것도 잃지 않는다. '오지 않음'만 있다.

| 실패 상황 | 원인 | 플레이어에게 보이는 것 | 재도전 경로 |
|---|---|---|---|
| 열었는데 빈 방 | 간식이 떨어짐 | 빈 간식 그릇, 정령의 작은 발자국과 흔적("다녀가려다 갔어요") | 간식을 채우고 닫는다 → ② |
| 열었는데 빈 방 | 판정 운 (드묾, 목표 10% 이하) | 지난번에 받지 않은 선물이 있으면 그것을 보여 줌 | 그대로 다시 닫거나, 놀잇감을 바꾼다 → ① |
| 희귀 정령이 안 옴 | 조건 불일치 | 도감 실루엣 힌트 | 힌트대로 배치나 날씨를 기다린다 → ① |
| 재화 부족 | 아직 덜 모음 | 상점에 가격과 '조금 더 모으면' 표시 | 닫고 기다린다 → ② |

## 중단·재개
- **도중에 앱을 닫아도 된다.** 모든 변경은 즉시 저장된다.
- **재개:** 다시 열면 ③부터 시작한다.

## 핵심 수치 (값은 X9·T7에서 정함)

| 수치 | 값 |
|---|---|
| 방문 판정 간격 | 10분 (T7) |
| 정령이 머무는 시간 | 흔한 30~90분 · 희귀 20~60분 (T7) |
| 간식 지속 시간 (기본·좋은) | 24시간 · 16시간, 앱이 꺼져 있을 때만 (T7) |
| 방치 계산 상한 | 24시간 (X11) |
| 희귀 확률 | 가중치 1 (흔한 10) + 첫 만남 보장 8회 (G7) |
| 선물 재화량 | 흔한 5~9 · 희귀 25~35 이슬구슬 (G6) |
| 둘째 방 가격 | 800 (G9) |

**목표:** 1~3시간 뒤에 열면 빈 방 비율이 10% 이하여야 한다.

## 검증 가설 (D7)
플레이어가 하루 3번 이상 스스로 앱을 연다.

## 테스트 시나리오 (Given/When/Then)
1. **정상:**
   - **Given** 간식을 가득 채우고 놀잇감 3개를 놓은 뒤 앱을 닫았다.
   - **When** 2시간 뒤에 연다.
   - **Then** 적어도 1명의 정령이 와 있거나 선물이 있고, 2초 안에 보인다.
2. **실패:**
   - **Given** 간식 그릇이 비어 있다.
   - **When** 6시간 뒤에 연다.
   - **Then** 아무 정령도 없고, 빈 그릇이 강조된다. 재화, 도감, 사진은 하나도 줄지 않았다.
3. **예외:**
   - **Given** 앱을 닫은 뒤 기기 시계를 하루 뒤로 돌렸다.
   - **When** 연다.
   - **Then** 방치 계산 상한과 시계 조작 방어가 적용되어 선물이 비정상적으로 늘지 않는다 (F7에서 상세화).

- [x] 단계별 필요 시스템 표가 있다.
