# G5 놓는 물건 · 소비 · (장비·재료 없음)

> 2026-11-16 · 초안. 놓기·소비 규칙은 K1·K3에서 사용자가 확정한 것을 따른다.
> 타입은 **사용 방식**으로 나눈다. 이 게임에서 쓰는 방식은 놓기와 소비 두 가지다. 장비와 재료는 없다.

## 비교표

| | **놓기 (Toy)** | **소비 (좋은 간식)** | 기본 간식 | 수집 (Keepsake) |
|---|---|---|---|---|
| 사용 위치 | 놀잇감 칸 | 그릇 칸 | 그릇 칸 | 정령 상세 (보기만 함) |
| 사용 조건 | 가진 수 − 놓인 수 ≥ 1, 칸 종류 맞음 | 보유 ≥ 1, 그릇 칸 | 언제나 | - |
| 사용 성공 시 | placement 기록. 수량은 그대로 ('놓임') | 그릇 = 좋은 간식 가득 · **성공한 뒤** 보유 −1 | 그릇 = 기본 간식 가득 | - |
| 교체 | 칸의 놀잇감을 바꾸면 이전 것은 소지품으로 돌아옴. 노는 정령은 떠나고 선물은 남김 | 좋은 간식이 남은 그릇에 기본 간식을 넣으면 남은 좋은 간식은 **사라진다** (확인 창) `[결정 필요: 사라짐 vs 1개 돌려줌]` | 기본 → 좋은: 그대로 교체 | - |
| 해제 | 빼기 → 소지품 | 불가 (그릇은 늘 무언가로 차거나 빈 상태) | 불가 | - |
| 쿨타임 | 없음 | 없음 | 없음 | - |
| 저장 | placement, inventory | inventory, food_bowls | food_bowls | collection |
| UI 액션 | 고르기 판: 놓기 / 빼기 / 바꾸기, 끌어 놓기 | 고르기 판: 넣기 | 그릇 탭 (비었을 때 바로) | 정령 상세에서 보기 |

**과세분화 금지:** 놀잇감을 '앉는 것 / 매달리는 것'으로 나누지 않는다. 차이는 PoseDef(그림)가 맡고, 규칙은 같다.

## 규칙
1. **성공한 뒤에 줄인다.** 넣기 검증(보유, 칸)이 끝나고 그릇 갱신에 성공한 다음에 보유를 −1 한다. 중간에 실패하면 아무것도 바뀌지 않는다.
2. **놓인 놀잇감은 잃어버리지 않는다.** 방을 넘겨도, 앱을 꺼도 그대로다.
3. **같은 놀잇감 중복:** 종류당 1개라면 한 놀잇감은 한 칸에만 놓을 수 있다 (G4 결정에 따름).

## 예외

| 조건 | 처리 | 피드백 |
|---|---|---|
| 좋은 간식 0개인데 넣기 | 판에 '없음'으로 흐리게. 상점 바로가기 | "상점에서 구할 수 있어요" |
| 이미 같은 간식이 가득한 그릇에 같은 것 넣기 | 무시 (소모 없음) | 없음 |
| 놓인 놀잇감을 다른 방 칸으로 끌기 | 원래 칸은 비고, 새 칸에 놓임. 원래 칸의 정령은 떠남 | 정령 손 흔들기 |
| 저장 중 앱 종료 (넣기 직후) | 원자적 저장 (C7). 그릇은 갱신되고 보유는 안 줄어든 상태가 되는 일은 없다 | - |

## 테스트
1. **Given** 좋은 간식 3개, 그릇 비어 있음. **When** 좋은 간식을 넣는다. **Then** 그릇이 좋은 간식으로 가득 차고, 보유는 2가 된다.
2. **Given** 좋은 간식 0개. **When** 넣기를 시도한다. **Then** 무변경이고 안내 띠가 뜬다.
3. **Given** 칸 A에 실패 미끄럼틀, 정령이 노는 중. **When** 병뚜껑으로 바꾼다. **Then** 정령이 떠나 선물 1개가 생기고, 실패는 소지품에 '놓을 수 있음'으로 돌아오고, 칸 A는 병뚜껑이 된다.
4. **Given** 그릇에 좋은 간식이 절반 남아 있다. **When** 기본 간식으로 바꾼다. **Then** 확인 창이 뜨고, 확인하면 정책대로 처리된다 `[결정 필요]`.
