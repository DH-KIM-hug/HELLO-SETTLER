# F7 비정상 입력 · 악용

> 2026-11-16 · 확정 (위임 결정 1·2 반영). 악용 허용 범위는 위임 결정 2 (Sonnet max, 2026-11-16 — 위임결정-2.md) F-1. 싱글 오프라인 게임이라 부정행위 방지(Anti-Cheat)는 범위 밖이다. 다만 **재화를 공짜로 늘리는 쉬운 길**은 막는다. 유료 재화가 들어가는 0.9판에서는 서버 검증으로 강화한다.

## 3단 방어
1. **UI Guard:** 입력을 막고, 비활성화하고, 같은 대상 재탭을 무시한다 (K1).
2. **System Validation:** 실행 직전에 다시 검증한다 (F1).
3. **Data Authority:** 정적 데이터가 가격, 확률, 보상을 정한다. 0.9판에서는 서버가 유료 재화와 구매를 정한다.

## 기능별 비정상 입력

| 기능 | 비정상 입력 | 방어 층 | 처리 |
|---|---|---|---|
| 선물 받기 | 연타, 두 손가락 동시 | 1·2 | 한 번만 (F6) |
| 구매 | 사기 연타, 확인 창 뒤 상점 탭 | 1·2 | 거래 중 막음, 모달 뒤 입력 막음 |
| 놓기 | 끌기 중 다른 탭, 끌기 중 백그라운드 | 1 | 무시, 취소 |
| 놓기 ↔ 빼기 반복 | 선물 뽑기 (G8) | 2 | MVP는 허용하고 측정한다 (위임 결정 9). 이득 상한은 정상의 약 3배이고 10분 판정에 막힌다. 0.9 전에 '머문 비율' 규칙으로 바꾼다 |
| 그릇 | 기본 ↔ 좋은 간식 반복 교체 | 2 | 좋은 간식은 넣는 순간 소모한다. 이득 없음 |
| 사진 | 셔터 연타 | 1 | 0.5초 잠금 |
| 화면 전환 | 전환 중 탭, 로딩 중 Back | 1 | Busy |
| 콜백 중복 | 신호가 두 번 옴 (버그) | 2 | 상태 머신이 금지 전환을 거절, Claim 검증 |
| 잘못된 순서 | 정령이 Arriving인데 선물 탭 | 2 | 선물이 없음 → 무시 |

## 시간 · 저장 악용 (F-1 — 허용 확정)

**보강:**
- 경과 시간이 음수면 0으로 하고 `last_seen = now`로 다시 기준을 잡는다.
- 벽시계가 크게 튀면 시험 기록에 `clock_jump`를 남기고, 그 구간은 H1과 빈 방 지표에서 제외한다.
- 0.9판의 광고 횟수와 유료 재화는 서버 기준이다.

| 악용 | 발생 가능성 | 영향 | 초안 정책 |
|---|---|---|---|
| 기기 시계를 앞으로 돌림 (방치 시간 늘리기) | 중 | 중 (재화와 수집 가속) | **방치 상한**(`offline_cap_s`, 12시간)이 한 번 돌릴 때의 이득을 묶는다. 그릇은 막지 못한다 (기본 간식은 무료라 채우고 반복할 수 있음). 반복 조작으로 가속하는 것은 싱글 게임이라 **허용**한다. 0.9판 유료 재화는 서버 기준 |
| 시계를 뒤로 돌림 | 저 | 저 | 경과 시간 음수는 0, `last_seen = now`로 다시 기준 (미래로 잘못 가 있던 시계를 고친 경우 진행이 멈추지 않게) |
| 저장 파일 복사·되돌리기 (save scumming) | 저 | 저 (희귀 정령 다시 굴리기) | 결정적 난수(save_seed + visit_seq) 때문에 같은 결과가 다시 나온다. 파일 복사는 막지 않는다 → **허용** (싱글이고 유료 재화가 없음) |
| 저장 파일 직접 편집 | 저 | 중 | MVP는 막지 않는다. 0.9판(유료 재화)에서 서버 영수증 기준으로 유료 재화를 관리한다 `[X6]` |
| 앱을 껐다 켜기 반복 (방치 계산 재실행) | 중 | 없음 | last_seen을 먼저 갱신하고 결정적 난수를 쓴다 → 이득 없음 |
