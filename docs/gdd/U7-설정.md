# U7 설정 (P9)

전체 화면 설정은 없다 (폰 전용).

## 3값 정의
- **Saved:** 설정 파일에 저장된 값.
- **Applied:** 지금 소리와 화면에 적용된 값.
- **Editing:** 밀대를 움직이는 동안의 값.

**초안 `[U-결정 3]`:** 즉시 적용, 닫을 때 저장한다.
- 밀대를 움직이면 Editing과 Applied가 함께 바뀐다 (소리가 바로 커지고 작아짐).
- 화면을 닫거나 Back을 누르면 Saved에 쓴다.
- **취소 버튼은 없다.** 모바일 설정의 관례이고, 되돌릴 일이 적은 값들이기 때문이다.
- **예외:** '내 지역 날씨 쓰기'를 켤 때는 Q5 → 시스템 권한 창을 거친다. 권한이 거절되면 꺼진 상태로 남는다.

## 손상 복구
- **설정 파일이 없거나 읽을 수 없으면:** 기본값을 쓰고 새로 만든다. 진행 데이터에는 영향이 없다.
- **값이 범위를 벗어나면:** 범위 안으로 잘라낸다(clamp). 모르는 키는 무시한다.

## 진행 데이터와 분리
- 설정은 **별도 파일**이다 (`user://settings.cfg` 같은 것; 경로 규칙은 개발 단계에서 정한다).
- '처음부터 다시'를 해도 설정은 남는다 (U2).
- 부팅할 때 설정을 저장 파일보다 **먼저** 읽는다.
