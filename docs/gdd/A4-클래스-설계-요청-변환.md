# A4 클래스 설계 요청 변환

> 2026-11-16 · 확정 (위임 결정 1·2 반영). K8 책임표를 클래스 후보와 최소 공개 API로 옮긴다.
> **원칙:**
> - 명사는 클래스가 아니다. 동사가 책임이다.
> - Interface, 깊은 상속, '○○Manager' 남용을 금지한다.
> - 순서: 책임표 → 의존 다이어그램 → 공개 API → (승인) → 코드.

## 책임표 (분류 · 책임 한 문장 · 원본 · 수명)

| 클래스 (파일) | 분류 | 책임 (한 문장) | 원본(Source of Truth)으로 가진 값 | 수명 |
|---|---|---|---|---|
| `Defs` (sim/defs.gd) | Static | 정적 데이터를 읽고 검증해 ID로 찾게 한다 | 정적 Def 전부 (읽기 전용) | Application |
| `SaveStore` (sim/save_store.gd) | Save | 저장 데이터를 원자적으로 쓰고, 검증해서 읽는다 | 파일 | Application |
| `EnvClock` (sim/env_clock.gd) | Logic | 시각 t의 낮/밤과 날씨를 하나로 정한다 | weather_cache | Application |
| `Placement` (sim/placement.gd) | Logic | 칸에 놀잇감을 놓고 빼는 규칙을 지킨다 | placement, rooms_owned (읽기) | Session |
| `Inventory` (sim/inventory.gd) | Logic | 가진 물건 수를 더하고 뺀다 | inventory | Session |
| `FoodBowls` (sim/food_bowls.gd) | Logic | 그릇의 남은 양을 두 몫으로 줄이고 채운다 | food_bowls | Session |
| `Visits` (sim/visits.gd) | Logic | 누가 오고 머물고 떠나는지 정한다 | visits_now, visit_seq, pity, weather_last_met, cooldowns | Session |
| `CatchUp` (sim/catch_up.gd) | Flow | 닫혀 있던 시간을 같은 규칙으로 시간순 재생한다 | last_seen | Session |
| `Wallet` (sim/wallet.gd) | Logic | 선물 묶음을 만들고 받게 하며, 재화를 바꾸는 유일한 곳이다 | wallet, pending_gifts | Session |
| `Shop` (sim/shop.gd) | Logic | 구매를 검증하고 거래를 요청한다 | purchase_count, shop_seen | Session |
| `Collection` (sim/collection.gd) | Logic | 처음과 해금을 판정해 기록한다 | collection, scenes_unlocked | Session |
| `Photos` (sim/photos.gd) | Logic | 사진 목록을 관리한다 (파일 쓰기는 view) | photos | Session |
| `TutorialState` (sim/tutorial_state.gd) | Logic | 첫 안내 단계를 진행한다 | tutorial | Session |
| `PlaytestLog` (sim/playtest_log.gd) | Save | 시험 이벤트를 기기 파일에 남긴다 | 로그 파일 | Application |
| `World` (sim/world.gd) | Flow | 위 시스템을 만들고 순서대로 묶고 신호를 잇는다. 1초 틱 | 없음 (묶기만) | Application |
| `WeatherService` (platform/weather_service.gd) | Platform | 위치 권한과 날씨 조회 | 없음 (결과를 EnvClock에 넘김) | Application |
| `Main` (view/main.gd) | UI/Flow | 앱 흐름(F8 ②)과 화면 스택 | 화면 스택 (런타임) | Application |
| `InputRouter` (view/input/…) | UI | 터치 → 액션 → World 요청 | 컨텍스트 스택 (런타임) | Application |
| `RoomView`, `SpiritView`, 각 화면 | UI | 신호를 받아 그리기 | 없음 | Session |

## 의존 방향 (화살표 = 안다 / 부른다, 순환 없음)
```
view/* → World → {Visits, FoodBowls, Placement, Inventory, Wallet, Shop, Collection, Photos, TutorialState, CatchUp, EnvClock} → Defs
CatchUp → Visits, FoodBowls, EnvClock
Visits → Placement(읽기), FoodBowls(읽기), EnvClock, Defs      (Wallet·Collection에는 신호만)
Shop → Wallet, Inventory, Placement(방 열기)
모든 sim → SaveStore.mark_dirty()
WeatherService → (sim 모름) ; EnvClock.apply_fetched(result) 를 World가 연결
```

## 최소 공개 API (World — UI가 부르는 것만)

| 메서드 | 반환 | 출처 |

| `claim_gift(slot_id)` · `claim_all_in_room(room_id)` | RewardClaimResult | F6 |

| `shop_state(product_id)` | 상품 상태 6종 | U6 |
| `capture_photo_done(path, spirit_ids)` · `delete_photo(id)` | Result | F1 |
| `mark_seen(kind, id)` | - | U3 배지 |
| `tutorial_step_done(step)` · `skip_tutorial()` | - | L6 |
| `reset_game()` | Result | U2 |
| `on_app_paused()` · `on_app_resumed(now)` | - | F8 ② |

**신호 (World가 내보냄):** `visit_changed(slot)`, `spirit_settled(slot, spirit, is_new)`, `spirit_left(slot, spirit)`, `gift_changed(slot)`, `coins_changed(n)`, `bowl_changed(slot)`, `env_changed(env)`, `unlocked(kind, id)`, `catch_up_done(summary)`.
