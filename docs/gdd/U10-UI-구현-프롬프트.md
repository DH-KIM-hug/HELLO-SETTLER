# U10 UI 구현 프롬프트 (초안 — A5에서 최종화)

> 2026-11-16 · 초안. 설계 결정은 위임하지 않는다. 프롬프트는 기획서의 결정만 옮긴다. 최종 형식은 gdd-ai-handoff A5 템플릿을 따른다.

## 공통 머리 (모든 UI 프롬프트 앞에 붙임)
- **개발 환경:** Godot 4.7.2, 2D, Mobile 렌더러, GDScript (정적 타입). 세로 1080×2340 기준이며 다른 화면비에 맞춰 늘어난다. 터치만 쓴다.
- **용어:** 방(Room), 칸(Slot), 놀잇감(Toy), 간식(Food), 그릇(Bowl), 정령(Spirit), 선물(Gift), 재화(cur_main), 도감(Book), 일러(Card/Scene).
- **소유권:** UI는 원본이 아니다. UI는 `World`의 메서드로 **요청**하고, **신호**를 받아 다시 그린다. UI 코드에서 wallet, inventory, placement, collection을 직접 고치면 안 된다.
- **단계:** 구조(노드 트리) → 표시(정적 데이터) → 연결(신호, 요청) → 예외(실패 띠) → 시험(헤드리스 + 스크린샷).
- **제외:** 이 프롬프트에 없는 화면이나 기능은 추가하지 않는다. 그림은 임시 사각형이 아니라 `art/` 키를 쓰고, 없으면 회색 실루엣을 쓴다 (MVP 완성도 기준 때문에 최종 빌드에서는 금지).
