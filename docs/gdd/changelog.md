# 기획 변경 기록

## 2026-11-16 · D1 재오픈 — 손님은 정령만, 무대는 사람 크기 집
- **변경 전:** 손바닥 행성 '작은 지구' 위에 꼬마 주민(사람형 SD)과 정령이 섞여 찾아옴
- **변경 후:** 사람 크기의 집 전체(방 여러 개, 옆으로 넘겨 봄)에 작은 사람처럼 생긴 정령만 찾아옴. 정령은 손가락만 한 SD 모습에 속성 표식(꽃잎, 물방울, 별빛 등)을 지님
- **이유:** 사용자 요청 ("사람 대신 정령으로만, 네코아츠메처럼 사람 스케일의 집에 작은 사람같이 생긴 정령들이 오는 거")
- **영향:** D1~D7 문구 수정 (작은 지구 → 집·방, 마당 넓히기 → 방 늘리기, 차별화 항목). MVP 방 2개(제안). 제목 '나의 작은 지구'는 다시 정함 (후보 제시 중)
- **지킬 것:** 집 무대는 장르 공통 발상이다. 네코아츠메의 툇마루-마당 구도는 쓰지 않는다

## 2026-11-16 · D6 재오픈 — 일러스트 해금 추가
- **변경:** 보상에 일러스트 해금을 넣는다. 해금은 네 가지다. 처음 온 정령의 일러 카드, 특별 장면 일러(조건 조합), 단골 일러(여러 번 방문), 도감 달성 일러.
- **MVP:** 정령 일러 8장과 특별 장면 일러 3장, 일러 보기 화면을 넣는다. 단골 일러와 도감 달성 일러는 0.3판에 넣는다.
- **이유:** 사용자 ("일러 해금요소 필요. 일러가 이뻐야돼")
- **영향:** D6, D7(포함 목록, 완성도 기준, 로드맵), D8(필러 3), C1, C2

## 2026-11-16 · C1 재오픈 — 시간·날씨 위치 연동
- **변경:** S1 시간·환경이 기기 시각과 시드 날씨 대신, 대략 위치 기준의 실제 낮/밤(해 뜨고 지는 시각)과 실제 날씨를 쓴다. 위치를 허락하지 않거나 인터넷이 없으면 시드 날씨로 대체한다.
- **이유:** 사용자 ("시간날씨는 위치연동")
- **영향:** 온라인 범위(C1)가 MVP부터 '날씨 조회'로 늘었다. F5 네트워크 단절 처리가 필요해졌다. 개인정보(위치 권한)를 X5·X8에 다룬다. 지역별 비 빈도 차이 보정은 X9·T7에서 정한다.

## 2026-11-16 · K1·K3 결정
- 놓기: 탭 두 번과 끌어서 놓기 둘 다 쓴다 (사용자).
- 간식: 채운 순간부터 줄어든다. 정령 없이 줄어든 몫은 '수줍은 정령'이 먹은 것으로 연출한다(부스러기, 발자국). 수줍은 정령은 다음 판에서 숨은 정령 후보로 둔다 (사용자: 길고양이 아이디어를 대체함. 고양이는 네코아츠메와 겹쳐 보이는 위험이 있어서).
- 간식(추가): 수줍은 정령은 보고 있을 때 먹지 않는다. 그릇은 '수줍은 정령 몫(앱이 꺼져 있을 때만)'과 '와 있는 정령 몫'으로 줄어든다 (사용자).

## 2026-11-16 · 사용자 결정 — 비는 실제로 와야 한다
- **변경:** 위임 결정 6 ③ '건조기 보정'(72시간 비가 없으면 날씨 조건을 품)을 **폐기한다.** 날씨 조건은 실제 날씨로만 충족한다 (빗방울 왕관 = 실제 비, 이끼 모자 = 실제 흐림·비). 첫 만남 보장(①)은 유지하고, 비가 오는 동안 후보일 때만 쌓인다.
- **이유:** 사용자 ("비는 무조건 와야함 실제로")
