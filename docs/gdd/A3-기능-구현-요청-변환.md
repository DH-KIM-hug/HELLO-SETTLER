# A3 기능 구현 요청 변환 — 작업 Backlog

> 2026-11-16 · 확정 (위임 결정 1·2 반영). A1(모호성 해소)이 끝난 뒤 확정한다. 요청은 하나에 중심 목표 하나다. 의존 순서는 **Data → Domain(sim) → UI(view)**다. 요청 형식은 A2 11항을 따른다.

## 변환 방법 (기획 문장 → 요청)
1. 동사를 찾는다 ("놓는다", "판정한다", "받는다", "산다", "해금한다", "찍는다").
2. 하나를 고르고 경계를 정한다. 경계는 K8 책임표를 따른다.
3. 입력, 상태, 데이터, 정상 흐름(F9), 예외(F1), 결과, 완료 조건(A6 케이스)을 채운다.
4. **역검증:** 요청서의 각 요구 줄에 출처(문서:절)를 달고, 출처 문장과 같은지 확인한다.
