# K4 상태 머신 — 정령 손님

> 2026-11-16 사용자 확정.
> 이 게임에는 플레이어 캐릭터가 없다. **상태 머신의 주인은 칸에 찾아온 정령 한 명(방문 하나)**이다. 게임 상태(시작·방·첫 안내)는 이것과 따로 C4·F8에서 다룬다.

## 상태

| 상태 | 의미 | 진입 조건 | 유지 중 규칙 | 종료 조건 |
|---|---|---|---|---|
| **Away** 없음 | 칸에 정령이 없다 (기본) | 시작 · Leaving 끝 | 방문 판정(S4)의 대상이 된다 | 방문 판정 성공 |
| **Arriving** 오는 중 | 정령이 창틀이나 문틈에서 들어와 놀잇감으로 가는 짧은 연출 | Away에서 방문 성공 (화면에 보이는 방일 때) | 탭 불가 · 놀잇감을 바꾸면 바로 Leaving | 연출 끝 (`arrive_s`, TEMP 1.5초) |
| **Playing** 노는 중 | 놀잇감 위에서 그 놀잇감 자세로 논다 | Arriving 끝 · **Restore**(앱을 열 때 이미 와 있음) | 탭하면 반응 · 머무는 시간이 흐름 · 사진에 찍힘 · 도감에 '본 모습' 기록 | 머무는 시간 끝 · 놀잇감 바뀜/빠짐 |
| **Leaving** 떠나는 중 | 손을 흔들고 나가며 선물을 남긴다 | Playing에서 시간 끝 또는 놀잇감 바뀜 · Arriving 중 놀잇감 바뀜 | 탭 불가 · 선물 생성을 **진입할 때 한 번만** 요청 (S8) | 연출 끝 (`leave_s`, TEMP 1.0초) → Away |

**Enter / Update / Exit**

| 상태 | Enter | Update | Exit |
|---|---|---|---|
| Arriving | 등장 위치 정하기, 등장 애니 시작, 소리 | 이동 | 놀잇감 자세 자리 확정 |
| Playing | 자세 애니 루프, `leave_at` 확인, 처음 온 정령이면 S7에 알림 (→ 새 손님 띠·일러 해금) | 숨쉬기·깜빡임, 반응 플래그 처리 | 반응 플래그 해제 |
| Leaving | **S8에 선물 생성 요청 (1회)**, 방문 기록 +1 (S7), 손 흔들기 애니 | 나가는 이동 | visits_now에서 지움 |

## 상태가 아닌 것 (플래그, 독립 축)

| 플래그 | 뜻 | 상태를 따로 만들지 않는 이유 |
|---|---|---|
| `reacting` | 탭 반응 애니가 나오는 중 | 규칙은 Playing과 같다 (머무는 시간도 그대로 흐름). 다시 탭하는 것만 막는다 |
| `is_new` | 이번이 처음 온 방문 | 표시(새 손님 띠)만 다르다 |
| `is_rare` | 희귀 정령 | 소리와 효과만 다르다 |
| `offscreen` | 지금 보이지 않는 방에 있음 | Arriving과 Leaving 연출을 건너뛸 뿐, 상태는 같다 |

## 전환표

| # | 지금 → 다음 | 트리거 | 조건 (Guard) | 우선순위 |
|---|---|---|---|---|
| T1 | Away → Arriving | 방문 판정 성공 | 칸에 놀잇감 있음 · 그 방이 화면에 보임 · 앱이 켜져 있음 | 3 |
| T2 | Away → Playing (Restore) | 앱 열기·방치 계산 결과 '와 있음' / 보이지 않는 방에서 방문 성공 | 앱이 꺼져 있었거나 `offscreen` | 3 |
| T3 | Arriving → Playing | 등장 연출 끝 | - | 3 |
| T4 | Playing → Leaving | `leave_at` 도달 | - | 2 |
| T5 | Playing → Leaving | **놀잇감 바뀜/빠짐 (ForceLeave)** | - | **1 (최우선)** |
| T6 | Arriving → Leaving | 놀잇감 바뀜/빠짐 (ForceLeave) | - | **1** |
| T7 | Leaving → Away | 떠나는 연출 끝 · 또는 `offscreen`이거나 방치 계산 중이면 즉시 | - | 3 |
| T8 | Playing (reacting 켬) | 정령 탭 | reacting 꺼짐 · 컨텍스트 Room | 4 |

**우선순위:** 1(ForceLeave) > 2(시간 끝) > 3(진행) > 4(반응). 같은 틱에 여러 개가 걸리면 숫자가 작은 것만 적용한다. 예를 들어 반응 중에 시간이 끝나면 반응을 끊고 Leaving으로 간다.

## 금지 전환
- **Away → Leaving:** 오지 않았는데 떠나며 선물을 남기면 안 된다 (보상 중복 방지).
- **Leaving → Playing / Arriving:** 떠나기 시작한 정령은 다시 돌아오지 않는다. 다시 오려면 새 방문이어야 한다.
- **Arriving → Away:** 반드시 Leaving을 거친다. 그래야 선물 규칙이 한 곳에 모인다.
- **같은 정령이 두 칸에서 Away가 아닌 상태:** 한 정령은 한 곳에만 있다 (C7).

## 방치 계산에서의 상태
앱이 꺼져 있던 동안에는 연출 없이 **같은 전환표를 시간순으로** 적용한다 (S5가 S4를 다시 부름). Arriving과 Leaving은 0초로 지나간다. 앱을 열 때 `Playing`인 방문은 T2(Restore)로 보여 준다.
