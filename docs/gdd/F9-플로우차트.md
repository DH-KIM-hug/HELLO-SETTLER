## 1. 열기 (방치 계산 → 결과 공개)

```
[GameFlow]  앱 열기 □ → ◇ 저장 유효? ─아니오→ ◇ 백업 유효? ─아니오→ □ broken 보관 → □ 새 게임 → ⊗ P1+첫 안내
                          │예                    │예→(합류)
            □ 경과 = now − last_seen → ◇ 경과 < 0? ─예→ □ 경과 = 0, last_seen = now ──┐
                                           │아니오                                  │
                                    □ 경과 = min(경과, 상한) → □ last_seen = now (먼저!) │
[S5]        □ 판정 회차 루프 (시간순, 종료: 회차 시각 > now) ◀────────────────────────┘
[S3/S4]       └ 그릇 소모 → 떠남 처리(선물 생성 요청 1회) → 방문 판정 → (첫 방문이면 S7 해금 기록)
[S5]        ◇ 루프 중 예외? ─예→ □ 그 회차 건너뜀, 기록 → (루프 계속)
[GameFlow]  ◇ 2초 넘음? ─예→ □ P1 먼저 보이기 (입력: Busy) → (계산 끝) ─→ ⊗ Running
                       └아니오→ □ P1 → □ 0.5초 → □ 해금 대기열(최대 3) → ⊗ Running
```
- **Soft Lock 검사:** Busy 플래그는 계산이 끝나거나 예외가 나도 반드시 해제한다 (F2).
- **Branch 테스트:** 저장 정상 / 백업 복구 / 둘 다 실패 / 경과 음수 / 상한 초과 / 계산 예외 / 2초 초과.

## 3. 구매
G9 흐름 1~8과 같다. 모든 실패 분기는 F1의 buy 행, 결과 코드 7종으로 끝난다.
- **Retry:** 재시도 버튼은 없다. 다시 탭하면 처음부터 검증한다.
- **Branch 테스트:** 결과 코드 7종 + 확인 창이 떠 있는 동안 재화 변화.
