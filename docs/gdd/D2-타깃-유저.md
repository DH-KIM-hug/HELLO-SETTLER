# D2 타깃 유저

> 2026-11-16 사용자 결정

## 타깃 (1~2문장)

**모에 그림체와 서브컬처 수집 게임에 익숙한 10~30대.** 출퇴근길이나 자기 전에 폰을 들고 1~3분씩, 하루 3~6번 들어와 "누가 왔나"를 확인하고 간식을 채운 뒤 나간다. 어렵거나 경쟁하는 놀이보다 귀여운 캐릭터의 새 모습을 발견하고 모으는 데서 보상을 느낀다.

| 항목 | 내용 |
|---|---|
| 게임 경험 | 가챠·수집형 모바일 게임이나 서브컬처 게임을 해 봤다. 도감과 희귀 등급에 익숙하다 |
| 장르 숙련도 | 방치형의 기본(놓고 기다리기, 돌아와 받기)을 설명 없이 안다. 복잡한 경제나 수치 최적화는 원하지 않는다 |
| 1회 플레이 시간 | **1~3분**, 하루 **3~6번** |
| 플랫폼 | 휴대폰 세로 화면, 한 손 조작. 안드로이드 먼저, iOS는 나중에 |
| 조작 선호 | 엄지 탭 한두 번. 끌기는 놓기에만 쓴다. 긴 입력이나 빠른 반응을 요구하지 않는다 |
| 난이도 선호 | 실패하거나 잃는 것이 없다. 막히는 지점도 없다 |
| 반복 선호 | 짧게 자주 들어오는 습관형. 날씨와 계절이 바뀌어 다음에 올 이유가 생긴다 |
| 보상 선호 | 새 캐릭터, 처음 보는 모습 사진, 희귀 손님, 친밀도로 열리는 특별 모습. 숫자보다 그림이 보상이다 |

## 이 타깃이 기능을 제한하는 근거

1. **한 번에 1~3분이다.**
   - 들어오면 가장 먼저 "누가 와 있나"가 보여야 한다. 첫 화면이 바로 집(마지막으로 본 방)이다.
   - 메뉴를 세 번 넘게 눌러야 하는 핵심 기능은 금지한다.
   - 긴 대화, 긴 연출, 기다려야 하는 로딩은 넣지 않는다.
2. **한 손 세로 화면이다.**
   - 누르는 버튼은 화면 아래 절반에 둔다.
   - 누르는 영역은 최소 48dp로 한다.
   - 가로 화면은 지원하지 않는다.
3. **잃는 것이 없다.** 손님이 화를 내거나 떠나서 다시 안 오는 일, 시간 제한 실패, 벌칙을 넣지 않는다. 간식이 떨어지면 손님이 오지 않을 뿐이다.
4. **숫자보다 그림이 보상이다.** 생산량 곡선, 큰 수 표기, 효율 최적화 화면은 넣지 않는다. 재화는 상점용으로만 쓴다.
5. **모에 그림체에 익숙하다.** 캐릭터 그림의 품질 기준이 높다.
   - 그림이 들쭉날쭉하면 바로 이탈한다.
   - 따라서 그림체 고정(아트 바이블과 기준 그림)이 개발 첫 단계의 위험 항목이다.

## 게이트 체크 결과
- [x] 구체적 타깃을 1~2문장으로 적었다. 연령대, 취향, 플레이 습관이 들어 있다.
- [x] 플레이 시간(1~3분 × 하루 3~6번), 플랫폼(휴대폰 세로, 안드로이드 먼저), 조작 선호(엄지 탭)를 명시했다.
- [x] 타깃이 기능을 제한하는 근거를 5개 적었다.
