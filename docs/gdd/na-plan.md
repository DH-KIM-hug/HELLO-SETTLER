# 해당 없음(N/A) 확정 목록 — 2026-11-16 사용자 확인

도구가 선행 단계가 끝난 뒤에만 `na`를 받으므로, 해당 단계에 도달하면 아래 이유로 기록한다.

| 단계 | 이유 |
|---|---|
| B1~B9 | 전투 없음 |
| K2 | 직접 조작 캐릭터 없음 — 탭·배치만 |
| G3 | 능력치 성장 없음 |
| L1~L5, L7~L9 | 스테이지 없음 — 진행은 X9 해금 표 |
| T4 · T5 · T6 | 스킬·스테이지·퀘스트 없음 (도감이 목표) |
| F3 | 승패 없음 |
| X2 | 싱글 전용, 온라인은 클라우드 저장만 |
| X10 | 리셋형 메타 진행 없음 |
| X12~X14 | 규칙 기반(퍼즐·보드) 게임 아님 |

## 재해석해 남기는 단계
- K4~K6: 손님(캐릭터)의 상태 — 오는 중·노는 중·떠남·선물 두기
- G2: 친밀도 단계 · G7: 방문 확률
- L6 튜토리얼 유지 · X1 캐릭터 프로필·작은 세계관만 · X9·X11 필수
