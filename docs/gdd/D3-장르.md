# D3 장르

> 2026-11-16 사용자 결정. 메타 질문에서 정했다: "네코아츠메류 방치형 수집", 경험은 편안함과 수집·발견, 구성은 아이템·상점, 성장·해금, 확률·랜덤.

## 세부 장르

**세로 한 화면 방치형 방문 수집 게임 (+ 가벼운 꾸미기).**
- **방치형 방문:** 플레이어가 조건을 걸어 두면 시간이 지나는 동안 캐릭터가 알아서 찾아온다.
- **방 단위 화면:** 한 번에 방 하나를 보여 준다. 방이 늘어나면 옆으로 넘겨 본다. 정령은 손가락만 하고, 방과 가구는 사람 크기다. 이 크기 차이가 화면의 기본 그림이다.

| 구분 | 장르 | 이 게임에서 하는 일 |
|---|---|---|
| **주 장르** | 방치형 방문 수집 | 놓기 → 기다리기 → 방문 확인 → 사진·도감·선물 |
| 보조 장르 1 | 가벼운 꾸미기 | 방의 벽지, 바닥, 커튼, 테마 바꾸기. 방문 확률에 약하게 영향을 준다 |
| 보조 장르 2 | 환경 변화 | 날씨와 계절, 시간대가 바뀐다. 누가 올지를 바꾸는 조건이 된다 |
| 아닌 것 | 클리커, 생산 경영, 육성 RPG, 가챠 뽑기 | 탭을 연타하는 생산, 자원 체인, 능력치, 유료 뽑기는 없다 |

## 장르가 요구하는 핵심 시스템과 데이터 구조 힌트

| 시스템 | 하는 일 | 데이터 구조 힌트 |
|---|---|---|
| 배치 | 칸(슬롯)에 물건을 놓고 빼기 | 정적: `SlotDef(slot_id, 위치, 크기)` · 저장: `slot_id → item_id` |
| 간식 소모 | 간식이 시간에 따라 줄고, 0이면 손님이 오지 않음 | 정적: `FoodDef(지속 시간, 끌림 값)` · 저장: `남은 양, 채운 시각` |
| 방문 판정 | 일정 간격마다 빈 놀잇감에 손님을 뽑음 | 정적: `GuestDef(좋아하는 놀잇감·간식·날씨·계절, 희귀도, 가중치)` · 런타임: 현재 방문 목록 |
| 방치 시간 처리 | 닫혀 있던 시간을 다시 열 때 한꺼번에 계산 | 저장: `last_seen 시각` · 상한 시간 · 시계 조작 방어 |
| 환경 | 날씨, 계절, 시간대 | 파생: 실제 날짜·시각에서 계산(저장 안 함) 또는 시드 기반 일일 날씨 |
| 손님 모습 | 놀잇감마다 손님 자세 표시 | 정적: `PoseDef(guest_id, toy_id, 그림)` |
| 사진·사진첩 | 찍은 장면 저장, 처음 본 모습 표시 | 저장: 사진 목록(파일 경로, 날짜, 손님 id들) |
| 도감 | 손님별 처음 온 날, 방문 횟수, 본 모습 | 저장: `guest_id → {처음 온 날, 횟수, 본 모습 집합}` |
| 선물·재화 | 손님이 떠날 때 남기는 재화와 특별 선물 | 정적: 선물 표 · 저장: 받지 않은 선물 목록, 지갑 |
| 상점 | 재화로 물건 사기 | 정적: 가격표 · 저장: 가진 물건 |
| 친밀도 | 방문 횟수에 따라 단계가 오르고 특별 모습과 선물이 열림 | 저장: `guest_id → 친밀도 값` · 정적: 단계 기준표 |
| 해금 | 새 방 열기, 새 놀잇감·간식 등장 | 정적: 해금 표(조건 → 열리는 것) · 저장: 열린 것 집합 |
| 저장·클라우드 | 기기 저장, 기기 옮기기 | 저장 파일 버전 · 클라우드 키 |
| 수익화 | 광고 보상, 유료 재화 | 정적: 상품 표 · 저장: 구매 기록(영수증 검증은 서버) |
