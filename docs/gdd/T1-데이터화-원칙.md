# T1 데이터화 원칙

> 2026-11-16 · 초안. 데이터화 범위는 C5(사용자 확정)를 따른다. 이 문서는 그 원칙을 규칙으로 정리한다.

## 로직 / 데이터 / 상태
- **로직 (코드):**
  - 판정 순서 (K7)
  - 상태 전환 (K4)
  - 거래의 원자성 (G8)
  - 방치 계산 (S5)
  - 저장 형식 (S11)
- **데이터 (정적 파일):** 바뀔 수 있는 모든 '내용'과 '수치'
  - 정령
  - 놀잇감, 간식, 방, 칸
  - 선물 표, 상품, 장면 조건, 친밀도 표
  - 날씨 묶기, 소리, 안내 문구, 조정값
- **상태 (저장/런타임):** 플레이어마다 다른 현재 값 (G10 표)

## 데이터화 판단 표

| 기준 | 해당하면 데이터 | 예 |
|---|---|---|
| 자주 바뀜 | ○ | 가격, 확률, 시간 |
| 개체별로 다름 | ○ | 정령마다 좋아하는 것 |
| 밸런스 조정 대상 | ○ | weight, gift 범위 |
| 콘텐츠가 늘어남 | ○ | 정령, 놀잇감, 방, 장면 (판마다 추가) |
| 여러 시스템이 참조 | ○ | ToyId (S2, S4, S6, S9) |
| 어느 것도 아님 | 코드 상수 | 시험용 상수, 틱 1초, 저장 파일 이름 |

## 4분류
G10 표를 기준 표로 쓴다. 새 값을 추가할 때는 반드시 4분류 중 하나를 적는다.

## Source of Truth (값의 원본은 한 곳)

| 값 | 원본 |
|---|---|
| 정적 수치 | `data/*.json` (T8) 한 곳. 코드나 씬에 같은 값을 다시 쓰지 않는다 |
| 현재 값 | 저장 파일 (S11). 화면은 사본이다 |
| 파생값 | 저장하지 않는다. 매번 계산한다 |

## 단위 규약
- **시간:** 초 (실수). 파일에서는 `_s`로 끝나는 이름.
  - 사람이 읽기 쉽게 시간이 필요하면 `_h`를 쓰지 않고 초로 적고 주석을 단다. 예: `"duration_s": 21600  // 6h`
- **시각:** UTC 초 (정수). 낮밤 판단에만 현지 시각을 계산한다.
- **확률:** 0~1 실수. 퍼센트는 쓰지 않는다.
- **가중치:** 상대값, 0보다 크다.
- **배율:** 1.0 기준 실수.
- **재화와 수량:** 정수 ≥ 0.
- **그릇 양:** 0~1 실수.
- **화면 좌표:** 방 그림 기준 픽셀이다. 방 그림 크기(1080×1920 TEMP)에 대한 좌표.

## ID 규칙
G4 규칙을 따른다.
- **형식:** `<접두어>_<영문소문자_밑줄>`
- **변경과 재사용 금지:** ID는 바꾸지 않고, 한 번 쓴 ID는 다시 쓰지 않는다.
- **이름은 ID가 아니다:** 표시 이름은 `name` 필드에 둔다.
- **지운 ID:** `deprecated.json`에 남긴다.
- **칸 ID:** `room_xxx/slot_n`, n은 0부터 시작한다.
- **자세 ID:** `spirit_xxx@toy_xxx`.

## 검증 (Validation) — 시작할 때 한 번, 그리고 시험 묶음으로

| 종류 | 규칙 | 실패 시 |
|---|---|---|
| 중복 | 같은 표 안에서 ID가 중복되지 않음 | Error |
| 참조 | 모든 참조 ID가 존재함 (likes_toys, gift_table, target, condition) | Error |
| 범위 | 확률 0~1, weight > 0, stay_min ≤ stay_max, price ≥ 0, max_stack ≥ 1 | Error |
| Enum | type, rarity, weather, time 값이 정해진 목록 안에 있음 | Error |
| 그림 | 정령 × 좋아하는 놀잇감마다 PoseDef가 있음, card_art 파일이 있음 | Error (개발) / 회색 실루엣 + 경고 (출시) |
| 설계 경고 | 아무도 좋아하지 않는 놀잇감 · 시작 놀잇감으로 만날 정령 2명 미만 · 조건이 불가능한 장면 (조건 정령이 그 시간대나 날씨에 못 옴) | Warning |

## 필수 / 선택 · 기본값
- 필드마다 필수 여부와 기본값을 정의서(T2·T3)에 적는다.
- 선택 필드가 비면 기본값을 쓴다. 예: weather가 비면 '상관없음'.

## MVP 최소 필드
C5 'MVP 최소 필드'를 따른다.

## 과도한 범용화 금지
- '효과 스크립트'나 '조건 언어' 같은 범용 시스템은 만들지 않는다.
- 장면 조건은 정해진 필드 몇 개로만 쓴다 (정령 목록, 날씨, 시간대, 방, 동시 존재).

## 단계
1. 0.0 프로토: 코드 상수
2. 0.1: JSON 파일
3. 0.2 MVP: JSON + 검증 시험

Godot Resource(.tres)로 옮길지는 T8에서 정한다.

## 완료 기준 10항
1. 모든 정적 값이 데이터 파일에 있다.
2. 코드에 수치 상수가 없다 (틱과 파일 이름 제외).
3. 모든 값에 4분류가 있다.
4. 단위 규약을 지킨다.
5. ID 규칙을 지킨다.
6. 검증 시험이 있다.
7. 지운 ID 정책이 있다.
8. 기본값을 정의했다.
9. 파생값을 저장하지 않는다.
10. 새 정령 1명 추가가 데이터와 그림만으로 된다 (코드 수정 0).
