# F8 상태 전환표

> 2026-11-16 · 초안. 이 게임의 상태 머신은 네 개다.
> ① 정령 방문 (K4)
> ② 앱 흐름 (GameFlow)
> ③ 첫 안내 (S12)
> ④ 화면 스택 (U9)
>
> 스테이지, 적, 퀘스트는 해당 없음이다. 각 머신의 **전환 권한은 한 곳**에만 있다.

## ① 정령 방문 — 권한: S4 Visits
K4 표를 그대로 쓴다. 금지 전환 매트릭스는 아래와 같다.

| 지금 \ 다음 | Away | Arriving | Playing | Leaving |
|---|---|---|---|---|
| Away | - | ○ T1 | ○ T2 (Restore) | **X** |
| Arriving | **X** | - | ○ T3 | ○ T6 |
| Playing | **X** | **X** | (reacting 플래그) | ○ T4, T5 |
| Leaving | ○ T7 | **X** | **X** | - |

- **Terminal 없음:** 순환 구조다.
- 'Any → Dead'에 해당하는 것은 **ForceLeave**(우선순위 1)다.
- **독립 축 플래그:** reacting, is_new, is_rare, offscreen.

## ② 앱 흐름 — 권한: GameFlow

| 상태 | 시작/종료 범위 | 진입 | 탈출 |
|---|---|---|---|
| Booting | 실행 → 데이터 검증 | 실행 | Loading |
| Loading | 저장 읽기, 변환 | Booting | CatchingUp / Error→NewGame |
| CatchingUp | 방치 계산 (최대 2초는 P0, 넘으면 P1을 보이며 계속) | Loading, Resumed(30분 이상) | Running |
| Running | 보통 플레이 | CatchingUp | Backgrounded, Resetting, Quitting |
| Backgrounded | 앱이 뒤로 감 (즉시 저장 끝) | Running | Resumed |
| Resumed | 다시 앞으로 | Backgrounded | Running(30분 미만: 짧은 계산) / CatchingUp(30분 이상) |
| Resetting | 처음부터 다시 | Running | Running (새 게임) |
| Quitting | 종료 저장 | Running | (끝 — Terminal) |

**Transition List**

| Current | Trigger | Guard | Next | Priority |
|---|---|---|---|---|
| Booting | DataOk | - | Loading | - |
| Booting | DataError | 출시 판 | Loading (오류 항목 건너뜀) | - |
| Loading | LoadOk / Recovered / Migrated | - | CatchingUp | - |
| Loading | LoadFailed | 백업도 실패 | CatchingUp (NewGame) | - |
| CatchingUp | Done | - | Running | - |
| Running | AppPaused | - | Backgrounded | 1 |
| Running | ResetConfirmed | Q8 두 번 확인 | Resetting | 2 |
| Running | QuitRequested | Back 두 번 | Quitting | 2 |
| Backgrounded | AppResumed | 경과 < 30분 | Running (짧은 방치 계산 포함) | - |
| Backgrounded | AppResumed | 경과 ≥ 30분 | CatchingUp | - |
| Resetting | ResetDone | - | Running | - |

- **금지:** Running → Loading (저장을 다시 읽으려면 앱을 다시 시작해야 함). Quitting → (다른 상태 전부).
- **Priority 1:** 앱이 뒤로 가는 일(AppPaused)이 어떤 상태에서든 먼저다. 끌기, 확인 창, 구매 처리를 취소하거나 끝낸 뒤 저장한다.

## ③ 첫 안내 — 권한: S12
**상태 흐름:** `Step1 → Step2 → … → Step8 → Done`
- **Skip:** 어느 Step에서든 Done으로 간다 (Skip 처리는 L6).
- **금지:** 뒤로 가기(Step n → n−1).
- **Terminal:** Done.
- **진입:** New Game일 때 Step1부터. Continue일 때는 저장된 단계부터.

## ④ 화면 스택 — 권한: UI 라우터
U9 전환표를 쓴다.
- 'Transitioning'은 **플래그**다 (입력 막기).
- 팝업 대기열은 **상태가 아니라 큐**다.

## 고립 상태 점검
네 머신 모두 모든 상태에 진입 전환과 탈출 전환(또는 Terminal)이 있다.
