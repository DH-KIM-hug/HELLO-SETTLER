# U4 HUD (H1 — 방 화면 위)

> 2026-11-16 · 확정 (위임 결정 1·2 반영). 전투 HUD(체력, 쿨)는 없다. 이 게임의 HUD 정보는 **자원, 상태, 안내** 세 종류다. 아래 버튼 구성은 위임 결정 2 (Sonnet max, 2026-11-16 — 위임결정-2.md) U-1.
> **원칙:**
> - 화면 가운데(방과 정령)를 가리지 않는다.
> - 위쪽에는 정보만 둔다.
> - 아래쪽은 엄지 영역이라 버튼을 둔다 (D2).

## 배치 (기획. 모양과 색은 아트 바이블에서 정한다)

```
┌──────────────────────────┐
│ [재화 ◯ 1,240]     [☀/🌧 ] │ ← 위: 정보 (작게)
│                          │
│        (방 · 정령)         │ ← 가운데: 가리지 않음
│                          │
│          ● ○             │ ← 방 표시점
│ [상점][도감][소지품][📷][⚙] │ ← 아래: 버튼 5칸 고정 (앨범은 도감 탭) U-1
└──────────────────────────┘
```

## 원본 아님 확인
- HUD에는 자체 계산이나 타이머가 없다. 예를 들어 그릇 남은 양을 HUD가 줄이지 않는다. S3 값을 1분마다 읽어 그림 단계만 바꾼다.
- 재화를 HUD에서 고치지 않는다. 신호로 받은 값만 그린다.
- 시스템 값이 준비되기 전(P0 계산 중)에는 HUD를 보이지 않는다.

## L2 목표 표시
- L 단계(스테이지)는 해당 없음이다. 목표는 HUD에 상시로 두지 않는다.
- 다음 목표는 도감의 실루엣 힌트와 상점의 잠김 글이 대신한다 (G9, C2).

## 접근성
- **색에만 기대지 않는다:** 날씨는 아이콘 모양으로(해, 구름, 빗방울) 구분한다. 빈 그릇은 반짝임과 모양(빈 그릇 그림)으로 알린다.
- **크기:** 버튼은 48dp 이상이다. 재화 글자는 최소 14pt이고, 큰 글씨 설정은 X5에서 다룬다.
- **대비:** 위쪽 정보 글자에는 반투명 바탕을 둬서 방 그림 위에서도 읽히게 한다.
- **동작 줄이기 설정:** 반짝임을 멈춘다 (X5).
