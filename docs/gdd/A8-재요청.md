# A8 재요청 (0.0 규칙 층에서 실제로 한 재요청)

> 2026-11-16 · "다시 해 줘"라고 하지 않는다. 현재 상태, 기대 결과, 유지 조건, 수정 범위, 완료 조건의 5요소로 요청했다.

## 재요청 1 — 선물 중복 방지 (묶음 5, 유형: 데이터/규칙 불일치)

| 요소 | 내용 |
|---|---|
| 현재 (Actual) | `visit_seq <= last_processed_visit_seq`이면 선물을 무시한다. 나중에 온 정령이 먼저 떠나면 앞 번호의 선물이 사라진다 |
| 기대 (Expected) | 떠난 방문마다 선물이 정확히 1번 생긴다 (순서와 무관) |
| 유지 조건 | 같은 방문으로 두 번 만들지 않는다 (F6). 결정적 난수와 상한 규칙은 그대로 |
| 수정 범위 | `wallet.gd` create_gift, `save_store.gd` 새 게임 키 `gifted_seqs`, 시험 |
| 완료 조건 | seq 6 → 5 순서로 둘 다 생성되고, 6을 다시 넣으면 무시. 전체 시험 PASS |

- **회귀 조건:** 기존 TC-G1~G3 통과.
- **기획서 갱신:** F6의 '처리한 번호 이하 무시'를 '최근 집합'으로 바꿨다 (changelog).

## 재요청 2 — 방치 계산 중 즉시 처리, 상한 (묶음 6 → 7, 유형: 누락 + 수치)

| 요소 | 내용 |
|---|---|
| 현재 | 방치 이벤트를 계산이 끝난 뒤 한꺼번에 처리한다 → 처음 만난 시각이 다시 연 시각으로 기록되고, 첫 만남 보장과 R2가 늦게 반영된다. 12시간 상한 때문에 둘째 방이 6.52일 |
| 기대 | 회차마다 그 시각으로 처리한다. 둘째 방 중앙값 4.5~6.5일 |
| 유지 조건 | 같은 이벤트를 두 번 처리하지 않는다. 결정적이다 |
| 수정 범위 | `catch_up.gd` 콜백, `world.gd` 연결, tuning 상한 86,400, 시험 |
| 완료 조건 | first_seen_at = 실제 만난 시각, 장면 해금 시점 정확, 7일 시나리오 assert 복원 통과 |

- **회귀 조건:** catchup, world 묶음 의미 유지.
- **기획서 갱신:** X11, F7, T7, C2 (상한 24시간), changelog.

## 같은 실수를 공통 규칙으로 승격
- **"정렬되지 않는 사건에 '최댓값 이하 무시'로 중복 방지 금지"** → A2 공통 규칙에 추가한다.
- **"방치 계산 결과는 회차 시각으로 처리 (나중에 일괄 처리 금지)"** → A2 공통 규칙에 추가한다.
