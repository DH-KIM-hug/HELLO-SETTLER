# U3 로비 / 허브 (= P1 방)

> 2026-11-16 · 확정 (위임 결정 1·2 반영). 이 게임의 허브는 방 화면(P1)이다. 따로 로비 화면을 두지 않는다.

## 역할
- **상태 요약:** 누가 와 있나, 선물, 그릇, 날씨와 낮밤, 재화.
- **시스템 진입:** 아래 버튼으로 각 화면에 들어간다.
- **플레이 준비:** 놓기와 간식을 여기서 한다.

**Primary Action:** 이 방에 와 있는 정령을 보는 것이다. 버튼이 아니라 화면 자체가 주 행동이다. 다음 행동으로는 선물 받기, 간식 채우기, 놓기를 둔다.

## 표시 데이터와 출처

| 표시 | 출처 (원본) | UI가 하는 일 |

| 창밖 날씨, 낮밤 빛 | S1 env (파생) | 그리기 (하늘, 비, 빛 색) |

## Refresh (다시 읽는 때)

| 언제 | 다시 읽는 것 |
|---|---|
| P0 → P1 (열기) | 전부 |
| 다른 화면에서 P1로 돌아옴 | 재화, 소지품 수 (상점에서 바뀜), 배지 |
| 방 넘김 | 그 방의 전부 |
| 시스템 신호 (방문, 떠남, 선물 생김, 날씨 바뀜) | 해당 칸·표시만 (이벤트 기반) |
| 1분마다 | 그릇 단계 그림 (값이 계속 줄기 때문) |

## 팝업
한 번에 하나만 띄운다 (U8 대기열).
- 열기 직후 순서: 방이 먼저 보인다 → 0.5초 → 일러 해금(Q2) → 새 손님 띠(Q1).

## Back
- P1에서 Back을 누르면 "한 번 더 누르면 나가요" 띠가 뜬다. 2초 안에 다시 누르면 종료한다.

## 알림 배지 (실제 상태 기준)

| 배지 | 위치 | 켜지는 조건 (원본) | 꺼지는 조건 |
|---|---|---|---|
| 도감 점 | 도감 버튼 | 아직 안 본 새 정령이나 새 일러가 있음 (collection의 `seen_in_book` 플래그) | P5 또는 P6에서 그 항목을 봄 |
| 상점 점 | 상점 버튼 | 새로 잠금이 풀린 상품이 있음 (`shop_seen` 집합) | 상점을 엶 |
| 선물 개수 | 없음 (방에 선물 그림이 보임) | - | - |

배지를 위해 저장하는 플래그는 G10 표에 더한다 (`seen_in_book`, `shop_seen`).

## 잠금 메뉴
- 첫 안내 중에는 안내 순서에 따라 아래 버튼이 하나씩 나타난다.
- 잠긴 버튼은 **숨긴다.** 회색 버튼을 보여 두지 않는다. 한 번에 고를 것을 줄이려는 것이다 (힉).

## 시스템 기능 미포함 확인
- 방 화면은 판단하지 않는다. 누가 올지, 선물을 줄지, 살 수 있는지를 정하지 않는다.
- 하는 일은 신호를 받아 그리기, 탭을 요청으로 바꾸기 두 가지뿐이다.
