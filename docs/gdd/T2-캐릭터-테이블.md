# T2 캐릭터 테이블 — SpiritDef · PoseDef

> 2026-11-16 · 초안. 이 게임의 '캐릭터'는 정령 손님뿐이다. 전투, 적, NPC 전용 표는 없다. 테이블 분리 수준은 **SpiritDef 하나 + PoseDef(그림) 하나**다.

## SpiritDef 정의서 (6열)

| Field | Type | 설명 | 기본값 | 제약 (Validation) | Owner / 쓰는 시스템 |
|---|---|---|---|---|---|
| spirit_id | String | 고유 ID `spirit_xxx` | (필수) | 중복 금지, 형식 | 데이터 / 전부 |
| name | String | 표시 이름 (한국어) | (필수) | 1~8자 | 데이터 / UI |
| element | Enum | 속성 (flower, leaf, water, ember, wind, moss, rain, star …) | (필수) | 목록 안 | 데이터 / S6(움직임), UI |
| rarity | Enum | common / rare | common | 목록 안 | 데이터 / S4, S8(선물 표 선택), S13 |
| likes_toys | ToyId[] | 이 놀잇감 칸에만 온다 | (필수) | 1개 이상, 존재하는 ID | 데이터 / S4 |
| toy_bonus | {ToyId: float} | 특히 좋아하는 놀잇감 배율 | {} (= 1.0) | 1.0~3.0, likes_toys 안의 ID | 데이터 / S4 |
| likes_food | FoodId[] | 좋아하는 간식 (배율 ×1.2) | [] | 존재하는 ID | 데이터 / S4 |
| requires_food | FoodId 또는 null | 이 간식이 그릇에 있어야만 옴 (예: star → nectar) | null | 존재하는 ID | 데이터 / S4 |
| weather | Enum[] | 날씨 게이트 (비면 상관없음) | [] | clear/cloudy/rain | 데이터 / S4 |
| weather_relax | bool | 게이트가 72시간 안 맞으면 풀림 (건조기 보정) | false | - | 데이터 / S4 |
| weather_boost | Enum[] | 보너스 날씨 | [] | 목록 안 | 데이터 / S4 |
| weather_bonus | float | 보너스 날씨 배율 | 1.0 | 1.0~5.0 | 데이터 / S4 |
| time | Enum | day / night / any | any | 목록 안 | 데이터 / S4 |
| weight | float | 기본 뽑힘 세기 | 10 (common) / 1 (rare) | > 0 | 데이터 / S4 |
| stay_min_s · stay_max_s | float | 머무는 시간 | T7 | 0 < min ≤ max | 데이터 / S4 |
| gift_table | GiftTableId | 떠날 때 선물 표 | gift_common / gift_rare | 존재 | 데이터 / World→S8 |
| keepsake | ItemId 또는 null | 이 정령의 특별 선물 (0.3) | null | 존재, type=Keepsake | 데이터 / S7 |
| card_art | ArtKey | 정령 일러 카드 | (필수) | 파일 존재 | 데이터 / S7, UI |
| book_art · silhouette | ArtKey | 도감 칸 그림, 실루엣 | (필수) | 파일 존재 | 데이터 / UI |
| hint | String | 도감 빈 칸 힌트 (숫자 금지) | (필수) | 1~30자 | 데이터 / UI |
| profile | String | 짧은 소개 (0.3: 한마디 목록으로 확장) | "" | 숫자 금지 | 데이터 / UI |

**런타임 값은 이 표에 두지 않는다.** visit_count, 지금 상태, 쿨다운은 저장 데이터와 S4에 있다.

## PoseDef 정의서 (그림·표현 전용 — 규칙에 쓰지 않음)

| Field | Type | 설명 | 기본값 | 제약 | Owner |
|---|---|---|---|---|---|
| pose_id | String | `spirit_xxx@toy_xxx` | (필수) | 두 ID 존재, toy가 likes_toys 안에 있음 | 데이터 / S6, S7 |
| art | ArtKey | 자세 그림 (컷아웃 조각 묶음) | (필수) | 파일 존재 | 아트 |
| anchor | Vector2 | 놀잇감 그림에 붙는 자리 | (0,0) | - | 아트 |
| idle_anim | String | 숨쉬기·흔들림 설정 키 | "default" | - | 아트 |
| is_special | bool | '본 모습' 도감 대상 | true | - | 데이터 / S7 |

## 참조 검증
- `likes_toys`, `toy_bonus`, `likes_food`, `requires_food`, `gift_table`, `keepsake`는 모두 존재해야 한다.
- 정령 × likes_toys마다 PoseDef가 1개 있어야 한다 (T1 그림 검증).

## 역할 ↔ 수치 (상대 비교, MVP 8명 — G7 표)

| 역할 | 정령 | 수치 특징 | 맞는가 |
|---|---|---|---|
| 첫날 친구 (시작 놀잇감) | petal, leaf, breeze | weight 10, 조건 느슨함 (낮 또는 둘 다) | ○ |
| 놀잇감을 사면 오는 친구 | drop, ember, moss | weight 10, 상점 놀잇감 필요 | ○ |
| 날씨의 손님 | drop, moss (흐림·비 보너스) | weather_bonus 2 | ○ (날씨 차별화) |
| 밤의 손님 | ember (밤), star (밤만, 희귀) | time 제한 | ○ |
| 희귀 | rain, star | weight 1, 조건 강함, gift_rare, 첫 만남 보장 | ○ · rain은 건조기 보정도 받는다 (위임 결정 6) |
