## Current Rules (지금 개발 요청에 쓰는 규칙)
- A2 공통 규칙 블록에 아래 3줄을 더한다 (2026-11-16).
  1. 정렬되지 않는 사건(정령이 떠나는 순서 등)의 중복 방지에 '최댓값 이하 무시'를 쓰지 않는다. 최근 집합이나 고유 키를 쓴다.

- **검증:** 메인 세션이 코드를 읽고, 시험을 직접 실행하고, 기획서와 대조한다 (A7).
