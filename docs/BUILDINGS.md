# 나의 작은 지구 — 건물·생산 명세서 (v1)

> 기획서 7장(경제 & 생산)의 상세 명세. 수치 데이터는 [`buildings_v1.xlsx`](buildings_v1.xlsx)에 있다 (생성 스크립트: `tools/gen_buildings.py`).
> **모든 수치는 임시값(안)** 이다. 다음 단계인 경제·인구 밸런스 시트에서 검증한 뒤 확정한다.

## 1. 기준

| 항목 | 기준 |
|---|---|
| 시간 단위 | **현실 초 (1배속)**. 오프라인 진행도 같은 공식으로 요약 계산 |
| 기후 기준 | 온대 = 배율 1.0. 다른 기후는 분야별 배율을 곱함 (5장) |
| 건설 자재 | **판자 + 돌** 두 가지로 통일 (후반 건물만 예외 검토) |
| 화폐 용어 | **주화** = 병 안 부락의 화폐 (조폐소 생산, 시장·교역용) / **지폐** = 플레이어가 주민 판매로 얻는 재화. 서로 다르다 |

## 2. 건물이 지어지고 돌아가는 과정

```
 ① 터 지정 (플레이어)  ──▶  ② 도로 연결 (플레이어)
          │
          ▼
 ③ 짐꾼이 판자·돌을 날라옴  ──▶  ④ 건축공이 시공 (건설 시간)
          │
          ▼
 ⑤ 근무자 배정 ── 도구가 있는 빈 주민이 자동으로 들어감 (도구 없으면 '구인 중' 깃발)
          │
          ▼
 ⑥ 생산 사이클 ── 투입 재화가 도착하면 1회 생산 → 산출물을 건물 앞에 내놓음
          │
          ▼
 ⑦ 짐꾼이 산출물을 다음 건물 / 창고로 운반
```

- **근무자는 플레이어가 고르지 않는다.** 빈 주민 중 해당 직업 숙련도·특징이 맞는 사람이 우선 배정된다 (특징: [`traits_v1.xlsx`](traits_v1.xlsx)).
- **도구가 직업을 만든다.** 근무자가 들어갈 때 창고의 도구 1개를 가져간다. 도구 11종 (도끼·삽·톱·곡괭이·낫·밀대·낚싯대·활·양털가위·칼·망치).
- **병목이 눈에 보인다.** 투입 재화가 없으면 근무자가 건물 앞에서 기다리고(말풍선), 산출물이 안 빠지면 건물 앞에 쌓인다.
- 생산 속도 = 레시피 기본 시간 × 기후 배율 × 근무자 숙련도·특징 보정 × 행복·건강 보정.

- **설계 의도: 기본 비율이 깔끔하게 떨어지도록.**
  - 빵: **농장 2 : 방앗간 1 : 빵집 1 : 우물 1** → 빵 2개/분
  - 판자: **나무꾼 2 : 제재소 1 (+ 산림관 2)** → 판자 2개/분
  - 철: **철광산 1 + 석탄광산 1 → 제련소 1**, 광부 2명이 빵 2개/분을 먹음 → 빵 체인 1세트가 철 1개/분을 받친다
- 자원 고갈: 나무(산림관이 다시 심음), 물고기·동물(개체수가 줄면 느려짐 → 쉬게 두면 회복), 광맥(창조 단계에서 정해진 매장량, 고갈 시 새 광맥 탐사).

| 목표 | 필요 건물 수 |

| 판자 2개/분 | 5 |

| 도구 0.5개/분 | 15 |

- 엑셀 '체인 계산기' 시트에서 목표량·기후대를 바꾸면 바로 다시 계산된다.
- 체인마다 따로 올림하므로 합계는 넉넉하게 나온다 (실제로는 같은 종류 건물을 여러 체인이 함께 쓸 수 있음).

### 4.3 초기 도구 수급 (중요)
대장간은 '마을' 시대에 열리지만, 철을 만드는 광산·제련소는 '읍내' 시대에 열린다. 그 사이 도구가 끊기지 않게:
- **시작 창고**: 첫 정착민이 도구 11종을 2개씩 들고 온다.
- **마을 시대 철 공급원**: 외부 아이템 (예: *녹슨 못 한 줌* = 철 10), 폐허 발굴의 철 덩어리, 거인의 다리로 이어진 내 다른 병과의 교역. (닫힌 세계 — 바깥 상인은 없다)
- 읍내 시대부터 광산·제련소로 자급한다 → **"철을 자급하는 순간"이 경제의 첫 큰 고비이자 성취.**

## 6. 건물 효과 & 입지

| 효과 | 건물 |
|---|---|
| 반경 행복 ↑ | 빵집(+3, 빵 냄새), 술집, 교회, 광장 |
| 반경 행복 ↓ | 도축장(-2), 제련소(-2, 연기), 묘지(-1) |
| 반경 건강 ↑ | 치료소(질병 회복·전염↓), 목욕탕 |
| 화재 진압 | 우물 (반경) |
| 국경 | 망루(소), 초소(중), 성(대) |
| 특수 | 나루터 = 주민 판매 시 거인의 종이배가 뜨는 곳 / 교회 = 결혼식 / 광장 = 축제 |

- 입지 조건: 어부 오두막 = 물가, 광산 = 해당 광맥 위, 방앗간 = 풍차형(언덕) / 물레방아형(강가), 나무꾼·사냥꾼 = 숲 근처.
- 이사 시 건물은 **부서지지 않고** 그대로 옮겨진다 (기획서 8.1).

## 7. 주민 기본 소비 (안)

| 항목 | 간격 | 비고 |
|---|---|---|
| 식량 | 주민 1명당 **15분**마다 1개 (밸런스 v1에서 10분 → 15분으로 완화) | 빵·생선·고기 아무거나. 다양할수록 행복↑ |
| 땔감 | 집 1채당 10분마다 통나무 1개 (겨울만) | 석조 주택 ×0.5 |
| 옷 | 성인 1명당 4시간마다 1벌 | 추운 기후 ×2 |
| 도구 | 근무자 1명당 6시간마다 1개 | 낡으면 교체 |
| 맥주 | 성인 1명당 1시간마다 1개 | 선택 욕구 (행복) |

- 예시: **인구 40명** → 식량 약 2.7개/분 = 빵집 1.3개분, 집 9채, 가용 근무자 약 22명.

4. 도구 소비 속도와 대장간 수
