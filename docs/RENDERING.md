# 나의 작은 지구 — 렌더링 명세: 3D를 도트처럼 (v1)

> 기획서 [16장 아트](GAME_DESIGN.md)·[18장 기술](GAME_DESIGN.md)의 상세. 그림체 기준: [`design/concept/style-test/`](../design/concept/style-test/) (`mid_scene`, `mid_jar`, `mid_variety`, `mid_family`).
> **세계는 진짜 3D다. 화면에는 90년대 PC 전략 게임의 도트 그림처럼 보인다.** (엔진: Godot 4)

---

## 1. 왜 "3D를 도트처럼"인가

| 필요한 것 | 2D 도트로 그리면 | 3D를 도트처럼 렌더하면 |
|---|---|---|
| 병 돌리기 (90°) | 4방향 그림을 전부 따로 그려야 함 | 카메라·병만 돌리면 됨 |
| 지형 높낮이·흐르는 물·마르는 호수 | 매번 타일을 새로 그려야 함 | 높이 지도·물 높이를 그대로 그림 |
| 땅속 단면 (병 시점) | 따로 그림 | 같은 지형을 자른 단면 |
| 병 시점 ↔ 지구 시점 확대 | 크기별 그림 | 같은 장면을 카메라만 옮김 |
| 주민 부품 조합 (머리·옷·모자·소품…) | 조합마다 걷기·일하기 프레임을 다 그려야 함 | 부품 모델을 갈아 끼우기만 하면 모든 동작에 적용 |
| 모바일 배터리 | — | **낮은 해상도로 그리므로 가볍다** |

→ 도트의 정감은 지키고, 이 게임에 필요한 **살아 움직이는 세계**는 3D가 맡는다.

## 2. 핵심 기법

### 2.1 낮은 해상도로 그려서 크게 키우기
- 장면을 **작은 화면(렌더 텍스처)**에 그린 뒤, **가장 가까운 픽셀 방식(nearest)**으로 정수배 확대한다 → 픽셀이 또렷한 네모로 보인다.
- 기준 해상도 (세로 휴대폰, 안):
  | 기기 화면 | 내부 해상도 | 배율 |
  |---|---|---|
  | 1080×1920 급 | 360×640 | ×3 |
  | 1440×2560 급 | 360×640 | ×4 |
  | 태블릿 | 480×640 등 | 정수배가 맞는 값 |
- 배율이 정수가 아니면 픽셀 크기가 들쭉날쭉해진다 → **항상 정수배**, 남는 가장자리는 테두리·UI로 채운다.

### 2.2 카메라
- **정사영(직교) 카메라**, 아이소메트릭에 가까운 고정 각도 (내려다보는 각 약 30°, 방위 45° 단위).
- **방위 회전은 90° 단위** = 병 돌리기와 같은 단위 → 돌리는 순간 짧은 회전 연출(0.4초) 뒤 정위치에 딱 멈춘다. 회전 중엔 픽셀이 흔들려도 괜찮고, 멈추면 다시 또렷해진다.
- **확대는 단계로**: 병 시점(병 전체) / 지구 시점 원경 / 근경 / 주민 따라가기. 단계마다 '픽셀 하나 = 세계 몇 칸'이 정수배가 되도록 정한다. 단계 사이 전환은 짧은 픽셀 디졸브.
- **화면 이동(팬) 떨림 방지**: 카메라 위치를 픽셀 격자에 맞춰 반올림하고, 남는 소수점만큼 최종 확대 단계에서 화면을 밀어 준다 → 움직여도 픽셀이 반짝이지 않는다.

### 2.3 색
- **제한된 색표(팔레트) 64색 — 확정** (기획서 v3.5): 기준 그림 4장에서 k-평균으로 추출 → [`design/palette/`](../design/palette/) (`palette.json`, 색표 `palette.png`, 그래픽 툴용 `palette.gpl`). 흙·나무·피부·지붕 17 / 돌·그림자 13 / 풀·숲 13 / 초가·밀 10 / 물·하늘 9 (+ 하이라이트 #fffbea·가장 어두운 색 #1e1f2a). 48색 1차안보다 피부·옷 색과 물·하늘 단계가 넉넉하다. 다시 뽑기: `python3 tools/extract_palette.py`
- 3D 조명 결과를 마지막에 **팔레트 색으로 맞춘다** (색 지도 LUT). 계절·밤에는 팔레트를 바꿔 끼운다 (겨울 = 푸른 기운, 밤 = 남색, 노을 = 주황).
- **평평한 조명**: 빛은 창가 한쪽에서만, 그림자는 2~3단계(밝음·중간·그늘)로 끊는다. 부드러운 그라데이션 대신 **디더링 점무늬**로 단계 사이를 잇는다.

### 2.4 외곽선
- 화면 공간에서 깊이·면 방향이 갑자기 바뀌는 곳에 **1픽셀 어두운 선**을 넣는다 (건물·나무·주민). 땅의 등고선은 선 대신 색 단계로.
- 외곽선 색은 검정이 아니라 **그 물체 색의 어두운 버전** (기준 그림처럼 부드럽게).

### 2.5 모델과 텍스처
- **로우폴리 + 작은 텍스처**: 텍스처 해상도는 화면 픽셀과 맞춘다 (세계 1칸 ≈ 화면 8~12픽셀 기준으로 텍스처도 같은 밀도). 텍스처 필터링은 끈다 (nearest).
- 건물: 초가지붕·돌벽·나무 판자는 텍스처 위에 손으로 찍은 듯한 픽셀 무늬.
- 나무: 줄기 모델 + 잎은 **도트 그림 카드(빌보드)** 몇 장 → 돌려도 도트 나무처럼 보인다.

### 2.6 주민 (약 4등신)
- 키 약 **16~20 화면 픽셀** (지구 시점 기본 확대). 머리가 몸의 약 1/4.
- **부품 조합 3D 모델**: 체형(3) × 머리 모양(8) × 머리색(8) × 피부(4) × 수염(5) × 모자(10) × 옷(12) × 옷 색(팔레트) × 소품(12) → 겹치지 않는 사람이 충분하다.
  - 머리색·체형·코는 부모에게서 물려받음 (기획서 7.1).
  - 특징 일부는 소품으로 보인다: 어깨 위 고양이, 조약돌 주머니, 늘 든 피리.
- **동작**: 걷기·나르기·도끼질·곡괭이·낫질·두드리기·앉기·기도·춤·손 흔들기·숨기. 동작은 **낮은 프레임(초당 8~12장)**으로 끊어서 재생 → 도트 애니메이션 느낌.
- 멀리서는 실루엣·머리색·모자·옷 색으로, 가까이서는 얼굴·수염까지 구분된다.

### 2.7 물
- 호수·강은 **물 높이 지도**(시뮬레이션의 물 깊이)를 그대로 면으로 그린다 → 호수가 줄면 물가가 실제로 물러난다.
- 수면: 팔레트 파랑 2~3단계 + 픽셀 반짝임 몇 점. 물결은 4프레임 반복 무늬.
- **물방울 돌기**: 뚜껑에 매달린 도트 물방울이 늘어지다 떨어짐(6프레임) → 수면에 동심원 링 3픽셀 두께.
- **유리벽의 물줄기**: 벽 안쪽 면에 세로 픽셀 줄 + 흘러내리는 물방울 점.
- **소금 들판**: 흰색·연회색 디더링. 땅속 단면의 **암염층**도 같은 흰색 계열 띠.

### 2.8 유리
- 실제 굴절 계산 대신 **단순한 형태**로: 유리 테두리 하이라이트(밝은 픽셀 줄 2개), 김 서림은 **성긴 점무늬**(습도에 따라 밀도), 물방울 몇 개.
- 지구 시점에서 하늘 돔은 옅은 곡선 하이라이트 1~2줄, 세상 끝 유리벽은 빛나는 픽셀 띠.

## 3. 두 시점의 연출

| 시점 | 화면 |
|---|---|
| **병 시점** | 선반 위 세로 병 하나 (기준: `mid_jar`). 병 안 3D 세계를 축소해 그대로 보여줌 + 옆면은 **지형을 자른 단면**(흙·암반·광맥·암염·핵·광부의 굴). 방(선반·창가)은 도트 배경 그림 |
| **지구 시점** | 아이소메트릭 마을 (기준: `mid_scene`). 하늘엔 돔 하이라이트, 끝엔 유리벽 |
| 전환 | 두 손가락으로 벌리면 카메라가 병 속으로 들어가며 픽셀 디졸브 → 확대 단계 변경 |

## 4. UI

- **도트 글꼴 — 갈무리(Galmuri) 확정**: SIL 오픈 폰트 라이선스 1.1 (상업 이용·게임 포함 가능, 글꼴 파일 단독 판매만 금지). [`design/fonts/`](../design/fonts/)에 Galmuri11(본문)·Galmuri11 Bold(제목)·Galmuri9(작은 글자)와 라이선스 파일. 크기는 11·22픽셀(정수배) 위주.
- 창·버튼은 **나무 판자·양피지 질감의 9칸 늘리기 테두리**. 그림자 대신 1픽셀 테두리.
- UI도 정수배로 확대 (게임 화면과 같은 배율이거나 그 절반).
- 연대기는 양피지 + 손글씨 대신 **도트 필기체** 느낌.
- UI 시안([UI.md](UI.md))은 이 기준으로 다시 그린다 (현재 시안은 일러스트 톤).

## 5. 성능 (모바일)

- 내부 해상도가 작아서 **채우는 픽셀 수가 1/9~1/16** → 저사양에서도 30~60fps 목표.
- 주민 수백 명: 같은 부품끼리 묶어 한꺼번에 그리기(인스턴싱), 멀리 있는 주민은 더 단순한 모델.
- 물·소금 지도는 64×64(소형 병)~200×200(수조) 텍스처 → 매 프레임 그대로 올려도 가볍다.
- 그림자는 실시간 그림자 대신 **도트 원형 그림자**(물체 밑 어두운 타원).

## 6. 엔진 — Godot 4

- **Godot 4 (GDScript).** 필요한 기능이 기본으로 있다: `SubViewport`(낮은 해상도 렌더) + 정수배 확대, 정사영 `Camera3D`, 화면 셰이더(팔레트 맞추기·외곽선·디더링), 텍스처 Nearest 필터.
- 렌더러: **Mobile** (Godot 4.7.2). 오래된 기기용 Compatibility에서도 같게 보이도록 셰이더는 단순하게.
- 3D 모델 제작: Blender 또는 Blockbench → glTF(.glb)로 가져오기.
- 시작 안내: [GODOT_KICKOFF.md](GODOT_KICKOFF.md)
