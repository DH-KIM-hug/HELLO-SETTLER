# 나의 작은 지구 — 렌더링 명세 v2.1: 로우폴리 3D를 셀 채색 일러스트처럼

> 기획서 [16장 아트](GAME_DESIGN.md)·[18장 기술](GAME_DESIGN.md)의 상세. **v3.7에서 레트로 도트(v1) → 셀 채색 일러스트로 바꿈.**
> 그림체 기준: [`design/concept/style-test/flat2_map_a.png`](../design/concept/style-test/flat2_map_a.png), [`flat2_map_b.png`](../design/concept/style-test/flat2_map_b.png) (사용자가 고른 2차 시험).
> **세계는 진짜 3D다 (Blender로 만든 로우폴리 모델 → Godot). 화면은 위에서 내려다본 손그림 지도처럼 — 깔끔한 선, 큰 평면 색, 그늘 한 단계.** (엔진: Godot 4.7.2, Mobile 렌더러)
> v2.1 (2026-11-07): 카메라 각 48° 확정, 하늘·지평선을 GIANT_ROOM 4(끊김 없는 확대)와 맞춤.

---

## 1. 왜 3D인가 (v1과 같음)
등불 옮기기(빛 방향), 지형 높낮이·흐르는 물·마르는 호수, 땅속 단면, 병 시점 ↔ 지구 시점 확대, 주민 부품 조합 — 모두 2D로 그리면 그림이 끝없이 늘어난다. 3D 모델을 **셀 채색(툰) 셰이딩**으로 그리면 손그림 느낌을 지키면서 세계가 살아 움직인다.

## 2. 핵심 기법

### 2.1 해상도
- **기기 해상도 그대로** 그린다 (도트용 낮은 해상도·정수배 확대는 쓰지 않음). 저사양 기기는 3D 해상도 배율 0.75까지 낮추고 UI는 원래 해상도.
- 안티에일리어싱: MSAA 2× 또는 FXAA (선이 깨끗해야 한다). 기기별로 측정 후 결정.

### 2.2 카메라
- **정사영 카메라**, 내려다보는 각 **48°** (`godot/view/jar_camera.gd` `PITCH_DEG`). 처음 60°로 시작했다가 낮췄다 — 기준 그림(flat2_map_a는 약 45°)처럼 집의 지붕과 앞벽, 나무 줄기가 함께 보이면서도 지도 시점. 방위 45°.
- 카메라 방위는 90° 단위로 돌릴 수 있지만 **세상을 돌리는 행동은 없다** — 빛 방향은 등불 옮기기(GD 4.6)로 바뀐다.
- 확대는 부드럽게 (두 손가락), 단계 제한만 둔다: 병 시점 / 지구 시점 원경~근경 / 주민 따라가기.
- **하늘·지평선은 그리지 않는다.** 기본 확대(GIANT_ROOM 4의 ①②)에서는 바라보는 점을 땅 안쪽으로 묶어 화면 전체가 땅이다.
- 세상 끝 가까이 가거나 ③ '세상 전체'까지 오므리면 **유리벽**(3D 유리 — 폭포 띠·하이라이트, 2.8)이 보이고, 유리 **너머로는 하늘 대신 거인의 방**(창빛·벽, 흐릿하게 굴절)이 비친다. 주민이 믿는 '유리 돔 하늘'은 이 유리다 (GD 3.2).
- 더 오므리면 끊김 없이 ④ 유리병 → ⑤ 거인의 방으로 빠져나간다 (같은 3D 장면, 카메라만 움직임 — GIANT_ROOM 4). 방은 M2(ROADMAP B1) 전까지는 미리보기만.

### 2.3 색과 빛
- **색 기준**: 차분한 민트·세이지·청록 초록, 밝은 연두 풀밭, 옅은 하늘색 물. 따뜻한 색은 초가·나무·흙길·버섯·연꽃 정도로 아껴 쓴다. 채도 높은 노란 초록·형광색 없음.
- **셀 셰이딩**: 빛은 창가 한쪽에서만. 밝은 면 + **그늘 한 단계**로 끊는다 (경계는 또렷하게, 그라데이션 없음). 그늘 색은 검정을 섞지 말고 **청록 쪽으로 어둡게**.
- **그림자**: 나무·집·주민이 땅에 **평면 그림자**(짙은 청록, 한 방향)를 드리운다. 실시간 그림자 맵을 쓰되 결과는 한 단계 색으로 (부드러운 그림자 없음).
- 밤·계절·노을: 전체 색 조정(LUT)으로 바꾼다 (밤 = 남색, 겨울 = 푸른 기운, 노을 = 주황).
- 팔레트 강제 맞추기·디더링은 **쓰지 않는다** (v1의 64색 `design/palette/`는 참고용으로만 남김).

### 2.4 외곽선
- 물체 둘레에 **고른 두께의 얇은 선** (1080p 기준 약 2px). 색은 검정이 아니라 **그 물체 색의 짙은 버전** (풀·나무 = 짙은 청록, 집·흙 = 짙은 갈색).
- 방법: 깊이 차이 화면 셰이더 + 필요하면 물체별 뒤집은 껍데기(inverted hull). 땅의 높낮이는 선 대신 색 단계와 작은 둔덕 테두리로.

### 2.5 모델과 텍스처
- **로우폴리 + 평면 색**. 텍스처는 최소 (색 지도 정도), 무늬는 모델 모양과 셀 셰이딩으로 낸다.
- 나무: 둥근 덩어리 잎(2톤: 밝은 위쪽·짙은 아래쪽) + 줄기. 위에서 볼 때 동그란 수관이 겹친 모양.
- 땅 위 소품을 **무리로**: 버섯 무리, 이끼 낀 돌 무리, 고사리, 그루터기, 클로버·풀 포기. 사이사이엔 **빈 풀밭을 넓게** 남긴다.

### 2.6 주민 (약 4등신 (2026-11-07 사용자 확정, 지금 모델 3등신 → 다시 만듦 A23))
- 기본 확대에서 **나무 수관 폭의 약 1/6** 크기 (작다). 멀리서는 모자·옷 색·실루엣으로 구분.
- **부품 조합 3D 모델**: 체형 × 머리 모양 × 머리색 × 피부 × 수염 × 모자 × 옷 × 옷 색 × 소품 (기획서 7.1). 셀 셰이딩 + 외곽선.
- 동작은 부드러운 애니메이션 (도트용 초당 8~12장 끊기는 쓰지 않음).

### 2.7 물
- 호수·강은 시뮬레이션의 **물 깊이 지도**를 그대로 면으로 → 호수가 줄면 물가가 물러난다.
- 수면: 옅은 하늘색 + **큰 흰 물결 무늬**(평면 모양, 천천히 흐름). 물가는 한 단계 진한 띠.
- 물방울: 뚜껑에서 떨어져 수면에 **동심원**. 유리벽 물줄기는 가장자리에서 흰 물보라와 함께 시냇물로.
- 소금 들판: 흰색·연회색 평면 + 갈라진 선.

### 2.8 유리
- 지구 시점: 세상 끝의 **3D 유리벽** — 옅은 곡선 + 흰 하이라이트 1~2줄, 벽을 타는 폭포 (GD 4.2). 유리 너머로 거인의 방이 흐릿하게.
- 병 시점: 병 윤곽선, 하이라이트 줄, 김 서림은 흰 점 몇 개.

## 3. 두 시점
| 시점 | 화면 |
|---|---|
| **병 시점** | 선반 위 병 (기준: `style-test/flat_1-1_a.png`의 구성, 그림체는 flat2). 옆면은 지형 단면(흙·암반·광맥·암염·핵·광부의 굴) |
| **지구 시점** | 위에서 내려다본 마을 지도 (기준: `flat2_map_a/b`) |

## 4. UI
- 그림체에 맞춰 **다시 그린다** (갈무리 도트 글꼴·도트 UI 시안 `design/ui-v2/`는 v1 기준 — 쓰지 않음). 글꼴은 UI.md v3: **나눔스퀘어라운드**(본문·버튼) · **주아**(제목) · **나눔손글씨 펜**(편지·연대기·자막). UI 그림체는 열린 질문 (GD 22).

## 5. 성능 (모바일)
- 목표 30~60fps. 주민 수백 명: 부품별 인스턴싱, 멀리 있는 주민은 단순 모델.
- 그림자 맵 해상도·외곽선 방식은 기기 측정 후 결정.

## 6. Godot
- Mobile 렌더러. 셀 셰이딩은 `ShaderMaterial`의 `light()` 함수(단계 끊기) 또는 공용 툰 셰이더 하나로 통일.
- 외곽선은 `godot/render/outline_post.gdshader` (깊이 차이) + `hull.gdshader` (뒤집은 껍데기). 1단계의 도트용 `pixel_post`는 시험 장면에만 남아 있다 (팔레트·디더링 폐지).

## 확대 단계 고정 + 2D 그림 방향 (2026-11-08 밤 사용자)
- 사용자: "세틀러 2만도 못하면 어떡하냐 … 그럼 다 갈아엎고 그냥 2D로 할까? 세틀러처럼?" → 메인 제안: **섞어서** — 화면에 보이는 것(주민·강아지·나르는 물건·건물·소품)은 그림책 2D 그림, 땅·물·빛·거인의 방은 3D (등불 그림자는 보이지 않는 3D 대역이 드리움). 사용자: "확대 단계는 설정하긴 해야지."
- **확대 단계** (손을 떼면 가장 가까운 단계에 멈춤, 사이는 오갈 때만): ① 거인의 방(3D) ② 세상 지도(병 안 전체, 마을은 작은 표시) ③ **마을 기본**(마을 하나가 화면에 꽉, 약 ppu 16~24) ④ **마을 가까이**(주민 몇·건물 하나, 약 ppu 40~48). 2D 그림은 ③·④ 두 크기에서 또렷하게 맞춘다. ①→② 병 안 들어가기는 지금처럼 끊김 없이.
- 다음: 시험판 — 오두막·빵집·벌목장을 2D 그림으로 ③·④에서 지금 모습과 나란히 비교 → 사용자가 2D로 갈지 정함.
- '보이는 경제' 목표 (세틀러 2 수준): 물건마다 또렷한 소품 · 직업마다 일하는 동작과 건물 앞 작업 · 건물 앞 쌓인 재료·결과물 · 짓는 단계와 재료 도착 · 멈춘 건물 표시.
