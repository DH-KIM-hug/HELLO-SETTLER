# 나의 작은 지구 — 기획서 변경 이력

> v3.0에서 기획서를 처음부터 다시 정리했다. 그 전까지 대화하며 덧붙인 변경 기록은 아래와 같다.

| 버전 | 내용 |
|---|---|
| **v3.2** | **아트 방향 변경** — 3D 로우폴리 틸트시프트 디오라마 → **90년대 PC 전략 게임풍 레트로** (아이소메트릭, 픽셀 느낌, 평평한 조명; 3D 모델을 저해상도로 렌더). 주민 외형 사실적 비율 → **약 4등신** (마스코트 아님). 주민 생김새는 **부품 조합**(체형·머리·색·수염·모자·옷·소품), 가문 유전, 일부 고유 특징이 겉모습에 드러남 |
| v3.1 | 발견 목록 25종 (DISCOVERIES.md), 기획서 8.5 갱신 |
| **v3.0** | **기획서 전면 정리** — 확정 내용만 남기고 구조를 다시 짬 (세계 → 자연 → 창조 → 거인 → 주민 → 경제 순). 옛 설정(바다·자연 비·병 기울이기 등) 삭제, 중복 정리. 변경 이력은 이 파일로 분리 |
| v0.1 | 초안 — '실패 없는 힐링' 컨셉 |
| v0.2 | 방향 전환 — 진짜 인간 / 중세 문명 / 죽음 있음 / 주민 거래 / 외부 아이템 구매·배치 / 전쟁(후반) / 제목 확정: *나의 작은 지구* / 3D / Unity |
| v0.3 | 테라리움 창조(핵 넣기 → 기후대 선택) 오프닝 추가 / 출산 필수 / 주민은 거래로만 / 멸망 허용 / 부활 없음 / PvP 패배 = 병사 사망 + 부락 자원 약탈 |
| v0.4 | 다른 부락과의 관계 확장 — 부락 생성 경로, 관계 단계, 교역·상인·시장, 외교, 전쟁은 그중 하나로 재배치 |
| v0.5 | 주민 판매 = 시스템에 팔아 게임 재화 획득 (플레이어 간 주민 거래 삭제) / 병 안 다른 부락 직접 운영 가능 / 상단 약탈 없음 |
| v0.6 | 이웃 병과의 전쟁 삭제 — 이웃 병은 교역·외교 상대로만. 전쟁은 병 안 부락 간 + 플레이어 간(PvP) 2단계 |
| v0.7 | 더 큰 병으로 이사 = 주민을 팔아 번 게임 재화로만 가능 (유료 재화·현금 불가) |
| v0.8 | 유니크 주민(희귀 출생) — 비싸게 팔림 / 이사 때 건물·나무도 옮기기 (나무는 시들 수 있음) / 옛 병은 계속 직접 운영 가능 (여러 병 동시 운영) / 병 가격·판매가는 검토 중 |
| v0.9 | 모든 아이는 저마다 특별함 (고유 특징) / 서버 1명 규칙 삭제 / 나무 생존율은 기후 차이로 결정, 시들 나무는 바로 땔감 / 건물 파손 없음 / 기후가 다른 병으로 가면 주민이 힘들어함 (적응 시스템) |
| v1.0 | 고유 특징 1,000종 이상 확정 + 제작 방식 / 나무 생존율·기후 적응 수치 확정 |
| v1.1 | 핵은 크기만 (종류 없음)** / 기후대 점진 해금 / 한 병 = 한 기후대 / 폐허 구경·발굴 / 직접 운영 부락 상한 없음 / 약탈 수치는 보류 |
| v1.2 | 플레이어 재화 이름 = 지폐(부락 화폐 = 주화) / 건물·생산 명세 / **밸런스 v1 반영**: 병 가격 1,500 / 8,000 / 25,000, 일일 판매 상한 단계별 3·5·8·12명, 첫 정착민 10명, 식량 소비 15분 |
| v1.3 | 닫힌 세계 원칙 — 유랑민 삭제. 인구는 출생·분가(거인이 옮김)로만. 출산율 0.5 → 0.6으로 보정 (이사 16 / 35 / 66일차) |
| v1.4 | 닫힌 세계 정리 — 유랑 상단 → **거인의 종이배** (주민 판매), 병 사이 교역·이주·이사·PvP는 **거인의 다리**로만, 편지 비둘기 삭제 |
| v1.5 | 병 안은 넓은 평평한 지구 — 밖은 세로 병(땅속 단면), 안은 지평선까지 펼쳐진 둥근 대지. 병 시점 ↔ 지구 시점 두 단계 카메라 |
| v1.6 | 하늘 낟알 (만나) — 첫 수확 전까지만 매일 새벽 자동으로 하루치 주곡이 내림. 비축 불가, 첫 수확 다음 날 그침 |
| v1.7 | 주민은 신을 안다 / 테라리움이 세상의 전부 · **오프라인 자율 번성** (자율 건설·출산 계속, 상한 없음) · **문명 발전은 더딤** (시대 점수 30%, 시대 전환은 거인의 계시) · 하늘 낟알 확정 (도착 직후 1회 + 새벽, 첫 수확 4시간) |
| v1.8 | 신앙의 흔들림 (부재 → 아이들의 부정, 귀환 축제, 작은 기적) · **물 뿌리기 = 기적** · **닫힌 병의 자연** (물 순환 비, 세상 끝에서 시작하는 강, 현실 빛의 낮밤·계절, 서리 눈) |
| v1.9 | 병 안의 기후 지도 — 창가 쪽은 늘 따뜻·건조, 그늘 쪽은 서늘·비, 강은 그늘 쪽 유리벽에서 흘러내려 시작. 농사 효율 = 따뜻함 × 습기 |
| v2.0 | 병의 설계가 물길을 정한다 — 뚜껑 물방울 돌기 아래 강 없는 호수, 돌기 없는 곳은 유리벽에서 강 시작 → 습지. 자연 비 삭제. 병 종류별 돌기 배치, 창조 때 돌기 위치 정하기 |
| v2.1 | 햇빛이 강의 운명을 정한다 — 그늘 쪽 강은 멀리 흘러 호수에 닿고, 볕 드는 쪽 강은 말라 습지로. 한낮엔 가늘어지고 밤엔 분다. 태양 방향·커튼으로 물길이 바뀜 |
| v2.2 | 지형의 높낮이 + 살아 있는 물길 — 높이 지도, 물은 낮은 곳으로 흘러 고이면 호수·넘치면 새 강. 바다 없음, 창조 때 바이칼 같은 큰 호수 가능 — 물이 안 들어오면 며칠~몇 주에 걸쳐 증발해 사라지고 물길이 바뀜 |
| v2.3 | 병 돌리기 (빛은 그대로, 병만 돎 → 그늘이 바뀌어 강 물줄기가 달라짐, 물방울 호수 자리는 그대로) · **소금** (증류수엔 없음, 창조 때 물의 광물만 · 물과 함께 흐르고 증발하면 남음 → 소금 들판·소금밭·절임·염해) |
| v2.4 | 소금의 발견 — 호수가 말라 하얀 들판이 드러나면 주민이 맛보고 발견, 그때 소금밭이 열림. '세상의 변화가 새 지식을 연다' 원칙 |
| v2.5 | 소금의 근원 = 암염 — 창조 2단계에서 하얀 돌(암염)을 넣음. 물이 닿으면 녹아 흐르고, 물길이 끝나는 호수가 짜짐. 암염 없는 병엔 소금 없음 |
