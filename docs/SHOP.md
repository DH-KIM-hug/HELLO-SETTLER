# 나의 작은 지구 — 거인의 상점 (v1)

> 기획서 [9장](GAME_DESIGN.md), 효과는 [WORLD_EVENTS.md](WORLD_EVENTS.md) 4장, 값의 눈높이는 [BALANCE.md](BALANCE.md) v4 (보통 마을 하루 수입: 3일 ~370 · 7일 ~500 · 14일 ~630 · 21일 ~1,400 지폐). UI 06.
> 원칙: **크기 차이가 재미다.** 카드마다 '거인에게는 / 병 안에서는' 두 줄. 거인의 방에 굴러다니는 작은 물건이 기적이 된다. 모든 물건은 **뚜껑을 열어** 넣는다 (병의 법칙).

## 1. 진열 (탭)

| 탭 | 무엇 | 언제 열리나 |
|---|---|---|
| **건물** | 완성된 건물을 하늘에서 내려 주기 (이 병에 하나) | 1일차 (튜토리얼 T4: 우물) |
| **먹을 것·재료** | 빵 부스러기·쌀 한 톨·각설탕·밀 이삭·나무젓가락·자갈·녹슨 못 | 1일차: 빵 부스러기만 → 2일차 전부 (녹슨 못은 철기) |
| **돌봄** | 알약 부스러기·소독약 한 방울·반창고 조각·마른 약초·소금 한 꼬집·성냥개비·털실·이끼 | 첫 병자·첫 위기 조짐이 생긴 날 |
| **땅** | 영양제 앰플 (색별은 나중) | 첫 수확 다음 날 |
| **생물** | 작은 양 한 쌍·작은 닭 다섯·작은 당나귀 (병의 생물 — 작은 종 알·새끼) | '마을' 시대 |
| **이주민** | 뽑기 (11.2) | 2일차 |
| **꾸미기** | 병 받침·조약돌·유리 빛깔·코르크 무늬 | 3일차 |

- 처음엔 탭이 1~2개만 보이고, 하나씩 **열리는 순간이 작은 사건** (*"상점에 새 물건이 들어왔어요"* — 연대기·알림 아님, 상점 버튼 옆 작은 반짝임; 빨간 점 금지 원칙 유지).
- 키트 업그레이드(새 병마다 영구)는 상점이 아니라 **선반 화면**에서 판다 (5.5, BALANCE v3-4).

## 2. 물건 목록 (값은 안, 지폐)

### 2.1 건물 — 사 주기 (이 병에 하나, 즉시 완공)
| 건물 | 값 | 비고 |
|---|---|---|
| 우물 | 600 | 튜토리얼 T4. 첫 제물 웃돈 600으로 1일차에 살 수 있음 |
| 창고 | 800 | |
| 농장 · 나무꾼 · 채석장 | 1,000 | |
| 어부 | 1,500 | 물가에만 |
| 제재소 | 2,500 | 마을 시대 |
| 방앗간 · 빵집 | 4,000 | 마을 시대 |
| 목조주택 | 6,000 | 마을 시대 |
- 값 = BALANCE v3-4 업그레이드 값과 같은 눈높이. 같은 건물을 또 사면 ×1.5 (주민이 지을 몫을 남기려고).
- 주민 반응: *"하늘에서 방앗간이 내려왔다!"* 믿음↑. 소원 편지로 바란 건물을 사 주면 믿음 ×2.

### 2.2 먹을 것·재료 ('바깥 크기' — 주민에게는 산더미)
| 물건 | 거인에게는 | 병 안에서는 | 효과 | 값 |
|---|---|---|---|---|
| 빵 부스러기 | 손톱만 한 부스러기 | 갈색 바위 | 식량 반나절치 (마을 크기 비례) | 100 |
| 쌀 한 톨 | 한 톨 | 하얀 통나무만 한 낟알 | 식량 하루치 | 150 |
| 각설탕 | 한 조각 | 하얀 돌집 | 식량 1주일치를 천천히 깎아 먹음 (보이게 작아짐). 습한 병엔 곰팡이↑ | 500 |
| 밀 이삭 한 줄기 | 이삭 하나 | 쓰러진 황금 나무, 낟알 = 자루 | 식량 약 4일치 + 밀가루 재료 | 400 |
| 나무젓가락 | 한 짝 | 거대한 통나무 | 통나무 80 (켜서 판자로) | 450 |
| 자갈 한 알 | 한 알 | 바위산 | 돌 40 | 300 |
| 녹슨 못 | 못 하나 | 붉은 쇠기둥 | 철 20 (철기 시대) | 700 |

### 2.3 돌봄 (WORLD_EVENTS 4.1)
알약 부스러기 900 · 소독약 한 방울 700 · 반창고 조각 300 · 마른 약초 한 잎 400 · 소금 한 꼬집 450 · 성냥개비 400 · 털실 한 가닥 600 · 이끼 한 줌 350.

### 2.4 땅
영양제 앰플 1,500 (WORLD_EVENTS 4.4 — 하늘에서 꽂힌 탑, 7일 비옥, 숭배, 녹조 대가). 한 병에 동시에 2개까지.

### 2.5 생물 (병의 생물 — 작은 종)
| 물건 | 효과 | 값 |
|---|---|---|
| 작은 강아지 한 쌍 | 사냥↑, 늑대·곰팡이에 짖음, 아이들 친구 | 600 |
| 작은 돼지 한 쌍 | 양돈장 → 고기 | 900 |
| 작은 양 한 쌍 | 목장 → 양털·고기 | 800 |
| 작은 소 한 쌍 | 우유·밭 갈기·수레 | 1,800 |
| 작은 닭 다섯 | 달걀 (식량 다양성 → 행복) | 500 |
| 작은 당나귀 | 짐 나르기 ×1.3 (먼 곳 일터) | 1,000 |
- 모두 **이미 가축이 된 종** — 주민이 병 안 야생종(늑대·멧돼지·들양·들소)을 스스로 길들이는 긴 길의 지름길 (WILDLIFE.md 7장). 그 가축이 쓰이는 시대가 열려야 살 수 있다.
- 진짜 크기의 동물은 팔지 않는다 (병의 법칙: 바깥 생물은 거대 → 괴물이 됨).

### 2.6 이주민 (기획서 11.2)
그날 첫 300, 같은 날 ×1.5씩, 하루 5번. 등급 확률 공개. 거인의 손이 마을 어귀에 내려놓는다. (밖에서 온 병 위험 — WORLD_EVENTS 5장.)

### 2.7 꾸미기 (효과 작게)
병 받침 800 (흔들림↓) · 조약돌 200 (광장 장식, 행복+) · 유리 빛깔 1,200 (빛 색이 바뀜 — 순수 꾸미기) · 코르크 무늬 600.

## 3. 사고 넣기 — 손의 흐름
1. 상점에서 사면 물건이 **거인의 손**에 들린다 (화면 아래 '손' 칸에 쌓임, 최대 5개).
2. 병 시점으로 돌아가면 **뚜껑이 열리고** (뚜껑 열기 1번 — 날벌레·온기 규칙 적용), 손에 든 물건을 하나씩 끌어 원하는 자리에 놓는다. **여러 개를 한 번 열 때 넣는 것이 이득** (뚜껑을 덜 엶).
3. 떨어질 자리에 **그림자 미리보기** — 집·사람 위면 붉게 (*"여기 떨어뜨리면 집이 부서져요"*). 그래도 놓으면 부서짐 (기획서 9장).
4. 건물·앰플은 자리를 고르면 하늘에서 천천히 내려옴. 먹을 것·재료는 '바깥 크기'로 떨어져 주민이 몰려와 깎고 나른다 (시간이 지나며 작아지는 게 보임).
5. 놓지 않고 상점을 닫으면 손에 그대로 (저장됨). 환불 없음.

## 4. 화면 (UI 06)
- 시트. 위에 지폐, 탭 줄, 카드 2열.
- 카드: 물건 그림 (거인 크기 사진풍 아이콘) + 이름 + 두 줄 (*거인에게는: 각설탕 한 조각 / 병 안에서는: 마을 사람들의 일주일 양식*) + 값 버튼. 못 사면 값이 흐리게, 누르면 *"지폐가 n 모자라요"*.
- 숫자는 값에만. 효과는 말로 (*"식량 1주일치"*는 말이므로 허용).
- 주민 말·연대기에 '상점·구매·키트·상자' 금지 → 주민은 *"하늘에서 내려온 것"*으로만 말한다.

## 5. 밸런스 메모
- 첫 주(하루 ~400~500): 하루 수입으로 돌봄 1개 또는 이주민 1~2명 또는 재료 몇 개 — '무엇을 살까' 고민이 생기는 눈높이.
- 앰플 1,500 = 사나흘 벌이 — 큰 결심.
- 두 번째 병 6,000(13일)과 경쟁: 많이 사면 두 번째 병이 늦어진다 → 선택.
