## 1. 한 줄 요약

플레이어는 유리병 바깥의 **거인**이다. 병 안에는 **중세 문명을 이룬 작은 인간들**이 산다.
플레이어는 건물 자리와 길을 정해주고, 바깥 세상에서 물건을 사서 병 안에 넣어줄 수 있다. 하지만 **주민 한 명 한 명은 직접 조종할 수 없다.** 주민들은 스스로 일하고, 먹고, 사랑하고, 늙고, 죽는다. 그리고 병이 붐비면 **다른 부락이 생겨난다.** 그들과 물건을 바꾸고 혼인하며 어울리다가, 어항 속 물고기들처럼 **서로 싸우기도 한다.**

## 2. 디자인 기둥

| 기둥 | 의미 |
|---|---|
| **살아있는 진짜 문명** | 마스코트가 아니라 사람이다. 생산 체인과 경제가 있고, 생로병사가 있다 |
| **구경하는 맛** | 내가 만든 경제가 굴러가며 주민이 물자를 나르는 모습 자체가 보상 |
| **거인의 손** | 바깥에서 하는 작은 행동(물 한 방울, 물건 하나)이 병 안에선 큰 사건 |
| **나만의 지구** | 같은 병은 하나도 없다. 마을의 역사·혈통·전쟁이 그 병만의 이야기가 된다 |
| **분위기는 힐링, 내용은 진짜** | 비주얼·사운드·속도감은 잔잔하고 따뜻하게. 하지만 결과는 가볍지 않다 |

## 3. 시작 — 나의 작은 지구 만들기 (테라리움 창조)

게임은 **빈 유리병 하나**에서 시작한다. 실제 테라리움을 층층이 쌓는 과정을 **지구를 만드는 과정**처럼 연출한다.
> *"핵을 넣어주세요."* — 게임의 첫 대사

각 단계는 붓기·드래그·빚기 같은 손가락 조작이고, 전체 5~10분 분량의 튜토리얼 겸 오프닝이다. **여기서 한 선택은 이후 게임 전체에 영구적으로 영향을 준다.**

### 3.1 창조 단계

| 단계 | 연출 / 조작 | 실제 테라리움 대응 | 게임에 미치는 영향 |
|---|---|---|---|
| 1. **핵 넣기** | 붉게 빛나는 구슬을 병 바닥 중앙에 넣는다. 크기 선택 | (판타지 요소) | 지열·온천·화산 / 광물 풍부도. 크면 광물↑ 대신 화산·지진 위험↑ |
| 2. **암반 쌓기** | 자갈·돌을 종류별로 붓는다 | 배수층 (자갈) | 광맥 배치 (철·석탄·금 비율), 산의 높이 |
| 3. **흙 덮기** | 흙을 붓고 손가락으로 산·평지·골짜기를 빚는다 | 토양층 | 지형, 비옥도 |
| 4. **물 붓기** | 붓는 양과 위치 | 수분 | 바다·호수·강 비율 (육지 : 물) |
| 5. **태양 맞추기** | 병 위 태양의 높이·거리를 조절 → **기후대 결정** | 빛·온도 | 기후대 (3.2) |
| 6. **뚜껑 닫기** | 뚜껑을 닫으면 유리에 김이 서리고 첫 비가 내린다 | 밀폐 | 강수량·습도 |
| 7. **생명의 씨앗** | 이끼·풀·나무 씨앗을 뿌린다 → 타임랩스 | 식물 | 숲·초원 분포, 초기 동물 |
| 8. **첫 인간** | 숲 가장자리에 작은 모닥불이 켜진다. 첫 가족 5명 등장 | — | **본 게임 시작** |

- **창조 타임랩스**: 뚜껑을 닫으면 수천 년이 몇 초 만에 흐른다. 바다가 생기고, 대륙이 굳고, 숲이 퍼진다. 게임의 대표 장면이며, 공유용 영상으로 자동 저장된다.
- 단계마다 **[추천값]** 버튼 제공 (초보자가 막히지 않게).
- 완성된 결과는 **'지구 카드'** 로 남는다: 이름 짓기, 창조 시드 저장, 친구에게 공유.

### 3.2 기후대

| 기후대 | 풍경 | 주요 작물·자원 | 특산품 (교역용) | 주요 위협 | 난이도 |
|---|---|---|---|---|---|
| 🧊 **툰드라** | 영구동토, 이끼, 짧은 여름 | 순록, 생선, 모피. 작물 재배 거의 불가 | 모피, 고래기름 | 혹한, 식량난 | ★★★★★ |
| 🌲 **냉대 (타이가)** | 침엽수림, 긴 겨울 | 목재 풍부, 호밀·보리, 사냥 | 목재, 호밀빵 | 혹한, 늑대 | ★★★★ |
| 🌳 **온대** | 활엽수림, 뚜렷한 사계절 | 밀, 사과, 목축 | 밀빵, 맥주 | 큰 위협 없음 | ★★ (추천) |
| 🍇 **아열대 (지중해성)** | 구릉, 건조한 여름 | 포도, 올리브, 밀 | 와인, 올리브유 | 가뭄, 산불 | ★★★ |
| 🌴 **열대** | 우림, 우기·건기 | 쌀, 과일, 사탕수수 | 향신료, 설탕 | 역병, 홍수 | ★★★★ |
| 🏜 **건조 (사막)** | 사막, 오아시스 | 대추야자, 낙타 | 소금, 유리 (모래) | 물 부족, 모래폭풍 | ★★★★★ |

- 기후대가 바꾸는 것:
  - **생산 체인 변형** — 같은 '빵' 체인이라도 온대는 밀빵, 냉대는 호밀빵, 열대는 쌀 요리. 툰드라는 농업 대신 어업·사냥이 주식.
  - **건축 양식** — 북방 목조 롱하우스 / 온대 반목조 주택 / 지중해 석조·테라코타 / 열대 고상가옥 / 사막 흙벽돌.
  - **의복·계절 길이·위기 종류**
- 문명은 모두 **중세**를 바탕으로 하고, 기후에 따라 지역색만 달라진다.
- **기후 특산품이 교역의 이유가 된다** (툰드라 모피 ↔ 열대 향신료). 다른 기후의 플레이어와 거래할 동기.
- 후반의 **큰 병**은 위도처럼 위에서 아래로 여러 기후대를 가질 수 있다 → 서로 다른 부족이 공존 → 교역과 분쟁.

### 3.3 창조 이후

- 핵·암반은 **바꿀 수 없다** (영구).
- 물·기후는 거인의 손(물 주기·빛)으로 **조금씩만** 바꿀 수 있다. 너무 많이 바꾸면 기후 재앙(빙하기·대가뭄)이 온다.
- 새 병을 살 때마다 창조를 새로 한다 → 병마다 다른 지구.

## 4. 플레이어의 역할: 유리병 바깥의 거인

### 4.1 플레이어가 하는 것
| 분류 | 행동 | 비고 |
|---|---|---|
| **건설 지시** | 건물 터 지정, 도로 연결, 철거 | 세틀러식. 실제 시공은 주민(목수·석공)이 자재를 날라와서 함 |
| **경제 조율** | 물자 우선순위, 창고 분배, 직업 비율 슬라이더 | 직접 사람을 고르진 않음 |
| **환경 조작** | 물 주기, 빛(커튼), 병 기울이기, 유리 두드리기 | 지나치면 재해가 됨 (아래 4.3) |
| **외부 아이템 투입** | 상점에서 산 물건을 병 안에 떨어뜨리기 | 5장 |
| **주민 판매** | 주민을 시스템에 팔아 게임 재화 얻기 | 10장 |

### 4.2 플레이어가 못 하는 것
- 특정 주민에게 "너 저기 가서 이거 해" 직접 명령 ❌
- 죽은 주민 되살리기 ❌ — **어떤 아이템·결제로도 불가능.** 죽음은 되돌릴 수 없다
- 전투 유닛 직접 컨트롤 ❌ — 공격 목표·태세만 지정

### 4.3 거인의 힘은 양날의 검
| 행동 | 적당하면 | 지나치면 |
|---|---|---|
| 물 주기 | 작물 성장, 우물 수위↑ | **홍수** — 밭 유실, 익사자 발생 |
| 빛 | 생산성↑ | **가뭄·폭염** — 흉작, 열사병 |
| 유리 두드리기 | 주민들이 하늘을 올려다봄 (신앙↑) | **지진** — 건물 붕괴, 부상·사망 |
| 병 기울이기 | 360° 구경 | 크게 기울이면 **산사태** |

### 4.4 신앙 시스템
- 주민들은 거인(플레이어)의 존재를 어렴풋이 느낀다. 선물을 주면 **신앙**이 오르고, 재해를 내리면 **두려움**이 오른다.
- 신앙 높음 → 사원 건설, 축제, 생산 보너스 / 두려움 높음 → 순종적이지만 출산율·행복↓
- 마을마다 '거인을 믿는 방식'이 달라져 고유 문화가 됨 (예: 물방울을 성수로 모시는 마을).

## 5. 외부 아이템 (거인의 상점)

바깥 세상의 물건을 사서 병 안에 **직접 떨어뜨려** 놓는다. 크기 차이가 재미의 핵심이다.

| 카테고리 | 예시 | 병 안에서의 의미 |
|---|---|---|
| **자원 투하** | 각설탕, 쌀 한 톨, 나무젓가락, 자갈 | 각설탕 하나 = 마을 1주일치 식량 / 젓가락 = 목재 산더미 |
| **생물** | 양, 닭, 돼지, 말, 꿀벌통 | 목축·운송 체인 해금 |
| **씨앗** | 밀, 포도, 사과나무, 아마(리넨) | 새 작물·생산 체인 |
| **건축물** | 완성형 풍차, 성당, 등대, 성벽 | 시공 시간 스킵. 주민들이 "하늘에서 성당이 내려왔다"고 기록 |
| **기적** | 비 구름, 의사 가방(역병 치료), 풍요의 뿔 | 위기 극복용 |
| **거인의 유물** | 동전, 반지, 골무, 레고 블록 | 동전 → 광장 기념비 / 골무 → 우물 / 반지 → 왕관(왕권 강화) |
| **꾸미기** | 이끼, 조약돌, 유리 색, 병 받침 | 순수 코스메틱 |

- 물건을 떨어뜨리는 위치가 중요하다. 집 위에 떨어뜨리면 **집이 부서진다.**
- 구매 재화: 게임 내 재화(금화·별조각) + 일부 유료 재화 (14장).

## 6. 주민: 진짜 인간

### 6.1 개체
- 각 주민: **이름, 나이, 성별, 성격 2개, 기술 숙련도, 가족 관계, 건강, 행복**
  - 예) `한스 (34세, 남)` — [근면][다혈질] / 제빵 Lv.4 / 아내 `마르타`, 딸 `리나(6)` / 건강: 양호
- 외형: 중세 유럽풍 평민·장인·기사·성직자 복식. 머리 비율 약간 큰 3D 로우폴리, 단 **진짜 사람 비율에 가깝게** (마스코트 X).

### 6.2 생로병사
| 단계 | 현실 시간 기준 (안) | 특징 |
|---|---|---|
| 아기 | 0~1일 | 집 안에서만 |
| 아이 | 1~4일 | 놀기, 견습(부모 직업 따라다님) |
| 성인 | 4~20일 | 노동, 결혼, **출산**, 징집 가능 |
| 노인 | 20~25일 | 노동력↓, 숙련도 최고 → 제자 교육 시 숙련도 전수 |
| 사망 | — | 묘지에 묻힘. 비석에 생애 기록 |

- **출생**: 부부 + 빈 집 + 식량 여유 → 아이 탄생
  - **인구를 유지하는 주된 방법은 출산뿐이다.** 주민은 어디서도 사올 수 없으므로 (10장), 결혼·가정·출산이 마을의 미래를 결정한다.
  - 출산율을 높이는 요소: 넉넉한 집, 다양한 식량, 행복, 교회(결혼식), 축제
  - 자녀 수만큼 집·식량 부담도 커진다 → 인구 계획이 전략이 됨
- **사망 원인**: 노환, 굶주림, 질병(역병), 사고(광산·건설), 재해(거인의 실수), 전쟁
- **유산**: 숙련도 일부가 자녀/제자에게 상속 → 장인 가문이 생김
- **추모**: 묘지·비석·추모 행사. 유명 주민(영웅, 명장)은 동상으로 남길 수 있음
- **멸망 허용**: 주민이 모두 죽으면 그 병의 문명은 끝난다.
  - 병은 **폐허**로 남는다 (무너진 집, 묘지, 연대기). 폐허는 지울 수도, 기념으로 선반에 둘 수도 있다.
  - 다시 시작하려면: 아주 드물게 유랑민이 찾아와 폐허에 정착 / 내 다른 병의 부락에서 **분가**(이주) 보내기 / 병을 비우고 새로 창조
  - 인구가 위험 수준까지 줄면 경고(연대기·주민 대화)가 먼저 나온다

### 6.3 욕구
| 욕구 | 충족 | 장기 미충족 시 |
|---|---|---|
| 식량 | 빵·고기·생선 (다양할수록 좋음) | 생산성↓ → 영양실조 → **아사** |
| 주거 | 집 (가족 단위) | 행복↓, 출산 불가, 겨울 동사 위험 |
| 건강 | 우물 물, 약초사, 목욕탕 | 질병 → 전염 → 사망 |
| 행복 | 술집, 축제, 교회, 장식 | 노동 거부, 이주, **폭동·분열 (→ 분파 독립, 15장)** |

### 6.4 유니크 주민 (희귀 출생)

**모든 아이는 저마다 특별하게 태어난다.** 그중 낮은 확률로 더 특별한 아이가 태어난다. 돈 주고 뽑는 게 아니라, **마을을 잘 키우면 확률이 오르는 '자연 뽑기'** 다.

**모든 아이가 가지는 것 — 고유 특징**
- 태어날 때 **고유 특징 1~2개**가 무작위로 붙는다. 같은 조합의 아이는 거의 나오지 않는다.
  - 예) 노래하며 일하는 농부 (주변 행복↑) / 왼손잡이 목수 / 고양이만 보면 따라가는 아이 / 비 오는 날 힘이 나는 어부 / 겁이 많지만 손이 빠른 빵쟁이 / 할머니 레시피를 기억하는 아이
- 특징은 작지만 실제 효과가 있고(생산·행복·관계), 연대기에 그 아이만의 이야기를 만든다.
- 외형(얼굴·머리색·체형·버릇 동작)도 부모를 닮되 아이마다 다르다.
- 즉 **'일반' 등급도 똑같은 사람은 없다.** 등급은 '얼마나 강한가·얼마에 팔리나'의 차이일 뿐.

**고유 특징 1,000종 이상 — 만드는 방법**
- 출시 시 **1,000종 이상**을 목표로 한다. 전부 손으로 쓰지 않고 **조합형 + 수작업 특징**을 섞는다.
- **조합형 (대부분)**: `언제` × `무엇에` × `어떻게` 3조각을 조합
  | 조건 (언제) | 대상 (무엇에) | 효과 (어떻게) |
  |---|---|---|
  | 비 오는 날 / 아침에 / 축제 때 / 겨울에 / 혼자일 때 / 가족 곁에서 … | 빵 굽기 / 나무 베기 / 낚시 / 노래 / 이웃 관계 / 동물 … | 속도↑ / 품질↑ / 주변 행복↑ / 실수↓ / 숙련도 성장↑ … |
  - 조각 30 × 30 × 15만 돼도 이론상 1만 개 이상 → 그중 말이 되는 조합을 골라 **이름·한 줄 설명**을 붙여 1,000종 이상 확보
  - 예) `비 오는 날` × `낚시` × `속도↑` → **"빗속의 어부"** — *비가 오면 물고기가 말을 걸어온다고 믿는다*
- **수작업 특징 (수백 종)**: 조합으로 못 만드는 이야기형 특징 — "할머니 레시피를 기억함", "거인의 손가락을 본 적 있다고 우김", "고양이만 보면 따라감"
- **희귀·영웅·유니크 전용 특징**은 전부 수작업 (효과가 크고 연출이 붙음)
- 특징끼리 **시너지·충돌**: "노래하는 농부" + "음악을 좋아하는 이웃" → 친밀도 빠르게↑ / "겁 많음" + "병사" → 사기↓
- **부모 유전**: 부모의 특징 일부가 자녀에게 이어질 확률 → 가문마다 특색 ("빵쟁이 집안은 대대로 아침형 인간")
- **특징 도감**: 지금까지 내 병에서 태어난 특징을 모으는 컬렉션 → 1,000종이 장기 수집 목표가 됨
- 제작: 특징은 **데이터 테이블(스프레드시트 → 게임 데이터)** 로 관리해 기획자가 코드 없이 추가·수정, 라이브 업데이트로 계속 추가
- 📊 1차 데이터: [`docs/traits_v1.xlsx`](traits_v1.xlsx) — 조건 30 · 대상 30 · 효과 15 → 유효 조합 7,768 중 1,200 채택 + 수작업 60 + 등급 전용 24 = **1,284종** (생성 스크립트: `tools/gen_traits.py`)

**등급 (특별함의 크기)**

| 등급 | 출생 확률 (안) | 예시 | 마을 효과 | 판매가 배율 (안) |
|---|---|---|---|---|
| 일반 | 대부분 | 고유 특징 1~2개를 가진 보통 아이 | 작은 개성 효과 | ×1 |
| 재능 | ~10% | 손재주 좋은 아이 | 특정 기술 성장 빠름 | ×2 |
| 희귀 | ~2% | 타고난 장인, 명궁, 미성의 가수 | 해당 건물 생산성 크게↑ | ×5 |
| 영웅 | ~0.3% | 천재 건축가, 전설의 기사, 성녀 | 부락 전체 버프 (행복·신앙·전투력) | ×20 |
| **유니크** | 극히 낮음 | "거인의 목소리를 듣는 아이", "별을 읽는 현자" | 고유 능력 (예: 재해 예언, 새 기술 발명) | ×100 이상 |

- **확률을 올리는 것**: 부모의 숙련도·혈통(명장 가문), 높은 신앙과 행복, 축제 기간 출생, 특정 기후·외부 유물(예: 반지)
- 외형으로 구분: 특별한 머리색·옷·후광 등 → 태어나는 순간 연출(종이 울리고 빛기둥)
- 핵심 딜레마: **마을에 두면 강력한 버프, 팔면 큰 병으로 바로 이사갈 수 있는 거금.**
- 유니크 주민도 늙고 죽는다 → 전성기에 팔지, 끝까지 함께할지
- 출생 확률은 결제와 무관하므로 확률형 아이템 규제 대상이 아니지만, **확률은 게임 내에 공개**한다 (신뢰 확보)

## 7. 경제 & 생산 (중세 문명)

### 7.1 생산 체인

```
[목재]  나무꾼 ──▶ 통나무 ──▶ 제재소 ──▶ 판자
        산림관(묘목 심기)으로 숲 재생

[석재]  채석장 ──▶ 돌

[식량]  농장 ──▶ 밀 ──▶ 방앗간 ──▶ 밀가루 ─┐
        우물 ──▶ 물 ─────────────────────┴─▶ 빵집 ──▶ 🍞 빵
        어부 ──▶ 생선
        사냥꾼 ──▶ 고기
        양돈장(밀+물) ──▶ 돼지 ──▶ 도축장 ──▶ 고기
        양조장(밀+물) ──▶ 맥주 ──▶ 술집(행복)

[광업]  광산(식량 소모) ──▶ 철광석 / 석탄 / 금광석
        제련소(철광석+석탄) ──▶ 철
        대장간(철+판자) ──▶ 도구 (도끼·곡괭이·망치·낫·낚싯대…)
        무기공방(철+석탄) ──▶ 검 · 방패 · 창
        조폐소(금광석+석탄) ──▶ 금화

[직물]  양치기 ──▶ 양털 ──▶ 방직소 ──▶ 옷 (겨울 생존·행복)
```

- **도구가 직업을 만든다**: 도끼가 없으면 새 나무꾼이 생기지 않는다. 대장간이 경제의 심장.
- **광부는 밥을 먹어야 일한다**: 식량 체인과 광업이 맞물림 → 균형이 핵심 재미.
- 모든 물자는 **실물로 존재**한다. 숫자가 아니라 길 위에 쌓인 통나무, 수레에 실린 밀가루 포대.

### 7.2 물류
- 플레이어가 **도로**를 깔면 구간마다 **운반부**가 배치되어 물자를 한 칸씩 릴레이로 나른다.
- 도로가 붐비면 정체가 보인다 → 우회로·당나귀(외부 아이템)·창고로 해결.
- 주민이 자주 걷는 곳엔 **비포장 오솔길**이 자연 생성 → 나중에 정식 도로로 승격 가능.
- 강·웅덩이엔 다리 / 배 운송.

## 8. 유리병 (월드)

- 시작: **메이슨 자** — 작은 숲과 들판, 주민 5명, 최대 인구 ~40
- 확장: 더 큰 병으로 **이사** (8.1)
- 병 종류 = 크기·지형 형태. **기후대는 병 종류와 별개로 창조 단계(3장)에서 고른다** (예: 툰드라 어항, 열대 클로슈 돔)
  | 병 | 지형 | 특산 |
  |---|---|---|
  | 🫙 메이슨 자 | 숲·들판 | 목재·밀 |
  | 🐠 어항 | 호수·섬 | 생선·배·교역 |
  | 🔔 클로슈 돔 | 언덕·산 | 광물·석재 |
  | ⏳ 모래시계 | 위·아래 두 마을 | 모래로 연결된 두 세력 (분쟁 필연) |
  | 🍾 대형 수조 | 대륙형 | 여러 영지가 공존하는 후반 맵 |
- **선반**: 여러 병을 나란히. 병 간 교역·이주·외교 (15장). **병과 병 사이의 전쟁은 없다.**
- 실제 시간·계절 연동. 겨울엔 땔감과 옷이 없으면 사망자 발생.

### 8.1 더 큰 병으로 이사가기

> **더 큰 병은 돈을 벌어서 사야 한다. 그 돈은 주민을 팔아서 번다.**

- 병은 **게임 재화(금화)로만** 살 수 있다. 유료 재화·현금으로는 살 수 없다 → 큰 병 = 내가 키워낸 문명의 증거.
- 금화의 주된 수입원은 **주민 판매** (10장). 부락 교역의 이익은 보조 수입.

**이사 루프**
```
 인구가 늘어 병이 꽉 참 ──▶ 집·식량 부족, 불만↑
          │
          ▼
 남는 인구 일부를 유랑 상단에 판매 ──▶ 금화 저축
          │                         (일일 판매 상한 → 며칠~몇 주 걸림)
          ▼
 큰 병 구매 ──▶ 새 지구 창조 (3장) ──▶ 남은 주민들이 이사
```
- 핵심 딜레마: **팔수록 돈은 모이지만, 새 병에 데려갈 사람은 줄어든다.** 누구를 보내고 누구를 데려갈지가 이 게임의 큰 선택.
  - 늙은 명장을 팔면 큰돈이 되지만 기술이 끊긴다 / 젊은 부부를 남겨야 새 병에서 인구가 다시 는다.

**병 크기 단계 (⚠ 가격·판매가는 검토 중인 임시값)**
| 단계 | 병 | 최대 인구 | 가격 (금화) | 참고: 성인 1명 판매가 ~100금화 기준 |
|---|---|---|---|---|
| 1 | 소형 (시작 메이슨 자) | ~40 | 무료 | — |
| 2 | 중형 (어항·클로슈 돔 등) | ~100 | 3,000 | 약 30명분 |
| 3 | 대형 (모래시계 등) | ~250 | 10,000 | 약 100명분 (명장 판매·교역 수입 필요) |
| 4 | 대형 수조 (대륙형) | ~600 | 30,000 | 장기 목표 |

- 유니크 주민 등급 배율(6.4) 때문에 실제로는 **희귀 이상 주민 1~2명이 이사 시점을 크게 당긴다.** 밸런스 검토 시 '일반 주민만 팔 때'와 '유니크를 팔 때' 두 경로를 함께 봐야 함.

**이사 연출**
- 새 병을 사면 먼저 **새 지구를 창조**한다 (핵 → 기후대 → 뚜껑 …).
- 창조가 끝나면 주민들이 짐수레를 끌고 **'선반 다리'를 건너 새 병으로 행렬 이동**. 이사 축제.
- 주민의 숙련도·가족·연대기는 그대로 이어진다.

**건물·나무 옮기기 (거인의 손)**
- 이사할 때 **건물과 나무를 손가락으로 집어 새 병으로 옮겨 심을 수 있다.** 이사 축제 전에 '이삿짐 정리' 단계에서 진행.
- **나무 — 기후가 생존율을 정한다**
  - 같은 기후대로 옮기면 **기본 100% 생존.**
  - 기후 차이가 클수록 생존율이 떨어진다.
    | 옮기는 곳 | 생존율 |
    |---|---|
    | 같은 기후대 | 100% |
    | 이웃 기후대 (온대 → 냉대) | 70% |
    | 먼 기후대 (온대 → 툰드라) | 20% |
    | 극단적 차이 (열대 야자수 → 툰드라) | 0% — **곧 시듦 (확정)** |
  - 옮기기 전에 나무를 집으면 **생존율이 미리 표시**된다 → 운에 맡길지, 포기할지 선택.
  - 시들 나무(또는 이미 시든 나무)는 **바로 땔감으로 쓸 수 있다** — 나무꾼이 베어 통나무로. 손해만은 아니다.
- **건물 — 부서지지 않는다.** 언제든 그대로 옮겨진다.
  - 단, **기후에 안 맞는 건물은 주민이 살기 힘들다** (아래 '기후 적응').
    - 예) 온대 반목조 집을 툰드라로 → 춥다 (건강↓, 땔감 소모↑) / 툰드라 통나무 롱하우스를 열대로 → 덥고 습하다 (질병↑)
  - 현지 기후 양식으로 **개축**하면 해결 (자재 필요).

**기후 적응 (사람)**
- 기후대가 다른 병으로 이사하면 주민들이 **적응 기간**을 겪는다.
  | 기후 차이 | 적응 기간 중 영향 |
  |---|---|
  | 같은 기후대 | 없음 |
  | 이웃 기후대 | 잠깐 불편 — 행복 약간↓ |
  | 먼 기후대 | 건강↓, 생산성↓, 감기·열병 발생 |
  | 극단적 차이 | 노인·환자 사망 위험, 불만 → 분파 위험 |
- 적응을 돕는 것: 현지 기후에 맞는 **옷**(방직소)·**집**(개축)·**음식**, 약초사, 정착 축제
- **아이는 빨리 적응하고, 노인은 느리다.** 새 병에서 태어난 아이는 처음부터 현지 체질.
- 몇 세대가 지나면 그 기후에 완전히 적응한 부락이 된다 → 이사 직후의 고생도 연대기의 한 장.

**옛 병 처리 (선택)**
- **일부 주민을 남긴다** → 옛 병의 부락이 계속 살아간다. **플레이어가 계속 직접 운영**하거나 AI에게 맡길 수 있다.
- **모두 데려간다** → 옛 병은 폐허로 남음 (기념 보관 또는 비우고 재활용)

### 8.2 여러 병 동시 운영
- 선반 위의 병들은 **모두 동시에 시간이 흐르는 살아있는 지구**다. 원하면 여러 병을 한꺼번에 직접 운영할 수 있다 (하드코어 플레이어용).
  - 예) 본가 병(대형) + 옛 고향 병(소형) + 광산 전용 병(클로슈 돔) → 병끼리 교역으로 분업
- 선반 화면에서 병들을 한눈에 보고, 탭해서 들어간다. 병마다 위기 알림은 연대기·선반 위 아이콘으로.
- 운영 가능한 병 수 = **선반 슬롯 수** (선반 확장은 유료/게임 재화, 14장).
- 병을 많이 굴릴수록 출산 → 유니크 출생 기회와 판매 수입도 늘어난다 → **운영하는 만큼 보상**. 대신 관리 부담이 커지고, 방치한 병은 위기에 약해진다.

## 10. 주민 판매 (시스템 매각)

- **주민은 다른 플레이어에게 파는 게 아니라, 시스템에 팔아서 게임 재화를 얻는다.** 플레이어 간 주민 거래는 없다.
- 반대로 **주민을 사는 방법은 없다** (상점·유료 재화 모두 불가). 주민은 오직 출산·분가·유랑민으로만 늘어난다.
- 판매 연출: 바깥 세상의 **'유랑 상단'** 이 병 가장자리 나루터에 배를 대고, 팔린 주민은 짐을 싸서 배를 타고 떠난다. 다시 돌아오지 않는다.
- 판매 대금: **게임 재화(금화·별조각)** — ① **더 큰 병 구매 (8.1, 주 용도)** ② 거인의 상점(5장) 외부 아이템. 유료 재화로는 지급하지 않음.
- 가격 결정: **등급 (6.4 — 유니크일수록 훨씬 비쌈)**, 숙련도, 나이(전성기 성인 최고가), 성격, 혈통(명장 가문), 건강
  - 예) Lv.8 대장장이 = 고가. 대신 그 주민이 떠나면 마을 대장간이 멈춘다 → **당장의 재화 vs 마을의 미래** 선택
- 판매 제한 (경제 붕괴·출산 노가다 방지):
  - 아이(미성년)는 판매 불가
  - 하루 판매 수 상한, 같은 날 많이 팔수록 가격 하락
  - 마을 최소 인구 이하로는 판매 불가 (멸망은 판매가 아닌 다른 원인으로만)
- 가족 처리: 가족이 있으면 **혼자 보낼지 / 가족 단위로 보낼지** 선택. 가족 단위는 대금↑, 마을 인구 크게↓.
- 남은 주민 반응: 가족·친구가 팔리면 행복↓, 자주 팔면 마을 전체의 거인에 대한 **두려움↑ / 신앙↓** (4.4).
- 장점: 플레이어 간 주민 거래가 없으므로 **현금 거래(RMT)·작업장 위험이 크게 줄어든다.**

     ▲             (구경)              │
     │                                 ▼
 외부 아이템 ◀── 금화 획득 ◀──── 주민 판매 (+ 교역)

- **긴 세션 (20분+)**: 신규 구역 개발, 도로망 재설계, 교역·외교, 전쟁 준비

## 12. 오프라인 진행 & 연대기

- 앱을 꺼도 시간은 흐른다 (오프라인 시뮬레이션은 요약 계산, 최대 12시간).
- 돌아오면 **"마을 연대기"**: 양피지 느낌의 기록
  > *"겨울 3일째. 대장장이 한스가 숨을 거두었다. 그의 딸 리나가 망치를 물려받았다. 같은 날 북쪽 언덕에서 철광맥이 발견되었다."*
- 연대기는 영구 보관 → 병 하나의 **역사책**이 된다 (공유 가능).

## 13. 아트 & 사운드

- **3D 로우폴리 디오라마** + 미니어처(틸트시프트) 효과. 유리 굴절·김 서림·빛줄기 셰이더.
- 주민: 중세 복식의 사실적 비율에 가까운 작은 인간. 직업별 의상·도구로 한눈에 구분.
- 카메라: 병 바깥에서 보는 '거인 시점'이 기본 → 핀치 줌으로 병 안 '주민 시점'까지 (유리를 넘는 순간 소리가 바뀜).
- 사운드: 류트·리코더·하프 중심의 잔잔한 중세풍 BGM. 망치질, 물레방아, 교회 종, 장터의 웅성거림. 전쟁 땐 북소리.
- 분위기 원칙: 죽음·전쟁도 **잔혹하지 않게** — 피 연출 없음, 쓰러짐+묘비+조종(弔鐘) 소리로 표현 → 연령 등급 12세 목표.

## 15. 다른 부락 — 교역·외교·전쟁

> 다른 부락이 생긴다고 곧바로 싸우는 게 아니다. **먼저 만나고, 물건을 바꾸고, 혼인하고, 그러다 틀어지면 싸운다.** 전쟁은 관계의 여러 결말 중 하나일 뿐이다.

### 15.1 다른 부락이 생기는 경로
| 경로 | 내용 | 첫 관계 |
|---|---|---|
| **분가 (개척)** | 인구가 넘치면 젊은 가족들이 새 땅으로 나가 마을을 세움 | 우호 (혈연) |
| **분파 독립** | 행복이 낮으면 불만 세력이 떨어져 나감 | 경계 / 적대 |
| **이주민 정착** | 바깥에서 온 유랑민이 병 한쪽에 자리 잡음 | 중립 |
| **원주민** | 큰 병의 다른 기후대에 원래 살던 부족 | 중립 (문화가 다름) |
| **이웃 병** | 선반 위 다른 병 (AI 왕국) — **교역·외교 전용, 전쟁 불가** | 중립 |
| **다른 플레이어의 병** | 친구·다른 유저의 지구 | 중립 |

- **직접 운영 가능**: 병 안에 새 부락이 생기면 플레이어가 고른다 — **직접 운영** 또는 **AI에게 맡기기**. 언제든 전환 가능.
  - 직접 운영하는 부락마다 각자의 건설·경제·외교를 따로 관리한다 (화면 상단 부락 탭으로 전환).
  - 내가 운영하는 두 부락끼리도 관계·교역·분쟁이 일어난다. 관계는 플레이어 마음대로가 아니라 **양쪽 주민 여론**에 따라 움직인다.
  - 분파 독립으로 생긴 부락은 직접 운영해도 처음엔 거인에 대한 신앙이 낮다.
  - 한 병에서 직접 운영할 수 있는 부락 수에 상한을 둔다 (안: 3개, 병 크기에 따라 증가).
- 거인은 AI 부락에도 비를 내리거나 선물을 줄 수 있다 (편애하면 다른 부락이 질투함).
- 이웃 병(AI 왕국)과 다른 플레이어의 병은 직접 운영할 수 없다.

### 15.2 관계 단계
```
 적대 ◀── 경계 ◀── 중립 ──▶ 우호 ──▶ 동맹
 (전쟁)                              (혼인·공동방어)
```
| 관계를 올리는 것 | 관계를 떨어뜨리는 것 |
|---|---|
| 꾸준한 교역, 선물, 혼인, 축제 초대, 위기 때 식량 원조 | 국경 숲·광맥 경쟁, 불공정한 교역, 교역로 차단, 거인의 편애, 과거 전쟁의 기억 |

### 15.3 교역
- **왜 교역하는가**: 부락마다 가진 게 다르다 — 기후대(3.2), 광맥(창조 단계의 암반), 특화 산업이 다르기 때문.
  - 예) 산 쪽 부락은 철이 남고 빵이 모자람 ↔ 들판 부락은 밀이 남고 도구가 모자람
- **교역로**: 두 부락 사이를 도로로 잇거나, 강·호수엔 나루터와 배, 병과 병 사이엔 **선반 다리 / 편지 비둘기 / 상단**.
- **상인 (새 직업)**: 수레나 당나귀에 물자를 싣고 실제로 길을 오간다. 교역로 위를 줄지어 지나가는 상단 행렬이 새로운 구경거리.
- **시장**: 시장 건물에서 물물교환, 나중엔 금화(조폐소) 거래. 부락마다 시세가 달라 **싸게 사서 비싸게 파는 재미**.
- **교역이 가져오는 것**:
  - 물자 — 내 땅에서 안 나는 자원
  - **기술 전파** — 다른 부락의 건축 양식·작물·요리를 배움 (예: 지중해 부락에서 포도주 담그는 법)
  - **사람** — 상인끼리 정이 들어 혼인 → 주민이 부락을 오가며 이주
  - 위험 — 역병이 교역로를 타고 번지기도 함
- **다른 플레이어와의 부락 교역**: 내 부락 창고의 실물 자원을 상단에 실어 친구의 병으로 보냄 (도착까지 시간 소요). **부락 대 부락의 물자 교역**이며, 주민은 교역 대상이 아니다.
- **상단은 약탈할 수 없다.** 교역로 위 상단은 PvP·전쟁 중에도 공격 대상이 아니다 → 교역은 언제나 안전.
- 교역에 의존할수록 관계는 단단해지지만, 교역로가 끊기면 그만큼 갈등도 커진다 → 전쟁의 씨앗.

### 15.4 외교
| 행동 | 효과 |
|---|---|
| 사절 보내기 | 첫 접촉, 관계 확인 |
| 선물 | 관계↑ |
| 통상 조약 | 교역 세금↓, 상단 안전 |
| 혼인 동맹 | 두 부락 주민 간 결혼 → 혈연으로 묶임 |
| 불가침 조약 | 일정 기간 전쟁 불가 |
| 동맹 | 공동 방어, 연합 원정 |
| 조공 | 약한 쪽이 물자를 바쳐 평화 유지 |
| 선전포고 | 전쟁 (15.5) — 병 안 부락 / 다른 플레이어 대상만. 이웃 병엔 불가 |

- 외교 결정은 플레이어가 내리지만, **주민 여론**이 반영된다. 이웃 부락과 혼인한 가족이 많으면 선전포고 시 행복이 크게 떨어진다.

### 15.5 전쟁

> "어항 속 물고기도 자기들끼리 싸운다." — 병이 커지고 사람이 많아지면 갈등은 필연.

| 단계 | 내용 |
|---|---|
| **1단계: 병 안 부락 간** | 분파·분가·원주민 부락과의 국경 분쟁 / 내전. 모래시계 병 = 위·아래 세력전 |
| **2단계: 플레이어 간 (PvP)** | 비동기 원정 — 다른 플레이어의 병에 원정대 파견, 방어는 AI가 자동 진행 |

### 15.6 군사 시스템
- 병사 = 주민 + 검 + 방패 (병영에서 징집). **병사도 사람이라 죽으면 가족이 슬퍼한다.**
- 경제 의존: 무기공방·식량이 끊기면 군대가 유지되지 않음 → 전쟁도 결국 물류 싸움.
- 국경: 망루·초소·성으로 영역 확장, 상대 건물 점령.
- 플레이어 조작: 공격 목표·병력 비율·방어 태세만. 전투 자체는 자동 (구경하는 맛).
- 거인의 개입: 전쟁 중 외부 아이템(성벽, 투석기, 기적) 투입 가능 — PvP에선 제한/밸런스 필요.
- 전쟁 피해 회복용 '평화 협정'·포로 교환·전쟁 기념비 등 후일담 컨텐츠.

### 15.7 패배 시 잃는 것
| 잃는 것 | 잃지 않는 것 |
|---|---|
| 전투에 나간 **병사의 목숨** (되살릴 수 없음) | 플레이어 계정 재화 (금화·유료 재화) |
| **그 부락 창고의 물자** 일부 약탈 (빵·목재·철·금화 실물 등) | 구매한 아이템 보관함, 코스메틱 |
| | 병 자체, 건물 (점령은 국경 초소 수준까지만) |

- 약탈은 **병 안 부락이 쌓아둔 실물 자원**만 대상. 플레이어 지갑은 절대 건드리지 않는다.
- 약탈 상한: 창고의 일정 비율(예: 30%)까지. 패배 후엔 **휴전 보호막** 시간 부여 → 연속 약탈 방지.
- 민간인(비병사)은 전투로 죽지 않는다 → 전쟁 참여는 병사만 위험을 진다.

## 16. 기술 스택

### 엔진: **Unity 추천** (Unity 6 + URP)
| 이유 | 설명 |
|---|---|
| 모바일 3D 최적화 | URP가 모바일 저사양까지 커버, 유리 굴절/김 서림 셰이더 자료 풍부 |
| 대량 유닛 | 주민 수백 명 시뮬레이션 → 필요 시 DOTS/ECS로 확장 가능 |
| 수익화 SDK | 인앱결제·광고·분석 SDK가 대부분 Unity 우선 지원 |
| 인력 수급 | 국내 모바일 개발자 풀이 가장 큼 |
| 에셋 스토어 | 중세 로우폴리 에셋으로 프로토타입 속도↑ |

- Godot은 가볍고 무료지만, 모바일 3D 성능과 결제/광고 SDK·인력 면에서 이 프로젝트엔 불리.
- 서버(부락 교역·PvP): 초기엔 BaaS(Firebase / PlayFab 등)로 시작 → 규모 커지면 자체 서버.

## 19. 리스크

| 리스크 | 대응 |
|---|---|
| 힐링 감성 vs 죽음·전쟁의 톤 충돌 | 잔혹 연출 배제, 죽음은 '이야기'로 기억되게 (연대기·묘비·유산) |
| 주민 판매에 대한 거부감 | '유랑 상단과 떠나는 이주' 연출, 가족 단위 옵션, 남은 주민 반응으로 무게감 부여 |
| 출산→판매 반복으로 재화 노가다 | 미성년 판매 불가, 일일 판매 상한, 반복 판매 시 가격 하락 |
| 부락 교역 → 현금 거래(RMT)·작업장 | 게임 재화 전용, 교역량·쿨다운 제한 |
| 유료 아이템으로 PvP 밸런스 붕괴 | PvP에서 외부 아이템 효과 제한, 매칭 시 전력 보정 |
| 모바일 성능 (수백 명 + 3D + 유리 셰이더) | LOD, 화면 밖 시뮬레이션 틱 감소, 오프라인은 요약 계산 |
| 경제 시뮬레이션의 높은 진입장벽 | 시대별 점진 해금 + 병목을 시각적으로 보여주는 UI (쌓인 물자, 놀고 있는 주민) |
| 제목 상표 | '나의 작은 지구' 상표·스토어 중복 검색 필요 |

## 20. 결정 사항 (v1.0)

| 질문 | 결정 |
|---|---|
| 주민 수명 | 현실 시간 약 25일 유지. 자녀 출산이 인구 유지의 핵심 |
| 주민 판매 방식 | **시스템에 팔아 게임 재화 획득.** 플레이어 간 거래 없음, 주민 구매 수단 없음 |
| 완전 멸망 | **허용.** 병은 폐허로 남음 |
| 부활 수단 | **없음** |
| PvP 패배 손실 | **병사 사망 + 해당 부락의 창고 자원 약탈** (플레이어 계정 자원은 안전) |
| 병 안 다른 부락 운영 | **직접 운영 가능** (AI 위임도 선택 가능) |
| 상단 약탈 | **불가** — 교역은 항상 안전 |
| 이웃 병과의 전쟁 | **없음** — 교역·외교만 |
| 더 큰 병 구매 | **주민 판매로 번 금화로만.** 유료 재화·현금 불가 |
| 유니크 주민 | 희귀 출생 = **자연 뽑기** (결제 아님), 등급 높을수록 판매가↑. 서버 1명 규칙 없음 |
| 아이의 개성 | **모든 아이가 고유 특징**을 가지고 태어남. 출시 시 **1,000종 이상** (조합형 + 수작업) |
| 이사 시 나무 | 같은 기후 100% 생존, 기후 차이 클수록↓, 극단적이면 확정 시듦 → 바로 땔감 |
| 이사 시 건물 | 파손 없음. 기후 안 맞는 건물은 주민이 살기 힘듦 → 개축 |
| 다른 기후로 이사 | 주민 적응 기간 (건강·행복·생산성↓), 아이는 빨리 적응 |
| 나무 생존율·적응 수치 | 확정: 같은 기후 100% / 이웃 70% / 먼 기후 20% / 극단 0% (곧 시듦) |
| 옛 병 | 일부 주민 남기기 가능, 계속 직접 운영 가능 (여러 병 동시 운영) |
