# HELLO SETTLER — 게임 기획서 (v0.1)

> **"손바닥 위 유리병 속, 작은 사람들이 살아가는 걸 바라보는 게임"**
> 정착·물류 시뮬레이션 장르의 '지켜보는 재미'에, 테라리움을 키우는 '돌보는 감성'을 더한 모바일 힐링 게임.

---

## 1. 한 줄 요약

플레이어는 유리병(테라리움) 하나를 돌보는 사람이다. 병 안에는 손가락 마디만 한 **작은 주민들(호칭: 홀리 / Hollies, 가칭)** 이 살고, 이들이 스스로 길을 내고, 나무를 베고, 빵을 굽고, 이웃과 수다를 떤다.
플레이어는 **명령하지 않는다.** 빛을 비추고, 물을 뿌리고, 씨앗을 떨어뜨리고, 가끔 병을 톡 두드릴 뿐이다.

## 2. 디자인 기둥 (Design Pillars)

| 기둥 | 의미 | 판단 기준 |
|---|---|---|
| **바라보는 게 곧 플레이** | 화면을 아무것도 안 하고 30초 봐도 재밌어야 한다 | 이 기능은 '구경할 거리'를 늘리는가? |
| **실패가 없다** | 죽음·파산·전투·타이머 압박 없음 | 이 기능이 불안이나 죄책감을 만드는가? → 빼라 |
| **작은 개입, 큰 변화** | 손가락 한 번이 병 안에 잔잔한 파문을 만든다 | 한 번의 터치가 눈에 보이는 결과로 이어지는가? |
| **나만의 작은 세계** | 같은 병은 하나도 없다 | 플레이어의 선택이 병의 모습에 흔적을 남기는가? |

## 3. 장르 레퍼런스에서 가져올 것 / 버릴 것

정착·물류 시뮬레이션(도로망 위로 일꾼이 물자를 나르는 장르)의 핵심 재미는 **"내가 만든 시스템이 알아서 굴러가는 걸 구경하는 쾌감"** 이다. 이걸 힐링으로 재해석한다.

| 가져온다 | 바꾼다 / 버린다 |
|---|---|
| 물자가 사람 손을 거쳐 한 칸씩 이동하는 시각적 물류 | 효율 경쟁 → **느려도 예쁘면 OK** |
| 생산 체인 (나무 → 판자 → 집) | 긴 체인 → **2~3단계의 짧은 순환 체인** |
| 일꾼 하나하나가 눈에 보이는 개체 | 숫자 자원 → **주민마다 이름·성격·일상** |
| 영역 확장 | 영토 전쟁 → **유리병 자체를 키우고 바꾸기** |
| 도로 건설 | 플레이어가 깔기 → **주민이 자주 걸은 곳에 오솔길이 저절로 생김** |
| — | 전투, 적, 자원 고갈, 기아, 시간 제한 **전부 삭제** |

## 4. 핵심 루프

```
   ┌────────────── 관찰 (병을 들여다본다) ──────────────┐
   │                                                     │
   ▼                                                     │
 작은 개입 ──▶ 주민의 자율 반응 ──▶ 병 안의 변화 ──▶ 발견·수집
 (물/빛/씨앗)   (길, 일, 대화, 축제)   (꽃, 집, 새 주민)   (일기, 도감, 이야기)
```

- **3분 세션 (출퇴근길)**: 병을 열고 → 밤새 생긴 일을 '주민 일기'로 읽고 → 물 한 번, 씨앗 하나 → 닫기
- **15분 세션 (자기 전)**: 병을 천천히 돌려보며 구경 → 새 구역 꾸미기 → 주민 한 명 따라다니기(팔로우 캠) → 화이트노이즈처럼 켜두고 잠들기

## 5. 테라리움 시스템 (플레이어의 손)

플레이어가 직접 할 수 있는 행동은 **5가지뿐**이다. 의도적으로 적게 유지한다.

| 행동 | 조작 | 병 안의 결과 |
|---|---|---|
| 💧 **물 주기** | 화면 위에서 드래그 → 물방울 낙하 | 땅이 촉촉해짐, 작물 성장, 작은 웅덩이 생기면 주민들이 첨벙 놀이 |
| ☀️ **빛 조절** | 병 위 '커튼'을 손가락으로 열고 닫기 | 밝으면 주민 활동↑, 어두우면 일찍 귀가해 모닥불 |
| 🌱 **씨앗 떨어뜨리기** | 씨앗 주머니에서 원하는 위치로 드롭 | 나무·꽃·버섯·덤불 → 주민들이 그걸 보고 새 일을 시작 |
| 🫙 **병 기울이기** | 폰 기울이기(자이로) / 두 손가락 회전 | 360° 둘러보기. 살짝 기울이면 물이 흐르고 낙엽이 굴러감 |
| 👆 **톡 두드리기** | 유리를 탭 | 주민들이 고개 들고 손 흔듦 (가장 단순한 '안녕') |

> 건물 배치는 **"제안"** 방식: 플레이어가 빈 땅에 '푯말'을 꽂으면, 주민들이 회의(말풍선)를 거쳐 그곳에 무엇을 지을지 정한다. 플레이어가 고른 후보 2~3개 중 하나를 주민이 선택 → 예측 불가한 작은 놀람.

### 환경 변수
- **습도 / 햇빛 / 온도** 3개만. 수치 대신 **유리에 맺힌 김, 빛줄기, 주민 옷차림**으로 표현한다.
- **실제 시간·계절 연동**: 현실이 밤이면 병 안도 밤. 겨울엔 눈, 봄엔 꽃가루.
- 환경이 나빠도 망하지 않는다. 너무 건조하면 주민들이 **"비 오면 좋겠다~"** 하고 기우제 춤을 출 뿐.

## 6. 주민 (작은 사람들)

### 6.1 개체 설계
- 처음엔 **2명**으로 시작, 병이 풍요로워지면 **새 주민이 씨앗꼬투리/다리 건너/풍선 타고** 찾아온다. 최대 20~30명 (병 크기에 따라).
- 각 주민은 **이름, 성격 태그 2개, 좋아하는 것 1개, 꿈 1개**를 가진다.
  - 예) `모모` — [느긋함][수다쟁이] / 좋아하는 것: 버섯 수프 / 꿈: "언덕 위에 망원경을 놓고 싶어"

### 6.2 욕구 (실패 없는 버전)
| 욕구 | 충족 | 미충족 시 |
|---|---|---|
| 배부름 | 식사 | 조금 느려짐, 이웃이 음식을 나눠줌 |
| 쉼 | 집·벤치·낮잠 | 아무 데서나 꾸벅꾸벅 (귀여움 포인트) |
| 어울림 | 대화·축제 | 혼자 산책하며 흥얼거림 |
| 즐거움 | 취미·놀이 | 시무룩 표정 → 다른 주민이 위로하러 옴 |

> **원칙: 주민은 절대 죽거나 떠나지 않는다.** 결핍은 '귀여운 이벤트'의 트리거로만 쓴다.

### 6.3 일과 & 직업
- 직업은 고정이 아니라 **"요즘 빠져 있는 일"**. 주변 환경과 성격에 따라 자연스럽게 바뀐다.
- 나무꾼, 목수, 농부, 제빵사, 어부(웅덩이), 정원사, 우편배달부, 음악가, 별 보는 사람 …
- 하루: 기상 → 아침 식사 → 일 → 점심 수다 → 일 → 저녁 모닥불 → 잠

### 6.4 관계
- 주민 간 **친밀도**가 쌓이면: 같이 일하기 → 이웃집 짓기 → 함께 사는 집 / 단짝 산책 루트
- 관계는 **긍정 방향으로만** 발전 (다툼·이별 없음).

## 7. 물류 & 생산 (힐링 버전)

### 7.1 짧은 순환 체인
```
 🌳 나무 ──(나무꾼)──▶ 🪵 통나무 ──(목수)──▶ 🏠 집 / 🪑 벤치 / 🌉 다리
 🌾 밀   ──(농부)───▶ 🌾 곡식   ──(제빵사)─▶ 🍞 빵 ──▶ 이웃에게 나눔
 🍄 버섯 ──(채집)───▶ 🍲 수프 (모닥불에서 다같이)
 🌸 꽃   ──(정원사)─▶ 💐 꽃다발 ──▶ 축제 장식 / 선물
 🪨 조약돌 ─(줍기)──▶ 🧱 돌길 / 🗼 등대
```
- 모든 결과물은 **'창고 숫자'가 아니라 병 안의 실제 물건**으로 존재한다. 빵은 바구니에 담겨 집 앞에 놓인다.
- 자원은 고갈되지 않는다. 벤 나무 자리엔 그루터기 → 새싹 → 다시 나무.

### 7.2 오솔길 (Desire Paths)
- 주민이 같은 경로를 반복해 걸으면 **풀이 눌려 흙길 → 오솔길 → 조약돌 길**로 진화.
- 플레이어는 길을 깔지 않는다. 대신 **"길이 생긴 모양"이 곧 그 마을의 생활 지도**가 된다 → 병마다 고유한 모양.
- 길 위에 주민이 **물건을 들고 줄지어 걷는 모습**이 이 게임의 핵심 비주얼.

## 8. 유리병 (확장 & 꾸미기)

- 시작 병: 작은 **메이슨 자** (반경 작음, 주민 2~5명)
- 확장 방식: 영토 확장 대신 **병을 '옮겨 심기'** — 더 큰 병으로 이사하면 기존 마을이 그대로 옮겨감 (이사 축제 이벤트).
- 병 종류 (각각 다른 생태):
  - 🫙 메이슨 자 — 숲과 들판 (기본)
  - 💡 전구 병 — 반짝이는 버섯 동굴
  - 🐠 어항 — 물가 마을, 다리와 배
  - 🔔 종 모양 돔(클로슈) — 언덕과 풍차
  - ⏳ 모래시계 — 위·아래 두 마을이 모래로 교류
- **선반(Shelf)**: 여러 병을 선반에 나란히. 병끼리 **편지 비둘기**로 물건/주민 교환.
- 바닥재·조약돌·이끼 종류·유리 색 등 코스메틱 꾸미기.

## 9. 오프라인 진행 & 귀환 경험

- 앱을 꺼도 병 안의 시간은 흐른다 (실시간, 단 8시간 상한으로 '놓친 느낌' 방지).
- 돌아오면 **"주민 일기"** 한 장: 손글씨 느낌으로 3~5줄
  > *"오늘 모모가 언덕에서 네잎클로버를 찾았다. 저녁엔 다 같이 버섯 수프를 먹었다. 누가 물을 줬는지 모르겠지만 고마웠다."*
- 일일 보상·출석 압박 없음. 일주일 만에 와도 **"오랜만이야!"** 하고 반겨줄 뿐, 손해 없음.

## 10. 수집 & 장기 목표 (메타)

| 요소 | 내용 |
|---|---|
| **주민 도감** | 만난 주민, 그들의 성격·꿈·추억 사진 |
| **꿈 이루기** | 주민 각자의 꿈(망원경, 연못, 다락방…)을 환경을 만들어 도와주면 이루어짐 → 작은 컷신 |
| **풍경 앨범** | 사진 모드로 찍은 순간 저장 (공유용 세로 포맷) |
| **계절 축제** | 봄 꽃잔치, 여름 반딧불 밤, 가을 수확제, 겨울 눈사람 대회 |
| **생물 도감** | 병에 찾아오는 작은 생물들 (달팽이, 무당벌레, 반딧불이) |

> 레벨/전투력 같은 수직 성장 수치는 노출하지 않는다. 성장은 **"병이 풍성해 보이는 정도"** 로만 느껴지게.

## 11. 아트 & 사운드 방향

- **아트**: 따뜻한 로우폴리 3D 디오라마 + 틸트시프트(미니어처) 효과. 유리 굴절·김 서림·빛줄기가 핵심 셰이더.
  - 주민: 머리 큰 2.5등신, 단순한 얼굴 (점 눈), 동작은 과장되고 느릿하게.
  - 팔레트: 이끼 초록, 크림, 흙갈색, 저녁 앰버. 채도 낮게.
- **카메라**: 병 바깥에서 들여다보는 시점이 기본. 핀치 줌으로 병 안까지 들어갈 수 있음 (유리 경계를 넘는 순간 사운드가 바뀜).
- **사운드**: 어쿠스틱 기타·칼림바·우쿨렐레 로파이 BGM. 망치 소리, 빗방울, 주민들의 웅얼거리는 가상 언어. **"켜두고 자는 앱"** 으로 쓸 수 있는 수면 모드(타이머 + 화면 어둡게).
- **햅틱**: 유리 두드릴 때 '톡', 물방울 떨어질 때 미세 진동.

## 12. UI 원칙

- 기본 화면에 **UI 거의 없음**. 병 하나가 화면 중앙.
- 하단에 도구 5개(물·빛·씨앗·푯말·카메라)만 반투명 아이콘으로.
- 알림 배지·빨간 점 **금지**. 새 소식은 병 안 주민이 들고 있는 '편지'로 표현.
- 세로 모드 전용, 한 손 조작.

## 13. 수익 모델 (힐링을 해치지 않는 선에서)

- **기본 무료 + 코스메틱 중심**: 병 스킨, 이끼·조약돌 팩, 주민 옷, 계절 장식
- **'선반 확장'** (병 슬롯 추가) 일회성 구매
- **서포터 팩** (월 정액, 소액): 계절 테마 병 + 사운드트랙
- ❌ 하지 않는 것: 강제 광고, 에너지/스태미나, 가챠 주민, 시간 단축 결제, 한정 압박 타이머
  - 주민은 **절대 판매하지 않는다** (생명체를 돈으로 사는 느낌 배제).

## 14. MVP 범위 (첫 프로토타입)

목표: **"5분 동안 아무것도 안 하고 봐도 재밌는가?"** 를 검증

- [ ] 메이슨 자 1종, 360° 회전 카메라
- [ ] 주민 3명, 기본 일과(먹기·일하기·자기·대화)
- [ ] 체인 2개: 나무 → 통나무 → 집 / 밀 → 빵
- [ ] 플레이어 도구 3개: 물·씨앗·톡
- [ ] 오솔길 자동 생성
- [ ] 실시간 낮/밤
- [ ] 주민 일기 (오프라인 귀환 시)

**검증 지표**: 평균 세션 길이, 무입력 관찰 시간 비율, D7 리텐션, "스크린샷 찍은 유저 비율"

| 리스크 | 대응 |

| 압박이 없으니 **목표감이 약해 금방 질림** | 주민 '꿈'이라는 작고 개인적인 목표 + 예측 불가 이벤트로 호기심 유지 |
| 개입이 적어 **"내가 하는 게 없다"** 는 느낌 | 모든 터치에 즉각적·가시적 반응 (주민이 쳐다보기, 물 튀기) |
| 수십 명 개체 시뮬레이션의 **모바일 성능** | 화면 밖/줌아웃 시 LOD + 시뮬레이션 틱 낮추기, 오프라인은 요약 시뮬레이션 |
| 수익화 압박으로 **힐링 훼손** | 13장 '하지 않는 것' 목록을 팀 원칙으로 고정 |
