## 1. 한 줄 요약

플레이어는 유리병 바깥의 **거인**이다. 병 안에는 **중세 문명을 이룬 작은 인간들**이 산다. 밖에서 보면 손바닥만 한 병이지만, 안으로 들어가면 지평선까지 펼쳐진 **평평한 지구**다.
거인은 물건과 건물을 사 주고, 물을 뿌리고, 해(등불)를 옮기고, 바깥 물건을 떨어뜨려 줄 수 있다 (건물 자리는 주민이 정한다 — 6.7). 하지만 **주민 한 명 한 명은 조종할 수 없다.** 주민들은 스스로 일하고, 먹고, 사랑하고, 아이를 낳고, 늙어 죽는다. 거인이 없어도 살아가지만, 거인이 지켜볼 때 문명이 자란다. 병 안의 물은 실제로 흘러서 호수가 마르고 강이 옮겨 가며, 마을은 그 변화를 따라 살아간다.

## 2. 디자인 기둥

> **v5 기둥 (2026-11-07, /brainstorm 단계에서 사용자 확정 — 이 표가 아래 옛 표보다 우선. 정식본: design/gdd/game-concept.md)**
>
> | 기둥 | 정의 | 고민될 때의 기준 |
> |---|---|---|
> | **1. 스스로 살고, 나를 알아보는 사람들** | 주민은 거인 없이도 살아가고, 이름·세대·연대기가 남으며, 언젠가 하늘의 거인을 알아본다(깨달음·믿음·소원). 거인은 돕는 이이지 조종하는 이가 아니다 | 직접 시키기 vs 스스로 하게 → 스스로. 거인은 조건을 바꾼다. 이야기를 줄일까 → 지킨다 |
> | **2. 보는 것이 곧 재미** | 일하고 나르고 사는 모습이 눈에 보인다. 처음 알아채는 신호는 늘 화면 속 행동이고, 숫자는 거인 화면에서 확인용 | 숫자로 알리기 vs 행동으로 보이기 → 행동. 막힌 곳이 *보여서* 찾아낼 수 있게 |
> | **3. 작은 세상의 실감** | 5cm 소인, 닫힌 병의 물·빛이 진짜로 돈다. **생물끼리의 비율과 '왜'는 진짜로, 화면에 보이는 크기는 잘 보이게 조정해도 된다** | 편한 단순화 vs 세상의 이치 → 이치 (단 보이는 크기는 예외) |
> | **4. 의미 있는 손길** | 거인의 **손짓(행동 종류)은 적게**, 하나하나 분명한 까닭·결과·대가(지나치면 두려움). 내려 줄 **물건(내용)은 늘려도 된다** | 손짓 추가 vs 있는 손짓 깊게 → 깊게 |
> | **5. 안개 너머의 설렘** | 세상은 처음부터 다 보이지 않는다. **안개는 주민이 걷는다**(망루·나들이·분가). 거인은 안개 속 윤곽·소리(큰 나무의 실루엣)를 구경한다 | 다 보여 주기 vs 발견하게 → 발견하게 |
>
> **하지 않을 것**: 주민에게 직접 명령 · 주민이 짓는 건물의 터 지정 (맨 처음 스타터킷만 거인이 놓고, 그 뒤엔 하늘에서 내려 준 건물도 주민이 알아서 예쁜 자리에 세운다 — 사용자 2026-11-07) · 주민 쪽 화면에 숫자·확률 · 피 흘리는 전투·짐승 사냥 (개미 떼는 막아 내기, 사냥은 애벌레) · 의미 없는 손짓.
> **첫 출시 범위**: 돌봄이 뼈대 + 탐험 일부(큰 나무 다섯·안개·분가). 친구의 선반(온라인 이웃)은 나중 확장.
> **그림 방향 (시각 기준점)**: 「꽃그늘 아래」 바탕 — 큰 자연은 단순·소인의 것은 촘촘, 채도는 꽃만, 꽃 그늘이 꽃 색으로 물듦, 거인의 손길은 유리 흰빛·은청 / 안개 속 땅은 칠하지 않은 스케치(주민이 밟으면 색이 번짐) / 마을 재료는 이음매가 보이고 꽃잎 지붕은 그 철에 주운 꽃 색.


| 기둥 | 의미 |
|---|---|
| **살아있는 진짜 문명** | 마스코트가 아니라 사람이다. 생산 체인과 경제가 있고, 생로병사가 있다 |
| **구경하는 맛** | 내가 만든 경제가 굴러가며 주민이 물자를 나르는 모습 자체가 보상 |
| **거인의 손** | 바깥에서 하는 작은 행동(물 한 줌, 물건 하나, 병 한 바퀴)이 병 안에선 큰 사건 |
| **나만의 지구** | 같은 병은 하나도 없다. 창조·지형·물길·혈통·역사가 그 병만의 이야기가 된다 |
| **닫힌 세계** | 병은 닫혀 있다. 바깥에서 사람·배·상인·물이 저절로 들어오지 않는다. 사람은 태어나거나 **거인이 데려올 때(이주민)**만 생기고, 물과 소금은 사라지지 않고 옮겨갈 뿐이다. 병 사이의 길(거인의 다리)은 거인만 놓는다 |
| **분위기는 힐링, 내용은 진짜** | 비주얼·사운드·속도감은 잔잔하고 따뜻하게. 하지만 결과는 가볍지 않다 |

## 3. 세계 — 병 안의 평평한 지구

### 3.0 소인의 세상 — 나무가 없는 지구 (2026-11-07 사용자 결정)
- 주민은 **아주 작은 사람들**이다. 병 속 세상에는 **보통 나무가 없다.** 숲은 머리 위로 솟은 **거대한 꽃·풀대·클로버·이끼·버섯**의 숲이다 (비율: 주민 키 기준 풀 3~8배, 꽃 10~30배).
- 나무 대신 **작은 나뭇가지·마른 줄기·풀대**를 줍고 다듬어 쓴다 (자원 '통나무'는 '나뭇가지 다발'로, 벌목장은 가지 줍는 터로 — 숫자 균형은 그대로, 이름·모양만).
- **세상에 한 그루씩만 있는 큰 나무 다섯** (분재처럼 다듬어진 모양 — 굵고 구부러진 줄기, 납작하게 층진 잎 덩어리). 멀리서도 보이는 랜드마크이고 **베지 않는다**:
  | 나무 | 모습 | 하는 일 (첫 안) |
  |---|---|---|
  | **벚나무** (2026-11-07 사용자: '세계수'는 없음 — 처음 말한 '분재 세계수'는 분재처럼 큰 나무들의 느낌이었음) | 분재 벚나무 — 굽은 줄기, 봄에 분홍 꽃구름, 꽃잎이 눈처럼 날림 | 봄 꽃놀이·꽃잎(지붕·옷 재료), 곁에 살면 행복, 버찌(여름 먹을거리) |
  | **소나무** | 분재 소나무 — 비틀린 줄기, 층층이 납작한 솔잎 구름 | 송진(불·방수)·솔방울, 바람막이 |
  | **과일나무** | 꽃 피고 열매 맺는 분재 | **거대한 과일 열매**가 떨어진다 — 하나로 여러 날 먹는 큰 먹을거리, 나르는 모습이 볼거리 |
  | **은행나무** | 부채꼴 잎, 가을에 샛노랗게 | 은행알(먹을거리·약), 노란 잎 융단 |
  | **단풍나무** | 붉은 손 모양 잎 | 단풍 철 행복·축제, 수액(설탕 대신 단맛) |
- **재료도 소인의 것 (2026-11-07 사용자: "나무로 된 것들은 대부분 안 될 거야")** — 판자·통나무·각목 모양은 쓰지 않는다:
  | 옛 재료 | 소인의 재료 |
  |---|---|
  | 통나무 기둥·뼈대 | 곧은 **나뭇가지**·마른 **풀대**·속 빈 **갈대 줄기**를 묶은 뼈대 |
  | 판자 벽 | 엮은 **풀잎**·**나무껍질 조각**·흙을 바른 **엮은 가지**(흙벽) |
  | 초가지붕 | 겹친 **꽃잎·나뭇잎**·마른 풀 다발 · 큰 잎 한 장 |
  | 판자 바닥·다리 | **납작한 조약돌**·마른 큰 잎·갈대 줄기 다발 |
  | 수레 바퀴 | 둥글게 자른 **줄기 마디**·**씨앗 껍데기**·납작 조약돌 |
  | 통·그릇·바구니 | **도토리 깍정이**·씨앗 껍데기·엮은 풀 |
  | 울타리 | 꽂은 가지·풀대 |
  - 돌·흙·진흙·조약돌·조개껍데기(물가)는 그대로 쓴다. 거인의 방 물건(단추·실패·병뚜껑 같은 사람 물건)은 거인이 내려 준 것만 — 주민이 원래 가진 재료로 그리지 않는다.
- **꽃이 아주 많다 (2026-11-07 사용자: "꽃들도 많으면 좋겠어, 코스모스, 장미(가시) 등등")** — 꽃숲이 곧 숲이고, 철마다 피는 꽃이 바뀌어 세상의 색이 달라진다:
  | 철 | 꽃 (거대) | 소인에게 주는 것 |
  |---|---|---|
  | 봄 | 민들레(솜털 씨앗), 제비꽃, 튤립, 수선화, 은방울꽃(종 모양), 클로버꽃 | 민들레 솜털 = 이불·베개, 꽃잎 지붕 |
  | 여름 | **장미 덤불(가시)**, 해바라기(가장 큰 꽃 — 씨앗이 먹을거리), 수국(꽃잎 우산), 나팔꽃 덩굴, 데이지, 양귀비 | 장미 가시 = 바늘·창끝·울타리 (덤불은 지나가면 긁힘 — 길은 돌아감), 해바라기 씨 = 큰 먹을거리 |
  | 가을 | **코스모스**(가늘고 높게 흔들림), 국화, 억새·강아지풀 | 억새 = 지붕 다발, 코스모스 들판은 가을 산책 자리 |
  | 늘 | 이끼 숲, 고사리, 버섯 | 그늘·습기 |
  - 꽃에는 꿀벌·나비·무당벌레가 온다 (주민 키만 하거나 더 큼 — 들짐승 칸에서 다룸). 꿀은 귀한 단맛.
  - 처음 창조 씨앗 '꽃'은 철마다 여러 꽃이 섞여 핀다. 꽃 종류는 계속 늘린다.

- **사냥 = 애벌레 사냥** (2026-11-07 사용자: "동물 사냥은 없앨까" → "애벌레 사냥이 나을 것 같음"): 사슴·토끼는 없다 (아래 '사슴이 없는 세상'). 대신 **애벌레**(주민보다 길고 통통, 거대한 꽃잎·풀잎을 갉아 먹음 — 많으면 꽃숲이 상함)를 둘~셋이 한 조로 풀대 창·풀실 그물로 잡아 막대에 꿰어 메고 온다.
  - 얻는 것: 고기(먹을거리) · **고치 → 비단 실** (먼지 실보다 귀함, 공물 값 좋음) · 꽃숲 피해 줄임.

  | **배·뗏목** | 처음엔 **마른 갈대 다발 뗏목**, 다음 **말려 굳힌 큰 잎 배**(끝이 말려 올라감, 풀대 돛대에 꽃잎 돛), 나중엔 다섯 나무에서 떨어진 **씨앗 껍데기·열매 껍질 배** (귀함) | 잎 배는 물결에 살랑 흔들림, 꽃잎 돛이 바람에 부풂 |
  | **어장** | 물가 돌 위에 앉는 자리 + **풀대 낚싯대**(거미줄·풀실 줄, 가시 바늘), 물 위에 띄운 **연잎 발판**, 엮은 풀 통발 | 낚싯대가 휘고 물고기(주민만 한 크기!)를 둘이 끌어올림 |
  | **다리** | 작은 개울: **징검 조약돌** → 넓은 물: **떨어진 큰 풀대·갈대를 걸친 외나무다리** → 나중 시대: 큰 나무의 '큰 가지' 다리 | 건너는 사람이 팔을 벌려 균형 잡기 |
  | **물가 살림** | 조개껍데기 물그릇, 젖은 진흙 굽는 자리, 물가에 널어 말리는 풀실 | 아이들이 물방울을 굴리며 놂 |
  - **잡는 물고기 = 송사리** (2026-11-07 사용자: "송사리 정도는 잡아먹는 거 어때") — 소인 몸만 한 크기. 풀대 낚싯대·엮은 풀 통발로 잡아 큰 놈은 둘이 막대에 메고, 작은 놈은 한 명이 안고 온다. 호수의 큰 물고기는 잡지 못하는 구경거리 (소인에게는 고래).
  - 물고기는 소인에게 크다 — 작은 물고기 한 마리를 둘이 메고 간다 (나르기 볼거리, 먹을거리 양은 BALANCE 그대로).
  - 자원 이름 '판자'는 그대로 두되 모양은 **쪼갠 갈대 줄기·납작 껍질**로 보인다 (숫자 균형 유지).
  - 다섯 큰 나무의 가지가 떨어지면 아주 귀한 '큰 가지'가 된다 (나중 시대 건물·큰 다리).
- 창조 단계 7의 씨앗은 '이끼·풀·꽃'이 된다. 다섯 나무는 세상을 만들 때 저절로 서로 떨어진 자리에 하나씩 선다 (어느 부락도 처음부터 곁에 있지 않음 — 탐험·이주의 목표).
- 장르의 재미(작은 사람과 거대한 자연)만 가져온다. 특정 작품의 인물·집·소품은 쓰지 않는다.

### 3.1 두 개의 시점
| 시점 | 보이는 것 | 하는 일 |
|---|---|---|
| **병 시점** (밖, 거인) | 선반 위에 세로로 선 작은 유리병. 옆면으로 **땅속 단면**(핵·암반·광맥·광부의 굴)과 하늘이 보이는 살아 있는 축소판 | 구경, 거인의 손(물·빛·톡·등불 옮기기), 외부 아이템 떨어뜨리기, 제물 받기·이주민 데려오기, 선반·다리 |
| **지구 시점** (안, 땅 위) | 위에서 내려다본 **둥글고 평평한 대지** (기본 확대에선 화면 전체가 땅 — 하늘·지평선은 그리지 않음). 오므려 멀어지면 세상의 끝 **유리벽**이 보이고, 그 너머로 **거인의 방**이 비친다 (GIANT_ROOM 4). 주민이 믿는 '유리 돔 하늘'은 이 유리다 | 구경, 사 준 건물 놓기, 주민 따라가기 |

- 병을 두 손가락으로 벌리면(또는 [병 안으로 들어가기]) 유리를 지나 땅 위로 내려앉는다. 오므리면 다시 병 밖으로. 유리를 넘는 순간 소리가 바뀐다.
- **병은 안이 훨씬 넓다 (v3.8)**: 밖에서 보면 손바닥만 한 병이지만, 안은 **처음부터 끝이 보이지 않을 만큼 넓은 세상**이다 (안쪽 대지 지름 약 1,000칸 — 안, 기술 검토 후 확정). 병 크기 단계는 없다.
  - 처음 보이는 건 첫 마을 빈터(지름 약 64칸)뿐이고, 나머지는 **안개 속 미개척지**다. 주민이 길을 내고, 탐험하고, 분가해 새 마을을 세우며 세상이 넓어진다.
  - **부락 영역 (v3.9 확정)**: 부락은 자기 **영역**(마을 둘레의 원) 안의 땅에만 집·밭·일터를 짓는다. 품을 수 있는 인구 = 영역 넓이 × 0.5 ÷ 1인당 땅 (개척기·마을 40칸 / 읍내 34칸 / 영지 28칸).
    | 시대 | 영역 지름 (안) | 품는 인구 (약) |
    |---|---|---|
    | 개척기 | 64칸 | 40 |
    | 마을 | 96칸 | 90 |
    | 읍내 | 140칸 | 225 |
    | 영지 | 200칸 | 560 |
    - 국경 건물이 영역을 조금 더 넓힌다 (안: 망루 +8칸 · 초소 +16칸 · 성 +24칸, 지름 기준). 영역끼리는 겹치지 않고, 지구 시점에 옅은 점선으로 보인다.
    - 영역이 가득 차면 새 집을 못 지어 출산이 멈춘다 (집 크기 병목과 같은 원리). 대신 **분가**: 영역이 90% 넘게 하루 이상 차면 젊은 부부들이 *"새 땅으로 떠나고 싶어요"* 하고 편지를 보낸다 → 거인이 안개 밖 자리를 고르면(키트 놓기와 같은 화면) 그곳에 새 부락(영역 64칸)을 세운다. 거인이 없으면 스스로 가까운 좋은 자리를 고른다. 분가 부락은 우호로 시작한다 (13.1).
    - 뜻: 한 부락은 수백 명에서 멈추고, **넓은 세상은 분가로 채운다** (휴대폰 성능 — 주민 수백 명 단위). 한 세상 전체의 주민 수 상한은 성능 측정 후 정한다.
  - 세상 끝 유리벽은 지평선 너머 멀리 있다. 그곳까지 가 본 탐험가는 연대기의 영웅이 된다.
- **크기감**: 병 시점에서 떨어뜨린 각설탕이 지구 시점에서는 언덕만 한 흰 바위다.

### 3.2 세계관 — 평평한 지구는 진짜다
- 주민들은 *"땅은 평평하고, 하늘은 둥근 덮개이며, 세상 끝에는 빛나는 벽이 있다"* 고 믿는다. 이 병 안에서는 그게 사실이다.
- **테라리움이 세상의 전부다.** 주민은 병 밖을 모른다. 휴대폰·게임·플레이어라는 개념은 주민의 말과 기록에 절대 나오지 않는다.
- 세상의 끝(유리벽)까지 가 본 탐험가는 연대기의 영웅이 된다. 하늘 돔에 비친 거대한 그림자가 거인이다.
- **바다는 없다.** 물은 호수·강·습지·물방울뿐이다.

### 3.3 병의 종류
병 종류는 **모양(지형 성격·뚜껑의 물방울 돌기 배치·유리벽 모양)**만 정한다. 크기는 모두 넓다. 기후대는 창조 때 고른다 (한 병 = 한 기후대).

| 병 | 지형 | 물방울 돌기 | 물길 |
|---|---|---|---|
| 🫙 메이슨 자 | 숲·들판 | 여러 개 (8~12) | 곳곳의 물방울 호수 + 멀리 유리벽에서 흘러오는 강 여러 줄기 |
| 🐠 어항 | 호수·섬 | 0개 (평평한 덮개) | 큰 호수 대신 사방 벽에서 강 여러 줄기 |
| 🔔 클로슈 돔 | 언덕·산 | 꼭대기 1개 | 한가운데 큰 호수 + 둘레 벽의 짧은 강 |
| ⏳ 모래시계 | 위·아래 두 마을 | 잘록한 목에 1개 | 위 마을의 물이 목으로 떨어져 아래 마을의 호수가 됨 (두 세력) |
| 🍾 수조 | 대륙형 | 아주 많음 | 여러 영지가 공존하기 좋은 넓고 평평한 땅 |

## 4. 병의 자연 — 닫힌 병에서 물·빛·소금이 도는 법

자전도 공전도 없는 닫힌 병이다. 그래도 자연이 돈다. **실제 밀폐 테라리움의 원리 그대로**이고, 모든 규칙은 프로토타입에서 확인했다.

### 4.1 빛·낮밤·계절
| 현상 | 원리 | 주민의 해석 |
|---|---|---|
| **빛** | 빛은 병의 **한쪽(거인의 창가·등불)**에서만 들어온다 | 해 |
| **낮과 밤** | 빛은 **거인의 등불**이다 → 병은 **자기 시계**를 가진다. 하루 24시간, 1배속이면 현실과 같은 빠르기. **창조를 마치면 병 안은 아침(7시)에 시작**하고, 거인은 **시간을 빨리 돌릴 수 있다** (6.6) | *"하늘의 빛이 켜지고 꺼진다"* |
| **계절** | 거인의 방의 빛과 온기가 계절 따라 바뀐다 → **현실의 계절 그대로** (거인의 방만 현실 달력을 따름 — 병 안의 계절은 병 날짜, F-2 2026-11-08) | *"빛이 길어지고 짧아진다"* |
| **안개·이슬** | 밤에 식은 유리 쪽에서 새벽 안개 | *"하늘이 내쉰 숨"* |
| **눈 (툰드라·냉대)** | 등불이 먼 차가운 병: 천장에 맺힌 물이 서리로 얼었다가 떨어진다. 땅은 영구동토 | *"하늘의 서리꽃"* |

### 4.2 물방울 호수와 유리벽의 강 — 병의 설계가 물길을 정한다
병 안에는 하늘에서 넓게 내리는 '비'가 없다. 물이 어디로 오는지는 **유리병 자체의 모양**이 정한다.

```
          뚜껑 (안쪽에 물방울 돌기)
      ╭──────●────────────●──────╮      ● 물방울 돌기: 김이 모여 거대한 물방울로 똑… 똑…
     ╱  경사를 타고 벽으로 ↘       ↙ ╲     돌기 없는 곳의 김은 뚜껑 경사를 타고 유리벽으로
    │       💧                💧     │
    │  ≈ 강 ←── 유리벽의 '골'에서 흘러내린 물
    │       (호수)            (호수)  │    물방울 아래 = 호수 (호수에서 강이 흘러나가지 않음)
    ╰──────────────────────────────╯
```

| 병의 구조 | 일어나는 일 | 땅에 생기는 것 |
|---|---|---|
| **물방울 돌기** (뚜껑 안쪽) | 김이 모여 거대한 물방울이 똑… 똑… 떨어진다. 습한 새벽에 더 잦다 | 그 아래 **호수**. 마르지 않는다 |
| **돌기 없는 뚜껑 경사** | 맺힌 물이 경사를 타고 유리벽으로 미끄러진다 | — |
| **유리벽의 '골'** (경사가 모이는 곳) | 물줄기가 벽을 타고 흘러내린다. **그늘일수록 많이** | **강의 근원.** 모든 강은 세상 끝에서 시작한다 (*"세상 끝의 샘"* — 순례지) |

- **유리벽 폭포 — 강이 태어나는 곳은 제대로 보여야 한다** (v4.2, 그림·3D 명세):
  - 뚜껑 안쪽 경사를 미끄러진 물이 **유리벽의 '골'을 타고 흘러내린다**: 유리 안쪽 면에 붙어 흐르는 **얇고 반짝이는 물줄기**(유리 곡면을 따라 휘어짐, 흐르는 물결 무늬가 아래로 움직임, 가장자리 하이라이트). 세상 끝이라 멀리서 보면 **지평선 위로 수직의 은빛 띠**가 여럿 서 있다.
  - 땅에 닿는 곳: **폭포 웅덩이** — 하얀 물보라·물안개(입자), 동그란 물결, 이끼 낀 바위와 물에 젖어 짙어진 땅, 작은 무지개(볕 드는 시간에만). 소리: 폭포 소리 (가까이 갈수록 커짐).
  - 웅덩이에서 **강이 시작**해 지형의 낮은 곳을 따라 흘러간다 (지금의 강 계산 그대로).
  - 물의 양에 따라 굵기가 달라진다: 그늘진 골은 굵은 폭포, 볕 드는 골은 가는 물줄기 → **해를 옮기면(4.6) 폭포가 굵어지거나 가늘어지는 게 눈에 보인다** (미리보기 화살표와 연결).
  - 주민: 세상 끝의 샘 = 순례지 (발견 '세상 끝의 샘'). 폭포 아래에 작은 돌탑·제단을 쌓기도 한다.
  - 3D: 유리벽 안쪽 면에 붙은 흐르는 물 메시(스크롤되는 노멀·알파 셰이더, 굵기 = 그 골의 물 양), 바닥의 물보라 입자 + 물결 데칼. 병 밖(거인의 방)에서도 유리 안쪽에 물줄기가 흘러내리는 게 보인다.
- **강의 운명은 햇빛이 정한다**: 그늘 쪽 강은 증발이 적어 멀리 흐르고, 닿으면 **호수로 흘러든다.** 볕 드는 쪽 강은 금방 말라 **습지로 스며든다.** 한낮엔 볕 드는 쪽 강이 가늘어지고 밤엔 다시 분다.
- **넓은 세상의 물 (v3.8)**: 돌기가 여러 곳이라 물방울 호수가 세상 곳곳에 흩어져 있고, 그 사이는 메마른 들판이다. 유리벽은 지평선 너머라 강은 먼 세상 끝에서 흘러온다. 첫 마을 빈터는 물방울 호수 하나와 강 하나 곁에 놓인다.
- **하늘 물방울 vs 거인의 물 뿌리기**: 물방울은 늘 같은 자리에 똑똑, 거인의 물은 한낮에 갑자기 넓게 쏟아진다. 주민은 둘을 구별한다. 물방울은 자연이고, 거인의 물은 **기적**이다 (6.5). 의심하는 아이: *"하늘 물방울은 원래 떨어지는 거야."*

#### 4.2b 이슬의 하루 박자 (2026-11-07 사용자: "물이 항상 떨어지는 게 맞나" → 추천 수락)
- 이슬은 늘 떨어지지 않는다. **낮**: 등불 볕에 호수·땅의 물이 데워져 김으로 올라감 — 호수 위 아지랑이, 유리 위쪽이 뿌예짐, 물방울은 안 떨어짐. **해 질 녘~밤**: 뚜껑 안쪽 돌기에 물방울이 맺혀 점점 부풂 (보임). **새벽**: 똑, 똑 떨어져 강이 다시 불어남 — 아침의 신호 (물소리에 주민이 깸).
- 습도에 따라: 습하면 많이 맺히고 유리도 더 뿌예짐(유리 닦기 쓸모), 가뭄이면 거의 안 맺힘 (위기가 눈에 보임).
- **하루 물의 총량은 그대로** — 낮에 떨어지던 양을 새벽에 몰아서. 호수·강 균형 숫자(BALANCE) 불변.
- 떠돌이 물방울(WORLD_EVENTS, 사건)은 아무 때나 돌기가 아닌 곳에 크게 매달린다 — 새벽의 작은 이슬과 구별.

### 4.3 지형의 높낮이와 살아 있는 물
- 대지는 **높이 지도**를 가진다. 둘레가 조금 높은 그릇 모양 + 창조 때 빚은 언덕·골짜기·분지. 비탈은 명암, 높이는 등고선으로 보인다.
- **물의 규칙** — 병은 닫혀 있으므로 물은 사라지지 않고 옮겨갈 뿐이다.
  | 들어옴 | 나감 |
  |---|---|
  | 물방울 돌기 (호수 위) | **증발** (따뜻할수록, 넓을수록 많이) |
  | 유리벽의 골 (그늘일수록 많이) | 얕은 물은 **땅에 스며듦** → 강이 습지에서 끝남 |
  | 거인의 물 뿌리기 | — |
- 물은 **높은 곳 → 낮은 곳**으로 흐른다. 오목한 곳에 고이면 **호수**, 가득 차서 넘치면 그 틈으로 **새 강**.
- **큰 호수도 만들 수 있다**: 창조 때 깊게 파고 물을 많이 부으면 **바이칼 같은 큰 호수**. 하지만 **물방울도 강도 닿지 않는 호수는 조금씩 증발해 사라진다.**
  - 프로토타입: 볕 드는 쪽 큰 호수(144칸) → **약 9일 만에 사라짐**. 물방울 호수는 그대로.
  - 연대기: *"서쪽 큰 호수의 물가가 조금씩 물러난다. 이 호수로 흘러드는 강이 없다."* → *"절반 넘게 말랐다. 드러난 호수 바닥에 흰 소금기가 번진다."* → *"마침내 사라졌다. 그 자리에 하얀 소금 들판이 남았다."* 노인: *"내가 어릴 적엔 저기까지 물이었지."*
- **물길은 바뀐다**: 호수가 마르면 그리로 가던 물이 다른 낮은 곳을 찾고, 호수가 넘치면 새 강이 열린다. 물에 잠긴 나무는 죽고, 물러난 물가에는 새 땅이 드러난다. 마을은 물을 따라 옮겨간다 (자율 건설이 새 물가에 짓는다).
- 변화는 수천 년이 아니라 **며칠~몇 주** 단위 → 플레이어가 직접 목격한다.

### 4.4 기후 지도 — 자리마다 날씨가 정해져 있다
- **기온**은 창가와의 거리로, **습기**는 호수·강·습지와의 거리로 정해진다.
  | 자리 | 특징 |
  |---|---|
  | 창가 쪽 마른 들판 | 늘 따뜻하지만 건조. 집은 좋고 밭은 물이 필요 |
  | 물방울 호수 둘레 | 늘 촉촉함. 어부·숲·밭 |
  | 강가 | 촉촉함. 밭·물레방아 |
  | 습지 (강이 스며드는 끝) | 아주 축축함. 약초·갈대 |
  | 그늘 쪽 | 서늘함. 숲이 빨리 자람, 겨울 땔감↑ |
- **농사 효율 = 따뜻함 × 습기 ÷ (1 + 소금기)**. 따뜻하면서 물가인 곳이 최고다. 사 준 건물을 놓을 때 그 자리의 날씨와 농사 배율이 미리 보인다 (*"따뜻함 · 촉촉함 · 농사 ×1.2"*).
- 결과적으로 **숲은 그늘 쪽에, 밭은 물가에, 집은 따뜻한 쪽에** 모이는 마을 모양이 자연스럽게 생긴다.

### 4.4b 땅의 겉모습 — 잔디만 있지 않다 (v4.2)
땅 칸마다 **겉흙**이 있고 습기·볕·발길·기후·사람의 손으로 바뀐다. 화면은 칸마다 다른 색·무늬(셀 채색 평면 + 가장자리 섞임)로 그린다.
| 겉흙 | 생기는 곳 | 모습 |
|---|---|---|
| 풀밭 | 보통 땅 (기본) | 연두 — 들꽃 점 |
| 짧은 풀·마른 풀 | 볕 드는 마른 쪽, 여름 | 누런 연두 |
| 이끼 | 그늘·물가·습한 병 | 짙은 청록, 보송한 점 |
| 숲 바닥 | 나무 아래 | 낙엽·흙 갈색, 가을엔 붉은 잎 |
| 맨흙 | 밭·집터·공사장 | 갈색, 밭이랑 |
| 흙길 → 돌길 | 발길 (오솔길) | 밝은 흙색 → 마을 시대 돌 |
| 모래·자갈 | 호숫가·강가 | 베이지·회색 알갱이 |
| 진흙·습지 | 강이 스며드는 끝 | 짙은 갈색 + 물웅덩이 |
| 바위 | 언덕 위·광맥 | 회색 덩어리 |
| 소금 들판 | 마른 호수 바닥 (4.5) | 하얀 금 간 땅 |
| 눈 | 냉대·툰드라 겨울, 서리 | 흰색 (녹으면 진흙) |
| 마른 땅·모래땅 | 사막 병 | 주황 모래 |
- 계절(현실)이 겉흙 색을 바꾼다: 봄 연두+민들레, 여름 짙은 초록, 가을 누런 풀·낙엽, 겨울 마른 풀·서리.
- 거인의 손이 바꾸기도: 물 뿌리기 → 진흙, 앰플 → 짙은 초록, 소금 → 하얀 얼룩.
- 지금 화면은 거의 풀밭뿐 → 다음 그림 작업에서 겉흙 층을 넣는다 (개발 메모: 지형 셰이더에 겉흙 종류 텍스처 배열 + 칸 경계 섞기).

### 4.5 소금 — 닫힌 세계에서는 사라지지 않는다
- **물방울과 유리벽의 물은 증류수**(김이 맺힌 물)라서 소금이 없다. 병 안의 소금은 모두 **암염(하얀 돌)**에서 나온다. 암염은 **창조 2단계에서 넣는다** (5.1) → 소금 총량은 창조 때 정해진다. 암염을 안 넣은 병엔 소금이 없다.
- 암염 위에 물이 고이거나 흐르면 **조금씩 녹고**(흐르는 물이 더 많이), 녹은 소금은 물과 함께 흘러 **물이 끝나는 곳**에 모인다. 물이 증발하면 **그 자리에 남는다.**
  | 상황 | 결과 |
  |---|---|
  | 암염 위를 지나는 강 | 그 강이 끝나는 호수·습지가 짜진다 |
  | 물이 안 들어오는 호수가 마름 | 바닥에 **하얀 소금 들판** (현실의 우유니처럼) |
  | 소금 들판에 물이 다시 듦 | 소금이 녹아 **낮은 곳으로 씻겨 내려감** |
  | 오래 지나면 | 소금은 **가장 낮은 분지**로 모인다 → 짠 호수 / 소금 사막 |
- **소금의 발견**: 주민은 처음엔 소금을 모른다. 하얀 들판이 넓게 드러나면 누군가(주로 아이)가 맛본다.
  - 연대기: *"리나가 마른 호수 바닥의 하얀 흙을 손가락으로 찍어 맛보았다. 짰다! 사람들은 그것을 '소금'이라 불렀다. 호수 바닥 아래 하얀 바위가 오래도록 녹아든 것이었다."*
  - 믿는 사람: *"거인님이 호수를 거두어 소금을 남기셨다."* 의심하는 사람: *"그냥 물이 마른 것뿐이야."*
  - 발견하면 **소금밭이 열리고** 문명 점수 +15 (8.5). 프로토타입: 큰 호수가 절반쯤 마른 4일째.
- **쓰임과 대가**
  | | 내용 |
  |---|---|
  | 소금밭 | 소금 들판 위에 짓는다. 긁어 모은 만큼 땅의 소금이 줄어든다 |
  | 절임 | 창고에 소금이 있으면 식량 소비 **15% 절약** |
  | 교역 | 다른 병과 바꿀 수 있는 귀한 물자 |
  | 염해 | 소금기 많은 땅은 농사 배율이 크게 떨어진다 (최저 ×0.15) |
  | 짠 호수 | 물고기가 살지 못한다 (어부 불가) |
- 소금 들판을 밭으로 되살리려면: 소금을 다 캐내거나, 거인의 물로 씻어 낮은 곳으로 흘려보낸다.

### 4.6 등불 옮기기 — 해가 하늘을 건너간다 (v4.2: '병 돌리기'에서 바꿈)
> 바꾼 이유: '병 돌리기'는 화면이 돌 것처럼 들리는데 실제 효과는 **햇빛 방향이 바뀌는 것**(자전 같은 효과)이라 헷갈린다. 그래서 **해를 직접 옮기는** 행동으로 바꾼다 — 병 안의 해는 거인의 **등불**이다 (4.1).
- 거인은 **등불을 병 둘레의 네 자리(앞·오른쪽·뒤·왼쪽) 중 하나로 옮긴다.** 병과 땅은 그대로, 화면도 그대로 — **빛이 들어오는 쪽만** 바뀐다.
- 조작: 거인의 방에서 등불을 끌어 병 둘레 다른 자리에 놓는다 (자리 4개에 희미한 표시). 병 안에서는 [해 옮기기] → 네 방향 중 하나를 고름 (작은 나침반 그림: 해 아이콘이 원 둘레로 이동).
- 병 안 화면에서 바로 보이게: 그림자 방향이 천천히(3초) 돌고, 하늘 가장자리의 밝은 쪽이 옮겨 가고, 볕 드는 쪽 유리벽이 반짝인다. 화면 구석에 늘 **작은 해 표시**(지금 빛이 오는 쪽).
- 그래서 **볕 드는 쪽과 그늘 쪽이 바뀐다.** 그늘에 들어간 유리벽 골은 물이 많아져 강이 굵어지고, 볕에 나온 골은 말라 강이 끊긴다 → **강 물줄기가 달라진다.** 증발도 바뀌어 호수 크기가 서서히 변한다.
- **물방울 돌기는 뚜껑에 붙어 있으므로 호수 자리는 그대로다.**
- 프로토타입: 한 번 돌리자 골 다섯 곳의 물이 (180·200·162·76·43) → (145·61·9·200·0)로 바뀜.
- 주민에게는 큰 사건이다: *"해가 옮겨갔다!"* 처음엔 기적(믿음↑)이지만, **하루 세 번 넘게 옮기면 두려움↑** (*"해가 또 자리를 바꿨어… 무서워"*).
- 쓰임: 마른 땅에 강을 끌어오기, 커진 호수 줄이기. 대신 물가 마을이 마를 수 있다.
- **옮기기 전에 무엇이 바뀌는지 보여 준다** (v4.2) — 해를 옮기는 건 세상을 크게 바꾸는 일이라, 결과를 모르고 누르게 하지 않는다.
  - [해 옮기기] → 방향을 고르면 바로 옮기지 않고 **미리보기**가 뜬다 (병 안 화면 위에 반투명):
    | 미리보기 | 그림 | 한 줄 설명 |
    |---|---|---|
    | 볕과 그늘 | 지금 볕 드는 땅 ↔ 옮긴 뒤 볕 드는 땅을 노랑/파랑으로 칠함 | *"동쪽이 그늘이 되고 서쪽에 볕이 들어요"* |
    | 강 (물길) | 유리벽 골마다 물줄기를 화살표로: 굵어질 곳 파랑 ↑, 마를 곳 빨강 ↓, 새로 생길 곳 점선 | *"그늘이 된 동쪽 벽에서 물이 많아져 강이 굵어져요. 서쪽 강은 말라요."* |
    | 호수 | 물이 늘 호수 / 줄 호수에 작은 ▲▼ | *"볕을 받는 서쪽 큰 호수가 빨리 줄어요."* |
    | 마을에 미치는 것 | 영향받는 밭·어부·집에 작은 표시 | *"리나네 밭이 그늘이 돼요 (농사 ↓)"* · *"어부 오두막 앞 강이 말라요"* |
  - 아래에 [옮기기] / [그만두기]. 숫자 대신 화살표·색·말로 (UI 원칙). 예측은 물 계산을 몇 시간치 미리 돌려 얻는다 (프로토타입: 골 다섯 곳 물이 (180·200·162·76·43) → (145·61·9·200·0)).
  - **처음 한 번은 노인이 설명**: 해의 길을 처음 옮기려 할 때 노인 주민: *"거인님, 해가 옮겨 가면 그늘진 벽에서 물이 흘러내려 강이 돼요. 볕 든 쪽 강은 마르고요."* (발견 S3 '해의 길' 전에도 이 귀띔은 나옴).
  - **옮긴 뒤**: 그림자가 3초 동안 돌고, 며칠에 걸쳐 실제로 강이 굵어지고 마르는 것이 보인다 (물은 천천히 움직임). 연대기: *"해가 서쪽으로 옮겨 갔다. 동쪽 벽의 샘이 불어나 새 강이 생겼다."* 바뀐 강·호수는 사흘 동안 지도(오른쪽 위 둥근 지도)에 반짝 표시.
  - 되돌리기: 다시 옮기면 되지만 물은 천천히 돌아온다 (말라 버린 호수 바닥의 소금은 남는다 — 4.5).

## 5. 창조 — 나의 작은 지구 만들기

게임은 **빈 유리병 하나**에서 시작한다. 실제 테라리움을 층층이 쌓는 과정을 지구를 만드는 과정처럼 연출한다. 첫 대사는 *"핵을 넣어주세요."* 전체 5~7분이고, **여기서 한 선택은 게임 전체에 영구적으로 영향을 준다.** 화면 단위 명세는 [OPENING.md](OPENING.md).

### 5.1 창조 단계
| 단계 | 조작 | 정해지는 것 |
|---|---|---|
| 1. **핵 넣기** | 붉게 빛나는 구슬의 **크기만** 고른다 (종류 없음) | 광물 풍부도. 크면 광물↑ 대신 화산·지진 위험↑ |
| 2. **암반 쌓기** | 돌 컵 4개를 붓는다: 붉은(철)·검정(석탄)·반짝이(금)·**하양(암염)** | 광맥의 종류·위치, 산의 높이, **소금 매장지** |
| 3. **흙 덮기** | 흙을 붓고 손가락으로 빚는다. 한 손가락 = 쌓기, 두 손가락 = 파기 | 지형 높낮이, 분지 (깊게 파면 큰 호수 자리) |
| 4. **물 붓기** | 붓는 양과 위치 | 처음 호수들. 물방울·강이 닿지 않는 호수는 언젠가 마른다는 안내 |
| 5. **태양 맞추기** | 반원 궤도 위에 태양(거인의 등불)을 놓는다 | **기후대** (5.2) + **창가 쪽 방향** (기후 지도, 4.4) |
| 6. **뚜껑 닫기** | 뚜껑 안쪽을 찍어 **물방울 돌기** 여러 개 (병 모양마다 기본 배치, 옮기거나 더하기) → 돌려 잠근다 | 물방울 호수 자리. 잠그면 **잠시 배양** (타임랩스) — 김이 서렸다 걷히며 호수가 차고 유리벽에서 강이 생긴다 (v4.2: '수천 년'이 아님). 다음: 씨앗 → 배양 → **야생동물 키트·물고기 풀기** → 스타터킷 (OPENING 단계 6~8) |
| 7. **생명의 씨앗** | 숨구멍으로 이끼·풀·도토리를 뿌린다 | 숲·초원 분포, 초기 동물 |
| 8. **스타터킷 풀기** | 거인이 산 **스타터킷**(가칭 "사람 키우기 키트")을 열어, 세상 지도에서 **놓을 자리를 직접 고른다** (물가·숲 곁 추천 자리 표시) | 키트의 가족·집·살림이 그 자리에 놓인다 → 본 게임 시작 (5.5) |
| 9. **지구 이름** | 이름 짓기 | **지구 카드** (창조 시드 저장·공유) + 연대기 첫 장 '창세 신화' |

- **세상은 매번 무작위다 (v3.8)**: 새로 창조할 때마다 새 무작위 시드로 넓은 세상(지형·언덕·분지·암염 매장지·먼 땅의 호수·숲)이 만들어진다. 창조 단계의 선택(핵 크기·암반·흙 빚기·물·태양·돌기·씨앗)은 그 무작위 세상 위에 더해진다. 같은 세상은 다시 나오지 않는다 (지구 카드의 시드로 친구에게 보여 줄 수만 있다).
- 단계마다 **[추천값]** 버튼이 있다. 첫 병에서는 '망한 지구'를 만들 수 없게 보호한다 (세상에는 물가·숲이 함께 있는 좋은 자리가 늘 여러 곳 생기고, 키트를 놓을 때 추천 자리로 보여 준다. 물가가 없는 곳에 놓으려 하면 경고).
- 플레이어가 한 행동은 주민들의 **창세 신화**가 된다: *"태초에 거인이 어둠 속에 붉은 별 하나를 심었다…"*
- 두 번째 병부터는 **빠른 창조**(약 2분).

### 5.2 기후대
| 기후대 | 풍경 | 주곡·자원 | 특산품 | 위협 | 난이도 |
|---|---|---|---|---|---|
| 🌳 **온대** | 활엽수림, 뚜렷한 사계절 | 밀, 사과, 목축 | 밀빵, 맥주 | 큰 위협 없음 | ★★ (시작) |
| 🌲 **냉대** | 침엽수림, 긴 겨울 | 호밀·보리, 목재, 사냥 | 목재, 호밀빵 | 혹한, 늑대 | ★★★★ |
| 🍇 **아열대** | 구릉, 건조한 여름 | 포도, 올리브, 밀 | 와인, 올리브유 | 가뭄, 산불 | ★★★ |
| 🌴 **열대** | 우림 | 쌀, 과일, 사탕수수 | 향신료, 설탕 | 역병, 홍수 | ★★★★ |
| 🧊 **툰드라** | 영구동토, 이끼 | 순록, 생선, 모피 (작물 불가) | 모피, 고래기름 | 혹한, 식량난 | ★★★★★ |
| 🏜 **사막** | 사막, 오아시스 | 대추야자, 낙타 | 소금, 유리 | 물 부족 | ★★★★★ |

- 기후대는 병 전체의 **바탕 온도**이고, 기후 지도(4.4)는 그 안의 자리 차이다. 툰드라 병에서도 창가 쪽은 덜 춥다.
- **한 병 = 한 기후대.** 다른 기후를 키우려면 **새 병을 산다** (12.1). 다른 기후의 물자·문화는 병 사이 교역으로 얻는다.
- 기후대가 바꾸는 것: 작물(밀 → 호밀·쌀·대추야자, 툰드라는 순록 목장), 건축 양식(반목조 / 통나무 롱하우스 / 석조·테라코타 / 고상가옥 / 흙지붕 / 흙벽돌), 의복, 위기 종류. 문명은 모두 **중세**이고 지역색만 다르다.

### 5.3 기후대 해금 — 천천히 열린다
처음엔 온대만 고를 수 있다. 나머지는 문명을 키우며 열린다 (결제로 열 수 없음). 잠긴 자리는 창조 화면에서 안개에 가려 보인다.

| 순서 | 기후대 | 해금 조건 (안) |
|---|---|---|
| 1 | 온대 | 처음부터 |
| 2 | 냉대 | 첫 병에서 '마을' 시대 + 14일 유지 (약 2주) |
| 3 | 아열대 | 두 번째 병 구매 |
| 4 | 열대 | '읍내' 시대 + 다른 병과 첫 교역 (병 2개 + 거인의 다리) |
| 5 | 툰드라 | 냉대 병에서 혹한 위기 1번 극복 (냉대 병은 첫 14일 안에 혹한이 한 번 온다) |
| 6 | 사막 | '영지' 시대 + 병 3개 운영 |

- 계절은 현실 그대로라서 '겨울 3번'처럼 계절 횟수를 조건으로 쓰지 않는다 (몇 년이 걸림).

### 5.5 스타터킷 — 거인이 사 온 작은 마을 (v3.8)
> 테라리움을 꾸미듯, 거인은 **사람 키우기 키트**(가칭 — 이름은 정해야 함)를 사서 병 안에 풀어 놓는다. 주민들은 그걸 모른다 — 그들에겐 *"거인이 우리를 이 땅에 내려놓으셨다"*는 창세 신화다.

- **기본 키트 (무료, 언제나)**: 두 가족 10명 · 오두막 2채 · 침대·화덕 같은 살림 · 모닥불 · 도구 꾸러미 · 씨앗 한 자루 (안). 새 세상을 만들 때마다 기본 키트는 무료로 다시 받는다.
- **키트 업그레이드 (영구)**: 지폐로 ([BALANCE.md v3-4](BALANCE.md)) **스타터킷 안의 것**을 영구히 키운다 → 다음에 새 세상을 시작할 때부터 처음부터 함께 놓인다. 씨앗 → 밀밭 1,000 · 오두막 2채 → 목조 주택 2채 6,000 · 가족 하나 더 8,000 / 12,000 · 암반 컵 하나 더 4,000. 다른 건물(제재소·우물·풍차…)은 상점에서 그 병에 산다 (21장). 한 번 산 업그레이드는 모든 새 세상에 적용된다 (끄고 켤 수 있음).
  - 시대가 열리지 않은 건물은 업그레이드할 수 없다 (그 건물을 한 번이라도 지어 본 뒤 열림 — 안).
  - 뜻: 새로 시작하는 부담을 줄이고, 여러 세상을 키울수록 시작이 넉넉해지는 **장기 성장**.
- **추가 키트 (유료 재화)**: 한 세상에 키트를 **유료 재화로** 더 사서 **다른 자리에 또 풀 수 있다** → 처음부터 서로 모르는 두 무리 (예전의 '원주민'). 놓은 자리는 곧 안개에 덮이고, 탐험하다 만나면 연대기의 큰 사건 (13장).
- **키트 종류 (추가 키트, 안)**: 가족마다 **타고난 혈통**이 다르다. 혈통 특징은 자식에게 유전된다 (7.2 유전 규칙).
  | 키트 | 가족의 혈통 (안) |
  |---|---|
  | 강인한 가족 | 병·추위·굶주림에 강함, 수명 조금↑ |
  | 장인 가문 | 숙련이 빨리 오름, 명장 출생 확률↑ |
  | 다산 가족 | 개인 출산 배율이 높게 타고남 (1.2~1.6) |
  | 경건한 가족 | 믿음이 잘 오르고 잘 안 떨어짐 |
  | 탐험가 가족 | 멀리 걷고 안개를 넓게 걷어 냄 |
  | 힘센 가족 | 한 번에 더 많이 나름 (짐 ×1.5) |
  | 날랜 가족 | 걸음이 빠르고 일 손이 빠름 (작업 속도↑) |
  - 효과는 **작게** (한 가지 능력 +10~20% 수준) — 돈으로 압도하지 않게. 혈통은 **확률로 유전되어 대대로 남는다** (효과는 옅어지지 않고, 받느냐 못 받느냐만 갈림 — 안):
    - 부모 한쪽만 가진 혈통: 아이가 받을 확률 **50%**
    - 부모 둘 다 가진 혈통: **90%**
    - 부모에겐 없지만 조부모가 가졌던 혈통: **5%** (격세유전 — *"할아버지를 꼭 닮았네"*)
    - 한 사람이 가질 수 있는 혈통은 최대 2개. 서로 다른 혈통 가족끼리 혼인하면 두 혈통을 함께 받은 아이도 나온다.
  - **나쁜 혈통도 있다**: 키트로 팔지 않고 마을에서 저절로 생겨 같은 규칙으로 유전된다. 좋은 혈통과 짝을 이뤄 상쇄된다.
  - **전체 목록·규칙: [BLOODLINES.md](BLOODLINES.md)** (좋은 18 · 나쁜 15, 혈통 하나 = 능력 하나).
  - 희귀 이상 등급(7.2)은 키트에 넣지 않는다 — 특별한 아이는 마을에서 태어난다.
- 가격·업그레이드 목록: [BALANCE.md v3-4](BALANCE.md)의 **통합표** (상점 '건물 사 주기'·키트 업그레이드·암반 컵·등불 업그레이드를 한 표에). 키트·등불 업그레이드는 **선반 화면**(UI 05)에서 판다.

### 5.4 창조 이후
- 핵·암반은 바꿀 수 없다. 지형·물·기후는 거인의 손(물 뿌리기·등불 옮기기 — 커튼은 2026-11-07 없앰)으로 조금씩 바꿀 수 있다.
- 새 병을 살 때마다 창조를 새로 한다 → 병마다 다른 지구.

| **소원 들어주기** | 주민의 소원 편지(*"방앗간을 짓고 싶어요"*)를 들어주면 믿음↑, 그 건물을 더 빨리 짓는다 (6.7) |
| **거인의 손** | 물 뿌리기, 유리 톡, 등불 옮기기 (6.3 — 커튼·감싸기는 2026-11-07 없앰) |

| ~~병 돌리기~~ → **등불 옮기기** | 해(등불)를 병 둘레 네 자리 중 하나로 — 볕·그늘이 바뀜 (4.6) |
| **시간 빠르기** | 기본 하루=5분, 느리게 20분 ~ 1초=12시간 (10단계), 밤 건너뛰기, 비운 동안은 12시간=3일 (설정 1.5~6일) (6.6) |

### 6.6 시간 빨리 돌리기 (기본 기능)
- **기본 빠르기 = 병의 하루가 현실 5분** (2026-11-07 사용자 결정 — ×1 = 현실 하루는 폐기). 속도 단추(누르면 다음, 길게 누르면 목록): **느리게 (1일=20분) · 조금 느리게 (10분) · 보통 (5분, 기본) · 빠르게 (2분) · 아주 빠르게 (1분) · 1초=5분 · 1초=10분 · 1초=1시간 · 1초=5시간 · 1초=12시간**. 결제·제한 없음. 아주 빠를 땐 주민 걸음·효과는 생략하고 계산만 정확히, 탄생·죽음·위기 조짐·소원 같은 중요한 일이 생기면 저절로 느려진다. 첫 병의 첫날(창세의 날)만 약 10~12분 (OPENING 3.0).
- **시계는 빠르게, 사람은 제 걸음으로** (2026-11-07 사용자): 보통 이하에서는 주민이 화면에서 **현실 사람 걸음**(칸 1~1.5개/초)으로 걷고 동작도 제 빠르기로 움직인다. 빨라지는 것은 시계·해·자람뿐. 빠르게부터는 배속에 맞춰 걸음도 빨라지고, 아주 빠르면 순간이동. → 오가는 데 병 시간이 더 들므로 일터를 집 가까이, 하루 나들이 수·짓는 시간·일 시간을 이 걸음에 맞춰 다시 맞춘다 (BALANCE v5).
- **걸음 다시 (2026-11-07 사용자: "좀 빨랐어요")**: 보통 걸음을 **1초에 약 1칸(어른 키)**으로 낮춘다 (예전 1.5칸). **느리게·조금 느리게에서는 사람도 함께 느려진다** (같은 날 사용자: "사람도 느려지게" — 위 '보통 이하에서는 제 걸음'을 바꿈: 제 걸음은 보통에서, 느리게는 모든 것이 천천히). 다리 움직임을 걸음에 맞추고, 오가는 시간이 늘어난 만큼 일터 거리·일 시간·경제를 다시 맞춘다.
- **걸음 한 번 더 (2026-11-07 사용자: "보통 걸음이 너무 빠르고")**: 보통 걸음 1칸/초 → **약 0.7칸/초** (소인이 큰 꽃숲을 천천히 걷는 느낌, 사람 산책 걸음에 가까움). 첫날·대본 중 걸음 덤(×1.25)과 흙길 ×1.15가 겹쳐 실제로 1.4칸/초까지 나던 것을 없애고 **첫날도 보통과 같은 걸음** — 첫날 대본 시간은 오프닝 다시 짜기(ROADMAP A28)에서 걸음에 맞춤. 다리 움직임·나르기·경제(BALANCE v5-0)를 다시 잰다.
- **자리를 비운 동안은 더 천천히**: 기본 현실 12시간 = 병 3일 (등불 시간이 상한, 업그레이드 16/20/24시간). 설정 '자리를 비운 동안 시간': 느리게 1.5일 · 보통 3일 · 빠르게 6일 (12시간 기준). 돌아오면 아는 얼굴이 남아 있게.
- 나이·출산·식량·짓는 시간·시대·제물처럼 '하루마다'인 값은 새 시간에 맞춰 다시 맞춘다 (BALANCE v5 — 주민 한 사람의 일생 ≈ 현실 1~2주 목표).
- **밤 건너뛰기**: 주민이 모두 잠든 밤에 버튼 하나로 다음 새벽(6시)까지 **약 3초 타임랩스**로 넘어간다 (별이 돌고 하늘이 밝아지는 연출, 남은 밤 길이와 상관없이 3초). 끝나면 ×1로 돌아온다.
- 모든 수치(수명 25일, 시대 점수, 생산)는 **병의 날짜** 기준이다 → 빨리 돌리면 그만큼 빨리 진행된다.
- 오프라인(앱을 끈 동안)은 **×1** — 비운 현실 시간만큼만 흐른다 (14장).
- 빨리 돌리는 동안에도 '거인이 지켜보는 시간'으로 친다 (믿음↑). 위기(굶주림·재해)가 시작되면 ×1로 자동으로 돌아오고 알림을 띄운다.
- 주민은 빨라진 시간을 모른다. 연대기·대사에 '빨리감기'류 표현을 쓰지 않는다.

### 6.7 마을은 주민이 짓는다 (v4.0)
> 거인은 신이지 시장(市長)이 아니다. **집·밭·일터·길은 모두 주민이 스스로 정하고 짓는다.** 거인은 명령하지 않고 영향을 준다.

- **자율 건설**: 촌장(가장 나이 많은 성인)이 부락의 부족한 것을 보고 터를 잡는다 ([RESIDENT_AI 6.2](RESIDENT_AI.md)). 거인이 있든 없든 같다. 우선순위에 **'거인님이 좋아하시는 것'**(받은 제물, 11.1)과 **들어준 소원**이 더해진다.
- **길은 발길이 만든다**: 주민이 자주 다니는 곳이 흙길이 되고, 마을 시대부터 돌길로 다진다.
- **사 준 건물**: ~~거인이 놓을 자리를 고른다~~ → **맨 처음 스타터킷만 거인이 놓고, 그 뒤 하늘에서 내려 준 건물(기적)도 주민이 알아서 예쁜 자리에 세운다** (2026-11-07 사용자, 기둥 1). 하늘에서 내려온 건물 = 기적 (믿음↑).
- **소원 편지**: 주민이 원하는 건물을 편지로 보낸다 (*"방앗간을 짓고 싶어요"*, 하루 1~2통). [들어준다]를 누르면 믿음↑, 그 건물이 우선순위 맨 위로, 짓는 속도 ×1.5. 비용 없음 — 들어주지 않아도 언젠가 스스로 짓는다.
- 뜻: 마을마다 모양이 다르게 자라 구경하는 재미, 휴대폰 한 손 조작, 거인과 주민의 관계(믿음·제물·소원)가 게임의 중심.

- **건물 터 지정·길 놓기·철거·직업 배정** (v4.0에서 없앰) — 마을은 주민이 스스로 짓는다
- 죽은 주민 되살리기 — **어떤 아이템·결제로도 불가능**
- ~~전투 유닛 직접 조종 (공격 목표·태세만 지정)~~ — 없앰 (2026-11-07 기둥 1: 명령하지 않는다)

### 6.3 거인의 손은 양날의 검
| 행동 | 적당하면 | 지나치면 |
|---|---|---|
| **물 뿌리기** (기적) | 작물 성장, 소금 씻어내기, **본 주민 믿음↑** | 홍수 — 밭 유실, 익사. 같은 기적이 잦으면 감동↓ |
| ~~빛 조절 (커튼)~~ 없앰 | 증발·강 길이·생산 조절 | 가뭄·냉해 |
| **유리 톡** | 주민이 하늘을 올려다봄 (믿음↑) | 너무 잦으면 두려움↑, 크게 치면 지진 |
| **등불 옮기기** | 볕·그늘이 바뀌어 강 물줄기 변화 (4.6) | 하루 3번 넘으면 두려움↑ |

### 6.4 ~~커튼 — 빛 조절~~ (없앰, 2026-11-07 사용자: "의미 없지 않나" — 더위는 물 뿌리기·꽃 그늘)
- **조작**: 병 시점에서 창가의 커튼을 손가락으로 끌어 3단으로 맞춘다 — **열림 / 반쯤 / 닫힘**. 바꾸면 그대로 유지된다 (거인이 떠나도).
  | | 열림 | 반쯤 | 닫힘 |
  |---|---|---|---|
  | 빛의 양 | 100% | 60% | 25% |
  | 증발 | ×1 | ×0.6 | ×0.3 |
  | 볕 드는 쪽 강의 길이 | 짧음 (습지로 끝남) | 중간 | 그늘 쪽처럼 멀리 흐름 |
  | 작물·나무 자람 | ×1 | ×0.85 | ×0.6 |
  | 병 안 온기 | 그대로 | 기후 지도 한 단계 서늘 | 두 단계 서늘 |
- **밤에는 효과 없음** (빛이 없으니까). 낮밤은 병 시계(등불)를 따른다 (4.1·6.6).
- **지나치면**: 낮에 '닫힘'이 12시간 넘게 이어지면 냉해 (작물 성장 멈춤, 냉대·툰드라는 동사 위험). 덥고 마른 기후(아열대·사막)에서 '열림'만 쓰면 가뭄이 잦다.
- 주민: *"하늘이 흐려졌다"* — 믿음·두려움에는 영향 없음 (조용한 손). 하루 바꾸는 횟수 제한 없음.
- 쓰임: 마르는 호수 지키기(증발↓), 볕 드는 쪽 강을 늘려 새 물길 만들기, 소금 들판을 빨리 드러내기(열림 유지).

### 6.5 믿음과 신앙
- **처음엔 주민이 신(거인)을 모른다** (v4.2). 하늘에서 낟알이 내려도 *"하늘이 주는 것"*일 뿐, 누가 있다고는 생각하지 않는다. 그래서 처음엔 **기도도, 제단도, 제물도, 소원 편지도 없다.**
- **깨달음 (6.5a)**: 거인이 하는 일을 주민이 **목격**하면 '경이'가 쌓인다 — 유리 톡에 하늘이 울림, 뚜껑이 열려 바람이 듦, 꽃씨가 하늘 가득, 물이 쏟아짐, 하늘에서 우물이 내려옴, 거대한 손가락의 그림자. 아이와 노인이 먼저 알아챈다 (*"하늘에 누가 있어!"* / 다른 어른 *"그냥 바람이야"*).
  - 경이가 차면 **깨달음 사건**: 모두가 같은 기적을 함께 보고 하늘을 올려다본다 → 연대기 *"그날 사람들은 하늘 너머에 누군가 있다는 것을 알았다."* → 믿음이 처음으로 생긴다.
  - 그러면 촌장이 **제단을 짓자**고 한다 (자율 건설 최우선, 돌 몇 개 — 짧게). 제단이 완공되면 **첫 기도** → 그 저녁부터 제물 → 지폐. 그 뒤에야 **소원 편지**가 온다 (*"거인님께"*).
  - 거인은 이 과정을 앞당길 수만 있다 (기적을 자주 보여 줌). 아무것도 안 하면 늦게라도 언젠가 깨닫는다 (하늘 낟알·물방울만으로 며칠).
- **제단이 생긴 뒤 주민은 신(거인)의 존재를 안다.** 하지만 거인이 *무엇인지*는 모른다. 하늘의 그림자·낟알·울림·기적을 보고 신이 있다고 믿는다.
- **믿음은 사람마다 다르다** (0~1). 부락의 신앙 = 평균.
  | 상황 | 믿음 |
  |---|---|
  | 거인이 지켜볼 때 | 천천히↑ (*"거인님이 보고 계신다"*) |
  | **거인이 오래 안 올 때** | 어른 천천히↓, **아이는 빠르게↓**. 거인을 본 적 없는 세대가 신을 부정한다: *"거인 같은 건 없어. 그냥 하늘이야."* 노인: *"저 하늘의 그림자를 봐라."* |
  | **기적을 직접 봄** | 크게↑. 의심하던 사람이 무릎을 꿇는다 |
  | **거인의 귀환** | 비운 시간에 비례해 모두 크게↑ + **귀환 축제**. 의심하던 아이: *"정말 계셨어…!"* |
- 프로토타입: 4일 비우자 믿음 98% → 31%, 어린 세대 7명이 신을 부정. 돌아오자 귀환 축제와 함께 92%로 회복.
- **두려움**: 재해·잦은 톡·잦은 돌리기·**강제로 거두기**(11.1)로 오른다. 높으면 순종적이지만 출산율·행복↓, 숨는 일이 잦다.
- 신앙이 높으면 축제·기도가 잦고 **제물을 많이 바치며**, 소원을 들어준 건물을 빨리 짓는다. 의심하는 사람이 많아지면 분파의 씨앗이 된다.
- 마을마다 거인을 믿는 방식이 달라져 고유 문화가 된다 (예: 물방울 호수를 성수로 모시는 마을).

## 7. 주민 — 진짜 인간

### 7.1 한 사람
- 이름, 나이, 성별, **고유 특징 1~2개**, 직업 숙련도, 가족, 건강, 행복, 믿음.
- 외형: 중세 유럽풍 평민·장인 복식, **약 4등신**의 작은 사람 (짤막하지만 사람 비율, 마스코트 아님). 부모를 닮되 아이마다 다르다.
  - **부품 조합**: 체형 · 머리 모양 · 머리색 · 피부 · 수염 · 모자 · 옷 · 옷 색 · 소품. 옷 색·소품은 아이마다 다르다.
  - **겉모습 유전 (v3.8)**: 피부 톤·키·체격은 부모 사이의 **스펙트럼**으로, 눈 색·머리색·붉은 머리·머리결·주근깨·**대머리**는 **우성·열성**으로 유전된다 (숨은 유전자 때문에 부모와 다른 눈·머리색 아이도 나옴). 겉모습 유전자는 **능력에 영향 없음**, 게임 안에 인종 이름은 쓰지 않는다. 스타터킷 가족의 겉모습은 거인이 꾸민다. 상세: [BLOODLINES.md](BLOODLINES.md) 7장
  - 멀리서는 **실루엣·머리색·모자·옷 색**으로, 가까이(주민 상세)에서는 얼굴·수염·소품까지 구분된다.
  - 일부 고유 특징은 겉모습에도 드러난다 (예: 고양이를 따라다니는 아이 → 어깨 위 고양이, 조약돌 수집 → 조약돌 주머니).

### 7.2 고유 특징과 등급 — 모든 아이는 특별하다
- 태어날 때 고유 특징 1~2개가 붙는다. 작지만 실제 효과가 있고(생산·행복·관계), 연대기에 그 사람만의 이야기를 만든다.
  - 예) 노래하며 일하는 농부 / 비 오는 날 힘이 나는 어부 / 할머니 레시피를 기억함 / 거인의 손가락을 본 적 있다고 우김
- **1,000종 이상**: 조합형(`언제` × `무엇에` × `어떻게`) + 수작업 특징 + 등급 전용. 1차 데이터 1,284종 ([traits_v1.xlsx](traits_v1.xlsx)).
- 특징끼리 시너지·충돌이 있고, 부모 특징이 유전되어 가문마다 색이 생긴다. **특징 도감**이 장기 수집 목표다.
- **등급** — 마을을 잘 키우면 확률이 오르는 **자연 뽑기** (결제 아님, 확률은 게임 안에 공개)
  | 등급 | 확률 (안) | 예시 |
  |---|---|---|
  | 일반 | 대부분 | 고유 특징을 가진 보통 아이 |
  | 재능 | ~10% | 손재주 좋은 아이 |
  | 희귀 | ~2% | 타고난 장인, 명궁 |
  | 영웅 | ~0.3% | 천재 건축가, 성녀 |
  | 유니크 | 극히 낮음 | 거인의 목소리를 듣는 아이, 별을 읽는 현자 |
  - 확률을 올리는 것: 명장 혈통, 높은 신앙·행복, 축제 기간 출생, 유물.
  - 같은 등급표가 이주민 뽑기(11.2)에도 쓰인다 (확률 공개). 유니크도 늙고 죽는다.

### 7.3 생로병사
| 단계 | 현실 시간 | 특징 |
|---|---|---|
| 아기 | 0~1일 | 집 안 |
| 아이 | 1~4일 | 놀기, 부모 직업 견습 |
| 성인 | 4~20일 | 노동, 혼인, 출산, 징집 |
| 노인 | 20일~ | 일을 내려놓음, 제자에게 숙련 전수. 평균 수명 약 25일 |

- **혼인**: 성인(4일)부터, 미혼 남녀 짝마다 하루 0.5 확률 (남매 제외).
- **출생**: 부부 + 집에 빈 자리 → 하루 확률 **0.6 × 개인 출산 배율 × 환경 배율**.
  - 개인 출산 배율: 타고남, 0.4~1.6 (평균 1).
  - 환경 배율은 **식량·행복·축제 3가지만**: 식량 0.8 / 1.0 / 1.1 (굶주림 / 보통 / 음식 3종 이상), 행복 0.9 / 1.0 / 1.1, 최근 3일 안 축제 ×1.1.
  - **집 크기가 병목이다 (의도한 규칙)**: 집이 꽉 차면 '가족 + 1명'이 들어갈 더 넓은 집으로 옮겨야 아이를 낳는다. 오두막 4 / 목조 주택 6 / 석조 주택 8명. 다 자란 미혼 자녀는 독립한다. → 실제 출산은 부부당 하루 약 0.36명 ([BALANCE.md](BALANCE.md)).
  - **닫힌 세계라 인구는 출생, 거인이 데려오는 이주민(11.2), 거인이 다른 병에서 옮겨 주는 주민(12.1)으로만 는다.**
- **사망**: 노환, 굶주림, 질병, 추위·더위, 사고, 재해, 전쟁. 질병·부상·추위·더위·개인 두려움 규칙: [HEALTH.md](HEALTH.md). 묘지·비석·연대기로 기억된다.
- **멸망 허용**: 모두 죽으면 병은 **폐허**로 남는다 (12.3). 되살리려면 내 다른 병에서 분가를 보내거나 새로 창조한다. 위험 수준이 되면 경고가 먼저 나온다.
- **게임오버는 없다** (v4.2): 끝나는 것은 병 하나의 문명뿐. 지폐·업그레이드·기후·도감·연대기는 남는다. 멸망은 거인이 볼 때만 오고, '마지막 불씨' 경고와 병마다 7일에 한 번 무료 '구원의 가족'이 있다. 폐허 위에 새 마을을 무료로 시작할 수 있다 — [PROGRESSION.md 2.5](PROGRESSION.md).

- **아기 돌봄** (2026-11-07 사용자 결정): 아기가 태어나면 **부모 둘 다 일터 일을 쉬고** 집에서 아기를 돌본다 (흔들기·먹이기·안고 다니기 — 화면에 보임). 아기가 **걸음마(약 2세)**가 되면 일터로 돌아간다. 같은 집에 조부모·노인이 있으면 한 사람이 일찍 돌아갈 수 있고, 아무도 없으면 물 긷기 같은 꼭 필요한 일만 번갈아 잠깐. 일터가 비면 촌장이 다른 사람을 넣는다. 사람 목록: "아기 돌봄 (마르타의 아기 · 곧 걸음마)". 한꺼번에 많이 태어나면 한동안 일손이 모자람 — 대신 나중에 사람이 늘어나는 선택. 기간은 BALANCE v5. **아기 산책**: 부모가 **나무 유모차(바구니 수레)**를 끌고 마을을 한 바퀴 돈다 — 지나가던 주민이 멈춰 들여다보고 웃음·손 흔들기·'아이 귀여워' 말풍선, 아이들은 발돋움해 구경, 노인은 아기 머리를 쓰다듬음. 본 사람은 행복이 조금 오른다 (마을 분위기).

## 8. 경제 — 중세 문명

### 8.1 생산 체인
```
[목재]  나무꾼 → 통나무 → 제재소 → 판자        (산림관이 숲을 다시 심음)
[석재]  채석장 → 돌
[식량]  농장 → 밀 → 방앗간 → 밀가루 ─┐
        우물 → 물 ──────────────────┴→ 빵집 → 빵
        어부 → 생선 · 사냥꾼 → 고기 · 양돈장 → 도축장 → 고기 · 양조장 → 맥주
        (낚시·사냥·가축화: WILDLIFE.md / 작물 발견·포도·채소·요리: FOOD.md)
[소금]  (발견 후) 소금밭 → 소금 → 절임
[광업]  광산 → 철광석·석탄·금광석 → 제련소 → 철 → 대장간 → 도구 / 무기공방 → 검·방패
        조폐소 → 주화 (부락 화폐 — 플레이어 재화 '지폐'와 별개)
[직물]  목장 → 양털 → 방직소 → 옷
```
- **도구가 직업을 만든다**: 도구가 없으면 새 일꾼이 생기지 않는다. 시작 창고에 도구가 있고, 광산이 열리기 전엔 외부 아이템·발굴로 철을 구한다.
- 생산·가공 건물은 일꾼이 배정되어 있으면 **밤에도 돌아간다** (밸런스 기준). 채집형(나무꾼·채석장)은 일꾼이 직접 걸어가서 일한다.
- 모든 물자는 **실물**이다. 길 위에 쌓인 통나무, 수레에 실린 밀가루 포대.
- 상세: [BUILDINGS.md](BUILDINGS.md) (건물 42종 — 시대 39 + 제단·소금밭·버섯꾼 오두막, 레시피, 기후 변형)

### 8.2 물류
- 길은 거인이 깔지 않는다 (v4.0, 6.7). 주민이 자주 걷는 곳엔 **오솔길**이 생기고, 많이 밟은 흙길은 마을 시대부터 돌길로 다져진다 (RESIDENT_AI 6.2, 4.4b). 길에서는 짐꾼이 물자를 구간마다 릴레이로 나른다. 붐비면 정체가 보이고, 주민이 우회로·창고를 짓거나 당나귀(상점 '생물')로 푼다.
- 일꾼은 자기 건물 앞에 쌓인 산출물을 직접 창고로 나른다. 창고에 넉넉한 물자는 생산을 쉬고 그 일꾼이 운반·건설을 돕는다.

### 8.3 시대
| 시대 | 열리는 것 |
|---|---|
| 개척기 | 오두막·창고·우물·나무꾼·산림관·제재소·채석장·농장·묘지 |
| 마을 | 목조 주택·방앗간·빵집·어부·사냥꾼·목장·방직소·대장간·약초꾼·치료소·교회·광장·나루터·망루 |
| 읍내 | 석조 주택·양돈장·도축장·양조장·광산 3종·제련소·목욕탕·술집·시장 |
| 영지 | 무기공방·조폐소·초소·병영·성 → 전쟁 컨텐츠 |

- **시대 점수**는 인구·건물·발견으로 쌓인다. 거인이 지켜볼 때 100%, 없을 때 30%.
  - 필요 점수: 마을 100 / 읍내 200 / 영지 300.
  - 시간당 점수 = (인구 × 0.4 + 건물 × 0.6) × 시대 배율 (개척기 1 / 마을 0.08 / 읍내 0.03). 발견 점수는 따로 더한다 (발견이 약 30%를 채움, 소금 +15).
  - 하루 2시간 지켜볼 때 (보통 마을): **마을 약 2일차 · 읍내 약 17일차 · 영지 약 40일차**.
- 점수가 차면 거인이 **[계시]**를 내려야 다음 시대로 넘어간다.
- 시대와 별개로 열리는 건물: **제단** (깨달음 뒤 주민이 지음, 6.5), **소금밭** 등 발견 건물 (8.5), **버섯꾼 오두막** (큰 버섯이 나는 병, WORLD_EVENTS 2.6).

### 8.4 하늘 낟알 — 첫 수확 전까지만 (만나)
- 첫 정착민이 **도착하자마자 한 번**, 그 뒤 **매일 새벽 자동으로** 그 기후의 주곡 낟알(온대 밀, 열대 쌀 등, 툰드라는 말린 생선)이 **하루치만큼** 내린다.
- **비축 불가**: 하루가 지나면 상한다. 집 화덕에서 죽으로 먹는다 (배는 부르지만 행복↑ 없음).
- **첫 수확 다음 날 새벽부터 그친다.** 새 밭은 첫 수확까지 4시간 자란다. 그래서 보통 1~2번 내린다. 개척기엔 밀을 방앗간 없이 죽으로 먹을 수 있어 농장 하나로 10명을 먹인다.
- 연대기: *"들에서 첫 곡식을 거둔 다음 날, 하늘의 낟알이 그쳤다. 이제 우리는 우리 손으로 먹고산다."* → **첫 수확 축제**.
- 새로 산 병에서도 첫 수확 전까지 다시 내린다.

### 8.5 발견 — 세상의 변화가 새 지식을 연다
- 어떤 지식은 시대가 아니라 **세상이 변해야** 얻는다. 거인의 행동(물·빛·돌리기)이 자연을 바꾸고, 그 변화를 주민이 발견하며 문명이 자란다.
- 확정: **소금** — 호수가 말라 하얀 들판이 드러나면 맛보고 발견 → 소금밭, 시대 점수 +15 (4.5).
- **발견 목록 25종** — 물과 호수(소금·진흙·물레방아 등 6), 땅과 바위(드러난 광맥·벽돌·계단밭 등 5), 숲과 생물(갈대·약초·효모 등 5), 하늘과 세상의 끝(세상의 끝·세상 끝의 샘·해의 길 등 5), 사람과 마을(글·셈 등 4). 상세: [DISCOVERIES.md](DISCOVERIES.md)
- 원칙: 세상이 먼저 변하고, 그 자리에 있던 주민이 발견한다. **거인은 조건을 앞당길 수 있지만 발견을 줄 수는 없다** (결제로도 불가). 발견은 그 병의 것이고, 다른 병에는 거인의 다리로 전파된다.
- 발견이 시대 발전의 3분의 1~절반을 채운다 → 같은 시대라도 병마다 가진 기술이 다르다.

## 9. 외부 아이템 — 거인의 상점

> **상세: [WORLD_EVENTS.md](WORLD_EVENTS.md) 3·4장 (v4.2)** — 모든 물건은 **뚜껑을 열어야** 들어간다 (김·연기는 빠지지만 바깥 공기·날벌레·병이 따라 들어올 수 있음). 돌봄 물건 = 거인의 방의 작은 물건 (알약 부스러기·소독약 한 방울·반창고 조각·성냥개비·털실·이끼). 병 밖에서 하는 기적(커튼·병 옮기기·유리 닦기 — 손으로 감싸기는 없앰)은 무료.

바깥 세상의 물건을 사서 병 안에 떨어뜨린다. **크기 차이**가 재미의 핵심이다.

| 분류 | 예시 | 병 안에서 |
|---|---|---|
| 자원 | 각설탕, 쌀 한 톨, 나무젓가락, 녹슨 못, 자갈 | 각설탕 = 식량 1주일치 / 젓가락 = 통나무 산더미 / 녹슨 못 = 철 |
| 생물 | 양, 닭, 당나귀 | 목장·식량 다양성·운반 |
| 건축물 | 완성된 풍차, 작은 성당 | 즉시 완공. *"하늘에서 성당이 내려왔다"* |
| 기적 | 의사 가방, 풍요의 뿔 | 역병 치료, 위기 극복 |
| 유물 | 동전, 골무, 반지 | 기념비 / 우물 / 왕관 (희귀 출생↑) |
| 꾸미기 | 이끼, 조약돌, 유리 색, 병 받침 | 코스메틱 |

- 떨어뜨리는 위치가 중요하다. 집 위에 떨어뜨리면 집이 부서진다.
- 구매 재화: 지폐(제물 수입, 11장) + 일부 유료 재화 (17장 — 보류 중).
- **물건 목록·값·진열 탭·손의 흐름: [SHOP.md](SHOP.md)** (위 표는 분류의 예시. 생물은 '이미 가축이 된 작은 종'만, 건축물은 '건물 사 주기').

## 10. 위기와 자연의 변화

> **상세: [WORLD_EVENTS.md](WORLD_EVENTS.md) (v1.1~)** — 이 장은 요약만 둔다. 옛 위기 표(역병·흉작·혹한·화재·염해…)는 v4.3에서 없앴다.

- 위기는 날씨 재해(가뭄·홍수·혹한)가 아니라 **작은 세계라서 생기는 것들**이다 (WE 2장):
  - **곰팡이 무리** — 대표 위기. 김 서린 병에서 생기는 털뭉치 괴물, 창고를 썩히고 늘어남. 빛·불·소금·마른 공기에 약함. 누룩곰팡이는 길들이면 빵·맥주↑, 푸른곰팡이 가루는 곰팡이약 (2.1).
  - **뚜껑**을 열면 따라 들어오는 것 — 날벌레·먼지 뭉치·바깥 공기 (2.2, 3장).
  - **큰 버섯·하룻밤 버섯 숲** — 습한 병의 식량이자 길을 막는 숲, 얼룩버섯은 독 (2.6).
  - **큰 민들레** — 꽃씨가 그늘 쪽으로 번짐, 밭의 잡초이자 솜·물감 (2.7).
  - **밖에서 오는 병** — 열병·역병은 이주민·날벌레·먹는 물건으로만 들어온다 (5장, HEALTH 2.6).
  - 그 밖: 떠돌이 물방울(홍수 대신), 연기 갇힘(화재), 탁한 공기, 녹, 흔들림.
- 추위·더위·물길 변화(호수가 마름·염해)는 위기가 아니라 늘 있는 **병의 날씨** (WE 2.5) — 거인은 등불 옮기기·물 뿌리기·커튼으로 바꾼다 (손으로 감싸기는 2026-11-07 없앰).
- 무엇이 오는지는 **병의 상태가 쌓은 압력**이 정한다 → 병마다 단골 괴물이 다르다. 평균 4~6일에 하나, 첫 3일 없음, 세 번 겪으면 마을이 대응을 배운다 (WE 2.3).
- 위기는 **예고된다** (뿌연 유리·누런 하늘·주민 편지). 갑작스러운 몰살은 없다. 분열(불만 세력 → 분파)은 13장.

## 11. 거인의 장터 — 제물과 이주민 (v4.0)

> **주민은 팔지 않는다.** 주민이 거인에게 **제물**을 바치고, 거인은 그 제물을 장터에 팔아 지폐를 벌고, 그 지폐로 이주민을 데려온다. **믿음이 곧 수입이다.**

### 11.1 제물 — 지폐의 근원
- **제단**: 처음부터 있지 않다 — 주민이 거인을 **깨달은 뒤 직접 짓는다** (6.5 깨달음, v4.2). 모닥불 곁 작은 돌 제단 (교회가 생기면 교회 제단이 더 크다). 제단이 생긴 뒤 주민은 **저녁 기도 때** 창고의 남는 물건 일부를 제단에 바친다. 제단 전에는 기도·제물·소원이 없다.
  - 바치는 양 = 남는 물건(창고의 넉넉한 양을 넘는 몫) × **(0.3 + 0.7 × 마을 믿음)** (안). 의심하는 사람이 많으면 줄고, 거인이 오래 비우면 줄고, **귀환 축제 날은 제단이 가득** 찬다.
  - 무엇을 바치나: 남는 물건 중 **거인님이 좋아하신다고 믿는 것**부터 (아래 '받기').
  - 굶주리는 마을은 식량을 바치지 않는다. 단, **두려움이 높은 마을은 굶으면서도 바친다** (연대기의 어두운 이야기).
  - 제단에는 **이틀치**까지 쌓인다. 그보다 오래된 제물은 창고로 돌아간다 (*"거인님이 받지 않으셨다"*).
- **받기**: 거인이 제단의 제물을 손가락으로 집어 병 밖으로 가져간다 → 장터 값만큼 **지폐**. 받지 않고 둘 수도 있다.
  - 받은 물건 종류는 *"거인님은 빵을 좋아하신다"*가 되어, 주민이 그 물건을 **더 만들고 더 바친다** (자율 건설 우선순위에도 반영, 6.7). 거인이 마을의 일을 간접으로 이끄는 길.
  - 제물을 받으면 바친 사람들 믿음↑ (*"거인님이 받으셨다!"*).
- **강제로 거두기**: 거인은 창고에서 직접 물건을 집어 갈 수도 있다. 대신 **믿음↓·두려움↑** (안: 장터 값 100지폐어치마다 모두 믿음 −0.01, 두려움 +0.02. 굶주릴 때 식량이면 ×3). 거두기 전에 **"마을에 생기는 일"**(예: *"빵이 이틀치밖에 안 남아요"*)을 보여 준다.
- 값은 가공도가 높을수록 비싸다 (예: 밀 < 빵 < 맥주, 철 < 도구, 양털 < 옷, 소금은 비쌈). 기후대 특산품(와인·향신료·모피·유리…)은 더 비싸다 → 다른 기후 병을 키울 이유.
- 값 = 담긴 노동 × 가공 배율 (예: 밀 1 · 빵 3.2 · 옷 8.5 · 도구 16.9 지폐) — [BALANCE.md v3](BALANCE.md).
- **같은 물건을 많이 거둘수록 그날 값이 내려간다**: 60개째에 반값 (0.5^((n−1)/60)). '그날' = 현실 하루, **모든 병 합쳐서** → 한 가지만 찍어내는 노가다·빨리 돌리기 악용 방지, 다른 기후 병의 특산품이 값진 이유.
- 수입 (밸런스 v3, 남는 물건을 모두 판다고 본 값): 보통 마을 하루 약 500 (3일) → 870 (14일) → 1,900 (21일), 한 병의 장터 한계 약 3,500/일. 제물 v4 (믿음 0.7·매일 들름): 하루 약 370 (3일) → 630 (14일) → 1,400 (21일) → 2,500 (35일, 영역 상한) — [BALANCE.md v4](BALANCE.md).

### 11.2 이주민 — 거인이 데려오는 사람들
- 지폐로 **이주민 뽑기**를 한다. 누가 올지는 모른다 (나이·성별·특징·등급 무작위). 등급 확률은 7.2 표와 같고 **게임 안에 공개**한다.
- 연출: 거인의 손이 하늘에서 내려와 마을 어귀에 사람을 내려놓는다. 연대기: *"하늘에서 새 사람이 내려왔다."* 믿음이 높은 마을은 축제처럼 맞이하고, 낮은 마을은 경계한다 (행복 잠깐↓).
- 이주민은 혼자 오거나 작은 가족(2~4명)으로 온다 (안). 집이 없으면 모닥불 곁에서 지내며 촌장이 집을 짓는다.
- 가격 (밸런스 v3, 안): 그날 첫 번 **300 지폐**, 같은 날 다시 뽑을 때마다 ×1.5, **하루 5번** (현실 하루). 혼자 60% · 2~4명 가족 40%. 아이 이주민도 온다.
- **유료 재화로 뽑을지는 열린 질문** (22장). 유료면 확률형 아이템 규제(확률 공개·표시) 대상.

## 12. 병과 선반

### 12.1 새 병 사기 — 두 번째 세상 (v3.8)
- 병은 크기 단계가 없다. **새 병 = 새 기후대의 새 세상**이다. 해금된 기후대(5.3) 중 하나를 골라 창조한다.
- 새 병은 **지폐로만** 산다 (유료 재화·현금 불가). 가격 (밸런스 v4, 안): 두 번째 **6,000** (제물 수입으로 보통 약 13일차) / 세 번째 **30,000** / 네 번째부터 **80,000**.
- 새 병의 첫 주민은 스타터킷(기본 + 산 업그레이드, 5.5)의 가족이다. **원하면** 기존 병의 주민을 거인의 다리로 데려가거나 손으로 옮길 수 있다 (가족 단위, 선택 사항).
  - **기후 적응**: 다른 기후로 간 주민은 적응 기간 동안 건강·행복·생산성이 떨어진다. 아이는 빨리, 노인은 느리게 적응한다.
  - 건물·나무는 옮기지 않는다 (각 세상은 그 기후의 양식으로 짓는다).
- 두 세상은 동시에 흐르고, 모두 직접 운영하거나 한쪽을 AI에게 맡긴다. 병 사이 교역은 거인의 다리로 (13.3).

### 12.2 여러 병 동시 운영
- 선반 위 병들은 모두 동시에 시간이 흐른다. 원하면 여러 병을 한꺼번에 직접 운영한다.
- 병 사이의 교역·이주는 **거인의 다리**를 놓아야 열린다 (13.3). 병과 병 사이의 전쟁은 없다.
- 운영 가능한 병 수 = 선반 슬롯 수.

### 12.3 폐허 구경·발굴
- 멸망했거나 비운 병은 **유적**이 된다. 다른 플레이어(와 나)가 구경하고 발굴할 수 있다 (주인이 비공개 가능).
- **구경**: 그 문명의 연대기를 읽고, 비석에 꽃을 놓는다.
- **발굴**: 거인 1명당 **하루 3번**. 유적마다 유물 수 한정 = 그 병의 최대 인구 ÷ 10 (최소 3, 최대 30) + 명인의 유물 (연대기 명인 수, 최대 5).
  - 한 번 파면: 생활 유물 60% / 묻힌 자원 25% / 옛 설계도 10% / 명인의 유물 5% (남아 있을 때만).
  - 유물이 다 나오면 그 유적은 '구경만' 할 수 있다.
  | 나오는 것 | 쓰임 |
  |---|---|
  | 생활 유물 | 장식, 유물 도감 |
  | 명인의 유물 (실제 그 병에 살았던 유명 주민의 물건) | 버프 + 관련 직업 희귀 출생↑ |
  | 옛 설계도 | 기후 양식 개축 비용↓ |
  | 묻힌 자원 | 주화 항아리, 철 덩어리 |
- **묘지는 발굴할 수 없다** (꽃만). 주인은 구경될 때마다 추모 지폐 5, 발굴될 때마다 10과 방명록을 받는다 (하루 최대 200).

## 13. 다른 부락 — 교역·외교·전쟁

> 다른 부락이 생긴다고 곧바로 싸우지 않는다. 먼저 만나고, 물건을 바꾸고, 혼인하고, 그러다 틀어지면 싸운다.

### 13.1 다른 부락이 생기는 길
| 길 | 내용 | 첫 관계 |
|---|---|---|
| 분가 | 인구가 넘쳐 젊은 가족들이 새 땅에 마을을 세움 | 우호 |
| 분파 독립 | 행복·믿음이 낮은 불만 세력이 떨어져 나감 | 경계·적대 |
| 추가 키트 | 거인이 같은 세상의 다른 자리에 푼 **또 하나의 스타터킷** (5.5). 서로 모르다 탐험으로 만남 | 중립 |
| 이웃 병 | 선반 위 AI 병 — 교역·외교만, 전쟁 불가 | 중립 |
| 다른 플레이어의 병 | 친구의 지구 | 중립 |

- 병 안의 새 부락은 **직접 운영**하거나 **AI에게 맡긴다** (언제든 전환, 상한 없음). 내 두 부락 사이의 관계도 주민 여론을 따른다.

### 13.2 관계
**적대 ◀ 경계 ◀ 중립 ▶ 우호 ▶ 동맹**. 교역·선물·혼인·원조로 오르고, 국경·광맥 다툼, 불공정 교역, 교역로 차단, 거인의 편애로 떨어진다.

### 13.3 교역
- 부락마다 가진 게 다르다: 기후대, 광맥, 물(호수·강), **소금**, 특화 산업.
- 같은 병 안: 도로·나루터. **병과 병 사이: 거인의 다리**를 놓아야만 오간다. 다리를 치우면 교류가 끊긴다. 첫 다리는 *"하늘에 걸린 거인의 길"*로 연대기의 큰 사건이다.
- 상인이 수레·당나귀로 실제로 길을 오간다. 시장에선 물물교환, 나중엔 주화.
- 교역은 물자와 함께 **기술·혼인·역병**도 옮긴다.
- 친구 병과의 교역: 서로 수락하면 다리가 이어진다. 부락 창고의 실물만 오가고, 주민은 교역 대상이 아니다.
- **상단은 약탈할 수 없다** (전쟁 중에도 안전).

### 13.4 외교
사절 · 선물 · 통상 조약 · 혼인 동맹 · 불가침 · 동맹 · 조공 · 선전포고 (병 안 부락·다른 플레이어만). 결정은 플레이어가 하지만 **주민 여론**이 반영된다 (이웃과 혼인한 가족이 많으면 선전포고 시 행복↓).

### 13.5 전쟁
| 단계 | 내용 |
|---|---|
| 1. 병 안 부락 간 | 분파·분가·원주민과의 국경 분쟁, 내전. 모래시계 병의 위·아래 세력전 |
| 2. 플레이어 간 (PvP) | PvP 참여자끼리만. 공격하는 거인이 **전쟁용 거인의 다리**를 놓고 원정. 방어는 AI 자동 |

- 병사 = 주민 + 검 + 방패. 병사도 사람이라 죽으면 가족이 슬퍼한다. 전쟁도 결국 물류 싸움이다.
- 플레이어는 공격 목표·병력·태세만 정하고, 전투는 자동이다.
- **패배 시**: 병사의 목숨과 **그 부락 창고 물자 일부**(상한 비율, 패배 후 휴전 보호막)를 잃는다. 플레이어 계정 재화·아이템·병·건물은 잃지 않는다. 민간인은 전투로 죽지 않는다.

## 14. 거인이 없을 때 — 오프라인과 연대기

> 개발 명세: [SAVE.md](SAVE.md) — 저장 시점·두 칸 저장, 비운 시간 따라잡기(12시간까지 정밀, 그 이상 하루 단위 요약), 위기는 조짐에서 거인을 기다림, '자리를 비운 동안' 편지·귀환 축제, 알림.

- **앱을 꺼도 주민은 알아서 산다**: 먹고, 자고, 일하고, **필요한 건물을 직접 짓고** (거인이 있을 때와 같다), 혼인하고, 아이를 낳고, 늙고, 죽는다. 물도 흐르고 호수도 마른다.
- **단, 거인의 등불이 켜져 있는 동안만** (v4.2): 비운 시간은 **최대 12시간**(등불 업그레이드로 16 → 20 → 24시간)까지만 흐르고, 등불이 꺼지면 병 안 세상은 잠든다. 비운 동안의 제물은 제단에 고스란히 쌓여 돌아오면 [모두 받기] — [SAVE.md 3장](SAVE.md).
- **대신 문명 발전은 더디다**: 시대 점수 30%, 시대 전환은 거인의 계시가 필요하다. 자율 건설은 지금 시대에 열린 건물만 짓는다.
- **안전장치**: 거인이 없을 때 굶주림 등 위기 사망은 **하루 1명까지**, **부부 2쌍 아래로는 일어나지 않는다.** 돌아왔더니 멸망해 있는 일은 없다.
- 제물 받기·이주민·다리·외부 아이템·건물 사 주기·물 뿌리기·돌리기는 거인만 할 수 있다. 제물은 제단에 이틀치까지 쌓여 기다린다.
- 돌아오면 **연대기**로 그동안의 일을 읽는다 (*"거인이 없던 하루 동안"* — 인구 변화, 태어남·죽음, 지은 건물, 믿지 않게 된 사람 수). 연대기는 영구 보관되는 병의 역사책이다.
- 상세: [RESIDENT_AI.md](RESIDENT_AI.md) 6장

| 상품 | 내용 |
|---|---|
| 거인의 상점 | 외부 아이템 — 지폐 + 일부 유료 재화 |
| 이주민 뽑기 | 지폐 (유료 재화 허용 여부는 열린 질문). 확률 공개 |
| 새 병 | **팔지 않음** — 지폐로만. 병 *스킨*만 유료 |
| 스타터킷 업그레이드 | 지폐 (영구 추가) |
| 추가 키트 | **유료 재화** — 같은 세상에 다른 무리를 하나 더 (5.5) |
| 선반 확장 | 병 슬롯 추가 |
| 코스메틱 | 병 스킨, 주민 의상, 장식 |
| 시즌 패스 | 계절 테마 아이템, 연대기 꾸미기 |

- 경제 구조: 제물 받아 팔기 = 지폐 공급 / 상점·이주민·새 병 = 소각. 같은 물건 반복 판매 시 값↓로 인플레를 관리한다.
- 이주민 뽑기는 확률을 공개한다. 유료 결제 뽑기 허용은 열린 질문 (도입 시 확률형 아이템 표시 의무).

## 18. 기술 스택

> **성능 원칙 (v4.2, 2026-11-07)**: 넓은 세상은 **보는 곳만 자세히** 계산한다 — 보고 있는 마을(+이웃)은 주민 단위, 화면 밖 마을은 마을 단위 요약(몇 분마다), 먼 땅의 물·소금은 큰 덩어리로 거칠게, 빈 안개 땅은 큰 물 흐름만. 한 병 주민 수 상한은 측정 후 정함 (안 1,000~2,000).
> **C++(GDExtension)는 무거운 곳만**: 전부 옮기지 않는다. 측정해서 가장 무거운 2~3곳(물·소금 흐름, 많은 주민의 길·일 계산 등)만 C++로 → 그 부분 10~50배. 그림 그리기(GPU)는 C++로 빨라지지 않고, 나머지(UI·규칙·이야기)는 GDScript가 고치기 빠르고 테스트가 쉽다. 안드로이드 arm64·Mac 둘 다 빌드.

- **엔진: Godot 4 (GDScript)** — 무료(MIT, 수익 분배·매출 조건 없음). 셀 셰이딩(툰)·외곽선·정사영 카메라([RENDERING.md](RENDERING.md))가 기본 기능으로 쉽다. 장면 파일이 텍스트라 AI와 함께 개발하기 좋고, 로그인 없이 설치·실행된다. 버전은 **4.7.2**로 고정하고 개발은 사용자 Mac에서만 한다. 무거운 계산은 측정 후 GDExtension(C++). 감수할 점: 결제·광고 플러그인은 출시 전 검증 필요, 국내 경험자 적음. 개발 시작: [GODOT_KICKOFF.md](GODOT_KICKOFF.md)
- **시뮬레이션**: 주민(점수제 행동), 물(높이 지도 위 흐름·증발·스며듦), 소금(물과 함께 이동)은 프로토타입의 규칙을 그대로 옮긴다. 오프라인은 큰 간격으로 몰아서 계산한다.
- **서버** (부락 교역·PvP·유적): 처음엔 BaaS(Firebase / PlayFab 등) → 규모가 커지면 자체 서버.

## 21. 결정 사항

| 주제 | 결정 |
|---|---|
| 세계 | 병 안은 넓은 **평평한 지구**. 바다 없음. 닫힌 세계 (외부 유입 없음) |
| 주민의 세계관 | 테라리움이 세상의 전부. **처음엔 거인을 모른다** — 목격이 쌓여 깨달음 사건이 일어난 뒤에야 하늘 너머에 누군가 있음을 안다 (무엇인지는 끝내 모름, 6.5) |
| 믿음 | 사람마다 다름. 거인 부재 → 아이부터 부정, 귀환 → 축제, 기적 → 크게↑ |
| 빛·낮밤·계절 | 빛은 한쪽(창가·거인의 등불)에서만. **병 시계는 따로** — 창조 후 아침 7시 시작, 기본 하루=현실 5분, 느리게~1초=12시간 (10단계)·밤 건너뛰기·비운 동안 12시간=3일(약 3초) (6.6). 계절: **거인의 방은 현실 달력, 병 안은 병 날짜** (2026-11-08 F-2 정리) |
| 물 | 물방울 돌기 아래 = 호수 / 유리벽의 골 = 강의 근원. 넓게 내리는 비 없음 (거인의 물 뿌리기만) |
| 지형과 물길 | 높낮이 있음. 물은 흐르고 고이고 넘친다. 물이 안 들어오는 호수는 며칠~몇 주에 걸쳐 마르고 물길이 바뀐다 |
| 등불 옮기기 | 등불(해)을 병 둘레 네 자리 중 하나로 — 빛 방향이 바뀌어 강 물줄기 변화, 옮기기 전 미리보기. 호수 자리 고정. 하루 3번 넘으면 두려움 (4.6) |
| 소금 | 근원은 창조 때 넣은 **암염**뿐. 물에 녹아 흐르고 증발하면 남음. 하얀 들판이 드러나면 주민이 **발견**해야 소금밭이 열림 |
| 창조 | 핵은 크기만. 암반 4색(암염 포함). 뚜껑 물방울 돌기 위치를 정함. 세상은 매번 무작위 |
| 스타터킷 | 기본 키트(두 가족 10명·오두막·살림) 무료, 놓을 자리는 거인이 고름. 업그레이드(제재소·풍차·밀밭 등)는 지폐로 **영구 추가**, 모든 새 세상에 적용. 추가 키트 = 서로 모르는 다른 무리, **유료 재화** (5.5) |
| 기후대 | 6종, 천천히 해금 (결제 불가). 한 병 = 한 기후대 |
| 초반 식량 | 하늘 낟알 — 도착 직후 1회 + 매일 새벽, 하루치·비축 불가, 첫 수확 다음 날 그침 |
| 인구 | 출생(과 분가)으로만. 수명 약 25일. 부활 없음. 멸망 허용 (폐허) |
| 아이 | 모두 고유 특징. 1,000종 이상. 등급은 자연 뽑기 |
| 주민 판매 | **없음** (v3.8). 지폐는 **주민이 바친 제물**을 팔아 번다 — 믿음이 곧 수입. 강제로 거두면 믿음↓·두려움↑ (11.1, v4.0) |
| 건설 | **주민이 모두 알아서 짓는다** (터 지정·길·철거·직업 배정 없음, v4.0). 거인은 산 건물만 놓고, 소원을 들어주고, 받는 제물로 간접히 이끈다 (6.7) |
| 이주민 | 지폐로 **무작위 뽑기**, 확률 공개, 300부터 ×1.5·하루 5번 (11.2) |
| 장터 | 값 = 담긴 노동 × 가공 배율, 같은 물건 60개째 반값, 현실 하루·모든 병 합산 (11.1, BALANCE v3) |
| 건강·기후 | 병 날짜 = 창조일 + 흐른 날 → 계절·온도. 질병 하루 2%·3일 앓음·식구 전염, 부상, 추위·더위 노출, 사람마다 두려움 ([HEALTH.md](HEALTH.md)) |

| 인구·출생 | **부락 영역**이 인구를 정한다 (시대별 지름 64 / 96 / 140 / 200칸 → 약 40 / 90 / 225 / 560명, 국경 건물로 조금 더). 가득 차면 **분가** (3.1). 혼인 4일부터 짝마다 하루 0.5. 출산 0.6 × 개인 × 환경(식량·행복·축제). 집 크기 병목 유지 |
| 시대 점수 | 마을 100 / 읍내 200 / 영지 300, 시대 배율 1 / 0.08 / 0.03. 소금 +15·발견 점수 그대로 |
