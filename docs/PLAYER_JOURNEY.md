# 나의 작은 지구 — 플레이어 여정 · 훅 설계 (v1, 2026-11-07)

> 사용자: "기본 게임 제작 이론에 따라서 로드맵이 있는 게 아니네? 플레이어 여정 설계, 허들 설계 등등."
> 이 문서가 **로드맵의 순서를 정하는 기준**이다. 기능은 "여정의 어느 순간을 위해 있는가"로 고른다. 기능 상세는 다른 문서.

---

## 1. 핵심 판타지와 기둥

**판타지**: *"내 손바닥만 한 유리병 속에서, 나를 모르던 작은 사람들이 나를 알아보고, 대를 이어 살아간다."*

| 기둥 | 뜻 | 플레이어가 느끼는 것 |
|---|---|---|
| **돌봄** (Nurture) | 내가 만든 세상, 내가 지켜 준 사람들 | 정·책임감·뿌듯함 |
| **구경** (Watch) | 아기자기한 마을이 스스로 돌아감 — 밀 들고, 밀가루 들고, 빵 들고 길을 따라 | 편안함·소소한 재미 (보는 맛) |
| **기적** (Miracle) | 작은 손짓 하나가 그들에겐 기적 | 힘·경이·인정받음 |
| **이야기** (Story) | 이름 있는 사람들의 탄생·사랑·싸움·죽음이 연대기로 쌓임 | 애착·추억·자랑 |

**장르 위치**: 아늑한 방치형 신(神) 시뮬 + 정착민 경제 구경. 짧게 자주 들어오는 모바일 (하루 3번 × 5~10분).

## 2. 핵심 순환 (Core Loop) — 시간 단위별

| 단위 | 순환 | 보상 |
|---|---|---|
| **30초** (순간) | 마을을 본다 → 무언가 눈에 띈다 (막힘·배고픔·조짐·소원) → 손짓 하나 (내려 주기·물·톡) → 반응이 바로 보인다 | 주민의 반응 (기쁨·놀람), 일이 풀림 |
| **5~10분** (한 번 들어옴) | 돌아옴 → 편지·제단 공물 받기 → 지폐로 살 것 고르기 (설계도·이주민·물건) → 내려 주기 → 마을이 자라는 걸 구경 → 다음에 올 이유를 남기고 나감 | 지폐·새 건물·새 식구·발견 |
| **하루** | 등불이 타는 동안 마을이 살아감 → 돌아올 때마다 무슨 일이 있었는지 (편지) | 이야기 (연대기), 쌓인 공물 |
| **며칠~주** | 시대가 오름 (계시 = 가르침 고르기) → 새 사슬·새 건물 → 더 큰 마을 → 새 병 (새 기후) | 새 시대의 모습, 두 번째 세상 |
| **달** | 세대가 바뀜 (내가 이름 지어 준 아이가 노인이 됨), 혈통·연대기 | 애착의 깊이, 수집 (발견 도감·지구 카드) |

## 3. 플레이어 여정 (단계별)

각 단계마다: **시간 · 플레이어의 목표 · 느껴야 할 감정 · 새로 알게 되는 것 · 다음으로 이끄는 훅 · 이탈 위험**.

### 3.0 첫 1분 — "어? 예쁘다" (첫인상 훅)
- 화면: 회사 로고 → 거인의 방, 창가의 **빈 유리병** → [시작하기]
- 감정: 호기심, 아늑함. 목표: 없음 (구경)
- 훅: 빈 병 = "여기에 뭘 만들지?" → 창조
- 위험: 로딩·글이 길면 이탈 → 글 최소, 소리·빛으로

### 3.1 창조 (1~2분) — "내가 만든 세상"
- 버튼 몇 번 (핵·땅·물·씨앗·짐승·물고기) → 배양 타임랩스 → 자리 고르기 → 스타터킷이 열리고 사람들이 나옴 → **이름 짓기**
- 감정: 소유감 ("내 지구"), 기대
- 훅: 사람들이 나와 두리번거림 → "이 사람들 어떻게 될까?"
- 위험: 단계가 많으면 지루 → 각 단계 5초 안, 건너뛰기

### 3.2 첫 10분 (FTUE) — "나를 모르던 사람들이 나를 알아본다"
- 수첩 쪽지가 30초마다: 톡·통나무·낟알·따라가 보기 → **깨달음 (5분)** → **제단 (7분 반)** → 첫 기도 → 안내 창 (공물·지폐·제단 크기·등불)
- 감정: 경이 → 감동 (알아봐 줌) → 이해 ("아, 이렇게 돈을 버는구나")
- 배우는 것: 손짓, 주민은 스스로 산다, 공물 = 지폐
- 훅: 첫 소원 편지 → 첫 기적 → **"내 손이 기적이 된다"**
- 위험: 기다림 (30초 넘는 빈 시간), 이해 못 하는 도구 → 쪽지는 직관적인 일만, 도구는 사건 때 하나씩

### 3.3 첫 세션 끝 (10~20분) — "마을이 스스로 먹고산다"
- 첫 밀 → 맷돌간 → 밀가루 → 공용 화덕 → **첫 빵 (튜토리얼 끝)**. 아기자기한 나르기가 처음 눈에 들어옴.
- 감정: 뿌듯함, 안심 ("내가 없어도 굴러가겠구나")
- **떠날 때의 훅 (세션 끝 훅 — 가장 중요)**:
  - 무언가 진행 중: "아기가 곧 태어날 것 같아요", "목조 주택이 반쯤 올라갔어요", 조짐 ("숲에서 이상한 냄새가…")
  - 등불: "등불이 12시간 탈 거예요. 그동안 공물이 제단에 쌓여요"
  - 다음 목표가 보임: 시대 막대 70% ("곧 새로운 걸 배울 것 같아요")
- 위험: "다 봤다"고 느끼고 안 돌아옴 → 미완성 상태로 끝나게

### 3.4 첫날 (D0, 2~3번째 들어옴) — "다녀오니 무슨 일이 있었네"
- 돌아오는 훅 (복귀 훅): 알림 ("제단이 가득 찼어요", "아기가 태어났어요"), 유리에 붙은 쪽지, **돌아온 편지** (비운 동안의 이야기 3줄)
- 첫 아기 이름 짓기 · **계시 (가르침 셋 중 하나 고르기 — 첫 큰 선택)** · 마을 시대
- 감정: 반가움, 애착, 선택의 무게
- 위험: 돌아와도 별일 없음 → 비운 동안 반드시 작은 사건 1~2개 (출생·발견·혼례·소원)

### 3.5 첫 주 (D1~D7) — "내 마을의 모양이 생긴다"
- 정착민 경제가 커짐 (사슬·길·수레), 첫 위기 (곰팡이·날벌레) 와 해결, 발견 몇 개, 이주민, 첫 죽음과 장례, 싸움과 화해, 축제
- 목표 (보이게): **두 번째 병** (지폐 목표), 다음 시대, 발견 도감 채우기, 제단 넓히기·등불
- 감정: 숙련 ("어디가 막혔는지 보인다"), 이야기에 빠짐
- 훅: 가변 보상 (어떤 발견·어떤 이주민·어떤 사건) · 주간 축제 · 연대기 그림 카드
- 위험: 같은 일 반복 → 시대마다 새 사슬·새 장면, 위기와 휴식의 리듬 (5장)

### 3.6 첫 달 (D7~D30) — "세상이 둘, 세대가 바뀐다"
- 두 번째 병 (새 기후 — 다른 작물·짐승·위기), 읍내 시대 (도구·옷·맥주), **세대 교체** (내가 이름 지은 아이가 어른·부모가 됨), 혈통
- 목표: 세 번째 병, 모든 기후, 혈통 잇기, 발견 도감 완성
- 감정: 깊은 애착, 컬렉션, 나만의 이야기
- 훅: 지구 카드 공유 (자랑), 창세 신화, 가족 이야기

### 3.7 장기 (D30+) — "선반 위 작은 세계들"
- 여러 병의 선반, 연대기가 책처럼 쌓임, 폐허 위 새 마을 (게임 오버 없음 — 다시 일어서기), 시즌 행사 (계절 = 현실 달력)
- 감정: 잔잔한 습관, 소장 가치
- 위험: 할 게 없음 → 끝없는 목표가 아니라 **새로운 이야기**가 계속 나오게 (세대·혈통·사건)

## 4. 훅 설계 (Hooked: 계기 → 행동 → 가변 보상 → 투자)

| 단계 | 우리 게임에서 |
|---|---|
| **계기** (밖) | 알림: 제단 가득, 아기 탄생, 위기 조짐, 소원 편지 (하루 최대 2~3개, 밤엔 안 보냄) |
| **계기** (안) | "우리 마을 어떻게 됐을까?" — 애착이 생기면 저절로 |
| **행동** (쉽게) | 앱 열기 → 바로 마을 (로딩 짧게), [모두 받기] 한 번 |
| **가변 보상** | 무슨 일이 있었나 (돌아온 편지), 어떤 발견·이주민(특징·혈통)·사건, 아기의 얼굴, 공물 양 |
| **투자** | 이름 지어 주기, 설계도·건물 자리, 계시 고르기, 연대기, 혈통 — 쌓일수록 떠나기 어려움 |

**세션 시작 훅** (들어오면 3초 안에): 돌아온 편지 · 유리 쪽지 · 제단 반짝임 · "누가 태어났어요".
**세션 끝 훅** (나가기 전에): 진행 중인 일 하나 + 다음 목표 막대 + 등불 시간.
**하루 리듬**: 아침 (공물 받기·소원), 점심 (구경·사건), 저녁 (등불·축제) — 하루 3번 들어올 이유.

## 4b. 허들 설계 — 어디서 막히고, 어떻게 넘고, 무엇을 배우나

**원칙** (PROGRESSION 2를 새 시간 기준으로):
1. **세상 안의 이유로 막힌다** — 돈 벽·타이머 벽이 아니라 "밀가루가 없어서", "집이 모자라서".
2. **막힌 게 눈에 보인다** — 건물 위 상태 표시("밀이 없어 멈춤"), 주민의 말, 창고 막대, 경제 지도. 왜 막혔는지 모르는 허들은 나쁜 허들.
3. **넘는 길이 늘 둘 이상** — 기다리기(주민이 스스로) / 거인의 손(앞당김) / 선택(다른 길).
4. **허들 하나에 배움 하나** — 넘으면 새 시스템을 하나 이해한다.
5. **넘으면 보상** — 사건 연출 + 새 장면 + 안내 창.
6. **간격**: 첫 세션 안엔 '거의 안 막힘' (흐름을 배움) → 첫날부터 작은 허들 → 첫 주 중간 허들 → 첫 달 큰 허들. 큰 허들 사이엔 쉬는 구간.
7. 결제로 허들을 지우지 않는다. 게임 오버 없음.

| 여정 (실제 시간) | 허들 (주민이 겪는 것) | 보이는 신호 | 넘는 길 | 배우는 것 |
|---|---|---|---|---|
| 첫 10분 | (허들 없음 — 쪽지대로 흐름) | | | 손짓·주민은 스스로 산다 |
| 10~20분 | **날 밀은 못 먹는다** → 빵 사슬이 필요 | 촌장 "빻아야 해요", 죽만 먹는 얼굴 | 맷돌간·공용 화덕 (주민이 지음) / 통나무·돌 내려 주기 | 생산 사슬, 나르기 |
| 첫날 2~3번째 | **집이 모자라 아기를 못 가짐** | 오두막 밖에서 자는 사람, "우리 집이 좁아" | 주민이 짓기 / 판자·설계도(목조 주택) | 집 = 인구 |
| 첫날 | **첫 아기 → 부모 둘이 일을 쉼** → 일손 부족 | 비는 일터 표시 | 기다리기 / 이주민 / 일 순서 | 식구가 늘면 한동안 바쁨 |
| 1~2일 | **재료가 모자람** (통나무·판자 0) | 짓는 자리 "판자를 기다려요" | 벌목장 둘째·제재소 설계도 / 나무젓가락 | 재료 사슬, 설계도 |
| 1~3일 | **첫 병** (고뿔·배앓이) | 기침 말풍선, 누운 사람 | 약초원·우물 / 약초·반창고 내려 주기 | 돌봄, 도구가 열림 |
| 2~4일 | **첫 위기 조짐** (곰팡이 / 날벌레) | 유리 김, 윙윙 소리, 노인의 경고 | 대응 발견 / 핀셋·푸른 가루 (도구가 열림) | 위기는 예고된다 |
| 3~5일 | **시대 막대가 참** → 계시에서 가르침 고르기 (무엇을 먼저?) | 제단 빛, 노인 "하늘을 자주 올려다봐요" | 셋 중 하나 고르기 (안 고른 건 나중) | 선택의 무게 |
| 4~7일 | **나르기가 막힘** (길이 멀고 좁음, 붐빔) | 줄 선 짐꾼, 빨간 화살표(경제 지도) | 길이 자람 / 창고 가까이 / 수레 (가축 뒤) | 물류 |
| 5~10일 | **땅이 모자람** (영역이 참) | 출생 멈춤, "더 갈 데가 없어" | 분가 (새 마을) / 망루로 안개 걷기 | 세상 넓히기 |
| ~7~10일 | **두 번째 병** (지폐 목표) — 사고 싶은 것과 경쟁 | 선반의 빈 자리, 목표 막대 | 공물 모으기 (믿음·제단 크기·등불) | 저축과 선택 |
| 10~20일 | 새 기후의 낯선 위기 | 그 기후의 조짐 | 그 기후의 발견 | 병마다 다른 세상 |
| 20일~ | 읍내 사슬 (도구·옷) — 도구가 닳음 | 일이 느려짐 "도끼가 무뎌요" | 대장간·광맥 돌 / 녹슨 못 | 깊은 사슬 |
| 30일~ | 큰 마을의 탁한 공기·싸움 증가 | 누런 하늘, 다툼 말풍선 | 숲지기·광장·축제 | 균형·삶의 질 |

- 숫자(며칠)는 BALANCE v5에서 실제 플레이로 맞춘다. 같은 날 큰 허들 둘은 겹치지 않게.
- **허들을 넘었을 때의 장면**을 E1(사건 연출)의 목록에 넣는다: 첫 빵, 첫 새집, 첫 위기 극복, 첫 분가, 두 번째 병.

## 5. 감정 곡선 · 긴장과 휴식

- **긴장** (위기 조짐 → 위기 → 해결) 다음엔 꼭 **휴식** (축제·결혼·아기·풍년). 위기 둘이 연달아 오지 않음 (이미 규칙).
- 시대마다: 새것의 설렘 → 익숙해짐 → 막힘 (도전) → 해결 → 계시 (보상) 의 곡선.
- **게임 오버 없음** — 슬픈 일(죽음·멸종)은 이야기가 되고, 마을은 다시 일어선다 (마지막 불씨·구원의 가족 B9).

## 6. 동기 지도 (자기결정이론 + 플레이어 유형)

| 동기 | 채우는 것 |
|---|---|
| 자율성 | 자리 고르기, 계시 고르기, 무엇을 사 줄지, 무엇을 들어줄지 — **안 해도 되는 선택** |
| 유능감 | 막힌 곳을 찾아 풀기 (경제 지도·상태 표시), 마을이 커지는 숫자와 모습 |
| 관계 | 이름 있는 주민, 가족·혈통, 주민이 나를 알아보고 고마워함 |
