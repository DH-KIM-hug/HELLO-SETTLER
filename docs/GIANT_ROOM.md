# 나의 작은 지구 — 거인의 방 (병 밖 시점) (v1)

> UI 01·05 화면과 기획서 [3.1 두 개의 시점](GAME_DESIGN.md)·[4장 병의 자연](GAME_DESIGN.md)의 상세. 이 게임의 **얼굴** — 앱을 열면 가장 먼저 보이는 곳.

## 1. 장면
- 세로 화면. **창가 선반 위에 유리병 하나**가 가운데. 코르크 뚜껑, 유리 곡면의 반사광, 병 안에는 작은 세상(지금의 마을이 실시간으로 보임).
- 왼쪽 위 **창문** — 현실의 시각·계절을 따른다 (아침 햇살·노을·밤하늘·눈 오는 겨울). 창으로 들어온 빛이 병의 한쪽을 비춘다 (병 안 '볕 드는 쪽'과 일치).
- 창에 **커튼** (끈을 끌어 반쯤·다 닫기), 병 옆에 **등불** (병 안의 낮밤 = 등불, 기획서 4.1 — 병 안이 밤이면 등불이 꺼져 있고 병 안 창문 불빛만 반짝임).
- 선반 위 소품: 화분(창조 흙을 퍼 온 곳 — 이끼·민들레가 자라고 있음 → 바깥 생물의 고향), 작은 물뿌리개, 핀셋, 각설탕 그릇 (상점에서 산 물건이 놓이는 자리).
- 병이 여러 개면 선반에 나란히 — 좌우로 밀어 넘김 (선반 화면 05와 같은 공간).
- 그림체: 같은 셀 채색, 따뜻한 나무·크림·복숭아빛 (아이콘 L_2의 분위기). 방은 **거인 크기**라 결이 크고 단순하게.

## 2. 거인의 손 — 병 밖에서 하는 것

| 손짓 | 효과 | 규칙 |
|---|---|---|
| **톡** (유리 누르기) | 주민이 하늘을 봄 / 세게 = 두려움 | 기획서 6장, HEALTH 4장 |
| **길게 감싸기** (두 손가락 길게) | 체온 — 병 전체 +6°, 1시간 | 하루 3번↑ 두려움 (WORLD_EVENTS 4.2) |
| **돌리기** (병 가장자리를 원 그리듯) | 90°씩 — 볕·그늘이 바뀜 | 기획서 4.6, 하루 3번↑ 두려움 |
| **뚜껑 열기** (코르크를 위로 끌기) | 김·연기 빠짐, 바깥 공기·날벌레 | WORLD_EVENTS 3장, 1분 뒤 저절로 닫힘 |
| **불기** (뚜껑이 열린 동안 아래에서 위로 쓸기 또는 [불기]) | 꽃씨가 하늘 가득 | WORLD_EVENTS 2.7 |
| **커튼** (끈 끌기) | 볕↓ (더위 막음, 농사↓) | |
| **병 옮기기** (병을 끌어 창가 ↔ 그늘 자리) | 기온·빛 전체 | 옮길 때 흔들림 |
| **유리 닦기** (손가락으로 문지르기) | 김 서린 유리가 맑아짐 (보기만) | |
| **물뿌리개** (끌어 병 위로) | 뚜껑 열고 물 뿌리기 | 기획서 6.5 |
| **넣기** (손에 든 물건을 병 위로) | SHOP.md 3장 | |
| **들어가기** (두 손가락 벌리기 / 병 두 번 톡) | 병 안 시점(지구 시점)으로 확대 전환 | |

- 손짓이 많으므로 **처음엔 톡·들어가기만** 열리고, 나머지는 주민의 부탁·튜토리얼로 하나씩 (OPENING 3장).
- 각 손짓은 화면 아래 **'거인의 손' 칸**에서도 버튼으로 (손짓이 어려운 사람용).

## 3. 화면 배치 (390×844 기준)
```
┌──────────────────────────────┐
│ 지구 이름 · 시대   지폐 ⚙   │  ← 위 띠 (안전 영역 안)
│ ┌─────┐                      │
│ │ 창문 │ ╲ 빛줄기             │
│ └─────┘   ╲                  │
│        ╭──●──╮  ← 코르크      │
│        │ 작은 │                │
│        │ 세상 │  ← 병 (화면 폭 70%)
│        ╰─────╯                │
│ ═══════════════ 선반 ═══════ │
│  화분  물뿌리개  핀셋  설탕그릇 │
│ [제단] [상점] [손] [연대기] [선반] │ ← 아래 띠 (UI 01 도구 5개)
└──────────────────────────────┘
```
- 새 소식은 빨간 점 대신 **병 앞에 주민이 든 편지가 유리에 붙어 보임** (UI 원칙) — 누르면 편지.
- 위기 조짐은 병 자체가 말해 준다: 뿌연 유리, 누런 하늘, 유리 밖에 비친 날벌레 그림자.

## 4. 두 시점 사이
- 병 → 안: 병 쪽으로 카메라가 들어가며 유리를 통과 (반사광이 화면을 쓸고 지나감, 0.8초) → 지구 시점.
- 안 → 병: 두 손가락 오므리기 / [병 밖으로].
- 소리 (AUDIO.md 1장): 밖에서는 방의 오르골 음악이 앞, 마을 소리는 유리 너머 먹먹하게. 안으로 들어가면 반대.

## 5. 실시간 표현 (개발)
- 병 안 세상은 지구 시점의 같은 시뮬레이션을 **SubViewport로 작게 렌더**해 유리 셰이더(굴절 약간·반사광·김 서림 마스크) 안에 넣는다. 휴대폰 성능을 위해 병 밖 시점일 땐 병 안 렌더를 낮은 해상도·낮은 주기(초당 15장)로.
- 방은 정적인 그림 레이어 몇 장(벽·창·선반·소품) + 빛 레이어(현실 시각에 따라 색) + 커튼·등불·코르크만 움직임.
- 창밖 하늘은 현실 시각·계절 (기기 시각) — 병 안 시각과 다를 수 있다 (병의 등불은 병 시계).

## 6. 시험판 범위
- 1차: 방 한 장면(창·커튼·선반·등불), 병 하나 실시간, 톡·감싸기·돌리기·뚜껑·불기·들어가기, 편지가 유리에 붙음, 아래 도구 띠.
- 나중: 여러 병 선반 넘기기, 물뿌리개·핀셋·병 옮기기, 계절별 창밖, 병 꾸미기(받침·유리 빛깔).
