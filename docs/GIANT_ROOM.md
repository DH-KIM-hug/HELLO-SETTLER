# 나의 작은 지구 — 거인의 방 (병 밖 시점) (v1.2)

> UI 01·05 화면과 기획서 [3.1 두 개의 시점](GAME_DESIGN.md)·[4장 병의 자연](GAME_DESIGN.md)의 상세. 이 게임의 **얼굴** — 앱을 열면 가장 먼저 보이는 곳.

## 1. 장면
- 세로 화면. **창가 선반 위에 유리병 하나**가 가운데. 코르크 뚜껑, 유리 곡면의 반사광, 병 안에는 작은 세상(지금의 마을이 실시간으로 보임).
- 왼쪽 위 **창문** — 현실의 시각·계절을 따른다 (아침 햇살·노을·밤하늘·눈 오는 겨울). 창으로 들어온 빛이 병의 한쪽을 비춘다 (병 안 '볕 드는 쪽'과 일치).
- 창에 **커튼** (장식만 — 조작은 2026-11-07 없앰), 병 옆에 **등불** (병 안의 낮밤 = 등불, 기획서 4.1 — 병 안이 밤이면 등불이 꺼져 있고 병 안 창문 불빛만 반짝임).
- 선반 위 소품: 화분(창조 흙을 퍼 온 곳 — 이끼·민들레가 자라고 있음 → 바깥 생물의 고향), 작은 물뿌리개, 핀셋, 각설탕 그릇 (상점에서 산 물건이 놓이는 자리).
- 병이 여러 개면 선반에 나란히 — 좌우로 밀어 넘김 (선반 화면 05와 같은 공간).
- 그림체: 같은 셀 채색, 따뜻한 나무·크림·복숭아빛 (아이콘 L_2의 분위기). 방은 **거인 크기**라 결이 크고 단순하게.

## 4. 두 시점 사이 — 끊김 없는 확대·축소 (v1.1, 구글 어스처럼)
병 안과 거인의 방은 **따로 있는 두 화면이 아니라 하나의 연속된 공간**이다. 두 손가락으로 계속 오므리면:

| 단계 | 보이는 것 | 카메라 |
|---|---|---|
| ① 마을 | 주민·집이 크게 (기본). 화면 전체가 땅 | 정사영 48° (RENDERING 2.2) |
| ② 넓은 땅 | 탐험한 땅·안개·다른 마을, 길 | 더 높이, 기울기 그대로 |
| ③ 세상 전체 | 둥근 대지 전체, 가장자리의 **유리벽**과 폭포 띠, 위로 뚜껑의 안쪽. 유리 너머로 **거인의 방**이 흐릿하게 비침 (하늘·지평선은 그리지 않음 — RENDERING 2.2) | 높이↑, 점점 위에서 내려다보는 각으로 |
| ④ 유리병 | 대지가 담긴 **병 전체**가 유리 너머로 보임 — 유리 굴절·반사광이 나타남 | 병 밖으로 빠져나오며 옆에서 보는 각으로 |
| ⑤ 거인의 방 | 선반 위 병, 창·등불·화분 (타이틀과 같은 방) | 방 안 고정 각 |

- 반대로 벌리면 방 → 병 → 세상 → 마을로 쭉 들어간다. **버튼 없이 손가락만으로** 오간다 ([병 밖으로] 버튼은 지름길로 남김).
- 단계 사이는 **끊기지 않는다**: 같은 3D 장면 안에서 카메라가 움직인다. 병 안 세상은 실제 3D 지형·마을을 그대로 쓰고, 멀어질수록 단순한 모양(LOD)으로 바뀐다 — ④⑤에서는 세상 전체를 낮은 해상도의 한 덩어리(높이 지도 + 색)로.
- 유리는 ③→④ 사이에서 나타난다: 카메라가 유리벽을 지나는 순간 반사광이 화면을 쓸고, 유리 굴절이 조금 걸리고, 소리가 바뀐다 (AUDIO 1장 — 밖에서는 먹먹하게).
- 규모: 대지 지름 1,024칸 ↔ 병 안쪽 지름 약 11cm (거인의 방 모델 단위 1 = 1cm, room 세트의 병 안쪽 반지름 5.6) → 한 칸 ≈ 0.1mm. 확대 비율은 로그 스케일로 부드럽게.
- 타이틀 화면 = ⑤ 단계 그 자체. [시작하기]/[이어하기]를 누르면 ⑤ → ① 로 쭉 들어간다 (지금의 빛 쓸기 연출을 대신).
- **[마을로 가기] — 쉭~ 날아 들어가기** (구글 어스의 '날아가기'): 어디에 있든(방·병·세상 전체·다른 마을) [마을로 가기]나 지도·목록에서 마을을 누르면, 카메라가 **잠깐 위로 떠올라(멀어지며) → 목표 쪽으로 미끄러지듯 이동 → 쭉 내려앉아** 그 마을 광장에 멈춘다.
  - 길이 1.2~2.5초 (거리에 따라, 로그 스케일). 처음과 끝은 천천히, 가운데는 빠르게 (ease-in-out), 높이는 거리에 비례한 포물선.
  - 방에서 시작하면 병 유리를 뚫고 들어가는 순간 반사광이 화면을 쓸고, 바람 소리 '쉭~' → 마을 소리로 바뀜. 다른 마을로 갈 때는 구름 대신 안개 위를 스쳐 지나감.
  - 날아가는 동안 화면을 누르면 그 자리에서 멈춘다 (구글 어스와 같음).
  - 타이틀의 [시작하기]/[이어하기]도 이 날아가기로 들어간다 (방 → 첫 마을).
- 휴대폰 성능: ④⑤에서는 병 안 세상을 초당 몇 장만 다시 그리는 텍스처(또는 낮은 LOD 메시)로, ①②에서는 방을 그리지 않는다.

## 5. 실시간 표현 (개발)
- 병 안 세상은 지구 시점의 같은 시뮬레이션을 **SubViewport로 작게 렌더**해 유리 셰이더(굴절 약간·반사광·김 서림 마스크) 안에 넣는다. 휴대폰 성능을 위해 병 밖 시점일 땐 병 안 렌더를 낮은 해상도·낮은 주기(초당 15장)로.
- 방은 정적인 그림 레이어 몇 장(벽·창·선반·소품) + 빛 레이어(현실 시각에 따라 색) + 커튼·등불·코르크만 움직임.
- 창밖 하늘은 현실 시각·계절 (기기 시각) — 병 안 시각과 다를 수 있다 (병의 등불은 병 시계).

- 나중: 여러 병 선반 넘기기, 물뿌리개·핀셋·병 옮기기, 계절별 창밖, 병 꾸미기(받침·유리 빛깔).
