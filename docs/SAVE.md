# 나의 작은 지구 — 저장과 돌아왔을 때 (v1)

> 기획서 [14장 오프라인](GAME_DESIGN.md)·[6.6 시간](GAME_DESIGN.md)의 개발 명세. 서버 없이 기기에만 저장한다 (클라우드 백업은 출시 전 따로).

## 1. 무엇을 저장하나

| 묶음 | 내용 | 파일 |
|---|---|---|
| **거인** (병 밖) | 지폐, 첫 제물 웃돈 받음 여부, 장터 포화(현실 날짜별 물건 수), 이주민 뽑기 횟수(그날), 키트 업그레이드, 해금한 기후, 선반의 병 목록, 마지막 저장 시각(현실) | `user://save/giant.dat` |
| **병마다** | 병 시계·날짜, 지형·물·소금 격자, 주민 전부(유전자·혈통·관계·건강·면역·두려움·숙련·기억), 건물·터, 창고, 제단 제물, 소원 편지, 오솔길, 공기(김·연기·탁함)·뚜껑, 곰팡이 무리, 버섯·민들레, 유행 중인 병, 위기 압력, **난수 흐름 상태 전부** | `user://save/jar_<id>.dat` |
| **연대기** | 병마다 모든 기록 (영구, 지우지 않음) | `user://save/chronicle_<id>.dat` |
| 설정 | 소리·진동·알림·설치 ID | `user://settings.cfg` (이미 있음) |

- 형식: Godot `var_to_bytes` + `FileAccess.open_compressed(ZSTD)`, 맨 앞에 **형식 버전 번호**. 버전이 바뀌면 옮기는 함수(migration)로 옛 저장을 읽는다 — 옛 저장을 버리는 일은 없다.
- 난수 상태까지 저장 → 불러온 뒤에도 같은 결과 (결정론 유지, 테스트로 확인).

## 2. 언제 저장하나 — 완전 자동

> **저장 버튼·저장 칸 고르기·'저장하시겠습니까'는 없다.** 플레이어는 저장을 의식하지 않는다. 언제 앱을 꺼도(강제 종료·배터리 방전 포함) 잃는 것은 **최대 몇 초**, 거인이 한 행동(지폐·구매·소원·뚜껑)은 **0초**.

- **거인이 무언가 할 때마다 즉시** — 제물 받기·사기·뽑기·소원·뚜껑·물건 놓기·이름 짓기 등 플레이어 행동 직후 거인 묶음 + 그 병.
- **병 안의 큰 일마다** — 출생·사망·혼례·완공·발견·위기 시작 직후 그 병.
- **그 밖엔 10초마다** (현실 시간), 병 하나씩 돌아가며 조각으로 써서 끊김 없음 (한 번 쓰기 < 5ms 목표 — 바뀐 부분만 쓰는 방식은 성능 측정 후).
- **앱이 뒤로 갈 때** (`NOTIFICATION_APPLICATION_PAUSED` / 포커스 잃음) — 즉시 전부.
- 저장은 **두 칸 번갈아** (`.a`/`.b`) + 끝에 검사값. 쓰다가 꺼져도 다른 칸이 살아 있다. 둘 다 깨지면 마지막 정상 칸 + 연대기에 *"기억이 흐릿한 날"* 한 줄.

- **기기를 바꿔도 이어지게** (출시 전): Google Play 게임즈 저장 게임에 하루 몇 번 자동 백업 + 앱을 처음 열 때 백업이 더 새것이면 자동으로 가져옴 (묻지 않음, 충돌 시 더 오래 키운 쪽). 계정 연결은 설정에서 한 번.

## 3. 다시 켰을 때 — 등불이 켜져 있던 만큼만 (v1.1, 2026-11-06)

> **비운 시간은 최대 12시간까지만 흐른다.** 병 안의 낮밤은 거인의 **등불**이다 (기획서 4.1). 거인이 자리를 비우면 등불이 기름이 닿는 만큼만 타고 꺼지고, 등불이 꺼지면 **병 안의 세상도 잠든다** (시간이 멈춤). 거인이 돌아와 등불을 다시 켜면 이어서 흐른다.

| | 값 (안) |
|---|---|
| 처음 등불 | **12시간** |
| 등불 업그레이드 (지폐, 영구 — 모든 병) | 큰 기름병 16시간 2,000 → 더 큰 등잔 20시간 6,000 → 거인의 램프 **24시간** 15,000 |
| **비운 동안 흐르는 빠르기** (v1.2, 2026-11-07) | 보고 있을 땐 하루=현실 5분이지만, 비운 동안은 **현실 12시간 = 병 3일** (하루 = 현실 4시간). 설정 '자리를 비운 동안 시간': 느리게 1.5일 · 보통 3일 · 빠르게 6일 (12시간 기준). 등불 시간이 상한 |
| 24시간 넘게 비우면 | 24시간만 흐르고 나머지는 잠든 시간 (주민은 모른다 — 연대기에 *"긴 밤이 있었다"* 한 줄) |

- 따라서 따라잡기는 **언제나 정밀 계산** (최대 병 12일치 = 24시간 × 빠르게 — 몇 초 안, '자리를 비운 동안의 일을 펼쳐 보는 중…' 표시). 하루 단위 요약 계산은 쓰지 않는다 (나중에 필요하면 다시).
- 등불 상한 안에서는 기획서 14장 규칙 그대로 (위기는 조짐에서 기다림, 위기 사망 하루 1명, 2쌍 보호, 시대 점수 30%).
- 계절은 현실 달력을 따르므로 잠든 동안에도 계절은 바뀐다 (돌아오니 눈이 와 있음 — 연출).
- 거인의 방에서 등불이 보인다: 거인이 있을 땐 켜져 있고, 앱을 다시 열면 *"등불이 n시간 타고 꺼져 있었어요"* (꺼진 등불에 불을 붙이는 짧은 연출 → 병 안이 깨어남).
- 기기 시각이 뒤로 가면 비운 시간 0. 앞으로 크게 가도 등불 상한까지만.

### 3.1 비운 동안 받는 것 — 제물이 쌓인다

> **제단 크기 = 공물을 쌓아 둘 수 있는 양** (2026-11-07 사용자 결정). 비운 동안 받는 공물 = **등불 시간**과 **제단 자리** 중 작은 쪽. 가득 차면 주민은 계속 기도하지만 더 쌓이지 않는다 (제단 둘레로 넘쳐 쌓인 모습 → 화면에 "제단이 가득 찼어요").
>
> | 제단 | 모습 | 담는 양 (안 — BALANCE v5에서 정함) | 넓히기 |
> |---|---|---|---|
> | 1 돌무더기 제단 | 둥근 돌 + 나무 그릇 | 반나절치 | 처음 (깨달음 뒤 주민이 지음) |
> | 2 판석 제단 | 판석·양옆 돌기둥 | 하루치 | 지폐 (안) |
> | 3 꽃 제단 | 화환·초 | 이틀치 | 지폐 (안) |
> | 4 작은 사당 | 다듬은 돌·작은 지붕 | 사흘치 | 지폐 (안), 읍내 시대부터 |
> - 넓히면 주민들이 연출과 함께 제단을 실제로 다시 짓는다 (EVENTS_STAGING 2b). 제물은 제단 위에 실제로 쌓여 보인다.
> - 등불 업그레이드(시간)와 제단 넓히기(자리)는 서로 다른 이유로 사고 싶게.
- 비운 동안(등불이 켜져 있던 시간)의 저녁 기도 제물은 제단에 쌓이되 **제단 크기가 상한** (2026-11-08 사용자: "방치형 게임 시간 상한을 제단 상한·제물 상한 개념으로"). 등불 = 병이 흐르는 시간, 제단 = 쌓아 둘 수 있는 양 — 둘은 따로 커진다 (design/gdd/awakening-altar.md).
- 돌아오면 촌장 편지의 '기다리는 것'에 *"제단에 빵 12개·통나무 25개… (장터 값 약 n 지폐)"* + **[모두 받기]** 버튼 → 바로 지폐.
- 등불이 꺼진 뒤(잠든 시간)엔 제물이 생기지 않는다 → **등불 업그레이드 = 비운 동안 병이 흐르는 시간↑, 제단 넓히기 = 쌓이는 상한↑** (방치형 보상의 두 성장 축).
- 받지 않고 두면 평소처럼 이틀이 지나면 창고로 돌아간다.

## 4. 돌아왔을 때 보여 주는 것
1. 로딩 (따라잡기) → **병 밖 시점**(거인의 방)으로 열림 — 창가의 병, 그 사이 바뀐 계절·빛.
2. **"자리를 비운 동안"** 편지 한 장 (촌장이 씀, 손글씨):
   - 큰 일 3~5줄 (태어남·죽음·혼례·새 건물·발견), 인구 변화 *"13명 → 17명"*, 새 얼굴(아기 초상) / 떠난 얼굴.
   - 기다리는 것: 제물 *"제단에 빵 12개가 있어요"*, 소원 편지 n통, 위기 조짐.
   - [연대기에서 자세히] / [병 안으로].
3. **귀환 축제**: 하루(현실 24시간) 넘게 비웠으면 주민들이 광장에 모여 하늘을 보고 환호 (*"거인님이 돌아오셨다!"*), 제단 가득, 믿음↑. 하루 안이면 축제 없이 반가운 말풍선 몇 개.
4. 오래 비웠을 때 (7일↑): 믿음이 조금 식어 있다 (의심하는 사람↑ — 기획서 7장). 노인이 아이에게 거인 이야기를 들려주는 장면 → 다시 믿음을 쌓는 재미.

## 5. 알림 (설정에서 켠 경우만, 하루 최대 2번)
- 제단이 가득 찼을 때 (그 제단의 상한 — 첫 제단은 반나절치): *"제단에 제물이 가득 쌓였어요."*
- 큰 일: 첫 출생·첫 사망·위기 조짐 *"유리에 김이 서리기 시작했어요."*
- 금지: 출석 압박·보상 미끼 (*"지금 안 오면…"* 없음). 밤 10시~아침 8시엔 보내지 않음.
- 기기 안에서 예약하는 로컬 알림 (서버 없음) — 앱이 뒤로 갈 때 다음 예상 시각을 계산해 예약.

## 6. 개발 메모
- `SaveManager` 자동 로드: `save_all()`, `save_giant()`, `load_all()`, `catch_up(elapsed)`.
- 각 시뮬 객체에 `to_dict()/from_dict()` (Village·Resident·Building·Health·JarAir·Mold·Flora·Market…). 난수는 `RandomNumberGenerator.state`.
- 테스트: 저장→불러오기 후 N시간 진행 결과 == 저장 없이 N시간 진행 결과 (결정론). 옛 버전 저장 파일을 테스트 자료로 두고 매번 불러오기 확인. 깨진 칸 복구.
- **도구 지킴이 (2026-11-11 Q12, 메인 판단 — 사용자 위임)**: 도구 스크립트(`godot -s …` — 캡처·측정·시험)로 띄운 판은 저장·연대기 그림 카드·설정(`settings.cfg`·`hud.cfg`·`install_id.cfg`)·성능 결과를 `user://_tool/<스크립트 이름>/` 아래에 쓴다 (`godot/save/user_paths.gd` `UserPaths.of` — 기본 길을 정하는 자리에서만 바꿈, 상태 없음). 진짜 저장 폴더는 건드리지 않는다. 폴더를 직접 넣은 도구·시험(`GameSave.dir`·`StageDirector.pic_dir`·`GameSettings.path`·`NAZAKJI_SAVE_DIR`)은 그 값 그대로. `-s` 없이 띄운 놀이는 예전 길 그대로. 예외: 엔진 기록 `user://logs/`. `_tool/`은 스스로 비워지지 않는다 (ROADMAP Q13 ②). 시험 `tool_guard`.
- (v1.1부터 요약 계산 없음 — 등불 시간까지 늘 정밀 계산. 화면 밖 마을의 요약 계산은 성능 작업 ROADMAP B11에서 따로)
