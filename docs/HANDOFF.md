## 개발 시작 — 유니티는 사용자 컴퓨터의 Claude Code가 맡음 (방법 B)
- 클라우드 세션(여기)은 유니티를 실행할 수 없다 (화면 없는 리눅스, 유니티 계정 로그인 필요, 설치 용량).
