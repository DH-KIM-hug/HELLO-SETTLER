# 나의 작은 지구 — 농사와 요리 (v1)

> 기획서 8장 경제(식량은 다양할수록 좋다)의 상세. 작물도 짐승처럼 **병 안의 야생종을 발견하고 길러서** 늘어난다 ([WILDLIFE.md](WILDLIFE.md) 7장 가축화와 같은 흐름). 모두 병의 생물(작은 종 — 주민 크기).

## 1. 작물 — 야생에서 밭으로
처음 키트에는 **밀**(주곡)만 있다. 나머지는 병 안 들·숲·물가에 **야생으로** 자라고, 주민이 발견해 밭으로 옮긴다.

| 단계 | 일어나는 일 |
|---|---|
| ① 발견 | 채집하던 주민(대개 아이·노인)이 야생 열매·뿌리를 맛봄 → *"이 보라 열매, 달아요!"* (발견 도감) |
| ② 옮겨 심기 | 마을 곁 텃밭에 몇 포기 — 수확 적고 들쭉날쭉 |
| ③ 밭 | 몇 번 거둔 뒤 제대로 된 밭·과수원이 열림 (자율 건설) — 수확 안정 |
- 발견까지는 그 자리에 가야 한다 → 안개를 걷고 넓은 세상을 다닐 이유. 거인이 **씨앗을 사 줄 수도** (상점 '먹을 것·재료' — 작은 종 씨앗, 지름길).

### 1.1 작물 목록 (안)
| 작물 | 야생에서 자라는 곳 | 밭이 되면 | 기후 | 열리는 때 |
|---|---|---|---|---|
| 밀 | (키트) | 밀가루 → 빵 | 온대 | 처음 |
| 보리 | 마른 들판 | 맥주·죽 | 온대·냉대 | 개척기 |
| 호밀 | 추운 들판 | 호밀빵 | 냉대 | 개척기 |
| **야생 포도 → 포도** | 볕 드는 비탈의 덩굴 | 포도밭 → 생포도·건포도·**포도주** | 온대·아열대 | 마을 |
| **채소** — 야생 당근 · 순무 · 양배추류 · 콩 · 양파 · 마늘 | 물가·숲 가장자리 | **텃밭** (집마다 작게 + 큰 채소밭) | 기후마다 다름 | 개척기~마을 |
| 허브 — 백리향·박하·월계수 | 볕 드는 바위틈 | 약초밭 (약초꾼과 함께) · 요리 향 | 온대·아열대 | 마을 |
| 사과·배 | 숲속 야생 나무 | 과수원 (자라는 데 오래 — 5일) | 온대·냉대 | 마을 |
| 딸기 | 숲 바닥 | 텃밭 | 온대 | 개척기 |
| 꿀 (벌) | 꽃 많은 들 (민들레!) | 벌통 — 꿀·밀랍 | 온대 | 마을 |
| 쌀 · 향신료 · 올리브 | 열대·아열대 병의 물가·비탈 | 논 · 향신료밭 · 올리브밭 | 열대·아열대 | 그 병 |
- 기후마다 야생종이 다르다 → **다른 기후의 병을 키울 이유** (특산품 ×1.5, BALANCE v3).
- 같은 밭만 계속 쓰면 땅이 지친다 (농사 ×0.85씩) → 콩을 돌려 심으면 회복 (주민이 '돌려짓기'를 발견). 영양제 앰플로도 회복.
- 바깥 생물과의 다툼: 민들레 꽃씨 = 잡초, 토끼 = 갉아 먹음, 멧돼지 = 파헤침, 곰팡이 = 창고의 곡식.

## 2. 요리 — 맛있는 것이 행복이다

### 2.1 원칙
- 날것·죽보다 **요리가 행복을 준다.** 같은 음식만 먹으면 질린다 (다양성 — 기획서 8장).
- 주민마다 **좋아하는 음식**이 하나 있다 (주민 상세에 *"좋아하는 것: 사과파이"*) — 먹으면 행복 크게↑, 축제에서 그 음식이 나오면 춤춤.
- 요리는 집 화덕에서 (간단한 것) → 마을이 크면 **주막·여관의 요리사** (손 많이 가는 것).
- '할머니 레시피를 기억함' 특징 (기획서 7장)이 여기서 빛난다 — 그 집만의 요리.

### 2.2 요리 목록 (레시피 도감, 안)
| 요리 | 재료 | 어디서 | 효과 |
|---|---|---|---|
| 죽 | 곡물 | 집 화덕 (처음부터) | 배만 부름 |
| 빵 | 밀가루 | 빵집 | 기본 행복 |
| 채소 수프 | 채소 2종 | 집 화덕 | 행복 +, 고뿔에 좋음 (앓는 기간 ×0.9) |
| 민들레 나물 무침 | 민들레 잎 + 소금 | 집 화덕 | 굶을 때의 반찬 → 맛있게 |
| 버섯 스튜 | 버섯 + 채소 | 집 화덕 | 행복 +, 겨울에 몸을 데움 (추위 노출 ×0.9, 반나절) |
| 생선 구이 | 생선 + 소금 | 모닥불·집 | 행복 + |
| 토끼 스튜 | 토끼 고기 + 당근 + 허브 | 집 화덕 | 행복 ++ |
| 사슴 고기 파이 | 고기 + 밀가루 + 양파 | 빵집·주막 | 축제 음식 |
| 사과파이 | 사과 + 밀가루 + 꿀 | 빵집 | 행복 ++ (아이들이 가장 좋아함) |
| 꿀빵 | 밀가루 + 꿀 | 빵집 | 행복 + |
| 치즈 | 우유 + 소금 (+ 누룩곰팡이!) | 낙농장 | 오래 감, 제물 값 높음 |
| 포도주 | 포도 (+ 누룩곰팡이) | 양조장 | 축제·혼례 필수, 제물 값 높음 |
| 맥주 | 보리 (+ 누룩) | 양조장 | 행복 +, 일 끝난 저녁 |
| 축제 잔칫상 | 요리 4종 이상 | 광장 | 축제의 크기가 커짐 (믿음·행복↑↑) |
- 누룩곰팡이(WORLD_EVENTS 2.1)를 길들인 마을만 치즈·포도주·맥주가 잘 된다 — 작은 세계의 연결.
- 레시피는 **발견**한다: 재료가 창고에 함께 있으면 요리 잘하는 주민이 어느 날 새 요리를 만든다 (*"마르타가 처음으로 사과파이를 구웠다. 온 마을이 냄새를 맡고 모였다."*). 도감에 처음 만든 사람 이름.

### 2.3 제물과 요리
- 요리는 가공 단계가 많아 **장터 값이 높다** (가공 배율 1.3~1.5, BALANCE v3): 예) 채소 수프 4 · 사과파이 9 · 치즈 10 · 포도주 12 (안).
- 거인이 받은 요리는 *"거인님은 사과파이를 좋아하신다"* → 마을이 그 요리를 더 만든다 (과수원·꿀벌을 늘림) — 거인이 마을의 식탁을 간접으로 바꾼다.

## 3. 화면
- 밭마다 작물 모양이 다름 (포도 덩굴 줄, 채소밭의 알록달록 줄, 과수원 나무).
- 집 굴뚝 연기 + 창가에 파이를 식히는 모습, 저녁 식탁에 둘러앉은 가족 (가까이 볼 때).
- 요리 도감: 연대기 안 탭 — 그림 + 재료 + 처음 만든 사람.

## 4. 개발 메모 (나중)
- 작물 = Flora처럼 야생 분포 + 발견 사건 + 밭 종류. 요리 = 레시피 표(재료 → 결과, 장소), 주민 '좋아하는 음식' 하나, 다양성 행복 (최근 하루 먹은 종류 수).
- 시험판에는 넣지 않음 (현재: 밀·버섯·민들레 잎·생선 정도). 우선순위: 채소 텃밭 → 요리 몇 가지(수프·스튜·구이) → 포도·과수원 → 낙농·양조.
