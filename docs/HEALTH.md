# 나의 작은 지구 — 건강·기후·두려움 명세 v1 (안, 개발용)

> 기획서 [7.3 생로병사](GAME_DESIGN.md)·[7.4 욕구](GAME_DESIGN.md)·[6.5 두려움](GAME_DESIGN.md)·[10 위기](GAME_DESIGN.md)와 [혈통](BLOODLINES.md) 9·10·1·11번 짝의 상세.
> **원칙: 단순하게, 그리고 갑작스러운 몰살은 없다.** 사람은 아프고 다치고 추위에 떨지만, 대부분 낫는다. 죽음은 여러 나쁜 일이 겹칠 때 온다.
> 수치는 모두 **안**이며 `godot/data/balance.gd`에 모은다. 시간은 모두 **병 시계** 기준.

## 1. 병 날짜와 온도

### 1.1 병 날짜
- 병 날짜 = **세상을 만든 현실 날짜 + 병 시계로 흐른 날 수**. 계절은 이 날짜로 정한다 (북반구 달력, 기기 지역과 무관).
  - ×8로 돌리면 날짜도 빨리 간다 (병 안의 하루는 병 시계의 24시간).
- 계절: 3~5월 봄, 6~8월 여름, 9~11월 가을, 12~2월 겨울.

### 1.2 그 자리의 온도 (체감, °C 느낌 — 화면에는 숫자 대신 말·그림)
`온도 = 기후대 바탕 + 계절 + 낮밤 + 자리`

| 기후대 | 바탕 (연평균) | 계절 폭 (±) | 낮밤 폭 (±) |
|---|---|---|---|
| 온대 | 12 | 11 | 4 |
| 냉대 | 3 | 15 | 4 |
| 아열대 | 18 | 8 | 5 |
| 열대 | 26 | 2 | 3 |
| 툰드라 | −6 | 14 | 3 |
| 사막 | 24 | 10 | 9 |

- 계절: 코사인, 가장 추운 날 1월 15일, 가장 더운 날 7월 15일.
- 낮밤: 코사인, 가장 따뜻한 때 병 시계 14시, 가장 추운 때 4시.
- 자리: 기후 지도의 따뜻함(창가·그늘, 기획서 4.4) 0~1 → **+0~+3**.
- 예) 온대 1월 새벽 ≈ −3, 온대 7월 한낮 ≈ 27, 냉대 1월 새벽 ≈ −16.

### 1.3 추위·더위 정도 (노출)
- **추위 정도** = (5 − 온도) ÷ 10, 0~2로 자름. **더위 정도** = (온도 − 30) ÷ 8, 0~2로 자름.
- 막아 주는 것 (곱함, 겹치면 가장 좋은 것 하나만):

| 있는 곳 | 추위 | 더위 |
|---|---|---|
| 집 안 + 땔감 있음 | ×0.2 | ×0.5 |
| 집 안 + 땔감 없음 | ×0.6 | ×0.5 |
| 모닥불·화덕 반경 3칸 | ×0.5 | ×1 |
| 나무 그늘 (반경 1.5칸) | ×1 | ×0.6 |
| 밖 | ×1 | ×1 |

- **땔감**: 추위 정도가 0보다 큰 동안 집 1채당 병 시계 10분마다 통나무 1개 ([BUILDINGS 7장](BUILDINGS.md)). 석조 주택 ×0.5. 창고에서 나르는 일은 기존 운반 일에 섞는다 (부족하면 '땔감 없음').
- 옷(방직소)은 아직 없다 → 생기면 추위 ×0.7 (나중).

### 1.4 노출이 건강에 주는 영향
- 막고 남은 정도 1.0으로 **하루 내내** 있으면 건강 **−0.25** (정도·시간에 비례). 4일 연달아 밖에서 떨면 위험하다.
- 아기·노인 ×1.5.
- 혈통: **추위 견딤** 추위 ×0, **추위 탐** 추위 ×2 / **더위 견딤** 더위 ×0, **더위 탐** 더위 ×2. (짝을 함께 가지면 상쇄 — BLOODLINES 1장)
- 추위·더위 정도가 0.5를 넘으면 행동 점수: 집·불가로 가는 점수↑ (일을 일찍 접음). 더위 0.5↑이면 한낮(12~15시)에 쉬는 점수↑.
- 노출로 건강이 0이 되면 사망 원인 **'추위'·'더위'** (연대기: *"그 겨울, ○○는 끝내 따뜻해지지 못했다."*).

## 2. 질병

| 항목 | 값 (안) |
|---|---|
| 기본 발병 | 한 사람 **하루 2%** (병 시계 1시간마다 나눠 굴림) |
| 배율 (곱함) | 굶주림 ×2 · 건강 0.5 미만 ×1.5 · 추위·더위 노출 중 ×(1 + 정도) · 우물 반경 밖 집 ×1.3 · 집 정원이 꽉 참 ×1.2 · 아기·노인 ×1.5 · 열대 ×1.3 |
| 혈통 | 강인한 ×0.7 · 병약 ×1.3 |
| 앓는 기간 | **3일** (병약은 회복 느림 = 기존 회복 배율로 ×1.5) |
| 앓는 동안 | 일하지 않고 집(없으면 모닥불 곁)에서 쉼. 건강 하루 −0.15 |
| 치료소 반경 | 건강 하루 −0.05, 기간 ×0.6 |
| 약초 | 창고에 약초가 있으면 앓는 사람이 1개 먹음 → 남은 기간 절반 (한 번만) |
| 전염 | 앓는 사람과 **같은 집 식구**: 하루 +15% / 같은 일터·반경 2칸에서 함께 일함: 하루 +3% (모두 혈통 배율 적용). 치료소 반경이면 ×0.5 |
| 사망 | 앓다 건강 0 → 사망 원인 **'병'** |

- 결과 기대: 보통 마을(우물 있음, 잘 먹음)에서 한 사람이 1년 중 약 1주일 앓음, 질병 사망은 드묾. 굶주림·추위가 겹치면 늘어난다.
- 마을에서 앓는 사람이 **20%를 넘으면** 말풍선·편지: *"기침하는 사람이 늘었어요."* (위기 예고 — 기획서 10장)
- **역병**(기후 위기, 열대)은 나중에 이 위에 얹는다: 기본 발병 ×5, 전염 ×2, 며칠 동안.

## 3. 부상

| 항목 | 값 (안) |
|---|---|
| 일어나는 때 | 힘쓰는 일(벌목·채석·건설·짐 나르기) **병 시계 1시간마다 0.3%** |
| 혈통 | 강인한 ×0.7 · 병약 ×1.3 |
| 다치면 | 즉시 건강 −0.1, **2일** 동안 걸음·일 속도 ×0.5, 힘쓰는 일 대신 가벼운 일 |
| 치료소 반경 | 기간 ×0.6 |
| 사망 | 부상만으로는 죽지 않는다 (사고 사망은 재해·위기 몫) |

## 4. 두려움 — 사람마다

- 주민마다 **두려움 0~1**. 부락의 두려움(0~100) = 주민 두려움 평균 × 100 → 기존 신앙 상태(경건·경외·무관심·공포, RESIDENT_AI 2.3)는 이 값을 그대로 쓴다.

| 일 | 누가 | 두려움 오름 |
|---|---|---|
| 유리 톡 (그날 4번째부터) | 모두 | +0.05씩 |
| 크게 친 톡 (지진) | 모두 | +0.2 |
| 병 돌리기 (그날 4번째부터) | 모두 | +0.1씩 |
| 굶주릴 때 식량을 거둠 (11.1) | 모두 | +0.1 |
| 가족이 죽음 | 가족 (부모·자식·배우자·형제) | +0.2 |
| 죽음을 봄 | 반경 6칸 | +0.05 |
| 물 뿌리기가 집을 잠기게 함 | 반경 안 | +0.15 |
| 앓는 사람이 20% 넘음 | 모두 | 하루 +0.05 |

- 혈통: **담대** 오름 ×0.5 · **겁 많음** 오름 ×1.5 (내려감은 같음).
- 내려감: **12시간마다 절반** (반감기). 기도·축제에 함께하면 그동안 두 배 빨리.
- 효과:
  - 0.6 이상: 일 점수 ×0.7, 가끔 집으로 숨음 (말풍선 *"하늘이 또 울렸어… 무서워"*).
  - 행복 −0.1 × 두려움.
  - 출산 환경 배율은 기존대로 부락 상태(공포)에서만.

## 5. 어업 (물가 사람)
- 어부 오두막이 시뮬레이션에 있으면 **물가 사람** 혈통의 어업 +20%를 적용한다. 아직 없으면 값만 둔다 (지금처럼).

## 6. 화면에 보이는 것 (작게)
| 상태 | 모습 |
|---|---|
| 앓음 | 창백한 얼굴, 집 안에 누움 / 밖이면 천천히 걸음 |
| 다침 | 다리를 절며 걸음, 붕대 |
| 추움 (정도 0.3↑) | 몸을 움츠림, 겨울엔 입김 |
| 더움 (정도 0.3↑) | 이마의 땀방울, 그늘을 찾음 |
| 두려움 0.6↑ | 움츠린 어깨, 하늘을 자주 올려다봄 |
- 주민 상세 화면(UI.md 03)에는 말로: '앓고 있음 (2일째)', '다리를 다침', '추위에 떨고 있음', '무서워함'.

## 7. 개발 규칙
- 온도·질병·부상·두려움은 **genetics와 별도의 RNG 흐름**을 쓴다 (기존 결과 재현성 유지).
- ×1과 ×8, 밤 건너뛰기·오프라인에서 결과가 같아야 한다 (병 시계 고정 걸음).
- 기존 인구 테스트는 **병 날짜를 4월 15일(봄)**로 고정해 돌린다. 겨울 시험은 따로 (온대 1월 30일: 인구가 줄어도 마을이 망하지 않을 것).
