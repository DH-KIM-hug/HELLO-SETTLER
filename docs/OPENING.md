# 나의 작은 지구 — 창조 오프닝 상세 (v3.3)

> 기획서 5장(테라리움 창조)의 화면 단위 명세. 게임을 처음 켠 순간부터 **첫 30분**까지.
> 목표: **"내가 이 지구를 만들었다"는 감정을 5~8분 안에 심고, 첫 주민에게 정이 들게 한다.**

---

## 0. 설계 원칙

| 원칙 | 내용 |
|---|---|
| **숫자 대신 감각** | 핵 크기·광물 비율을 수치로 보여주지 않는다. 빛·색·소리·진동으로 느끼게 한다 |
| **틀려도 망하지 않는다** | 극단적인 선택은 부드럽게 막거나 되돌린다. 첫 병에서 '망한 지구'는 만들 수 없다 |
| **손가락이 곧 도구** | 단계마다 조작 하나 (넣기 / 붓기 / 빚기 / 끌기 / 돌리기 / 뿌리기). 버튼은 [다음] 하나 |
| **창조가 곧 신화** | 플레이어가 한 행동이 주민들의 **창세 신화**로 연대기 첫 장에 기록된다 |
| **첫 병은 짧게, 다음 병은 더 짧게** | 첫 창조 5~8분. 두 번째 병부터는 [빠른 창조]로 2분 |

### 화자 (목소리)
- 등장인물 없이 **화면 하단의 손글씨 자막**만 쓴다 (음성 없음, 은은한 효과음과 함께 한 글자씩 써짐).
- 자막은 플레이어에게 말을 걸지만, 나중에 연대기를 열면 **같은 문장이 주민들의 신화로 바뀌어** 있다.
  - 오프닝: *"핵을 넣어주세요."*
  - 연대기 1장: *"태초에 거인이 어둠 속에 붉은 별 하나를 심었다."*

## 2. 단계별 명세

### 단계 0. 빈 병
- **화면**: 어두운 방, 나무 선반 위에 빈 메이슨 자 하나. 창문으로 달빛.
- **자막**: *"아무것도 없는 병이 하나 있습니다."* → (2초) → *"톡, 두드려 보세요."*
- **조작**: 유리를 탭 → '톡' 소리 + 햅틱 + 유리 안에 작은 메아리처럼 빛이 퍼짐.
- **목적**: 가장 기본 조작(톡)을 첫 행동으로. 이 조작은 본 게임에서 '주민이 하늘을 올려다보는' 행동이 된다.

### 단계 1. 핵 넣기
- **자막**: *"핵을 넣어주세요."*
- **화면**: 손바닥 위에 붉게 맥동하는 구슬. 병 바닥 중앙에 희미한 자리 표시.
- **조작**:
  1. 두 손가락 핀치로 구슬 크기를 조절 (작게 ↔ 크게, 3단계로 스냅).
  2. 병 안 자리로 끌어 놓기 → '쿵' 저음 + 병 전체가 붉게 한 번 빛남.
- **크기에 따른 피드백** (숫자 없음):
  | 크기 | 구슬 | 소리 | 자막 | 게임 영향 |
  |---|---|---|---|---|
  | 작게 | 은은한 주황, 느린 맥동 | 낮고 부드러운 웅웅 | *"조용한 별이네요."* | 광물 적음, 지진·화산 거의 없음 |
  | 보통 | 붉은빛, 보통 맥동 | 심장 박동 | *"따뜻한 별이네요."* | 기본 |
  | 크게 | 하얗게 타는 붉은빛, 빠른 맥동, 손이 떨림(햅틱) | 거친 우르릉 | *"뜨거운 별이네요. 땅이 자주 흔들릴지도 몰라요."* | 광물 많음, 온천, **화산·지진 위험↑** |
- **첫 병 제한**: 없음 (크게 골라도 첫 병의 재해 확률은 완화 보정).

### 단계 2. 암반 쌓기
- **자막**: *"단단한 바위로 핵을 감싸주세요."*
- **화면**: 병 옆에 돌이 담긴 작은 컵 4개 — **붉은 돌(철)**, **검은 돌(석탄)**, **반짝이는 돌(금)**, **하얀 돌(암염)**.
- **조작**: 컵을 길게 눌러 병 위로 끌고 가 기울이면 돌이 쏟아진다. 붓는 양 = 그 광물의 양. 붓는 위치 = 광맥이 생길 방향.
- **피드백**: 병 옆면에 지층 단면이 보인다 (붉은색·검은색·금빛 띠). 돌 부딪히는 '자르르' 소리.
- **규칙**:
  - 세 컵 합계가 병 바닥 높이의 일정 선(점선)까지 차면 [다음] 활성화.
  - 한 가지만 붓는 것도 허용 → 그 광물만 풍부한 지구 (교역 필요성↑).
  - 금은 컵이 작아 많이 부을 수 없다 (희소성).
  - **하얀 돌(암염)** = 소금의 근원. 안 넣으면 그 병엔 소금이 거의 없다. 넣은 자리 위로 물이 고이거나 흐르면 녹아서, 그 물이 끝나는 호수가 짜진다. 자막: *"하얀 돌은 물에 녹아요. 언젠가 누군가 그 맛을 알게 되겠지요."*
- **자막 (완료 시)**: *"이 바위 깊은 곳에, 언젠가 누군가 곡괭이를 대겠지요."*

### 단계 3. 흙 덮기 (핵심 단계)
- **자막**: *"흙을 덮고, 손끝으로 땅을 빚어주세요."*
- **조작**:
  1. 흙 자루를 기울여 붓기 → 병 안이 고르게 덮임.
  2. **한 손가락 문지르기 = 흙을 쌓아 올림 (산·언덕)**, **두 손가락 문지르기 = 파냄 (골짜기·호수 자리)**.
  3. 병을 돌려가며 사방을 빚을 수 있다.
- **안내 영역**: 병 한쪽에 **은은하게 빛나는 원** — "첫 마을 자리". 이 원 안은 평평하게 유지해야 한다 (너무 높이 쌓으면 흙이 스르르 흘러내려 평지로 돌아감).
- **피드백**: 손끝 아래 흙 알갱이 파티클, 사각사각 소리. 높은 곳은 흙이 짙은 갈색 → 바위색으로 변함 (산 = 채석장·광산 후보).
- **연결**: 2단계 암반 위에 산을 쌓으면 광맥이 산 쪽으로 드러난다 → *"반짝이는 게 보여요."* (금광 위에 산을 쌓았을 때).
- **추천값**: [알아서 빚기] 버튼 → 무작위 자연 지형 생성 (초보자용).
- **큰 호수 파기**: 두 손가락으로 깊게 파면 큰 분지가 생긴다 → 4단계에서 물을 많이 부으면 바이칼 같은 큰 호수. 단, 6단계에서 그 위에 물방울 돌기를 두지 않고 강도 닿지 않으면 시간이 지나며 증발해 사라진다는 안내가 나온다 (*"이 호수는 물이 들어올 곳이 없어요. 언젠가 마를지도 몰라요."*).

### 단계 4. 물 붓기
- **자막**: *"물을 주세요. 너무 많지도, 적지도 않게."*
- **조작**: 물병을 기울이는 각도 = 붓는 속도. 손을 떼면 멈춤.
- **피드백**: 3단계에서 파낸 골짜기부터 물이 차오름 → **호수** (바다는 없다). 강은 이 단계가 아니라 6단계 이후 유리벽에서 흘러내린 물로 생긴다.
- **화면 가장자리 표시**: 물방울 아이콘이 채워지는 게이지 (숫자 없음). 적정 구간은 초록, 넘치면 파랑이 진해짐.
- **보호 장치**:
  - 육지가 너무 줄면 (첫 마을 원이 잠기려 하면) 물이 원 앞에서 멈추고 *"마을 자리는 남겨둘게요."*
  - 물을 전혀 안 부으면 [다음] 비활성 + *"생명에는 물이 필요해요."*
- **게임 영향**: 물 비율 → 어업·나루터·배 운송 가능 여부. 물가가 없으면 마을이 살 수 없으므로 **물가 최소 1곳은 강제 생성**.

### 단계 5. 태양 맞추기
- **자막**: *"이 지구를 비출 태양을 놓아주세요."*
- **화면**: 병 위 하늘에 반원 궤도. 궤도 위 6개 자리 중 **온대 자리만 밝고**, 나머지 5개는 안개에 덮여 있다.
- **조작**: 태양을 손가락으로 끌어 자리에 놓기. 안개 자리로 끌면 태양이 살짝 튕겨 돌아옴.
- **자막 (첫 병)**: *"다른 자리는 아직 안개 속이에요. 언젠가 이 문명이 자라면 걷힐 거예요."*
  → 기후대 점진 해금(기획서 5.3)을 첫 화면에서 예고.
- **피드백**: 태양을 놓는 순간 병 안 흙과 물에 따뜻한 빛이 퍼짐.
- **두 번째 병부터**: 해금된 자리를 고를 수 있고, 자리마다 미리보기 (눈 덮인 땅 / 야자수 실루엣 등).

### 단계 6. 뚜껑 닫기 — 타임랩스 (대표 장면)
- **자막**: *"이제 뚜껑을 닫아주세요."*
- **조작**: 뚜껑 안쪽에는 병 모양의 기본 **물방울 돌기**가 이미 찍혀 있다 — 메이슨 자는 **8~12개** (기획서 3.3). 손가락으로 돌기를 옮기거나 더 찍는다 (그 아래가 호수 자리가 됨). 그다음 뚜껑을 병 위로 끌어 올려 **두 손가락으로 돌려 잠그기** (딸깍 3번 + 햅틱).
- **타임랩스 (15초, 조작 불가, 건너뛰기 불가 — 첫 병만)**:
  | 초 | 화면 | 소리 |
  |---|---|---|
  | 0~3 | 유리 안쪽에 김이 서림. 물방울 돌기에서 첫 물방울이 떨어짐 | 고요 → 첫 물방울 '똑' |
  | 3~7 | 돌기 아래 호수가 차오르고, 유리벽을 타고 흘러내린 물이 강이 되어 흐르기 시작. 1단계 핵이 '크게'였다면 멀리 작은 화산이 연기를 뿜음 | 빗소리, 낮은 현악 |
  | 7~11 | 카메라가 병 주위를 천천히 돈다. 밤낮이 빠르게 바뀌며 햇빛이 휙휙 지나감. 지형이 조금씩 깎이고 해안선이 다듬어짐 | 현악이 커짐 |
  | 11~15 | 구름이 걷히며 맑은 아침. 아직 아무것도 자라지 않은 갈색 땅과 푸른 물 | 음악이 한 음으로 가라앉음 |
- **자막 (배양 끝)**: *"잠시 배양이 끝났어요. 물이 자리를 잡았어요."* (v4.2 — '수천 년'이 아니라 **테라리움을 잠시 배양**하는 것. 거인의 시간으로 며칠, 병 안에선 긴 세월)
- **공유**: 타임랩스는 자동으로 세로 영상으로 저장 → 9단계 후 [공유하기].

### 단계 7. 생명의 씨앗 → 배양 (v4.2)
- **자막**: *"생명을 뿌려주세요."*
- **화면**: 씨앗 주머니 3개 — **이끼** (초록 가루), **풀** (작은 씨앗), **나무** (도토리). 거인의 화분 흙에 섞여 온 버섯 포자·민들레 씨는 따로 넣지 않아도 들어 있다 (WORLD_EVENTS 1.1).
- **조작**: 주머니를 집어 병 위에서 흔들면 손가락이 지나간 곳에 뿌려진다 (뚜껑을 잠깐 열고).
- **배양 (10초)**: 뚜껑을 닫고 **잠시 배양** — 김이 서렸다 걷히며 이끼가 퍼지고 → 풀이 돋고 → 나무가 자라 숲이 됨.
- **규칙**: 나무를 뿌린 곳 = 숲. 나무를 하나도 안 뿌리면 작은 숲 하나를 자동 생성.
- **자막 (완료 시)**: *"배양이 끝나서 식물들이 자랐어요."*

### 단계 7b. 작은 생명이 깨어남 — 상자 없음 (v4.3, 2026-11-08 사용자: "동물상자는 없어야 되지 않나")
- ~~야생동물 키트(상자)·물고기 병~~ 없앰. 사슴·늑대·들짐승이 없는 소인 세계(GD 3.0)이고, 손도 보이지 않으므로(아트 바이블) **생명은 상자로 오지 않고 병 안에서 저절로 깨어난다.**
- **자막**: *"꽃이 피자 작은 생명들이 깨어나요."*

### 3.0 첫날의 시간 — '창세의 날'
- 문제: ×1에서 병의 하루는 현실 하루다. 창조가 끝나면 아침 7시 → 첫 저녁 기도(19시)까지 현실 12시간, 첫 집도 한참 걸린다 → 첫 세션에 아무 일도 없다.

### 3.1b 거인의 수첩 — 첫 10분에 할 일 (v3.3, 2026-11-07 사용자 지적: "첫 10분간 할 게 없어 보여요")
3.1 대본은 주민 쪽 이야기다. 그 사이 **플레이어가 30초~1분마다 직접 할 일**을 '거인의 수첩' 쪽지로 하나씩 준다.
- 쪽지는 화면 구석 작은 종이 (반짝임만, 막지 않음). 하나 하면 다음 쪽지. 무시해도 이야기는 흐른다 (깨달음은 늦어질 뿐).

- **쪽지마다 이유가 눈에 보여야 한다** (도와 짓기·물 주기·먹이기·만나기·소원·이름·제물). 이유가 안 보이는 일(예: 민들레 불기)은 안내하지 않는다 — 불기는 평소 도구로만 (먼지 뭉치·넘치는 솜털 흩기).
- 뚜껑이 닫히고 배양이 시작되면 자막: *"유리병에 이슬이 맺히고, 흘러내리며 강이 생겨요."* (병의 물 순환을 처음 알려 주는 말, 2026-11-07 사용자)
- 뚜껑은 플레이어가 조작하지 않는다 — 손을 쓰면 저절로 열리고 닫힌다 (WORLD_EVENTS 3). 뚜껑·환기 쪽지는 없다.
- 쪽지마다 작은 지폐(30~80)와 경이·믿음. 다 하면 연대기 *"거인이 첫날을 지켜 주었다."* (깨닫기 전이면 *"그날은 이상하게 일이 잘 풀렸다."*)

| 때 (실제) | 쪽지 (할 일) | 바로 보이는 결과 | 쓰는 것 |
|---|---|---|---|
| 0:20 | 유리 톡톡 | 주민들이 하늘을 올려다보며 웅성 (목격 1) | 유리 톡 |
| 0:50 | 손으로 통나무 몇 개 내려 주기 (터 옆) | 짐꾼이 바로 주워 감 → 첫 오두막이 눈에 띄게 빨리 오름 | 손 → 내려놓기 (무료 '주운 통나무' 3개) |

- 첫날은 병 시계가 빨리 흐른다 (지금 ×12) — 쪽지 사이 기다림이 30초를 넘지 않게 조절.
- 수첩은 두 번째 병부터 나오지 않는다 (설정에서 다시 켤 수 있음).

> **하늘 낟알(만나)은 저절로 내리지 않는다** (2026-11-07 사용자). 밀밭 → 첫 빵까지의 단계에서는 **거인이 손으로 내려 주는 것**이 주 식량이다: 배고픈 얼굴·말풍선 → 쪽지 "배고파 보여요. 낟알을 곁에 내려 줘요" → 한 줌 내려 주기 (이 단계엔 무료). 첫 빵이 나오면 공짜 한 줌은 끝 (상점 먹을 것은 그대로). 안 줘도 바로 굶어 죽지 않게: 처음 가져온 건량 하루치 + 열매·버섯 조금 + 모닥불 죽.

### 3.1c 튜토리얼의 끝 = 첫 빵 (2026-11-07 사용자: "공용 화덕까지가 튜토리얼 내에서 해야 되는 일")
첫날(제단·첫 기도)에 이어 **둘째 날까지** 수첩이 이어진다. 날 밀은 못 먹으므로 빵 사슬이 첫 목표:
| 차례 | 쪽지 / 사건 | 플레이어 | 보이는 것 |
|---|---|---|---|
| 1 | 첫 밀 거두기가 다가옴 → "밀은 그냥 못 먹어요. 빻아야 해요." | (구경) | 밭이 황금빛, 낫질 |
| 2 | 촌장이 **맷돌간** 자리를 잡음 → "통나무·돌을 내려 주면 빨리 지어요" | 통나무·돌 내려 주기 | 8단계로 지어짐 |
| 3 | 첫 **밀가루** — 맷돌 돌리는 사람, 밀가루 포대가 쌓임 | 일꾼 눌러 보기 | 손에 든 밀단 → 포대 |
| 4 | 촌장이 **공용 화덕** 자리를 잡음 (모닥불 곁) | 돌 내려 주기 | 흙 화덕이 올라감 |
| 5 | **첫 빵** — 사건 연출: 화덕 앞에 줄 선 사람들, 첫 빵을 나눠 먹음, 아이 얼굴 '기쁨' → 카드 *"마을에 처음으로 빵 냄새가 퍼졌다."* | (구경) | 빵 바구니를 안고 집으로 |
| 6 | 안내 창: **"이제 마을이 스스로 먹고살아요."** 밀 → 밀가루 → 빵, 창고 화면에서 볼 수 있어요. 앞으로는 주민들이 알아서 해요. → 수첩 끝 | [확인] | 수첩 마무리 연대기 한 줄 |
- 그 전까지는 모닥불 죽으로 버틴다 (쪽지: "빵이 생길 때까지 죽으로 버텨요").
- 빵 사슬은 E0-2/A22 (경제 재조정 + 맷돌간·공용 화덕)이 먼저 들어간 뒤 수첩에 붙인다.

### 3.2 빠진 옛 단계
- 옛 T7(첫 밤)·T8(연대기)는 자동 사건으로 첫날 안에 남는다. 옛 T6(물 주기)은 9:00으로.
- 옛 '첫 30분'의 나머지 20분은 자유 구경 — 창세의 날이라 집·밭·첫 수확이 눈앞에서 자란다.

## 6. 구현 메모 (Godot)

| 요소 | 방법 (안) |
|---|---|
| 흙 빚기 | 병 바닥 원형 영역의 하이트맵 (예: 128×128) + 브러시 스컬팅. 높이에 따라 흙 → 바위 머티리얼 블렌딩 |
| 물 | 단일 수면 높이 + 하이트맵 비교로 물 영역 결정. 강은 산 → 저지대 경로를 자동 계산해 스플라인으로 |
| 돌·흙 붓기 | 파티클 + 지층 단면은 셰이더로 (실제 물리 시뮬레이션은 하지 않음) |
| 유리 | 김 서림·하이라이트 셰이더 (셀 채색 기준 RENDERING.md 2.8 — 실제 굴절은 하지 않음). 김 서림은 타임랩스에서 습도에 따라 |
| 타임랩스 | 미리 만든 연출이 아니라 **플레이어의 지형으로** 재생: 하늘·조명 애니메이션 + 해안선 침식은 하이트맵을 살짝 스무딩 |
| 식생 | 씨앗 뿌린 위치를 밀도 맵으로 저장 → 타임랩스 동안 인스턴싱으로 단계적 생성 |
| 창조 시드 | 핵 크기·광물 붓기 기록·하이트맵·수면 높이·기후·밀도 맵을 압축 저장 → 지구 카드·재현용 |
| 영상 저장 | 타임랩스 구간을 기기 화면 녹화 API로 세로 영상 저장 |
