# 캡처 메모

## 1단계 — 도트 렌더링 시험 장면 (2026-11-06, Godot 4.7.2 · Mobile 렌더러 · Mac M4 Pro)

`stage1_sheet.png` = 병 방향 0° / 90° / 180° / 270° / 도트 효과 끔(비교). `*_1x.png` = 실제 내부 해상도 360×640, `*_3x.png` = 정수배 확대.
다시 찍기: `godot --path godot -s res://tools/shot.gd`

| 확인 항목 (GODOT_KICKOFF 4장) | 결과 |
|---|---|
| 둥근 땅(지름 64칸, 완만한 언덕·호수 분지) + 오두막 + 나무 + 호수 + 약 4등신 주민 | ✅ 도형으로. 비탈 명암 2단계 |
| 낮은 해상도 360×640 → 정수배 nearest 확대 | ✅ 프로젝트 설정 stretch = viewport, scale = integer (창 720×1280 = ×2) |
| 정사영 카메라, 내려다보는 각 30°, 방위 45° | ✅ `view/jar_camera.gd` |
| 90° 회전 (병 돌리기) 0.4초 후 정위치 | ✅ 버튼·Q/E 키. 캡처 4장 |
| 팔레트 48색 + 4×4 디더링 | ✅ `render/pixel_post.gdshader` — 화면 셰이더에서 가장 가까운 색. 캡처 1장의 색 수 47 |
| 1픽셀 외곽선 (물체 색의 어두운 버전) | ✅ 깊이 차이만 사용 (Mobile 렌더러에는 화면 노멀이 없음) → 나무·집·주민 가장자리. 같은 깊이의 면 경계(지붕 접힌 곳 등)엔 선이 없음 |
| 팬 떨림 방지 (픽셀 격자 맞춤) | ✅ 코드로 (멈춘 상태에서 카메라 위치를 화면 1픽셀 단위로 반올림). 눈으로 확인 필요 |
| 성능 | Mac 약 110fps. **안드로이드 30fps는 아직** (Android SDK·내보내기 템플릿 필요) |
| 글꼴 | 갈무리11 — woff2는 Godot에서 열리지 않아 TTF로 변환해 사용 (`godot/fonts/*.ttf`, OFL 그대로) |
